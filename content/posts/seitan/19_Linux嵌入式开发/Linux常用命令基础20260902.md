# Linux 常用命令基础

命令行是 Linux 开发的基本功。本文按用途整理最常用的一批命令：文件与目录操作、内容查看与检索、权限管理、进程与系统状态、压缩打包，并标注容易混淆的点。

## 文件与目录操作

| 命令 | 用途 | 示例 |
| --- | --- | --- |
| `pwd` | 打印当前工作目录（print working directory） | `pwd` |
| `ls` | 列出目录内容 | `ls -la`（含隐藏文件+长格式） |
| `cd` | 切换目录 | `cd ~`（家目录）、`cd -`（上一个目录） |
| `mkdir` | 创建目录 | `mkdir -p a/b/c`（多级） |
| `cp` | 复制 | `cp file1 /home/user/`、`cp -r dir1 dir2`（目录要 -r） |
| `mv` | 移动/重命名 | `mv old new` |
| `rm` | 删除 | `rm -rf dir`（递归+无确认，慎用） |
| `find` | 按条件查找文件 | `find . -name "*.c"` |

易混点：

- `cp` 复制后**原文件还在**；`mv` 是移动，原位置不再保留——"复制到 /home/user 用 cp，用 mv 就错了"；
- `rm` 没有回收站，`rm -rf` 配合变量为空的路径是经典事故源；
- `cp/mv` 目标是目录时最后带 `/` 更安全（目录不存在会报错而不是误当文件名）。

## 管道与重定向

每个进程默认打开三个文件：**stdin（0）**、**stdout（1）**、**stderr（2）**。重定向和管道就是重新接线这三个描述符：

| 写法 | 含义 |
| --- | --- |
| `cmd > file` | stdout 覆盖写入 file |
| `cmd >> file` | stdout 追加 |
| `cmd < file` | stdin 从 file 读 |
| `cmd 2> err.log` | 只把 stderr 写文件 |
| `cmd > out.log 2>&1` | **stderr 并入 stdout**（顺序重要：先重定向 stdout，再让 2 指向 1 的去处） |
| `cmd &> all.log` | 上式的简写（bash） |
| `cmd > /dev/null 2>&1` | 全部丢弃（定时任务静默） |
| `cmd1 \| cmd2` | cmd1 的 stdout 接 cmd2 的 stdin |
| `cmd \| tee file` | 边上屏边存文件（看日志同时留档） |
| `cmd1 \| xargs cmd2` | 把 stdin 的行变成 cmd2 的**参数**（管道传数据流，xargs 传参数，别混） |

常用组合：

```bash
grep -rn "TODO" src/ | wc -l            # 数 TODO 出现次数
ps aux | grep nginx | grep -v grep      # 找进程但排除 grep 自己
find . -name "*.log" | xargs rm         # 删掉找到的所有 log（路径有空格要用 -print0 | xargs -0）
make 2>&1 | tee build.log               # 编译输出同时留档（含报错）
command > /dev/null 2>&1 || echo fail   # 静默判断命令成败
```

注意 `2>&1` 与 `> file 2>&1` 的区别：`cmd 2>&1 > file` 只把 stdout 进文件、stderr 还是在屏幕——重定向按从左到右生效。

## 内容查看与检索

| 命令 | 用途 | 示例 |
| --- | --- | --- |
| `cat` | 输出整个文件 | `cat a.txt` |
| `less` / `more` | 分页查看 | `less +F app.log`（跟踪） |
| `head` / `tail` | 看头/尾 N 行 | `tail -f app.log`（实时追加）、`head -n 20` |
| `grep` | 文本检索 | `grep -rn "TODO" src/`（递归+行号） |
| `wc` | 统计行/词/字节 | `wc -l a.txt` |

`grep` 最常用组合：`-r` 递归目录、`-n` 显示行号、`-i` 忽略大小写、`-v` 反选、`-E` 扩展正则。

## 权限管理

```bash
ls -l        # -rwxr-xr-- 1 user group ...
chmod 755 f  # rwxr-xr-x
chmod u+x f  # 给属主加执行位
chown user:group f
```

九位权限分三组（属主/属组/其他）× 三种（r=4, w=2, x=1），`755` = rwxr-xr-x。目录的 `x` 表示"可进入"，去掉 x 即使有 r 也进不去。

## 进程与系统状态

| 命令 | 用途 |
| --- | --- |
| `ps aux` / `ps -ef` | 快照列出进程 |
| `top` / `htop` | 实时进程监控 |
| `kill -9 PID` | 强杀（SIGKILL，不可被捕获）；默认 `kill` 发 SIGTERM（可优雅退出） |
| `df -h` | 文件系统剩余空间 |
| `du -sh dir` | 目录占用大小 |
| `free -h` | 内存使用 |
| `uname -a` | 内核与架构信息 |

`kill -9` 是最后手段：进程来不及保存/清理，嵌入式设备上可能留下半写文件，优先 `kill`（SIGTERM）。

## 压缩与打包

```bash
tar -czf out.tar.gz dir/   # 打包+gzip 压缩
tar -xzf out.tar.gz        # 解压
tar -xf out.tar.gz -C dest # 解到指定目录
```

助记：`c`reate / e`x`tract / `z` gzip / `f` 文件名 / `v` 显示过程。

## 查找命令本身

- `which cmd`：可执行文件在 PATH 中的位置；
- `whereis cmd`：二进制+源码+手册页；
- `man cmd` / `cmd --help`：手册与速查。

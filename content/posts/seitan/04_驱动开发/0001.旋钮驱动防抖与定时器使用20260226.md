# 旋钮驱动防抖与定时器使用

## 标签
#嵌入式 #面试题 #驱动开发 #防抖 #定时器

## 问题描述
旋钮驱动怎么防抖？定时器怎么用的？

## 参考答案
### 1. 旋钮驱动防抖方法

**硬件防抖：**
- **RC滤波电路**：在按键/旋钮信号线上加入RC低通滤波电路
- **施密特触发器**：使用施密特触发器整形信号，消除毛刺
- **电容滤波**：在信号线对地并联电容（常用0.1uF）

**软件防抖：**
- **延时检测法**：
  ```c
  void button_isr() {
      delay_ms(20);  // 延时20ms
      if (button_read() == pressed) {
          handle_event();
      }
  }
  ```
  - 缺点：延时阻塞，影响系统响应

- **定时器消抖法**（推荐）：
  ```c
  volatile uint32_t last_tick = 0;
  
  void button_isr() {
      uint32_t current_tick = get_tick();
      if (current_tick - last_tick > DEBOUNCE_TIME) {
          last_tick = current_tick;
          // 记录状态变化
      }
  }
  ```

- **状态机消抖法**：
  ```c
  enum {IDLE, DEBOUNCE, PRESSED, RELEASE_DEBOUNCE};
  void debounce_fsm() {
      switch(state) {
          case IDLE:
              if (button_pressed()) state = DEBOUNCE;
              break;
          case DEBOUNCE:
              if (timer_expired()) {
                  if (button_pressed()) {
                      state = PRESSED;
                      trigger_event();
                  } else {
                      state = IDLE;
                  }
              }
              break;
          // ...其他状态
      }
  }
  ```

### 2. 定时器使用方法

**定时器配置流程：**

1. **时钟使能**：
   ```c
   // STM32示例
   RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
   ```

2. **定时器初始化**：
   ```c
   TIM_TimeBaseInitTypeDef TIM_InitStruct;
   TIM_InitStruct.TIM_Period = 1000 - 1;  // 自动重装载值
   TIM_InitStruct.TIM_Prescaler = 7200 - 1;  // 预分频
   TIM_InitStruct.TIM_ClockDivision = TIM_CKD_DIV1;
   TIM_InitStruct.TIM_CounterMode = TIM_CounterMode_Up;
   TIM_TimeBaseInit(TIM2, &TIM_InitStruct);
   ```

3. **中断配置**：
   ```c
   TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);
   NVIC_InitTypeDef NVIC_InitStruct;
   NVIC_InitStruct.NVIC_IRQChannel = TIM2_IRQn;
   NVIC_InitStruct.NVIC_IRQChannelPreemptionPriority = 0;
   NVIC_InitStruct.NVIC_IRQChannelSubPriority = 1;
   NVIC_InitStruct.NVIC_IRQChannelCmd = ENABLE;
   NVIC_Init(&NVIC_InitStruct);
   ```

4. **启动定时器**：
   ```c
   TIM_Cmd(TIM2, ENABLE);
   ```

5. **中断服务函数**：
   ```c
   void TIM2_IRQHandler(void) {
       if (TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET) {
           TIM_ClearITPendingBit(TIM2, TIM_IT_Update);
           // 定时器中断处理
           tick_count++;
       }
   }
   ```

**定时器应用场景：**
- **精确延时**：使用定时器实现微秒级延时
- **PWM输出**：控制电机、LED亮度等
- **输入捕获**：测量脉冲宽度、频率
- **周期性任务**：定时执行数据采集、状态检测
- **看门狗**：防止程序死机

**旋钮驱动中的定时器应用：**
```c
// 旋钮状态检测定时器
#define ENCODER_DEBOUNCE_TIME  10  // 10ms

void encoder_debounce_timer_callback() {
    static uint8_t stable_count = 0;
    static uint8_t last_state = 0;
    
    uint8_t current_state = read_encoder_pin();
    if (current_state == last_state) {
        stable_count++;
        if (stable_count >= ENCODER_DEBOUNCE_TIME) {
            handle_encoder_event(current_state);
            stable_count = 0;
        }
    } else {
        stable_count = 0;
        last_state = current_state;
    }
}
```

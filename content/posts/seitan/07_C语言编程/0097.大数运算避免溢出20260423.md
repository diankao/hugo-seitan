# 大数运算避免溢出

## 题目

两个大数进行加减乘除怎么避免溢出？

## 考察点

整数溢出原理、大数运算策略、高精度计算、嵌入式场景下的数值安全。

## 回答要点

### 1. 溢出原理

C/C++ 中有符号整数溢出是**未定义行为**，无符号整数溢出是**回绕**喵~

```cpp
int32_t a = 2147483647;
int32_t b = 1;
int32_t c = a + b;

uint8_t x = 255;
uint8_t y = x + 1;
```

### 2. 加法避免溢出

#### 方案1：提前检测

```cpp
bool safe_add_int32(int32_t a, int32_t b, int32_t *result) {
    if (b > 0 && a > INT32_MAX - b) return false;
    if (b < 0 && a < INT32_MIN - b) return false;
    *result = a + b;
    return true;
}
```

#### 方案2：使用更大类型

```cpp
int64_t safe_add(int32_t a, int32_t b) {
    return (int64_t)a + (int64_t)b;
}
```

#### 方案3：大数加法（字符串模拟）

```cpp
#include <string>
#include <algorithm>

std::string bigAdd(const std::string &a, const std::string &b) {
    std::string result;
    int carry = 0;
    int i = a.size() - 1;
    int j = b.size() - 1;

    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        result.push_back(sum % 10 + '0');
        carry = sum / 10;
    }

    std::reverse(result.begin(), result.end());
    return result;
}
```

### 3. 减法避免溢出

```cpp
bool safe_sub_int32(int32_t a, int32_t b, int32_t *result) {
    if (b > 0 && a < INT32_MIN + b) return false;
    if (b < 0 && a > INT32_MAX + b) return false;
    *result = a - b;
    return true;
}
```

### 4. 乘法避免溢出

#### 方案1：提前检测

```cpp
bool safe_mul_int32(int32_t a, int32_t b, int32_t *result) {
    if (a > 0) {
        if (b > 0 && a > INT32_MAX / b) return false;
        if (b < 0 && b < INT32_MIN / a) return false;
    } else if (a < 0) {
        if (b > 0 && a < INT32_MIN / b) return false;
        if (b < 0 && a < INT32_MAX / b) return false;
    }
    *result = a * b;
    return true;
}
```

#### 方案2：使用更大类型

```cpp
int64_t safe_mul(int32_t a, int32_t b) {
    return (int64_t)a * (int64_t)b;
}
```

#### 方案3：大数乘法

```cpp
std::string bigMul(const std::string &a, const std::string &b) {
    int n = a.size(), m = b.size();
    std::vector<int> res(n + m, 0);

    for (int i = n - 1; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            int mul = (a[i] - '0') * (b[j] - '0');
            int p1 = i + j, p2 = i + j + 1;
            int sum = mul + res[p2];
            res[p2] = sum % 10;
            res[p1] += sum / 10;
        }
    }

    std::string result;
    for (int num : res) {
        if (!(result.empty() && num == 0)) {
            result.push_back(num + '0');
        }
    }

    return result.empty() ? "0" : result;
}
```

### 5. 除法避免溢出

**特殊情况**：`INT32_MIN / -1` 会溢出喵~

```cpp
bool safe_div_int32(int32_t a, int32_t b, int32_t *result) {
    if (b == 0) return false;
    if (a == INT32_MIN && b == -1) return false;
    *result = a / b;
    return true;
}
```

### 6. 嵌入式场景实用方案

| 场景 | 推荐方案 |
|------|---------|
| 传感器数据累加 | 使用 `int64_t` 或 Kahan 求和 |
| ADC 值计算 | 放大后用整数运算 |
| 协议字段 | 明确位宽，用 `uint16_t`/`uint32_t` |
| 金融/精确计算 | 定点数或字符串大数 |
| 通用安全检查 | `safe_xxx` 函数封装 |

### 7. 总结

| 运算 | 溢出条件 | 避免方案 |
|------|---------|---------|
| 加法 a+b | a > MAX - b | 升级类型 / 提前检测 / 大数 |
| 减法 a-b | a < MIN + b | 升级类型 / 提前检测 |
| 乘法 a*b | a > MAX / b | 升级类型 / 提前检测 / 大数 |
| 除法 a/b | b==0 或 MIN/-1 | 特殊值检查 |

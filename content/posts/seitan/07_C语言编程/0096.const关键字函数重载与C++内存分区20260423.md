# const关键字、函数重载与C++内存分区

## 题目

1. const关键字有哪些作用？
2. 函数重载是怎么做的，编译器是怎么实现的？
3. C++内存分区都有哪些，全局变量和常量存放在哪？

## 考察点

const的多层次用法、函数重载原理（名称修饰）、C++程序内存布局、变量存储位置。

## 回答要点

### 1. const关键字作用

#### 1.1 修饰变量

```cpp
const int MAX_SIZE = 100;
// MAX_SIZE = 200;
```

#### 1.2 修饰指针

```cpp
int value = 42;
int another = 100;

const int *p1 = &value;
// *p1 = 50;
p1 = &another;

int * const p2 = &value;
*p2 = 50;
// p2 = &another;

const int * const p3 = &value;
```

**记忆口诀：** `const` 在 `*` 左边修饰数据，在 `*` 右边修饰指针喵~

| 声明 | 指针可变 | 数据可变 |
|------|---------|---------|
| `const int *p` | ✅ | ❌ |
| `int * const p` | ❌ | ✅ |
| `const int * const p` | ❌ | ❌ |

#### 1.3 修饰函数参数

```cpp
void printArray(const int *arr, int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
}
```

#### 1.4 修饰成员函数

```cpp
class MyClass {
    int value;
public:
    int getValue() const {
        return value;
    }

    void setValue(int v) {
        value = v;
    }
};
```

`const` 成员函数承诺不修改对象的成员变量，编译器会检查喵~

#### 1.5 修饰返回值

```cpp
const std::string& getName() const {
    return name;
}
```

### 2. 函数重载

#### 2.1 什么是函数重载

同一作用域内，函数名相同但参数列表不同的多个函数喵~

```cpp
int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}
```

**重载规则：**
- 参数个数不同
- 参数类型不同
- 参数顺序不同
- **不能仅靠返回值不同来重载**

#### 2.2 编译器如何实现重载（名称修饰）

编译器通过**名称修饰（Name Mangling）** 将同名的重载函数转换为不同的内部符号名喵~

```cpp
int add(int, int);
int add(int, int, int);
double add(double, double);

// GCC 编译后的符号名（示意）：
// _Z3addii      → add(int, int)
// _Z3addiii     → add(int, int, int)
// _Z3adddd      → add(double, double)
```

**GCC/Clang 的修饰规则：**
- `_Z` 前缀
- 函数名长度 + 函数名
- 参数类型缩写：`i` = int, `d` = double, `f` = float, `Pv` = void* 等

```bash
# 查看修饰后的符号
nm a.out | grep add
# 或使用 c++filt 反修饰
c++filt _Z3addii
# 输出: add(int, int)
```

**为什么不能仅靠返回值重载？**

因为调用时编译器无法仅从调用上下文确定返回值类型喵~

```cpp
add(1, 2);
```

编译器无法根据上面这行代码判断应该调用 `int add(int,int)` 还是 `double add(int,int)` 喵~

### 3. C++内存分区

C++ 程序的内存分为以下几个区域喵~

```mermaid
graph TB
    subgraph "内存布局（地址从低到高）"
        A["代码段（.text）<br/>机器指令"]
        B["只读数据段（.rodata）<br/>const常量、字符串字面量"]
        C["数据段（.data）<br/>已初始化全局/静态变量"]
        D["BSS段（.bss）<br/>未初始化全局/静态变量"]
        E["堆区（Heap）<br/>↑ 向上增长<br/>new/malloc分配"]
        F["... 空闲 ..."]
        G["栈区（Stack）<br/>↓ 向下增长<br/>局部变量、函数参数"]
    end
    A --> B --> C --> D --> E --> F --> G
```

#### 3.1 各区域详解

| 区域 | 存储内容 | 生命周期 | 管理者 |
|------|---------|---------|--------|
| 代码段（.text） | 机器指令 | 程序运行期间 | 操作系统加载 |
| 只读数据段（.rodata） | const常量、字符串字面量 | 程序运行期间 | 编译时确定 |
| 数据段（.data） | 已初始化的全局/静态变量 | 程序运行期间 | 编译时分配 |
| BSS段（.bss） | 未初始化的全局/静态变量 | 程序运行期间 | 启动时清零 |
| 堆区 | 动态分配（new/malloc） | 手动管理 | 程序员 |
| 栈区 | 局部变量、函数参数、返回地址 | 函数调用期间 | 编译器自动 |

#### 3.2 变量存储位置

```cpp
const int MAX = 100;
int global_init = 42;
int global_uninit;
static int static_init = 10;
static int static_uninit;
const char *str = "hello";

void func() {
    int local_var = 5;
    static int static_local = 20;
    int *heap_var = new int(100);
}
```

| 变量 | 存储位置 |
|------|---------|
| `MAX` | .rodata |
| `global_init` | .data |
| `global_uninit` | .bss |
| `static_init` | .data |
| `static_uninit` | .bss |
| `"hello"` (字符串字面量) | .rodata |
| `str` (指针变量) | .data |
| `local_var` | 栈 |
| `static_local` | .data |
| `heap_var` (指针) | 栈 |
| `*heap_var` (new分配的值) | 堆 |

#### 3.3 MCU上的内存布局

在STM32等MCU上，内存布局由链接脚本（.ld文件）定义喵~

```
Flash（ROM）
├── .isr_vector    中断向量表
├── .text          代码段
├── .rodata        只读数据
└── .data（初始值）  初始化值存储在Flash，启动时拷贝到RAM

RAM
├── .data          已初始化全局/静态变量（从Flash拷贝）
├── .bss           未初始化全局/静态变量（启动时清零）
├── Heap           堆（malloc/free使用）
└── Stack          栈（向下增长）
```

```c
int g_init = 0x1234;
int g_uninit;
const int g_const = 0x5678;

void main(void) {
    static int s_init = 0x9ABC;
    int local = 0;
    int *p = (int *)malloc(sizeof(int));
}
```

| 变量 | MCU存储位置 |
|------|-----------|
| `g_init` | RAM (.data)，初始值在Flash |
| `g_uninit` | RAM (.bss) |
| `g_const` | Flash (.rodata) |
| `s_init` | RAM (.data)，初始值在Flash |
| `local` | RAM (栈) |
| `p` | RAM (栈) |
| `*p` | RAM (堆) |

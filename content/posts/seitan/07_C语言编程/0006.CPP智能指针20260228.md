# C++智能指针

## 题目

C++有哪些智能指针？

## 答案

C++11引入了智能指针来自动管理内存，主要包括以下几种：

### 1. unique_ptr

**特点：**
- 独占所有权，不能复制，只能移动
- 性能开销最小
- 没有引用计数机制

```cpp
#include <iostream>
#include <memory>
using namespace std;

class Resource {
public:
    Resource() {
        cout << "Resource构造函数" << endl;
    }
    ~Resource() {
        cout << "Resource析构函数" << endl;
    }
    void doSomething() {
        cout << "Resource正在工作" << endl;
    }
};

int main() {
    unique_ptr<Resource> ptr1(new Resource());
    ptr1->doSomething();
    
    unique_ptr<Resource> ptr2 = make_unique<Resource>();
    ptr2->doSomething();
    
    unique_ptr<Resource> ptr3 = move(ptr1);
    if (!ptr1) {
        cout << "ptr1已移动" << endl;
    }
    ptr3->doSomething();
    
    return 0;
}
```

**unique_ptr的使用场景：**
- 对象只有一个所有者
- 需要传递所有权
- 数组管理

```cpp
unique_ptr<int[]> arr(new int[10]);
arr[0] = 100;
```

### 2. shared_ptr

**特点：**
- 共享所有权，可以复制
- 使用引用计数
- 当引用计数为0时自动删除对象

```cpp
#include <iostream>
#include <memory>
#include <vector>
using namespace std;

class Resource {
public:
    Resource(int id) : id(id) {
        cout << "Resource " << id << " 构造函数, 引用计数: 1" << endl;
    }
    ~Resource() {
        cout << "Resource " << id << " 析构函数" << endl;
    }
    void doSomething() {
        cout << "Resource " << id << " 正在工作" << endl;
    }
private:
    int id;
};

int main() {
    shared_ptr<Resource> ptr1 = make_shared<Resource>(1);
    cout << "引用计数: " << ptr1.use_count() << endl;
    
    {
        shared_ptr<Resource> ptr2 = ptr1;
        cout << "引用计数: " << ptr1.use_count() << endl;
        ptr2->doSomething();
    }
    
    cout << "引用计数: " << ptr1.use_count() << endl;
    
    vector<shared_ptr<Resource>> resources;
    resources.push_back(make_shared<Resource>(2));
    resources.push_back(make_shared<Resource>(3));
    
    cout << "resources中第一个元素的引用计数: " 
         << resources[0].use_count() << endl;
    
    return 0;
}
```

**shared_ptr的内部引用计数实现：**

```cpp
#include <iostream>
using namespace std;

template<typename T>
class SimpleSharedPtr {
private:
    T* ptr;
    int* refCount;
public:
    SimpleSharedPtr(T* p = nullptr) 
        : ptr(p), refCount(new int(1)) {
        cout << "构造函数, 引用计数: " << *refCount << endl;
    }
    
    SimpleSharedPtr(const SimpleSharedPtr& other) 
        : ptr(other.ptr), refCount(other.refCount) {
        (*refCount)++;
        cout << "拷贝构造, 引用计数: " << *refCount << endl;
    }
    
    SimpleSharedPtr& operator=(const SimpleSharedPtr& other) {
        if (this != &other) {
            (*refCount)--;
            if (*refCount == 0) {
                delete ptr;
                delete refCount;
            }
            ptr = other.ptr;
            refCount = other.refCount;
            (*refCount)++;
            cout << "赋值操作, 引用计数: " << *refCount << endl;
        }
        return *this;
    }
    
    ~SimpleSharedPtr() {
        (*refCount)--;
        cout << "析构函数, 引用计数: " << *refCount << endl;
        if (*refCount == 0) {
            delete ptr;
            delete refCount;
            cout << "对象被删除" << endl;
        }
    }
    
    T* operator->() const { return ptr; }
    T& operator*() const { return *ptr; }
    int use_count() const { return *refCount; }
};

class Resource {
public:
    Resource() { cout << "Resource构造函数" << endl; }
    ~Resource() { cout << "Resource析构函数" << endl; }
    void doSomething() { cout << "Resource正在工作" << endl; }
};

int main() {
    SimpleSharedPtr<Resource> ptr1(new Resource());
    {
        SimpleSharedPtr<Resource> ptr2 = ptr1;
        ptr2->doSomething();
    }
    return 0;
}
```

**shared_ptr的线程安全：**
- 引用计数的增减是原子操作，线程安全
- 指向对象的操作不是线程安全的
- 多个线程访问同一个对象需要额外加锁

### 3. weak_ptr

**特点：**
- 不控制对象生命周期
- 不增加引用计数
- 用于解决循环引用问题
- 需要检查对象是否存活

```cpp
#include <iostream>
#include <memory>
using namespace std;

class B;

class A {
public:
    shared_ptr<B> bPtr;
    
    A() { cout << "A构造函数" << endl; }
    ~A() { cout << "A析构函数" << endl; }
    
    void setB(shared_ptr<B> b) {
        bPtr = b;
    }
};

class B {
public:
    weak_ptr<A> aPtr;
    
    B() { cout << "B构造函数" << endl; }
    ~B() { cout << "B析构函数" << endl; }
    
    void setA(shared_ptr<A> a) {
        aPtr = a;
    }
    
    void accessA() {
        if (shared_ptr<A> a = aPtr.lock()) {
            cout << "A对象存活" << endl;
        } else {
            cout << "A对象已销毁" << endl;
        }
    }
};

int main() {
    shared_ptr<A> a = make_shared<A>();
    shared_ptr<B> b = make_shared<B>();
    
    a->setB(b);
    b->setA(a);
    
    cout << "a的引用计数: " << a.use_count() << endl;
    cout << "b的引用计数: " << b.use_count() << endl;
    
    b->accessA();
    
    return 0;
}
```

### 4. auto_ptr（已废弃）

**特点：**
- C++98引入，C++11废弃
- 独占所有权，但可以复制（会转移所有权）
- 不推荐使用，已被unique_ptr取代

```cpp
auto_ptr<int> ptr1(new int(100));
auto_ptr<int> ptr2 = ptr1;  // ptr1失去所有权
```

### 智能指针对比

| 特性 | unique_ptr | shared_ptr | weak_ptr | auto_ptr |
|------|-----------|------------|----------|----------|
| 所有权 | 独占 | 共享 | 无 | 独占 |
| 可复制 | ❌ 否 | ✅ 是 | ✅ 是 | ✅ 是 |
| 可移动 | ✅ 是 | ✅ 是 | ✅ 是 | ✅ 是 |
| 引用计数 | 无 | 有 | 无 | 无 |
| 性能 | 最好 | 较好 | 好 | 差 |
| 状态 | C++11 | C++11 | C++11 | C++98废弃 |

### 循环引用问题

```cpp
#include <iostream>
#include <memory>
using namespace std;

class Node {
public:
    shared_ptr<Node> next;
    shared_ptr<Node> prev;
    
    Node() { cout << "Node构造函数" << endl; }
    ~Node() { cout << "Node析构函数" << endl; }
};

int main() {
    shared_ptr<Node> node1 = make_shared<Node>();
    shared_ptr<Node> node2 = make_shared<Node>();
    
    node1->next = node2;
    node2->prev = node1;
    
    cout << "node1引用计数: " << node1.use_count() << endl;
    cout << "node2引用计数: " << node2.use_count() << endl;
    
    return 0;
}
```

输出：
```
Node构造函数
Node构造函数
node1引用计数: 2
node2引用计数: 2
```

**解决方法：使用weak_ptr**

```cpp
#include <iostream>
#include <memory>
using namespace std;

class Node {
public:
    shared_ptr<Node> next;
    weak_ptr<Node> prev;  // 使用weak_ptr
    
    Node() { cout << "Node构造函数" << endl; }
    ~Node() { cout << "Node析构函数" << endl; }
};

int main() {
    shared_ptr<Node> node1 = make_shared<Node>();
    shared_ptr<Node> node2 = make_shared<Node>();
    
    node1->next = node2;
    node2->prev = node1;
    
    cout << "node1引用计数: " << node1.use_count() << endl;
    cout << "node2引用计数: " << node2.use_count() << endl;
    
    return 0;
}
```

输出：
```
Node构造函数
Node构造函数
node1引用计数: 1
node2引用计数: 1
Node析构函数
Node析构函数
```

### 智能指针最佳实践

```cpp
#include <iostream>
#include <memory>
#include <vector>
using namespace std;

class Widget {
public:
    Widget(int id) : id(id) {
        cout << "Widget " << id << " 构造函数" << endl;
    }
    ~Widget() {
        cout << "Widget " << id << " 析构函数" << endl;
    }
    void process() {
        cout << "Widget " << id << " 处理中" << endl;
    }
private:
    int id;
};

void processWidget(unique_ptr<Widget> widget) {
    widget->process();
}

int main() {
    auto widget1 = make_unique<Widget>(1);
    
    auto widget2 = make_shared<Widget>(2);
    vector<shared_ptr<Widget>> widgets;
    widgets.push_back(widget2);
    
    weak_ptr<Widget> weakWidget = widget2;
    
    {
        shared_ptr<Widget> temp = weakWidget.lock();
        if (temp) {
            temp->process();
        }
    }
    
    processWidget(move(widget1));
    
    return 0;
}
```

### 自定义删除器

```cpp
#include <iostream>
#include <memory>
using namespace std;

class File {
public:
    File(const char* filename) {
        cout << "打开文件: " << filename << endl;
    }
    ~File() {
        cout << "关闭文件" << endl;
    }
};

void fileDeleter(File* file) {
    cout << "自定义删除器" << endl;
    delete file;
}

int main() {
    unique_ptr<File, decltype(&fileDeleter)> file(new File("test.txt"), fileDeleter);
    
    shared_ptr<File> file2(new File("test2.txt"), [](File* f) {
        cout << "lambda删除器" << endl;
        delete f;
    });
    
    return 0;
}
```

### 智能指针与原始指针混用

```cpp
#include <iostream>
#include <memory>
using namespace std;

class Resource {
public:
    Resource() { cout << "Resource构造函数" << endl; }
    ~Resource() { cout << "Resource析构函数" << endl; }
    void doSomething() { cout << "Resource正在工作" << endl; }
};

int main() {
    shared_ptr<Resource> shared = make_shared<Resource>();
    
    Resource* raw = shared.get();
    raw->doSomething();
    
    delete raw;
    
    shared->doSomething();
    
    return 0;
}
```

**危险！不要这样做！** 会导致double free。

### 总结

**智能指针选择原则：**
1. **默认使用unique_ptr**：独占所有权，性能最好
2. **需要共享时使用shared_ptr**：多个所有者
3. **解决循环引用使用weak_ptr**：不增加引用计数
4. **不要使用auto_ptr**：已废弃，使用unique_ptr替代

**注意事项：**
- 不要混用智能指针和原始指针
- 小心循环引用
- 使用make_shared/make_unique创建对象
- 理解线程安全性
- 自定义删除器用于特殊资源管理

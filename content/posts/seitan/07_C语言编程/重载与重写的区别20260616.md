# 重载与重写的区别

## 题目

重载（Overload）和重写（Override）有什么区别？

## 考察点

C++ 面向对象的函数同名机制：编译时多态（重载/隐藏/重定义）与运行时多态（重写）的区别、作用域、函数签名要求、绑定时机。

## 回答要点

### 1. 核心对比表

| 维度 | 重载 Overload | 重写 Override |
|------|--------------|--------------|
| 发生范围 | **同一作用域**（同类） | **不同作用域**（基类与派生类） |
| 函数名 | 相同 | 相同 |
| 参数列表 | **必须不同** | **必须相同**（签名一致） |
| 返回值 | 无要求（不能仅靠返回值区分） | 一般相同（允许协变返回类型） |
| virtual 关键字 | 无关，普通函数即可 | 基类必须是 `virtual` 才叫重写 |
| 绑定时机 | **编译时**（静态绑定/静态多态） | **运行时**（动态绑定/动态多态） |
| 关键字 | 无 | `override`（C++11，建议显式标注） |
| 实现机制 | 名字修饰（name mangling）+ 重载决议 | 虚函数表（vtable） |

### 2. 重载 Overload

**定义**：同一作用域内，函数名相同、参数列表不同的一组函数。编译器根据调用时的实参类型选择匹配版本。

```cpp
class Print {
public:
    void show(int x) {            // 版本1：整型
        std::cout << "int: " << x << "\n";
    }
    void show(double x) {         // 版本2：浮点
        std::cout << "double: " << x << "\n";
    }
    void show(const char* s) {    // 版本3：字符串
        std::cout << "str: " << s << "\n";
    }
};

Print p;
p.show(10);        // 调用版本1
p.show(3.14);      // 调用版本2
p.show("hello");   // 调用版本3
```

**编译期实现**：编译器通过"名字修饰"把参数类型编码进符号名，例如 `show(int)` 可能被修饰成 `_ZN5Print4showEi`，`show(double)` 是 `_ZN5Print4showEd`，链接时就是两个完全不同的符号。

**注意**：仅返回值类型不同不能构成重载——调用点 `p.show(10)` 无法仅凭返回值区分。

### 3. 重写 Override

**定义**：派生类中重新定义基类的**虚函数**，函数签名完全一致，运行时通过基类指针/引用调用会绑定到派生类版本。

```cpp
class Animal {
public:
    virtual void speak() {        // 基类虚函数
        std::cout << "Animal sound\n";
    }
};

class Dog : public Animal {
public:
    void speak() override {       // 重写：签名必须一致
        std::cout << "Woof\n";
    }
};

Animal* a = new Dog();
a->speak();   // 输出 Woof —— 运行时根据实际对象类型绑定到 Dog::speak
```

**运行期实现**：通过虚函数表（vtable）。`Animal*` 指向的实际对象 `Dog` 内部的 `vptr` 指向 `Dog` 的 vtable，查表得到 `Dog::speak` 的地址。

### 4. 容易混淆的"隐藏/重定义"

派生类中**同名但参数不同**的函数会**隐藏**基类的同名函数（不是重载也不是重写）：

```cpp
class Base {
public:
    virtual void f(int x) {}
    void f(int x, int y) {}
};

class Derived : public Base {
public:
    void f(double x) {}   // 隐藏了 Base 中所有名为 f 的函数，不是重载！
};

Derived d;
d.f(10);          // 调用 Derived::f(double)，而非 Base::f(int)
d.f(10, 20);      // 编译错误！Base::f(int,int) 被隐藏
// d.Base::f(10, 20);  // 需显式指定作用域才能调用
```

原因：重载只发生在**同一作用域**。跨作用域时同名函数会被隐藏。可用 `using Base::f;` 把基类函数引入派生类作用域恢复重载。

### 5. override 关键字的作用（C++11）

显式告诉编译器"我要重写一个虚函数"，让编译器检查签名是否真的匹配，避免手误变成隐藏：

```cpp
class Base {
public:
    virtual void func(int x) {}
};

class Derived : public Base {
public:
    void func(double x) override {}   // 编译错误！签名不匹配，不是真正重写
    // 没有 override 时，这会被误当作"重载"，实际是隐藏，埋下 bug
};
```

建议：派生类重写虚函数时**永远加 `override`**。

### 6. 三种"同名"机制一图分清

| 机制 | 作用域关系 | 参数 | 是否需要 virtual | 多态类型 |
|------|-----------|------|-----------------|---------|
| 重载 Overload | 同一类内 | 必须不同 | 无关 | 编译时（静态） |
| 重写 Override | 基类↔派生类 | 必须相同 | 基类必须是 virtual | 运行时（动态） |
| 隐藏/重定义 Redefine | 基类↔派生类 | 可同可不同 | 无关 | 无多态，按静态类型调用 |

### 7. 记忆口诀

- **重载**：同类同名不同参，编译期选，名字修饰。
- **重写**：子类同名同参虚函数，运行期选，虚表查找。
- **隐藏**：子类同名（不论参），挡住父类同名函数，按指针类型静态调用。

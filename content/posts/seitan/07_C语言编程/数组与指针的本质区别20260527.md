# 数组与指针的本质区别

## 题目

数组和指针的区别是什么？为什么说数组名是指针又不完全是指针？

## 考察点

数组与指针的内存模型差异、数组名退化规则、sizeof 差异、赋值行为差异。

## 回答要点

### 1. 本质区别

**数组**是一块连续内存空间，在定义时就分配好了，数组名代表这块空间的首地址。

**指针**是一个变量，存储的是某个内存地址，可以指向任何同类型的对象。

```c
int a[5] = {1, 2, 3, 4, 5};   // 数组：分配 20 字节连续内存
int *p = a;                     // 指针：分配 4/8 字节存储 a 的地址
```

```
数组 a 的内存布局：
地址:  0x100  0x104  0x108  0x10C  0x110
     +------+------+------+------+------+
     |  1   |  2   |  3   |  4   |  5   |
     +------+------+------+------+------+
      a[0]   a[1]   a[2]   a[3]   a[4]

指针 p 的内存布局：
地址:  0x200
     +--------+
     | 0x100  | -----> 指向 a[0]
     +--------+
      p（4或8字节）
```

### 2. 核心区别对比

| 特性 | 数组 | 指针 |
|------|------|------|
| 本质 | 一块连续内存 | 存储地址的变量 |
| sizeof | 整个数组的大小 | 指针本身的大小（4/8字节） |
| 赋值 | **不能**对数组名赋值 | 可以随时改变指向 |
| 地址含义 | 数组名 = 首元素地址（但不是指针变量） | 取地址得到的是指针变量的地址 |
| 初始化 | `int a[5] = {0}` | `int *p = NULL` |
| 存储 | 数据本身存放在数组中 | 只存一个地址 |

### 3. 数组名退化

数组名在大多数场景下会**退化为指向首元素的指针**，但并非总是如此。

#### 3.1 退化的场景（数组名 = 首元素地址）

```c
int a[5];

// 1. 作为函数参数
void func(int arr[]);  // 等价于 void func(int *arr)
func(a);               // a 退化为 &a[0]

// 2. 赋值给指针
int *p = a;            // a 退化为 &a[0]

// 3. 算术运算
int *q = a + 2;        // a 退化为 &a[0]，然后 +2*sizeof(int)

// 4. 下标访问
a[3];                  // 等价于 *(a + 3)，a 退化为指针
```

#### 3.2 不退化的场景

```c
int a[5];

// 1. sizeof
sizeof(a);             // 20，不是 4/8！数组名没有退化

// 2. 取地址
int (*pa)[5] = &a;     // &a 的类型是 int(*)[5]，指向整个数组

// 3. 字符串初始化
char str[] = "hello";  // 数组初始化，str 是数组不是指针
```

### 4. sizeof 的关键差异

```c
int a[5];
int *p = a;

sizeof(a);    // 20（5 × 4）— 数组大小
sizeof(p);    // 4 或 8 — 指针大小
sizeof(&a);   // 4 或 8 — 指向整个数组的指针，但仍然是指针
sizeof(a[0]); // 4 — 单个元素
```

### 5. 赋值行为差异

```c
int a[5] = {1, 2, 3, 4, 5};
int b[5];

// 数组不能直接赋值
b = a;           // 编译错误！数组名不是可修改的左值

// 指针可以随时改变指向
int *p = a;
p = b;           // 合法，p 现在指向 b

// 数组复制必须用 memcpy
memcpy(b, a, sizeof(a));
```

### 6. &a 和 &a[0] 的区别

虽然数值相同，但类型不同：

```c
int a[5];

&a;      // 类型: int (*)[5]  — 指向整个数组的指针
&a[0];   // 类型: int *       — 指向第一个元素的指针

// +1 的步长不同
&a + 1;    // 跳过整个数组（跳过 20 字节）
&a[0] + 1; // 跳过一个元素（跳过 4 字节）
```

```
&a + 1:
a:  [1][2][3][4][5]
     ^               ^
     &a              &a + 1（跳过整个数组）

&a[0] + 1:
a:  [1][2][3][4][5]
     ^  ^
     |  &a[0]+1（跳过1个int）
     &a[0]
```

### 7. 函数参数中的经典陷阱

```c
void get_size(int arr[]) {
    // arr 已退化为指针！
    printf("%zu\n", sizeof(arr));  // 4 或 8，不是数组大小
}

// 正确做法：传长度参数
void process(int arr[], int len) {
    for (int i = 0; i < len; i++) {
        arr[i] *= 2;
    }
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    process(a, sizeof(a) / sizeof(a[0]));
    return 0;
}
```

### 8. 面试速记

- **数组**是内存块，**指针**是地址变量
- `sizeof(数组)` = 数组总大小，`sizeof(指针)` = 4/8
- 数组名在大多数场景**退化为指针**，但 `sizeof` 和 `&` 除外
- 数组不能赋值，指针可以改变指向
- `&a` 是指向整个数组的指针（+1 跳过整个数组），`&a[0]` 指向首元素（+1 跳过1个元素）

# 如何在main函数之前执行函数

## 题目

一个函数，如何让它在main函数之前执行？

## 答案

在C++中，有几种方法可以让函数在main函数之前执行：

### 方法1：全局对象的构造函数

这是最常用的方法。全局/静态对象的构造函数在main函数之前执行，析构函数在main函数之后执行。

```cpp
#include <iostream>
using namespace std;

class BeforeMain {
public:
    BeforeMain() {
        cout << "在main函数之前执行" << endl;
    }
};

// 全局对象，其构造函数在main之前执行
BeforeMain beforeMain;

int main() {
    cout << "main函数执行" << endl;
    return 0;
}
```

### 方法2：使用函数返回值初始化全局变量

```cpp
#include <iostream>
using namespace std;

int initialize() {
    cout << "在main函数之前执行" << endl;
    return 100;
}

// 使用函数返回值初始化全局变量
int globalVar = initialize();

int main() {
    cout << "main函数执行" << endl;
    return 0;
}
```

### 方法3：使用GCC/Clang的constructor属性

```cpp
#include <iostream>
using namespace std;

__attribute__((constructor))
void beforeMain() {
    cout << "在main函数之前执行" << endl;
}

int main() {
    cout << "main函数执行" << endl;
    return 0;
}
```

### 方法4：使用MSVC的#pragma init_seg

```cpp
#include <iostream>
using namespace std;

#pragma init_seg(".CRT$XCU")
void beforeMain() {
    cout << "在main函数之前执行" << endl;
}

int main() {
    cout << "main函数执行" << endl;
    return 0;
}
```

### 方法5：C++11的constexpr（编译期执行）

```cpp
#include <iostream>
using namespace std;

constexpr int compileTimeCalc() {
    return 100;
}

int main() {
    constexpr int result = compileTimeCalc();
    cout << "main函数执行" << endl;
    return 0;
}
```

### 方法6：使用static局部变量（第一次调用时执行）

```cpp
#include <iostream>
using namespace std;

void function() {
    static int initialized = []() {
        cout << "第一次调用时执行" << endl;
        return 0;
    }();
}

int main() {
    cout << "main函数执行" << endl;
    function();
    return 0;
}
```

### 执行顺序的注意事项

当有多个全局对象或函数需要在main之前执行时，它们的执行顺序是不确定的（除非在同一个编译单元中）。

```cpp
#include <iostream>
using namespace std;

class A {
public:
    A() { cout << "A构造" << endl; }
};

class B {
public:
    B() { cout << "B构造" << endl; }
};

// 同一编译单元中，按定义顺序执行
A a;
B b;

int main() {
    cout << "main函数执行" << endl;
    return 0;
}
```

### 跨编译单元的初始化顺序问题

不同编译单元中的全局对象初始化顺序是不确定的，这是C++的静态初始化顺序灾难。

```cpp
// file1.cpp
class A {
public:
    A() { cout << "A构造" << endl; }
};
extern A* globalA;
A* globalA = new A();

// file2.cpp
class B {
public:
    B() { cout << "B构造" << endl; }
};
extern B* globalB;
B* globalB = new B();

// main.cpp
int main() {
    cout << "main函数执行" << endl;
    return 0;
}
```

### 解决静态初始化顺序问题：使用函数返回局部静态变量

```cpp
#include <iostream>
using namespace std;

class A {
public:
    A() { cout << "A构造" << endl; }
};

A& getA() {
    static A instance;
    return instance;
}

class B {
public:
    B() { 
        cout << "B构造" << endl;
        getA();  // 确保A已经初始化
    }
};

B& getB() {
    static B instance;
    return instance;
}

int main() {
    getB();
    cout << "main函数执行" << endl;
    return 0;
}
```

### 在main函数之后执行

对应地，可以使用以下方法在main函数之后执行代码：

1. **全局对象的析构函数**

```cpp
#include <iostream>
using namespace std;

class AfterMain {
public:
    ~AfterMain() {
        cout << "在main函数之后执行" << endl;
    }
};

AfterMain afterMain;

int main() {
    cout << "main函数执行" << endl;
    return 0;
}
```

2. **使用GCC/Clang的destructor属性**

```cpp
#include <iostream>
using namespace std;

__attribute__((destructor))
void afterMain() {
    cout << "在main函数之后执行" << endl;
}

int main() {
    cout << "main函数执行" << endl;
    return 0;
}
```

### 实际应用场景

1. **日志系统初始化**
2. **内存池初始化**
3. **插件系统注册**
4. **配置文件加载**
5. **单例模式的延迟初始化**

### 总结

- **推荐方法**：使用全局对象的构造函数（跨平台、标准C++）
- **编译器特定**：constructor/destructor属性（GCC/Clang）
- **注意**：不同编译单元的初始化顺序不确定，使用函数包装解决
- **对应**：全局对象析构函数在main之后执行

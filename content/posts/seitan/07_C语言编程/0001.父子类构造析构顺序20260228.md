# 父子类构造函数和析构函数的执行顺序

## 题目

父子继承时候，它构造函数和析构函数的顺序是什么？析构时候，如何让父子类里所有的析构都调用一遍？

## 答案

### 构造函数执行顺序

构造函数的执行顺序遵循"先基类后派生类"的原则：

1. **基类构造函数**：先调用基类的构造函数
2. **成员对象构造函数**：按照成员对象在类中声明的顺序（而非初始化列表中的顺序）
3. **派生类构造函数体**：最后执行派生类构造函数的函数体

### 析构函数执行顺序

析构函数的执行顺序与构造函数相反，遵循"先派生类后基类"的原则：

1. **派生类析构函数体**：先执行派生类析构函数的函数体
2. **成员对象析构函数**：按照成员对象在类中声明的逆序
3. **基类析构函数**：最后调用基类的析构函数

### 代码示例

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    Base() {
        cout << "Base构造函数" << endl;
    }
    virtual ~Base() {
        cout << "Base析构函数" << endl;
    }
};

class Member {
public:
    Member() {
        cout << "Member构造函数" << endl;
    }
    ~Member() {
        cout << "Member析构函数" << endl;
    }
};

class Derived : public Base {
private:
    Member m;
public:
    Derived() {
        cout << "Derived构造函数" << endl;
    }
    ~Derived() {
        cout << "Derived析构函数" << endl;
    }
};

int main() {
    Derived d;
    return 0;
}
```

输出结果：
```
Base构造函数
Member构造函数
Derived构造函数
Derived析构函数
Member析构函数
Base析构函数
```

### 确保所有析构函数被调用

要确保父子类里所有的析构函数都被调用，需要满足以下条件：

1. **基类析构函数必须声明为virtual**
   - 只有虚析构函数才能保证在通过基类指针删除派生类对象时，派生类的析构函数会被调用
   - 如果基类析构函数不是虚函数，通过基类指针删除派生类对象时，只会调用基类的析构函数

```cpp
class Base {
public:
    virtual ~Base() {
        cout << "Base析构函数" << endl;
    }
};

Base* ptr = new Derived();
delete ptr;  // 会调用Derived和Base的析构函数
```

2. **避免内存泄漏和资源未释放**
   - 每个类的析构函数都应该正确释放该类申请的资源
   - 遵循RAII（Resource Acquisition Is Initialization）原则

3. **多重继承情况**
   - 多重继承时，按照继承列表中的顺序依次构造各个基类
   - 析构时按照相反的顺序

### 虚析构函数的重要性

```cpp
class Base {
public:
    ~Base() {
        cout << "Base析构函数" << endl;
    }
};

class Derived : public Base {
private:
    int* data;
public:
    Derived() : data(new int[100]) {}
    ~Derived() {
        delete[] data;
        cout << "Derived析构函数" << endl;
    }
};

Base* ptr = new Derived();
delete ptr;  // 只调用Base析构函数，Derived的内存泄漏！
```

解决方法：

```cpp
class Base {
public:
    virtual ~Base() {
        cout << "Base析构函数" << endl;
    }
};
```

### 总结

- **构造顺序**：基类 → 成员对象 → 派生类
- **析构顺序**：派生类 → 成员对象 → 基类
- **确保全部调用**：基类必须声明虚析构函数
- **RAII原则**：使用对象管理资源生命周期

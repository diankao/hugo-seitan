# C++继承构造析构拷贝构造与运算符重载

## 题目

1. 编写一个类继承并实现接口的程序。
2. 给出一段涉及继承、构造、拷贝构造（参数传值）、运算符重载、析构的代码，写出程序输出结果。

## 考察点

类继承与接口实现、构造/析构顺序、拷贝构造触发时机、运算符重载机制。

## 回答要点

### 1. 类继承与接口实现

C++ 没有专门的 `interface` 关键字，通过**纯虚函数的抽象类**实现接口喵~

```cpp
#include <iostream>
using namespace std;

class IShape {
public:
    virtual double area() const = 0;
    virtual void display() const = 0;
    virtual ~IShape() {}
};

class Colorable {
public:
    virtual void setColor(const string &color) = 0;
    virtual string getColor() const = 0;
    virtual ~Colorable() {}
};

class Circle : public IShape, public Colorable {
private:
    double radius;
    string color;

public:
    Circle(double r) : radius(r), color("white") {
        cout << "Circle 构造, radius=" << radius << endl;
    }

    ~Circle() {
        cout << "Circle 析构, radius=" << radius << endl;
    }

    double area() const override {
        return 3.14159 * radius * radius;
    }

    void display() const override {
        cout << "Circle: radius=" << radius
             << ", area=" << area() << endl;
    }

    void setColor(const string &c) override {
        color = c;
    }

    string getColor() const override {
        return color;
    }
};

class Rectangle : public IShape {
private:
    double width, height;

public:
    Rectangle(double w, double h) : width(w), height(h) {
        cout << "Rectangle 构造, " << width << "x" << height << endl;
    }

    ~Rectangle() {
        cout << "Rectangle 析构, " << width << "x" << height << endl;
    }

    double area() const override {
        return width * height;
    }

    void display() const override {
        cout << "Rectangle: " << width << "x" << height
             << ", area=" << area() << endl;
    }
};

int main() {
    IShape *shapes[] = {
        new Circle(5.0),
        new Rectangle(3.0, 4.0)};

    for (auto s : shapes) {
        s->display();
    }

    Circle *c = dynamic_cast<Circle *>(shapes[0]);
    if (c) {
        c->setColor("red");
        cout << "Circle color: " << c->getColor() << endl;
    }

    for (auto s : shapes) {
        delete s;
    }

    return 0;
}
```

输出：

```
Circle 构造, radius=5
Rectangle 构造, 3x4
Circle: radius=5, area=78.5397
Rectangle: 3x4, area=12
Circle color: red
Circle 析构, radius=5
Rectangle 析构, 3x4
```

### 2. 综合程序结果题

这道题综合考察构造、拷贝构造、运算符重载、析构的调用顺序喵~

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    int value;

    Base(int v = 0) : value(v) {
        cout << "Base 构造(" << value << ")" << endl;
    }

    Base(const Base &other) : value(other.value) {
        cout << "Base 拷贝构造(" << value << ")" << endl;
    }

    Base &operator=(const Base &other) {
        cout << "Base 赋值运算符(" << other.value << "→" << value << ")" << endl;
        value = other.value;
        return *this;
    }

    ~Base() {
        cout << "Base 析构(" << value << ")" << endl;
    }
};

class Derived : public Base {
public:
    int extra;

    Derived(int v = 0, int e = 0) : Base(v), extra(e) {
        cout << "Derived 构造(" << value << "," << extra << ")" << endl;
    }

    Derived(const Derived &other) : Base(other), extra(other.extra) {
        cout << "Derived 拷贝构造(" << value << "," << extra << ")" << endl;
    }

    Derived &operator=(const Derived &other) {
        cout << "Derived 赋值运算符" << endl;
        if (this != &other) {
            Base::operator=(other);
            extra = other.extra;
        }
        return *this;
    }

    ~Derived() {
        cout << "Derived 析构(" << value << "," << extra << ")" << endl;
    }
};

void funcByValue(Base obj) {
    cout << "funcByValue: obj.value=" << obj.value << endl;
}

Derived funcReturnValue() {
    Derived temp(100, 200);
    return temp;
}

int main() {
    cout << "--- 1. 基本构造 ---" << endl;
    Derived d1(1, 2);

    cout << "\n--- 2. 拷贝构造 ---" << endl;
    Derived d2 = d1;

    cout << "\n--- 3. 赋值运算符 ---" << endl;
    Derived d3(3, 4);
    d3 = d1;

    cout << "\n--- 4. 参数传值(触发拷贝构造) ---" << endl;
    funcByValue(d1);

    cout << "\n--- 5. 返回值 ---" << endl;
    Derived d4 = funcReturnValue();

    cout << "\n--- 6. 析构顺序 ---" << endl;
    return 0;
}
```

**逐步分析输出：**

```
--- 1. 基本构造 ---
Base 构造(1)            ← d1 先构造 Base 部分
Derived 构造(1,2)       ← 再构造 Derived 部分

--- 2. 拷贝构造 ---
Base 拷贝构造(1)        ← d2 拷贝构造 Base 部分
Derived 拷贝构造(1,2)   ← 再拷贝构造 Derived 部分

--- 3. 赋值运算符 ---
Base 构造(3)            ← d3 先构造
Derived 构造(3,4)
Derived 赋值运算符      ← d3 = d1
Base 赋值运算符(1→3)    ← 调用基类赋值运算符

--- 4. 参数传值(触发拷贝构造) ---
Base 拷贝构造(1)        ← 传值时，Derived→Base 切片，只拷贝 Base 部分
funcByValue: obj.value=1
Base 析构(1)            ← 函数结束，局部对象析构

--- 5. 返回值 ---
Base 构造(100)          ← temp 构造
Derived 构造(100,200)
Base 拷贝构造(100)      ← 返回值拷贝构造（可能被 RVO 优化掉）
Derived 拷贝构造(100,200)
Derived 析构(100,200)   ← temp 析构（如果 RVO 优化则不会触发）
Base 析构(100)

--- 6. 析构顺序 ---
Derived 析构(1,2)       ← d4 析构（LIFO，后构造先析构）
Base 析构(1)
Derived 析构(1,2)       ← d3 析构
Base 析构(1)
Base 析构(1)            ← d2 析构（注意：d2 的 value 被 d1 赋值过）
Derived 析构(1,2)       ← 等等，d2 是 Derived 类型...
Base 析构(1)
Derived 析构(1,2)       ← d1 析构
Base 析构(1)
```

**注意**：步骤5中的返回值可能被编译器的 RVO（返回值优化）省略拷贝构造喵~ 如果启用了 RVO，输出会更简单。

### 3. 关键知识点总结

#### 3.1 构造顺序

```
基类构造 → 成员对象构造 → 派生类构造
```

#### 3.2 析构顺序（与构造相反）

```
派生类析构 → 成员对象析构 → 基类析构
```

#### 3.3 拷贝构造触发时机

| 场景 | 是否触发 | 示例 |
|------|---------|------|
| 对象初始化 | ✅ | `Derived d2 = d1;` |
| 函数参数传值 | ✅ | `funcByValue(d1);` |
| 函数返回值 | ✅（可能被RVO优化） | `return temp;` |
| 赋值操作 | ❌（用 operator=） | `d3 = d1;` |

#### 3.4 对象切片

当派生类对象以**值传递**方式传给基类参数时，派生类部分被"切掉"，只拷贝基类部分喵~

```cpp
void funcByValue(Base obj);

Derived d(1, 2);
funcByValue(d);  // obj 只有 Base 部分，extra 被丢弃
```

| 传递方式 | 行为 | 是否切片 |
|---------|------|---------|
| 值传递 `Base obj` | 拷贝构造 Base 部分 | ✅ 切片 |
| 引用传递 `Base &obj` | 引用原对象 | ❌ 不切片 |
| 指针传递 `Base *obj` | 指向原对象 | ❌ 不切片 |

#### 3.5 运算符重载要点

```cpp
Derived &operator=(const Derived &other) {
    if (this != &other) {          // 防止自赋值
        Base::operator=(other);     // 必须显式调用基类赋值
        extra = other.extra;        // 赋值派生类成员
    }
    return *this;                   // 返回 *this 支持链式赋值
}
```

**易错点**：派生类的 `operator=` 不会自动调用基类的 `operator=`，必须显式调用喵~

### 4. 做这类题的技巧

1. **从 main 开始**，按语句逐行分析
2. **构造看继承链**：先基类后派生类
3. **析构看作用域**：后构造的先析构（LIFO）
4. **传值 = 拷贝构造**，**赋值 = operator=**
5. **注意对象切片**：值传递到基类会丢失派生类部分
6. **注意 RVO**：现代编译器可能优化掉返回值的拷贝

### 5. 总结

| 要点 | 说明 |
|------|------|
| 构造顺序 | 基类 → 成员对象 → 派生类 |
| 析构顺序 | 派生类 → 成员对象 → 基类 |
| 拷贝构造 | 初始化、传值、返回值时触发 |
| 赋值运算符 | 必须显式调用基类的 operator= |
| 对象切片 | 值传递导致派生类部分丢失 |
| 虚析构 | 通过基类指针删除时确保完整析构 |

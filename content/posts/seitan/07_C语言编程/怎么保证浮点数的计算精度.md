# 怎么保证浮点数的计算精度

## 面试题目

怎么保证浮点数的计算精度？

## 考察点

浮点数表示原理、IEEE 754 标准、精度问题、比较方法、C++ 解决方案

## 回答要点

### 1. 浮点数精度问题的根源

浮点数在计算机中采用 IEEE 754 标准存储，使用二进制科学计数法表示，存在固有的精度限制。

#### IEEE 754 单精度和双精度

| 类型     | 存储位数 | 符号位 | 指数位 | 尾数位 | 有效数字         | 指数范围     |
| ------ | ---- | --- | --- | --- | ------------ | -------- |
| float  | 32   | 1   | 8   | 23  | \~7 位十进制     | ±3.4E38  |
| double | 64   | 1   | 11  | 52  | \~15-16 位十进制 | ±1.8E308 |

#### 精度丢失的原因

```cpp
#include <iostream>
#include <iomanip>

int main() {
    float a = 0.1f;
    float b = 0.2f;
    float sum = a + b;

    std::cout << std::setprecision(20) << sum << std::endl;
    std::cout << (sum == 0.3f ? "等于 0.3" : "不等于 0.3") << std::endl;

    return 0;
}
```

输出：

```
0.30000001192092895508
不等于 0.3
```

0.1 在二进制中是无限循环小数，无法精确表示，存储时会截断。

***

### 2. 常见的精度问题场景

#### 2.1 直接比较失败

```cpp
float a = 0.1f + 0.2f;
float b = 0.3f;

if (a == b) {
    std::cout << "相等" << std::endl;
}
```

条件永远不会为 true，因为 `a` 实际存储的是 `0.30000001192092895508`。

#### 2.2 累积误差

```cpp
float sum = 0.0f;
for (int i = 0; i < 1000000; i++) {
    sum += 0.000001f;
}
std::cout << sum << std::endl;
```

预期结果 1.0，实际结果可能偏差较大。

#### 2.3 大数吃小数

```cpp
float large = 1e20f;
float small = 1.0f;
float result = large + small;

std::cout << (result - large) << std::endl;
```

输出 `0`，小数被大数"吃掉"了。

***

### 3. 解决方案

#### 3.1 使用 epsilon 进行近似比较

定义一个足够小的阈值，判断两个浮点数是否"足够接近"：

```cpp
#include <cmath>

bool floatEqual(float a, float b, float epsilon = 1e-6f) {
    return std::fabs(a - b) < epsilon;
}

int main() {
    float a = 0.1f + 0.2f;
    float b = 0.3f;

    if (floatEqual(a, b)) {
        std::cout << "近似相等" << std::endl;
    }
}
```

**更稳健的相对误差比较：**

```cpp
bool floatEqualRelative(float a, float b, float maxRelDiff = FLT_EPSILON) {
    float diff = std::fabs(a - b);
    a = std::fabs(a);
    b = std::fabs(b);
    float largest = (b > a) ? b : a;

    if (diff <= largest * maxRelDiff) {
        return true;
    }
    return false;
}
```

#### 3.2 使用更高精度类型

```cpp
double a = 0.1 + 0.2;
double b = 0.3;

std::cout << std::setprecision(20) << a << std::endl;
std::cout << std::setprecision(20) << b << std::endl;
std::cout << (a == b ? "相等" : "不相等") << std::endl;
```

double 的有效数字更多，精度问题相对较少，但仍非绝对精确。

#### 3.3 使用定点数或整数运算

对于金融计算等需要精确结果的场景，使用整数表示：

```cpp
class Currency {
private:
    long long cents;
public:
    Currency(double dollars) : cents(static_cast<long long>(dollars * 100 + 0.5)) {}

    double toDollars() const {
        return cents / 100.0;
    }

    Currency operator+(const Currency& other) const {
        return Currency(toDollars() + other.toDollars());
    }
};

int main() {
    Currency a(1.23);
    Currency b(4.56);
    Currency c = a + b;

    std::cout << c.toDollars() << std::endl;
}
```

#### 3.4 使用 C++ 标准库的比较函数

C++20 引入了浮点数比较的标准化方法：

```cpp
#include <cmath>
#include <numbers>

int main() {
    float a = 0.1f + 0.2f;
    float b = 0.3f;

    bool result = std::isgreaterequal(a, b);
    bool approx = std::abs(a - b) < std::numeric_limits<float>::epsilon() * 10;
}
```

#### 3.5 使用高精度数值库

```cpp
#include <boost/multiprecision/cpp_dec_float.hpp>

using namespace boost::multiprecision;

int main() {
    cpp_dec_float_50 a = "0.1";
    cpp_dec_float_50 b = "0.2";
    cpp_dec_float_50 c = a + b;

    cpp_dec_float_50 d = "0.3";

    std::cout << std::setprecision(50) << c << std::endl;
    std::cout << std::setprecision(50) << d << std::endl;
    std::cout << (c == d ? "精确相等" : "不相等") << std::endl;
}
```

### 4. 不同场景的推荐做法

| 场景      | 推荐方案         | 备注        |
| ------- | ------------ | --------- |
| 一般浮点数比较 | epsilon 近似比较 | 使用相对误差更稳健 |
| 金融/金额计算 | 整数或定点数       | 避免浮点数     |
| 科学计算    | double + 数值库 | 使用高精度库    |
| 图形/游戏   | float        | 牺牲精度换性能   |
| 实时系统    | 避免累积运算       | 定期重置累积值   |

### 5. 最佳实践

```cpp
class FloatUtils {
public:
    static constexpr float EPSILON_ABS = 1e-6f;
    static constexpr float EPSILON_REL = FLT_EPSILON * 10;

    static bool isZero(float x, float epsilon = EPSILON_ABS) {
        return std::fabs(x) < epsilon;
    }

    static bool equal(float a, float b, float epsilon = EPSILON_ABS) {
        return std::fabs(a - b) < epsilon;
    }

    static bool equalRelative(float a, float b, float maxRelDiff = EPSILON_REL) {
        float diff = std::fabs(a - b);
        a = std::fabs(a);
        b = std::fabs(b);
        float largest = std::max(a, b);

        if (diff <= largest * maxRelDiff) {
            return true;
        }
        return false;
    }

    static bool greater(float a, float b, float epsilon = EPSILON_ABS) {
        return a > b + epsilon;
    }

    static bool less(float a, float b, float epsilon = EPSILON_ABS) {
        return a < b - epsilon;
    }
};
```

面试官可能会追问：

### 如何避免大数吃小数的问题

这个问题在数值计算中称为"灾难性抵消"或"精度丢失"，原因是浮点数有效位数有限，当两个数量级相差很大的数相加时，小数的有效位会被舍去。

**解决方案：**

1. **使用更高精度类型**

```cpp
float large = 1e20f;
float small = 1.0f;
float result_float = large + small;

double large_d = 1e20;
double small_d = 1.0;
double result_double = large_d + small_d;

std::cout << "float: " << (result_float - large) << std::endl;
std::cout << "double: " << (result_double - large_d) << std::endl;
```

2. **Kahan 求和算法**

```cpp
#include <iostream>
#include <cmath>

double kahanSum(const double* data, size_t n) {
    double sum = 0.0;
    double c = 0.0;

    for (size_t i = 0; i < n; i++) {
        double y = data[i] - c;
        double t = sum + y;
        c = (t - sum) - y;
        sum = t;
    }
    return sum;
}

int main() {
    double arr[] = {1e20, 1.0, -1e20, 1.0, 1.0};
    double sum = 0.0;
    double sum_kahan = kahanSum(arr, 5);

    for (int i = 0; i < 5; i++) {
        sum += arr[i];
    }

    std::cout << "普通求和: " << sum << std::endl;
    std::cout << "Kahan求和: " << sum_kahan << std::endl;
}
```

3. **先累加小数，再与大数合并**

```cpp
double large = 1e20;
double small[3] = {1.0, 2.0, 3.0};

double sum_small = 0.0;
for (int i = 0; i < 3; i++) {
    sum_small += small[i];
}

double result = large + sum_small;
```

4. **使用整数或定点数**

```cpp
// 将数据放大为整数，计算后再还原
int scale = 1000000;
int64_t large_scaled = static_cast<int64_t>(1e20 / scale);
int64_t small_scaled = 1000;

int64_t result_scaled = large_scaled + small_scaled;
double result = result_scaled * scale;
```

5. **使用高精度数值库**

```cpp
#include <boost/multiprecision/cpp_dec_float.hpp>

using namespace boost::multiprecision;

int main() {
    cpp_dec_float_100 large("1e20");
    cpp_dec_float_100 small("1.0");
    cpp_dec_float_100 result = large + small;

    std::cout << std::setprecision(50) << result << std::endl;
}
```

**最佳实践：**

| 场景 | 推荐方案 |
|--------|----------|
| 一般计算 | 使用 double 代替 float |
| 大量累加 | Kahan 算法或先分组累加 |
| 金融计算 | 整数或定点数 |
| 极高精度需求 | 高精度数值库 |

# C++类型转换_cast系列

## 题目

C++的类型转换有哪些？_cast

## 答案

C++提供了四种类型转换操作符，相比C风格的强制类型转换更加安全和明确：

### 1. static_cast

**用途：** 编译时类型检查，用于相关类型之间的转换

**适用场景：**
- 基本数据类型转换（int、float、double等）
- 父类和子类之间的指针/引用转换
- void*指针转换
- 枚举类型转换

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    virtual void func() {
        cout << "Base::func()" << endl;
    }
};

class Derived : public Base {
public:
    void func() override {
        cout << "Derived::func()" << endl;
    }
    void derivedFunc() {
        cout << "Derived::derivedFunc()" << endl;
    }
};

int main() {
    double d = 3.14;
    int i = static_cast<int>(d);  // 浮点转整数
    cout << "i = " << i << endl;
    
    Derived derived;
    Base* basePtr = &derived;
    
    Derived* derivedPtr = static_cast<Derived*>(basePtr);  // 父类转子类
    derivedPtr->derivedFunc();
    
    void* voidPtr = &d;
    double* doublePtr = static_cast<double*>(voidPtr);  // void*转换
    cout << "*doublePtr = " << *doublePtr << endl;
    
    return 0;
}
```

**注意事项：**
- 没有运行时类型检查，转换失败会导致未定义行为
- 不能用于不相关类型之间的转换
- 不能去除const或volatile属性

### 2. dynamic_cast

**用途：** 运行时类型检查，用于多态类型之间的转换

**适用场景：**
- 基类和派生类之间的指针/引用转换（多态类型）
- 向下转换（基类指针转为派生类指针）
- 跨继承转换（兄弟类之间）

```cpp
#include <iostream>
#include <typeinfo>
using namespace std;

class Base {
public:
    virtual void func() {
        cout << "Base::func()" << endl;
    }
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void func() override {
        cout << "Derived::func()" << endl;
    }
    void derivedFunc() {
        cout << "Derived::derivedFunc()" << endl;
    }
};

class AnotherDerived : public Base {
public:
    void func() override {
        cout << "AnotherDerived::func()" << endl;
    }
};

int main() {
    Base* base = new Derived();
    
    Derived* derived = dynamic_cast<Derived*>(base);
    if (derived) {
        cout << "转换成功" << endl;
        derived->derivedFunc();
    } else {
        cout << "转换失败" << endl;
    }
    
    AnotherDerived* another = dynamic_cast<AnotherDerived*>(base);
    if (another) {
        cout << "转换成功" << endl;
    } else {
        cout << "转换失败" << endl;
    }
    
    Base& baseRef = *base;
    try {
        Derived& derivedRef = dynamic_cast<Derived&>(baseRef);
        derivedRef.derivedFunc();
    } catch (const bad_cast& e) {
        cout << "引用转换失败: " << e.what() << endl;
    }
    
    delete base;
    return 0;
}
```

**dynamic_cast的安全性：**
- 如果转换失败，指针转换返回nullptr
- 引用转换抛出bad_cast异常
- 只有包含虚函数的类才能使用dynamic_cast
- 运行时检查，性能开销比static_cast大

**dynamic_cast如何保证安全：**
- 使用RTTI（运行时类型信息）
- 检查对象的实际类型
- 检查转换路径的合法性

### 3. const_cast

**用途：** 添加或移除const或volatile属性

**适用场景：**
- 移除const属性（谨慎使用）
- 添加const属性

```cpp
#include <iostream>
using namespace std;

void printString(const string& str) {
    cout << str << endl;
}

void modifyString(string& str) {
    str = "Modified";
}

int main() {
    const string str1 = "Hello";
    string str2 = "World";
    
    printString(str1);
    printString(str2);
    
    const string& constRef = str2;
    string& mutableRef = const_cast<string&>(constRef);
    mutableRef = "Modified via const_cast";
    cout << str2 << endl;
    
    const char* constStr = "const string";
    char* mutableStr = const_cast<char*>(constStr);
    cout << mutableStr << endl;
    
    return 0;
}
```

**注意事项：**
- 移除const后修改原const对象会导致未定义行为
- 主要用于处理接口不匹配的情况
- 不要滥用，违反const的正确语义

**const_cast的合法用途：**

```cpp
class MyClass {
public:
    void constMethod() const {
        const_cast<MyClass*>(this)->nonConstMethod();
    }
    
    void nonConstMethod() {
        cout << "非const方法" << endl;
    }
};
```

### 4. reinterpret_cast

**用途：** 低级转换，重新解释比特位

**适用场景：**
- 指针和整数之间的转换
- 不相关类型指针之间的转换
- 函数指针转换（谨慎）

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    int value = 0x12345678;
    int* ptr = &value;
    
    uintptr_t intPtr = reinterpret_cast<uintptr_t>(ptr);
    cout << "Pointer as integer: 0x" << hex << intPtr << endl;
    
    int* ptr2 = reinterpret_cast<int*>(intPtr);
    cout << "Value: " << dec << *ptr2 << endl;
    
    double d = 3.14;
    long long ll = reinterpret_cast<long long&>(d);
    cout << "Double as long long: " << ll << endl;
    
    char buffer[sizeof(int)];
    int num = 0x41424344;
    memcpy(buffer, &num, sizeof(int));
    cout << "Bytes: ";
    for (int i = 0; i < 4; i++) {
        cout << buffer[i];
    }
    cout << endl;
    
    return 0;
}
```

**注意事项：**
- 最不安全的转换，可能导致未定义行为
- 破坏类型系统，谨慎使用
- 主要用于底层系统编程
- 不保证可移植性

### 类型转换对比表

| 转换类型 | 编译时检查 | 运行时检查 | 用途 | 安全性 |
|---------|----------|----------|------|--------|
| static_cast | ✅ 是 | ❌ 否 | 相关类型转换 | 中等 |
| dynamic_cast | ✅ 是 | ✅ 是 | 多态类型转换 | 高 |
| const_cast | ✅ 是 | ❌ 否 | const/volatile属性 | 低 |
| reinterpret_cast | ✅ 是 | ❌ 否 | 低级转换 | 最低 |

### C风格强制转换 vs C++类型转换

```cpp
// C风格强制转换（不推荐）
double d = 3.14;
int i1 = (int)d;  // 隐式执行static_cast
Base* b = new Derived();
Derived* d1 = (Derived*)b;  // 危险！没有类型检查

// C++类型转换（推荐）
int i2 = static_cast<int>(d);
Derived* d2 = dynamic_cast<Derived*>(b);  // 安全！运行时检查
```

### 使用建议

1. **优先使用static_cast**：大多数类型转换场景
2. **多态转换使用dynamic_cast**：基类指针转派生类指针
3. **谨慎使用const_cast**：仅在必要时使用
4. **避免使用reinterpret_cast**：除非在底层系统编程中
5. **不要使用C风格强制转换**：不够明确，容易出错

### 实际应用示例

```cpp
#include <iostream>
#include <vector>
#include <memory>
using namespace std;

class Shape {
public:
    virtual double area() const = 0;
    virtual ~Shape() {}
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}
    double area() const override {
        return 3.14159 * radius * radius;
    }
};

class Rectangle : public Shape {
private:
    double width, height;
public:
    Rectangle(double w, double h) : width(w), height(h) {}
    double area() const override {
        return width * height;
    }
};

int main() {
    vector<unique_ptr<Shape>> shapes;
    shapes.push_back(make_unique<Circle>(5.0));
    shapes.push_back(make_unique<Rectangle>(3.0, 4.0));
    
    for (const auto& shape : shapes) {
        cout << "Area: " << shape->area() << endl;
        
        if (dynamic_cast<Circle*>(shape.get())) {
            cout << "This is a circle" << endl;
        } else if (dynamic_cast<Rectangle*>(shape.get())) {
            cout << "This is a rectangle" << endl;
        }
    }
    
    return 0;
}
```

### 总结

- **static_cast**：编译时检查，用于相关类型转换
- **dynamic_cast**：运行时检查，用于多态类型转换，最安全
- **const_cast**：移除/添加const属性，谨慎使用
- **reinterpret_cast**：低级转换，最不安全，避免使用
- **推荐**：优先使用C++类型转换，避免C风格强制转换
- **原则**：选择最具体、最安全的转换方式

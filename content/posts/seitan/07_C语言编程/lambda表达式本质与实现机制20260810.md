# lambda表达式本质与实现机制

## 题目

C++ 的 lambda 表达式本质是什么？它的底层是如何实现的？

## 考察点

C++11 lambda 的编译期语义、闭包类型、捕获机制、与仿函数/`std::function` 的关系。

## 回答要点

### 1. lambda 的本质：编译器生成的匿名类（闭包类型）

C++ 标准规定：**每个 lambda 表达式都会生成一个唯一的、匿名的类类型（闭包类型 Closure Type）**。lambda 的函数体就是这个类的 `operator()` 实现，捕获的变量是类的成员变量。

```cpp
// 写一个 lambda
int x = 10;
auto f = [x](int a) { return a + x; };

// 编译器等价生成
class __lambda_unique_name {
    int x;                                  // 捕获的变量作为成员
public:
    __lambda_unique_name(int x_) : x(x_) {} // 构造函数
    int operator()(int a) const {           // 重载 operator()
        return a + x;
    }
};

__lambda_unique_name f(x);                  // 用捕获值构造一个闭包对象
f(5);                                       // 调用 operator()(5)
```

**核心结论**：lambda 本质是一个**重载了 `operator()` 的类（仿函数）的实例**，称为闭包对象。

### 2. 闭包类型 vs 闭包对象

| 概念 | 含义 |
|------|------|
| 闭包类型（Closure Type） | 编译器为每个 lambda 生成的匿名类，每个 lambda 都独一无二 |
| 闭包对象（Closure Object） | 该类的一个实例，即 `auto f = []{...};` 中的 `f` |

```cpp
auto f1 = [](int x){ return x; };
auto f2 = [](int x){ return x; };
// f1 和 f2 是不同类型！即使写法一样
static_assert(!std::is_same_v<decltype(f1), decltype(f2)>);
```

### 3. 捕获方式的底层差异

不同的捕获语法对应不同的成员类型和构造方式：

```cpp
int a = 1, b = 2;

[a]            {};   // 按值捕获 a：成员 int a;  构造时拷贝
[&a]           {};   // 按引用捕获 a：成员 int& a; 构造时存引用
[=]            {};   // 按值捕获所有用到的变量
[&]            {};   // 按引用捕获所有用到的变量
[a, &b]        {};   // 混合
[this]         {};   // 捕获当前对象指针（成员函数中常用）
[*this]        {};   // C++17：按值捕获当前对象副本

// 编译器展开
class __cap_by_value {
    int a;            // 值成员
public:
    __cap_by_value(int a_) : a(a_) {}
    void operator()() const { /* 用 a */ }
};

class __cap_by_ref {
    int& a;           // 引用成员
public:
    __cap_by_ref(int& a_) : a(a_) {}
    void operator()() const { /* 通过 a 读写原对象 */ }
};
```

#### `mutable` 的作用

默认情况下，`operator()` 是 `const` 的，不能修改值捕获的成员。加 `mutable` 去掉 const：

```cpp
int x = 0;
auto counter = [x]() mutable { return ++x; };   // 可修改值捕获的 x 副本

// 等价于
class __counter {
    int x;
public:
    int operator()() { return ++x; }    // 非 const
};
```

注意：值捕获 + mutable 改的是闭包内的副本，原变量 `x` 不变。

### 4. 没有捕获的 lambda 可转换为函数指针

```cpp
auto f = [](int a) { return a * 2; };     // 无捕获
int (*fp)(int) = f;                        // 隐式转换为函数指针

// 标准保证：无捕获 lambda 有到对应函数指针的转换函数
// 等价类内定义：
// using Fptr = int(*)(int);
// operator Fptr() const { return &__impl; }
```

这是 C 回调函数与 lambda 桥接的基础：

```cpp
#include <cstdlib>
// C 标准库 qsort 要求函数指针
int arr[] = {3, 1, 4, 1, 5};
std::qsort(arr, 5, sizeof(int),
           [](const void* a, const void* b) {
               return *(int*)a - *(int*)b;
           });                              // 无捕获 lambda 可隐式转
```

但**有捕获的 lambda 不能转为函数指针**，必须借助 `std::function` 或全局变量中转。

### 5. `std::function` 与 lambda 的关系

`std::function` 是一个**类型擦除的可调用对象容器**，能持有任意签名的可调用对象（lambda、函数指针、仿函数、成员函数）。

```cpp
#include <functional>

std::function<int(int)> f;

// 可装入不同类型的可调用对象
f = [](int x) { return x + 1; };             // lambda
f = std::bind(&Foo::bar, &foo, std::placeholders::_1);  // 成员函数
int (*fp)(int) = some_func;
f = fp;                                       // 函数指针

f(10);                                        // 统一调用
```

| 维度 | lambda（auto 推导） | std::function |
|------|-------------------|---------------|
| 类型 | 每个不同，编译期确定 | 统一的运行时多态类型 |
| 开销 | 零（可内联） | 类型擦除 + 可能堆分配 |
| 灵活性 | 不能跨类型存容器 | 可存入 vector、做回调 |
| 使用建议 | 优先 auto | 需要类型擦除时才用 |

```cpp
// 推荐：能用 auto 就用 auto，避免 std::function 开销
auto f = [](int x){ return x*2; };   // 零开销，可内联

// 需要：回调注册、容器存储时用 std::function
std::vector<std::function<void()>> callbacks;
callbacks.push_back([]{ puts("a"); });
```

### 6. 捕获表达式与初始化捕获（C++14）

```cpp
std::unique_ptr<Widget> pw = std::make_unique<Widget>();

// C++14 初始化捕获：可 move 进闭包
auto f = [up = std::move(pw)]() { up->do_something(); };
// 成员是 unique_ptr，构造时 move

// 用初始化捕获给捕获变量改名或计算
auto g = [sum = a + b](int x){ return x + sum; };
```

### 7. lambda 与 STL 算法的配合

```cpp
std::vector<int> v = {5, 2, 8, 1, 9};

// 排序：lambda 作比较器
std::sort(v.begin(), v.end(), [](int a, int b){ return a > b; });

// 查找
auto it = std::find_if(v.begin(), v.end(), [](int x){ return x > 5; });

// for_each
std::for_each(v.begin(), v.end(), [count=0](int x) mutable {
    /* ... */
});

// 捕获外部 count 变量
int threshold = 5;
auto big = std::count_if(v.begin(), v.end(),
                         [threshold](int x){ return x > threshold; });
```

### 8. 常见陷阱

#### 悬垂引用：按引用捕获局部变量后超出作用域

```cpp
std::function<int(int)> make_bad() {
    int local = 42;
    return [&local](int x){ return x + local; };   // local 引用会悬垂！
}
auto f = make_bad();
f(1);   // UB：local 已销毁
```

修复：按值捕获 `[local]` 或用初始化捕获。

#### `this` 捕获在异步场景的悬垂

```cpp
class Worker {
    void start() {
        std::thread([this]{ this->run(); }).detach();   // this 可能失效
    }
};
```

C++17 用 `[*this]` 按值捕获当前对象副本，或保证对象生命周期。

#### `auto` 返回 lambda 的递归

```cpp
// 不能用 auto 直接递归 lambda（类型推断不出来）
// auto fib = [](int n){ return n<2 ? n : fib(n-1)+fib(n-2); }; // 错

// 用 std::function 包一层
std::function<int(int)> fib = [&](int n){
    return n < 2 ? n : fib(n-1) + fib(n-2);
};
```

### 9. 性能：零开销抽象

```cpp
// 直接写仿函数
struct Adder {
    int x;
    int operator()(int a) const { return a + x; }
};
Adder adder{10};
adder(5);

// 写 lambda
auto lam = [x=10](int a){ return a + x; };
lam(5);

// 生成的代码完全等价，编译器都能内联 → "零开销抽象"
```

## 扩展问题

面试官可能会追问：
- lambda 和仿函数（functor）有什么区别？（本质一样，lambda 是语法糖）
- `std::function` 为什么有开销？（类型擦除、可能堆分配、虚调用不可内联）
- 为什么无捕获 lambda 能转函数指针？（标准规定有转换函数，本质是静态函数）
- 泛型 lambda（C++14 `[](auto x){}`）怎么实现？（`operator()` 是模板）

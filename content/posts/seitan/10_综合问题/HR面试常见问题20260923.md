# HR面试常见问题

## 问题清单

1. 看来你虽然是个理工科还是蛮文艺的嘛，你什么时候学画画的？
2. 你的家人在做什么？
3. 你选择这个专业是出于自己的兴趣，还是家人推荐？
4. 你如何看待vivo？觉得vivo是一家什么样的公司？
5. 你投了哪些公司？不考虑对方是否接受的话，排前三的是什么？这些公司最吸引你的是什么？vivo在你心里是第几梯队？
6. 期望的工作环境？
7. 期望工资？
8. 你觉得自己从事这个岗位，优势和劣势是什么？
9. 你怎么理解压力？
10. 反问环节
11. 问：你了解过我们单位吗？
12. 问：你倾向于做公司哪一类项目
13. 问：你觉得智能硬件用到了什么关键技术
14. 问：期望的工作环境、是否是凭自己能力拿工资
15. 杭州工作可以接受吗？
16. 实习公司有转正吗？

## 回答要点

### 1. 个人兴趣爱好

#### 回答策略
```
1. 真诚回答
   - 不要编造
   - 自然表达
   - 体现个性

2. 适当展示
   - 展示积极的一面
   - 体现综合素质
   - 不要过度展开

3. 联系岗位
   - 如果爱好与岗位相关，说明联系
   - 如果不相关，简要说明即可
   - 避免花费过多时间
```

#### 示例回答
```
确实，我平时比较喜欢画画。
从小就开始学习素描和水彩，一直坚持到现在。

画画对我来说是一种放松方式，
也培养了我的审美能力和专注力。

我觉得这些能力在工作中也是有帮助的，
比如在做UI设计或者产品原型时，
可以更好地理解和沟通。
```

### 2. 家庭情况

#### 回答策略
```
1. 简要说明
   - 不需要太详细
   - 避免敏感信息
   - 体现家庭支持

2. 积极正面
   - 强调家庭的支持
   - 体现家庭的教育
   - 展现积极的家庭氛围

3. 适当联系
   - 如果家庭背景与工作相关，简要说明
   - 如果不相关，简要带过
```

#### 示例回答
```
我父亲是工程师，母亲是教师。
家庭氛围比较开明，父母一直支持我的选择。

父亲的工作让我对技术产生了兴趣，
母亲则教会了我学习方法。

他们都支持我选择自己喜欢的事业，
这也让我能够专注于自己的专业发展。
```

### 3. 专业选择

#### 回答策略
```
1. 结合实际
   - 说明当时的考虑
   - 体现思考过程
   - 展现自主选择

2. 展现热情
   - 对专业的热爱
   - 对技术的兴趣
   - 对未来的规划

3. 持续发展
   - 入学后的深入学习
   - 对专业的更深入理解
   - 对未来方向的明确
```

#### 示例回答
```
我选择这个专业主要是出于自己的兴趣。

高中时我对电子技术很感兴趣，
参加过一些科技活动，
这让我对嵌入式技术产生了浓厚兴趣。

家人也很支持我的选择，
没有给我施加压力。

入学后，通过系统的学习，
我对这个专业有了更深入的理解，
也更加确定了自己未来的发展方向。
```

### 4. 对公司的了解

#### 回答策略
```
1. 展现准备
   - 说明做过调研
   - 了解公司产品
   - 了解公司文化

2. 积极正面
   - 赞美公司的优点
   - 体现匹配度
   - 表达加入意愿

3. 具体细节
   - 提到具体产品
   - 提到具体技术
   - 避免空泛
```

#### 示例回答
```
我对vivo有一定的了解。

首先，vivo在智能手机领域有很强的实力，
特别是在拍照和音质方面有很好的口碑。

其次，vivo在技术研发上投入很大，
有自己的研发团队和技术积累。

我认为vivo是一家注重用户体验、
技术实力强的公司。

我非常欣赏vivo在创新方面的努力，
也希望能加入这样的团队。
```

### 5. 公司选择

#### 回答策略
```
1. 诚实回答
   - 列出投递的公司
   - 说明选择标准
   - 避免贬低其他公司

2. 展现匹配
   - 说明为什么选择这家公司
   - 体现与公司的匹配度
   - 表达加入意愿

3. 积极态度
   - 对公司的重视
   - 对岗位的渴望
   - 对未来的期待
```

#### 示例回答
```
我投递了几家在嵌入式和智能硬件领域
比较有代表性的公司。

排前三的是：vivo、小米、华为。

这些公司最吸引我的是：
- 强大的技术实力
- 良好的发展平台
- 丰富的项目机会

vivo在我心里是第一梯队的公司。
我非常看重vivo在智能硬件领域的技术积累，
也希望能在这里发挥自己的优势。
```

### 6. 工作环境期望

#### 回答策略
```
1. 积极正面
   - 重视技术氛围
   - 看重团队协作
   - 期望成长环境

2. 适度要求
   - 合理的期望
   - 不提过高要求
   - 体现务实态度

3. 展现适应性
   - 表示可以适应
   - 重视团队文化
   - 关注工作本身
```

#### 示例回答
```
我期望的工作环境有几个特点：

首先是技术氛围浓厚，团队重视技术质量，
鼓励创新和学习。

其次是良好的团队协作，同事之间
能够互相帮助，沟通顺畅。

最后是有成长空间，公司重视员工发展，
提供学习和晋升的机会。

当然，我也理解每个公司都有自己的文化，
我会积极适应，专注于工作本身。
```

### 7. 薪资期望

#### 回答策略
```
1. 调研了解
   - 了解市场行情
   - 了解公司范围
   - 了解岗位要求

2. 合理期望
   - 符合市场水平
   - 符合个人能力
   - 符合公司标准

3. 灵活态度
   - 表示可以商量
   - 看重综合待遇
   - 看重发展机会
```

#### 示例回答
```
关于薪资，我做过一些调研。

根据市场行情和岗位要求，
我的期望薪资在XX-XX之间。

当然，我更看重的是这个岗位的发展机会
和公司的平台。

如果综合待遇和发展机会都很好，
薪资方面我是可以商量的。
```

### 8. 优势劣势

#### 优势
```
1. 技术能力
   - 扎实的技术基础
   - 丰富的项目经验
   - 快速学习能力

2. 工作态度
   - 认真负责
   - 主动积极
   - 持续改进

3. 团队协作
   - 善于沟通
   - 团队精神
   - 互相帮助
```

#### 劣势
```
1. 诚实面对
   - 不要隐瞒
   - 说明改进计划
   - 展现成长意愿

2. 选择劣势
   - 不要说致命缺点
   - 选择可改进的
   - 避免与岗位冲突

3. 改进计划
   - 说明如何改进
   - 展现主动性
   - 持续学习
```

#### 示例回答
```
我的优势：

首先是技术能力比较扎实，
在嵌入式开发方面有系统的学习
和丰富的项目经验。

其次是学习能力强，
能够快速学习新技术和新知识。

最后是工作态度认真负责，
能够主动发现和解决问题。

我的劣势：

实践经验还需要积累，
在学校环境中做的主要是学习和研究，
在企业环境中的实战经验还需要提升。

不过，我正在积极改进，
通过实习和项目实践不断提升自己的实战能力。
```

### 9. 压力理解

#### 回答策略
```
1. 积极态度
   - 把压力看作动力
   - 正确面对压力
   - 合理管理压力

2. 应对方法
   - 时间管理
   - 优先级排序
   - 寻求帮助

3. 个人调节
   - 适度放松
   - 保持健康
   - 保持积极
```

#### 示例回答
```
我对压力的理解：

适度的压力是好事，
可以激发潜能，提高效率。

面对压力，我会：
1. 合理规划时间，分解任务
2. 设定优先级，重要的事情优先做
3. 遇到困难及时寻求帮助

同时，我也会注意调节，
保持良好的身体和心理状态，
以积极的态度面对工作。
```

### 10. 反问环节

#### 好的问题
```
1. 工作内容相关
   - 团队的主要工作内容
   - 我会参与哪些项目
   - 团队的技术栈是什么

2. 团队情况相关
   - 团队规模和结构
   - 团队的工作方式
   - 团队的文化氛围

3. 个人发展相关
   - 有什么样的培训机会
   - 有什么样的晋升机制
   - 对新人的培养计划
```

#### 示例问题
```
1. 请问团队目前的主要项目是什么？
2. 我入职后会参与哪些项目？
3. 团队的技术栈主要是什么？
4. 公司对新员工有什么样的培训计划？
5. 团队的工作方式和文化氛围是怎样的？
```

## 注意事项

1. 诚实回答，不要编造
2. 积极正面，避免负面
3. 展现准备，体现重视
4. 表达意愿，展现热情
5. 适度展示，避免过度

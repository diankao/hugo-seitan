# 两数之和

## 题目

找出给定数组中，两个数加起来等于目标值的数，找出那两个数的下标。（NC61两数之和）

## 答案

### 题目描述

给定一个整数数组 `nums` 和一个目标值 `target`，请在数组中找出和为目标值的那两个整数，并返回它们的下标。

假设：
- 每种输入只会对应一个答案
- 不能重复使用相同的元素
- 答案存在唯一解

### 解法1：暴力枚举

```cpp
#include <vector>
#include <iostream>

class Solution {
public:
    std::vector<int> twoSum(std::vector<int>& nums, int target) {
        int n = nums.size();
        for (int i = 0; i < n - 1; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] + nums[j] == target) {
                    return {i, j};
                }
            }
        }
        return {};
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {2, 7, 11, 15};
    int target = 9;
    
    std::vector<int> result = solution.twoSum(nums, target);
    if (!result.empty()) {
        std::cout << "Indices: " << result[0] << ", " << result[1] << std::endl;
        std::cout << "Values: " << nums[result[0]] << " + " << nums[result[1]] 
                  << " = " << target << std::endl;
    }
    
    return 0;
}
```

**时间复杂度：** O(n²)
**空间复杂度：** O(1)

### 解法2：哈希表

```cpp
#include <vector>
#include <unordered_map>
#include <iostream>

class Solution {
public:
    std::vector<int> twoSum(std::vector<int>& nums, int target) {
        std::unordered_map<int, int> numToIndex;
        
        for (int i = 0; i < nums.size(); i++) {
            int complement = target - nums[i];
            
            if (numToIndex.find(complement) != numToIndex.end()) {
                return {numToIndex[complement], i};
            }
            
            numToIndex[nums[i]] = i;
        }
        
        return {};
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {3, 2, 4};
    int target = 6;
    
    std::vector<int> result = solution.twoSum(nums, target);
    if (!result.empty()) {
        std::cout << "Indices: " << result[0] << ", " << result[1] << std::endl;
        std::cout << "Values: " << nums[result[0]] << " + " << nums[result[1]] 
                  << " = " << target << std::endl;
    }
    
    return 0;
}
```

**时间复杂度：** O(n)
**空间复杂度：** O(n)

### 解法3：双指针（需要先排序）

```cpp
#include <vector>
#include <algorithm>
#include <iostream>

class Solution {
public:
    std::vector<int> twoSum(std::vector<int>& nums, int target) {
        std::vector<std::pair<int, int>> indexedNums;
        for (int i = 0; i < nums.size(); i++) {
            indexedNums.push_back({nums[i], i});
        }
        
        std::sort(indexedNums.begin(), indexedNums.end());
        
        int left = 0;
        int right = indexedNums.size() - 1;
        
        while (left < right) {
            int sum = indexedNums[left].first + indexedNums[right].first;
            
            if (sum == target) {
                return {indexedNums[left].second, indexedNums[right].second};
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
        
        return {};
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {2, 7, 11, 15};
    int target = 9;
    
    std::vector<int> result = solution.twoSum(nums, target);
    if (!result.empty()) {
        std::cout << "Indices: " << result[0] << ", " << result[1] << std::endl;
        std::cout << "Values: " << nums[result[0]] << " + " << nums[result[1]] 
                  << " = " << target << std::endl;
    }
    
    return 0;
}
```

**时间复杂度：** O(n log n)
**空间复杂度：** O(n)

### 解法4：处理重复元素

```cpp
#include <vector>
#include <unordered_map>
#include <iostream>

class Solution {
public:
    std::vector<std::vector<int>> twoSumAllPairs(std::vector<int>& nums, int target) {
        std::unordered_map<int, int> numCount;
        std::vector<std::vector<int>> result;
        
        for (int num : nums) {
            numCount[num]++;
        }
        
        for (auto& [num, count] : numCount) {
            int complement = target - num;
            
            if (complement == num) {
                if (count >= 2) {
                    result.push_back({num, complement});
                }
            } else if (complement > num && numCount.find(complement) != numCount.end()) {
                result.push_back({num, complement});
            }
        }
        
        return result;
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {1, 2, 3, 2, 4, 3, 5};
    int target = 5;
    
    std::vector<std::vector<int>> result = solution.twoSumAllPairs(nums, target);
    std::cout << "All pairs that sum to " << target << ":" << std::endl;
    for (const auto& pair : result) {
        std::cout << pair[0] << " + " << pair[1] << std::endl;
    }
    
    return 0;
}
```

### 解法5：三数之和扩展

```cpp
#include <vector>
#include <algorithm>
#include <iostream>

class Solution {
public:
    std::vector<std::vector<int>> threeSum(std::vector<int>& nums, int target) {
        std::vector<std::vector<int>> result;
        std::sort(nums.begin(), nums.end());
        
        for (int i = 0; i < nums.size() - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            
            int left = i + 1;
            int right = nums.size() - 1;
            
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                
                if (sum == target) {
                    result.push_back({nums[i], nums[left], nums[right]});
                    
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    
                    left++;
                    right--;
                } else if (sum < target) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        
        return result;
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {-1, 0, 1, 2, -1, -4};
    int target = 0;
    
    std::vector<std::vector<int>> result = solution.threeSum(nums, target);
    std::cout << "Triplets that sum to " << target << ":" << std::endl;
    for (const auto& triplet : result) {
        std::cout << triplet[0] << " + " << triplet[1] << " + " << triplet[2] << std::endl;
    }
    
    return 0;
}
```

### 边界情况处理

```cpp
#include <vector>
#include <unordered_map>
#include <iostream>

class Solution {
public:
    std::vector<int> twoSum(std::vector<int>& nums, int target) {
        std::unordered_map<int, int> numToIndex;
        
        for (int i = 0; i < nums.size(); i++) {
            int complement = target - nums[i];
            
            if (numToIndex.find(complement) != numToIndex.end()) {
                return {numToIndex[complement], i};
            }
            
            numToIndex[nums[i]] = i;
        }
        
        return {};
    }
    
    void testEdgeCases() {
        std::vector<std::pair<std::vector<int>, int>> testCases = {
            {{}, 5},
            {{1}, 2},
            {{1, 2, 3, 4}, 7},
            {{-1, -2, -3, -4, 5}, 1},
            {{0, 4, 3, 0}, 0},
            {{3, 3}, 6}
        };
        
        for (auto& testCase : testCases) {
            auto nums = testCase.first;
            int target = testCase.second;
            
            auto result = twoSum(nums, target);
            
            std::cout << "Test case: target=" << target << std::endl;
            std::cout << "Array: ";
            for (int num : nums) {
                std::cout << num << " ";
            }
            std::cout << std::endl;
            
            if (!result.empty()) {
                std::cout << "Found: indices " << result[0] << ", " << result[1];
                std::cout << " (values " << nums[result[0]] << " + " << nums[result[1]] << ")" << std::endl;
            } else {
                std::cout << "No solution found" << std::endl;
            }
            std::cout << std::endl;
        }
    }
};

int main() {
    Solution solution;
    solution.testEdgeCases();
    return 0;
}
```

### 总结

**解题思路：**
1. 暴力枚举：简单直观，但效率低
2. 哈希表：最优解，时间复杂度O(n)
3. 双指针：需要排序，适合有序数组

**关键点：**
- 理解题目要求：找出两个数的下标
- 考虑边界情况：空数组、单元素、重复元素、负数
- 选择合适的数据结构：哈希表提供O(1)查找
- 注意不重复使用相同元素

**时间复杂度对比：**
- 暴力枚举：O(n²)
- 哈希表：O(n)
- 双指针：O(n log n) + O(n) = O(n log n)

**空间复杂度对比：**
- 暴力枚举：O(1)
- 哈希表：O(n)
- 双指针：O(n)（需要存储索引）

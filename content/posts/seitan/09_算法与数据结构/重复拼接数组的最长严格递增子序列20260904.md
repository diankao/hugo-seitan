# 重复拼接数组的最长严格递增子序列

## 题目

给定长度为 n 的数组 {a1, a2, …, an}，将其与自身完全相同的副本连续拼接到末尾，共拼接 10^9 次，得到长度为 n×(10^9+1) 的新数组 a′（对任意 n < i ≤ n×(10^9+1) 有 a′i = a′i−n）。求新数组 a′ 的最长**严格递增子序列**的长度。

子序列：从原序列删除任意个元素（可以为零、可以为全部）后按原相对顺序得到的新序列。严格递增：相邻元素满足 b1 < b2 < … < bk。

## 考察点

从问题的极端规模反推本质：严格递增 + 无限重复拼接 ⇒ 答案与顺序无关，只与不同元素的个数有关。

## 回答要点

### 1. 算法思想

三步推理：

1. **严格递增 ⇒ 每个值最多取一次**：子序列中不能出现两个相等的元素，所以答案的上限是数组中不同值的个数 d；
2. **重复次数足够多 ⇒ 上限可以达到**：把 d 个不同值从小到大排列，第一个值在原数组里取，第二个值总能在它的**下一份拷贝**里找到出现位置，以此类推。只要拷贝份数（10^9+1）不少于 d（题目里 n 远小于 10^9，d ≤ n），这 d 个值就能按升序依次取到；
3. 结论：**答案 = 数组中不同元素的个数**，与元素顺序无关。

因此不需要真的拼接，也不需要做 O(n log n) 的 LIS，直接用 set 去重计数即可，复杂度 O(n log n)（或用哈希 O(n)）。

### 2. 参考实现

```python
import sys

input = sys.stdin.readline
t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(len(set(a)))
```

C++ 版本：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        unordered_set<int> s;
        while (n--) {
            int x;
            cin >> x;
            s.insert(x);
        }
        cout << s.size() << '\n';
    }
    return 0;
}
```

### 3. 小结

看到"拼接 10^9 次"这种天文数字，先想**不是模拟**，而是问"重复之后什么性质变了"：严格递增子序列在无限重复下退化为"不同值计数"。同类信号还有"对 10^9+7 取模"（周期性）、"n ≤ 20"（状压/枚举）。

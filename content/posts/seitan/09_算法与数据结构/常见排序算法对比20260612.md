# 常见排序算法对比

## 题目

介绍几种排序算法及其优劣情况。

## 考察点

常见排序算法的思想、时间/空间复杂度、稳定性、适用场景。

## 回答要点

### 1. 总览对比表

| 算法 | 平均时间 | 最坏时间 | 最好时间 | 空间 | 稳定性 | 基本思想 |
|------|---------|---------|---------|------|--------|---------|
| 冒泡排序 | O(n²) | O(n²) | O(n) | O(1) | 稳定 | 相邻元素两两比较交换 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 | 每轮选最小放前面 |
| 插入排序 | O(n²) | O(n²) | O(n) | O(1) | 稳定 | 将元素插入已排序序列 |
| 快速排序 | O(nlogn) | O(n²) | O(nlogn) | O(logn) | 不稳定 | 分治，选基准分区 |
| 归并排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(n) | 稳定 | 分治，合并有序子序列 |
| 堆排序 | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | 不稳定 | 堆结构，反复取堆顶 |

**稳定性**：相等元素的相对顺序是否保持不变。稳定排序在多关键字排序时很重要。

### 2. 冒泡排序（Bubble Sort）

**思想**：从头到尾两两比较，大的往后冒泡。每轮把当前未排序部分的最大值"冒泡"到末尾。

```c
void bubble_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
                swapped = 1;
            }
        }
        if (!swapped) break;  // 优化：某轮无交换说明已有序
    }
}
```

**优点**：实现简单、稳定、适合小数据量或基本有序的数据。
**缺点**：O(n²) 时间复杂度，大数据量时效率低。

### 3. 选择排序（Selection Sort）

**思想**：每轮从未排序部分找到最小元素，放到已排序部分的末尾。

```c
void selection_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[min_idx]) {
                min_idx = j;
            }
        }
        if (min_idx != i) {
            int tmp = arr[i];
            arr[i] = arr[min_idx];
            arr[min_idx] = tmp;
        }
    }
}
```

**优点**：交换次数最少（最多 n-1 次）、实现简单。
**缺点**：不稳定（如 `[5, 5, 2]` 第一次交换后两个 5 的相对顺序变了）、无论数据是否有序都是 O(n²)。

### 4. 插入排序（Insertion Sort）

**思想**：将每个元素插入到前面已排序序列的正确位置（类似整理扑克牌）。

```c
void insertion_sort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

**优点**：稳定、对基本有序的数据效率高（接近 O(n)）、适合小数据量。
**缺点**：大数据量时 O(n²) 效率低。

**嵌入式应用**：数据量小或基本有序时（如传感器数据缓冲区的增量排序），插入排序比快排更实用。

### 5. 快速排序（Quick Sort）

**思想**：选一个基准值（pivot），将数组分成两部分——左边比 pivot 小，右边比 pivot 大，然后递归排序左右两部分。

```c
void quick_sort(int arr[], int left, int right) {
    if (left >= right) return;

    // 选最右元素为基准
    int pivot = arr[right];
    int i = left;

    for (int j = left; j < right; j++) {
        if (arr[j] <= pivot) {
            int tmp = arr[i];
            arr[i] = arr[j];
            arr[j] = tmp;
            i++;
        }
    }

    // pivot 放到正确位置
    int tmp = arr[i];
    arr[i] = arr[right];
    arr[right] = tmp;

    quick_sort(arr, left, i - 1);
    quick_sort(arr, i + 1, right);
}
```

**优点**：平均 O(nlogn) 且常数因子小，实际运行最快。
**缺点**：最坏 O(n²)（已排序数组 + 选端点为 pivot）、不稳定、递归栈空间 O(logn)。

**优化**：随机选 pivot 或三数取中法避免最坏情况。

### 6. 归并排序（Merge Sort）

**思想**：将数组不断二分，直到每部分只有一个元素，然后两两合并为有序序列。

```c
void merge(int arr[], int left, int mid, int right, int tmp[]) {
    int i = left, j = mid + 1, k = left;

    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) tmp[k++] = arr[i++];
        else                  tmp[k++] = arr[j++];
    }
    while (i <= mid)   tmp[k++] = arr[i++];
    while (j <= right) tmp[k++] = arr[j++];

    for (int i = left; i <= right; i++) arr[i] = tmp[i];
}

void merge_sort(int arr[], int left, int right, int tmp[]) {
    if (left >= right) return;
    int mid = (left + right) / 2;
    merge_sort(arr, left, mid, tmp);
    merge_sort(arr, mid + 1, right, tmp);
    merge(arr, left, mid, right, tmp);
}
```

**优点**：稳定、时间复杂度恒为 O(nlogn)、适合链表排序和外部排序。
**缺点**：需要 O(n) 额外空间。

### 7. 堆排序（Heap Sort）

**思想**：将数组建成最大堆，反复取堆顶（最大值）放到末尾，然后调整堆。

```c
void heapify(int arr[], int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && arr[left] > arr[largest])  largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;

    if (largest != i) {
        int tmp = arr[i];
        arr[i] = arr[largest];
        arr[largest] = tmp;
        heapify(arr, n, largest);
    }
}

void heap_sort(int arr[], int n) {
    // 建堆
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(arr, n, i);

    // 逐个取出堆顶
    for (int i = n - 1; i > 0; i--) {
        int tmp = arr[0];
        arr[0] = arr[i];
        arr[i] = tmp;
        heapify(arr, i, 0);
    }
}
```

**优点**：时间 O(nlogn) 且空间 O(1)、不需要额外内存。
**缺点**：不稳定、实际运行比快排慢（缓存不友好）。

### 8. 面试中如何回答

1. 先说**总览**：列出 6 种常见排序及其时间复杂度
2. 再说**最常用的**：重点讲快排（思想 + 最坏情况 + 优化）
3. 提**稳定性**：什么时候需要稳定排序（多关键字排序）
4. 结合**场景**：小数据量用插入排序，大数据量用快排，需要稳定用归并，内存受限用堆排序

# 链表基础与识别方法

## 标签

## 问题描述
1. 链表（单向链表）介绍

## 参考答案
### 1. 单向链表介绍

**链表定义：**
链表是一种动态数据结构，由节点组成，每个节点包含数据和指向下一个节点的指针。

**单向链表结构：**
```c
struct ListNode {
    int data;              // 数据域
    struct ListNode *next;  // 指针域，指向下一个节点
};
```

**单向链表特点：**
- **动态分配**：节点在堆内存中动态分配，大小可变
- **非连续存储**：节点在内存中不连续，通过指针链接
- **插入删除高效**：O(1)时间复杂度，只需修改指针
- **随机访问低效**：需要从头遍历，O(n)时间复杂度
- **内存开销**：每个节点额外需要存储指针

**基本操作：**
```c
// 创建节点
struct ListNode* createNode(int data) {
    struct ListNode* node = (struct ListNode*)malloc(sizeof(struct ListNode));
    node->data = data;
    node->next = NULL;
    return node;
}

// 头部插入
void insertHead(struct ListNode** head, int data) {
    struct ListNode* node = createNode(data);
    node->next = *head;
    *head = node;
}

// 尾部插入
void insertTail(struct ListNode** head, int data) {
    struct ListNode* node = createNode(data);
    if (*head == NULL) {
        *head = node;
        return;
    }
    struct ListNode* current = *head;
    while (current->next != NULL) {
        current = current->next;
    }
    current->next = node;
}

// 删除节点
void deleteNode(struct ListNode** head, int data) {
    if (*head == NULL) return;
    
    if ((*head)->data == data) {
        struct ListNode* temp = *head;
        *head = (*head)->next;
        free(temp);
        return;
    }
    
    struct ListNode* current = *head;
    while (current->next != NULL && current->next->data != data) {
        current = current->next;
    }
    
    if (current->next != NULL) {
        struct ListNode* temp = current->next;
        current->next = temp->next;
        free(temp);
    }
}
```

### 2. 识别链表的头和尾

**识别链表头：**
- **定义方式**：链表头通常通过一个头指针维护
  ```c
  struct ListNode* head = NULL;  // 空链表
  ```
- **头指针特点**：
  - 指向链表的第一个节点
  - 是访问整个链表的唯一入口
  - 头指针为NULL表示空链表
- **保护头指针**：实际应用中常使用虚拟头节点简化操作
  ```c
  struct ListNode dummy;  // 虚拟头节点
  dummy.next = head;
  ```

**识别链表尾：**
- **遍历查找**：从头节点遍历，直到next指针为NULL
  ```c
  struct ListNode* findTail(struct ListNode* head) {
      if (head == NULL) return NULL;
      
      struct ListNode* current = head;
      while (current->next != NULL) {
          current = current->next;
      }
      return current;
  }
  ```
- **尾节点特征**：
  - next指针值为NULL
  - 是链表的最后一个节点
- **维护尾指针**：频繁在尾部操作时，可维护尾指针
  ```c
  struct ListNode* head = NULL;
  struct ListNode* tail = NULL;
  
  void insertWithTail(int data) {
      struct ListNode* node = createNode(data);
      if (head == NULL) {
          head = tail = node;
      } else {
          tail->next = node;
          tail = node;
      }
  }
  ```

**嵌入式系统中的链表应用：**
- **任务链表**：RTOS中管理就绪任务
- **设备链表**：管理驱动设备
- **内存块链表**：内存池管理
- **事件队列**：实现消息队列

**注意事项：**
- **内存泄漏**：删除节点时要释放内存
- **野指针**：删除节点后要置NULL
- **遍历安全**：删除节点时注意保持遍历指针
- **嵌入式限制**：频繁malloc/free可能导致碎片化，建议使用内存池

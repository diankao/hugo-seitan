# 数组与链表的区别

## 题目

数组和链表的区别是什么？

## 考察点

线性表的两种基本存储结构（顺序存储 vs 链式存储）、内存布局差异、随机访问与插入删除性能差异、空间开销、各自适用场景。

## 回答要点

### 1. 核心对比表

| 维度 | 数组（Array） | 链表（Linked List） |
|------|--------------|--------------------|
| 内存分配 | 连续内存空间 | 离散内存，节点间通过指针连接 |
| 大小 | 静态数组固定，动态数组需整体搬迁 | 动态增长，按需分配节点 |
| 随机访问 | O(1)，下标直接计算地址 `base + i*size` | O(n)，需从头遍历 |
| 头部插入/删除 | O(n)，需要移动元素 | O(1)，修改指针即可 |
| 中间插入/删除 | O(n) | O(1)（已定位到节点时），查找 O(n) |
| 空间开销 | 仅存储数据本身，紧凑 | 每个节点额外存储指针（单链表多一个，双链表多两个） |
| 缓存友好性 | 高（连续内存，预取命中率高） | 低（节点分散，cache miss 频繁） |
| 扩容方式 | 静态数组不可扩；动态数组翻倍扩容并整体拷贝 | 天然支持按节点扩容 |

### 2. 内存布局示意

```c
// 数组：连续内存
int arr[5] = {10, 20, 30, 40, 50};
// 内存：[10][20][30][40][50]   <- 地址连续
//       arr[0]            arr[4]

// 单链表：离散内存 + 指针
struct Node {
    int data;
    struct Node* next;
};
// 内存：[10|*] -> [30|*] -> [20|*] -> NULL
//       地址不连续，靠 next 串起来
```

### 3. 随机访问性能差异本质

数组下标访问能 O(1) 的关键是**地址可计算**：

```c
// arr[i] 的地址 = 基地址 + i * sizeof(元素)
int* elem = (int*)((char*)arr + i * sizeof(int));
```

链表节点地址无规律，只能从 head 开始逐个 `next` 跳转，所以是 O(n)。

### 4. 插入/删除性能差异本质

**数组**插入/删除需要搬运后续元素以保持连续性：

```c
// 在下标 i 处插入元素：i 之后的所有元素都要后移
for (int j = n; j > i; j--) {
    arr[j] = arr[j - 1];
}
arr[i] = value;
```

**链表**插入/删除只需改指针，不搬数据（前提是已拿到目标位置的前驱节点）：

```c
// 在节点 p 之后插入新节点 s
s->next = p->next;
p->next = s;
```

> 注意：链表"O(1) 插入"指的是**修改指针**本身，若还需查找定位，整体仍是 O(n)。

### 5. 动态数组的扩容代价

```c
// std::vector / 动态数组扩容流程
// 1. 申请更大的新内存（通常 2 倍）
// 2. 逐个拷贝旧元素到新内存
// 3. 释放旧内存
// 单次扩容 O(n)，但均摊（amortized）后每次 push_back 是 O(1)
```

链表不需要扩容，但每次插入都要 `malloc` 一个新节点，频繁分配有系统调用开销且易产生内存碎片。

### 6. 适用场景

| 场景 | 优先选择 |
|------|---------|
| 频繁按下标读，元素个数大致已知 | 数组（环形缓冲区、查表、DMA 缓冲） |
| 频繁在头部/中间插入删除 | 链表（任务队列、消息链） |
| 内存碎片敏感、需稳定地址 | 链表（节点地址固定，不随增删失效） |
| 数据量大、需遍历密集访问 | 数组（cache 友好，性能远超链表） |
| 嵌入式实时系统、禁止动态分配 | 静态数组 + 环形缓冲（避免 malloc） |

### 7. 嵌入式开发的实际取舍

嵌入式场景中**很少直接用 malloc 链表**，原因：
- 动态分配引入不确定性延迟、内存碎片
- 实时性要求下避免堆操作

常见替代方案是**静态数组实现的链表（数组链表/索引链表）**：用数组存储节点，用下标代替指针连接，兼顾随机访问和 O(1) 插入，且无动态分配。

```c
#define POOL_SIZE 64
struct Node {
    int data;
    int next;   // 存下标，-1 表示结束
};
struct Node pool[POOL_SIZE];   // 静态池
int head = -1;
int free_list = 0;             // 空闲链表头
```

### 8. 一句话总结

数组胜在**连续内存带来的随机访问 O(1) 和缓存友好**，链表胜在**非连续内存带来的插入删除 O(1) 和动态扩容**。选择依据是"读多还是写多""是否需要动态扩容""是否允许动态分配"。

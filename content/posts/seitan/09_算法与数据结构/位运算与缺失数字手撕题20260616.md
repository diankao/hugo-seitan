# 位运算与缺失数字手撕题

## 题目

二面手撕两道：

1. 给出一个数，求它转化成二进制后 `1` 的个数。
2. 给出一个 n 个数的整数数组，其中最大值不超过 n、无重复元素，找出 `[0, n]` 中缺失的那一个数。

## 考察点

位运算基础、`n & (n-1)` 技巧、异或性质、数学求差法、边界处理。

## 回答要点

### 题一：二进制中 1 的个数

#### 思想

核心是反复"消除最低位的 1"并计数。关键位运算技巧：`n & (n-1)` 会把 `n` 的最低有效位 1 翻转为 0，其余位不变。能执行多少次这个操作，就有多少个 1。

#### 过程示意（以 n = 13，二进制 1101 为例）

```
n       = 1101   n & (n-1) = 1101 & 1100 = 1100   count=1
n       = 1100   n & (n-1) = 1100 & 1011 = 1000   count=2
n       = 1000   n & (n-1) = 1000 & 0111 = 0000   count=3
n       = 0      结束
共 3 个 1
```

#### 思路要点

- 用 `while (n)` 配合 `n &= (n - 1)`，循环次数等于 1 的个数，比逐位右移（固定 32 次）更高效。
- 注意负数场景：若用有符号 `int`，右移会高位补 1 导致死循环，建议按无符号处理或改用 `n & (n-1)` 法（此法不依赖右移，对补码负数也正确）。

#### 参考实现

```c
int count_one(int n) {
    int cnt = 0;
    unsigned int x = (unsigned int)n;   // 转无符号避免负数右移问题
    while (x) {
        x &= (x - 1);   // 抹掉最低位的 1
        cnt++;
    }
    return cnt;
}
```

> 另有查表法（按字节预存 0~255 的 1 的个数）和 `__builtin_popcount` 内建函数，嵌入式里查表法最稳。

### 题二：[0, n] 中缺失的数字

#### 题目变形

数组有 n 个元素，取值在 `[0, n]` 内且无重复，意味着恰好缺失一个数。本质就是经典"丢失的数字"题（LeetCode 268）。

#### 方法一：数学求差法（最直观）

`[0, n]` 完整序列的和为 `n*(n+1)/2`，用总和减去数组实际和，差值就是缺失的数。

- 时间 O(n)，空间 O(1)
- 注意 n 较大时的整型溢出，用更大类型承载求和

```c
// 思想：sum(0..n) - sum(nums)
int missingNumber(int* nums, int n) {
    int total = n * (n + 1) / 2;    // 注意数组长度是 n，范围是 [0,n]
    int sum = 0;
    for (int i = 0; i < n; i++) sum += nums[i];
    return total - sum;
}
```

#### 方法二：异或法（最优雅，防溢出）

利用异或的自反性 `a ^ a = 0` 和交换律：把数组每个元素与下标（及 n）全异或一遍，成对的会抵消，剩下的就是缺失的数。

- 时间 O(n)，空间 O(1)，无溢出风险
- 不依赖求和公式，更鲁棒

```c
// 思想：missing = (0^1^...^n) ^ (nums[0]^nums[1]^...^nums[n-1])
int missingNumber(int* nums, int n) {
    int x = n;                      // 先把 n 放进去
    for (int i = 0; i < n; i++) {
        x ^= i ^ nums[i];          // 下标 i 与元素 nums[i] 配对异或
    }
    return x;
}
```

> 原理：完整的 `[0, n]` 共 n+1 个数，数组里只有 n 个。把"下标 0..n-1"和"元素"逐个异或，再补一个 n，所有出现的数都成对抵消，唯独缺失那个数只出现一次，留在结果里。

#### 方法对比

| 方法 | 时间 | 空间 | 优点 | 缺点 |
|------|------|------|------|------|
| 排序后查相邻 | O(nlogn) | O(1) | 直观 | 慢，改原数组 |
| 哈希表 | O(n) | O(n) | 简单 | 额外空间 |
| 数学求差 | O(n) | O(1) | 最快 | 大 n 可能溢出 |
| 异或 | O(n) | O(1) | 无溢出、不改原数组 | 理解门槛稍高 |

**推荐回答顺序**：先讲数学求差法（秒解），再讲异或法（展示位运算功底），面试官加分。

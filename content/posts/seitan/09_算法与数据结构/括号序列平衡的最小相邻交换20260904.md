# 括号序列平衡的最小相邻交换

## 题目

平衡括号序列的归纳定义：空串是平衡的；若 A 平衡则 `(A)` 平衡；若 A、B 均平衡则 `AB` 平衡。

给定一个偶数长度、左右括号数量相等的括号序列 s（仅含 `(` 与 `)`）。每次操作可选择相邻两个字符交换。求使 s 变为平衡括号序列所需的**最少相邻交换次数**。

## 考察点

贪心策略与逆序对思想：前缀中"多出来的右括号"必须整体左移越过后续的左括号，代价可以 O(n) 一次累加出来。

## 回答要点

### 1. 算法思想

从左到右扫描，维护一个计数器 `balance`：遇到 `(` 加一，遇到 `)` 减一。正常情况下任意前缀的 balance 都不应为负，为负就说明前面有"暂时配不上对"的右括号。

关键观察：**多出来的右括号一定是连续的一段**（贪心地看，能匹配的早就被前面的左括号消费掉了）。当扫描到一个 `(` 而 `balance < 0` 时，前面累积的 `|balance|` 个失配右括号必须全部越过这个 `(`（移动到它左边）才能与更后面的左括号重新配对——把连续一段右括号与一个左括号交叉换位，恰好需要 `|balance|` 次相邻交换。累加这个代价后 `balance` 加一，继续扫描。

由于左右括号数量相等，最终 balance 归零，累加值即最少交换次数，复杂度 O(n)。

### 2. 参考实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t;
    cin >> t;
    while (t--) {
        int n;
        string s;
        cin >> n >> s;
        long long ans = 0;
        long long balance = 0;
        for (char c : s) {
            if (c == '(') {
                if (balance < 0)
                    ans += -balance;
                balance++;
            } else {
                balance--;
            }
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 3. 小结

本质是"失配的右括号段"与"后续左括号"之间的**交叉计数**（类似逆序对），但因为失配段连续，可以不用树状数组，一次线性扫描就把代价加完。同类题型：交换相邻字符使字符串有序/回文，都是统计"必须跨越的配对数"。

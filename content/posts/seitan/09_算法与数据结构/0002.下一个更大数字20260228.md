# 下一个更大数字

## 题目

找出数组里的下一个更大的数字（可以循环查找）。

输入：[2,5,3,7,2,6,9,3]
输出：[5,7,7,9,6,9,-1,5]

## 答案

### 题目描述

给定一个循环数组，对于数组中的每个元素，找到下一个比它大的元素，返回对应的结果数组。如果不存在更大的元素，返回-1。

### 解法1：暴力枚举

```cpp
#include <vector>
#include <iostream>

class Solution {
public:
    std::vector<int> nextGreaterElements(std::vector<int>& nums) {
        int n = nums.size();
        std::vector<int> result(n, -1);
        
        for (int i = 0; i < n; i++) {
            for (int j = 1; j < n; j++) {
                int nextIndex = (i + j) % n;
                if (nums[nextIndex] > nums[i]) {
                    result[i] = nums[nextIndex];
                    break;
                }
            }
        }
        
        return result;
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {2, 5, 3, 7, 2, 6, 9, 3};
    
    std::vector<int> result = solution.nextGreaterElements(nums);
    
    std::cout << "Input: [";
    for (int i = 0; i < nums.size(); i++) {
        std::cout << nums[i];
        if (i < nums.size() - 1) std::cout << ", ";
    }
    std::cout << "]" << std::endl;
    
    std::cout << "Output: [";
    for (int i = 0; i < result.size(); i++) {
        std::cout << result[i];
        if (i < result.size() - 1) std::cout << ", ";
    }
    std::cout << "]" << std::endl;
    
    return 0;
}
```

**时间复杂度：** O(n²)
**空间复杂度：** O(n)

### 解法2：单调栈

```cpp
#include <vector>
#include <stack>
#include <iostream>

class Solution {
public:
    std::vector<int> nextGreaterElements(std::vector<int>& nums) {
        int n = nums.size();
        std::vector<int> result(n, -1);
        std::stack<int> st;
        
        for (int i = 0; i < 2 * n; i++) {
            int index = i % n;
            
            while (!st.empty() && nums[st.top()] < nums[index]) {
                result[st.top()] = nums[index];
                st.pop();
            }
            
            if (i < n) {
                st.push(index);
            }
        }
        
        return result;
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {2, 5, 3, 7, 2, 6, 9, 3};
    
    std::vector<int> result = solution.nextGreaterElements(nums);
    
    std::cout << "Input: [";
    for (int i = 0; i < nums.size(); i++) {
        std::cout << nums[i];
        if (i < nums.size() - 1) std::cout << ", ";
    }
    std::cout << "]" << std::endl;

        std::cout << result[i];
        if (i < result.size() - 1) std::cout << ", ";
    }
    std::cout << "]" << std::endl;
    
    return 0;
}
```

### 解法3：单调栈优化版

```cpp
class Solution {
public:
    std::vector<int> nextGreaterElements(std::vector<int>& nums) {
        int n = nums.size();
        std::vector<int> result(n, -1);
        std::stack<int> st;
        
        for (int i = 2 * n - 1; i >= 0; i--) {
            int index = i % n;
```

### 解法4：带索引的详细过程

```cpp
#include <vector>
#include <stack>
#include <iostream>

class Solution {
public:
    std::vector<int> nextGreaterElements(std::vector<int>& nums) {
        int n = nums.size();
        std::vector<int> result(n, -1);
        std::stack<int> st;
        
        std::cout << "Processing circular array:" << std::endl;
        
        for (int i = 0; i < 2 * n; i++) {
            int index = i % n;
            
            std::cout << "Step " << i << ": processing nums[" << index << "] = " << nums[index] << std::endl;
            std::cout << "  Stack: ";
            printStack(st);
            
            while (!st.empty() && nums[st.top()] < nums[index]) {
                int popped = st.top();
                result[popped] = nums[index];
                st.pop();
                std::cout << "  Found next greater for nums[" << popped << "]: " << nums[index] << std::endl;
            }
            
            if (i < n) {
                st.push(index);
                std::cout << "  Pushed index " << index << " to stack" << std::endl;
            }
            
            std::cout << "  Result: [";
            for (int j = 0; j < result.size(); j++) {
                std::cout << result[j];
                if (j < result.size() - 1) std::cout << ", ";
            }
            std::cout << "]" << std::endl << std::endl;
        }
        
        return result;
    }
    
private:
    void printStack(std::stack<int> st) {
        if (st.empty()) {
            std::cout << "empty" << std::endl;
            return;
        }
        
        std::vector<int> temp;
        while (!st.empty()) {
            temp.push_back(st.top());
            st.pop();
        }
        
        std::cout << "[";
        for (int i = temp.size() - 1; i >= 0; i--) {
            std::cout << temp[i];
            if (i > 0) std::cout << ", ";
        }
        std::cout << "]" << std::endl;
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {2, 5, 3, 7, 2, 6, 9, 3};
    
    std::vector<int> result = solution.nextGreaterElements(nums);
    
    std::cout << "\nFinal Output: [";
    for (int i = 0; i < result.size(); i++) {
        std::cout << result[i];
        if (i < result.size() - 1) std::cout << ", ";
    }
```

```cpp
        int n = nums.size();
```

```cpp
            for (int j = 1; j < n; j++) {
                int nextIndex = (i + j) % n;
                if (nums[nextIndex] > nums[i]) {
                    result[i] = nums[nextIndex];
                    break;
                }
            }
        }
        
        return result;
    }

        int n = nums.size();
        std::vector<int> result(n, -1);
        std::stack<int> st;
        
        for (int i = 0; i < 2 * n; i++) {
            int index = i % n;
            
            while (!st.empty() && nums[st.top()] < nums[index]) {
                result[st.top()] = nums[index];
                st.pop();
            }
            
            if (i < n) {
                st.push(index);
            }
        }
        
        return result;
    }
};
```

### 总结

**解题思路：**
1. 暴力枚举：对每个元素向后查找，简单但效率低
2. 单调栈：维护一个单调递减栈，从右向左或从左向右遍历
3. 循环处理：将数组长度翻倍处理循环问题

**关键点：**
- 理解循环数组的处理方式：遍历2n次，使用i % n获取实际索引
- 单调栈的性质：栈中元素保持单调递减，遇到更大元素时弹出
- 时间复杂度优化：从O(n²)优化到O(n)

**单调栈原理：**
- 栈中存储的是还未找到下一个更大元素的索引
- 当遇到一个更大的元素时，它就是栈中所有较小元素的下一个更大元素
- 每个元素最多入栈出栈一次，所以总时间复杂度是O(n)

**时间复杂度对比：**
- 暴力枚举：O(n²)
- 单调栈：O(n)

**空间复杂度对比：**
- 暴力枚举：O(n)（存储结果）
- 单调栈：O(n)（栈空间）

# 相反数的个数算法实现

## 题目

给定一个整数数组，统计其中相反数的个数。如果数组中有 a 和 -a，则称 a 和 -a 为相反数。

## 考察点

算法思维、哈希表、时间复杂度

## 回答要点

### 1. 问题理解

#### 示例
```
输入：[1, 2, 3, -1, -2, 4]
输出：2
解释：1 和 -1 是相反数，2 和 -2 是相反数，共 2 对

输入：[1, 2, 3, 4, 5]
输出：0
解释：没有相反数

输入：[1, -1, 2, -2, 3, -3]
输出：3
解释：3 对相反数
```

### 2. 解法一：暴力法

#### 思路
对于每个元素，遍历数组查找其相反数。

```cpp
#include <vector>
#include <iostream>

int countOppositeNumbersBruteForce(const std::vector<int>& nums) {
    int count = 0;
    int n = nums.size();

    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (nums[i] == -nums[j]) {
                count++;
                // 标记已匹配，避免重复计算
                break;
            }
        }
    }

    return count;
}

int main() {
    std::vector<int> nums = {1, 2, 3, -1, -2, 4};
    std::cout << countOppositeNumbersBruteForce(nums) << std::endl;
    return 0;
}
```

#### 复杂度分析
- 时间复杂度：O(n²)
- 空间复杂度：O(1)

### 3. 解法二：哈希表（推荐）

#### 思路
使用哈希表记录已遍历的元素，对于每个元素，检查其相反数是否在哈希表中。

```cpp
#include <vector>
#include <unordered_set>
#include <iostream>

int countOppositeNumbersHash(const std::vector<int>& nums) {
    std::unordered_set<int> seen;
    int count = 0;

    for (int num : nums) {
        // 检查相反数是否已存在
        if (seen.count(-num)) {
            count++;
        }
        // 将当前数加入哈希表
        seen.insert(num);
    }

    return count;
}

int main() {
    std::vector<int> nums = {1, 2, 3, -1, -2, 4};
    std::cout << countOppositeNumbersHash(nums) << std::endl;
    return 0;
}
```

#### 复杂度分析
- 时间复杂度：O(n)
- 空间复杂度：O(n)

### 4. 解法三：排序 + 双指针

#### 思路
先排序数组，然后使用双指针从两端向中间遍历。

```cpp
#include <vector>
#include <algorithm>
#include <iostream>

int countOppositeNumbersSort(const std::vector<int>& nums) {
    std::vector<int> sorted(nums);
    std::sort(sorted.begin(), sorted.end());

    int left = 0;
    int right = sorted.size() - 1;
    int count = 0;

    while (left < right) {
        int sum = sorted[left] + sorted[right];

        if (sum == 0) {
            count++;
            left++;
            right--;
        } else if (sum < 0) {
            left++;
        } else {
            right--;
        }
    }

    return count;
}

int main() {
    std::vector<int> nums = {1, 2, 3, -1, -2, 4};
    std::cout << countOppositeNumbersSort(nums) << std::endl;
    return 0;
}
```

#### 复杂度分析
- 时间复杂度：O(n log n)（排序）
- 空间复杂度：O(1)（如果不考虑排序的空间）

### 5. 边界情况处理

#### 处理 0
```cpp
int countOppositeNumbersWithZero(const std::vector<int>& nums) {
    std::unordered_set<int> seen;
    int count = 0;
    int zeroCount = 0;

    for (int num : nums) {
        if (num == 0) {
            zeroCount++;
        } else {
            if (seen.count(-num)) {
                count++;
            }
            seen.insert(num);
        }
    }

    // 0 的相反数还是 0，如果有多个 0，每两个 0 算一对
    count += zeroCount / 2;

    return count;
}
```

#### 处理重复元素
```cpp
int countOppositeNumbersWithDuplicates(const std::vector<int>& nums) {
    std::unordered_map<int, int> freq;
    int count = 0;

    // 统计频率
    for (int num : nums) {
        freq[num]++;
    }

    // 计数相反数对
    for (auto& [num, f] : freq) {
        if (num > 0 && freq.count(-num)) {
            count += std::min(f, freq[-num]);
        } else if (num == 0) {
            // 0 的处理
            count += f / 2;
            freq[num] = 0;  // 避免重复计算
        }
    }

    return count;
}
```

### 6. 完整实现

#### 综合版本
```cpp
#include <vector>
#include <unordered_map>
#include <algorithm>
#include <iostream>

class OppositeNumberCounter {
public:
    // 方法 1：哈希表（推荐）
    static int countByHash(const std::vector<int>& nums) {
        std::unordered_map<int, int> freq;
        int count = 0;

        for (int num : nums) {
            if (num == 0) {
                freq[num]++;
            } else {
                if (freq.count(-num)) {
                    count++;
                    freq[-num]--;  // 减少已匹配的数量
                }
                freq[num]++;
            }
        }

        // 处理 0 的情况
        count += freq[0] / 2;

        return count;
    }

    // 方法 2：排序 + 双指针
    static int countBySort(const std::vector<int>& nums) {
        std::vector<int> sorted(nums);
        std::sort(sorted.begin(), sorted.end());

        int left = 0;
        int right = sorted.size() - 1;
        int count = 0;

        while (left < right) {
            int sum = sorted[left] + sorted[right];

            if (sum == 0) {
                count++;

                // 处理重复元素
                int leftCount = 1;
                int rightCount = 1;

                while (left + 1 < right && sorted[left] == sorted[left + 1]) {
                    left++;
                    leftCount++;
                }

                while (right - 1 > left && sorted[right] == sorted[right - 1]) {
                    right--;
                    rightCount++;
                }

                count += std::min(leftCount, rightCount) - 1;
                left++;
                right--;
            } else if (sum < 0) {
                left++;
            } else {
                right--;
            }
        }

        return count;
    }
};

int main() {
    std::vector<std::vector<int>> testCases = {
        {1, 2, 3, -1, -2, 4},
        {1, 2, 3, 4, 5},
        {1, -1, 2, -2, 3, -3},
        {0, 0, 0},
        {1, 1, -1, -1, 2, -2},
        {}
    };

    for (const auto& testCase : testCases) {
        std::cout << "Input: ";
        for (int num : testCase) {
            std::cout << num << " ";
        }
        std::cout << std::endl;

        std::cout << "Hash method: "
                  << OppositeNumberCounter::countByHash(testCase) << std::endl;
        std::cout << "Sort method: "
                  << OppositeNumberCounter::countBySort(testCase) << std::endl;
        std::cout << std::endl;
    }

    return 0;
}
```

void testCountOppositeNumbers() {
    OppositeNumberCounter counter;

### 9. 优化建议

#### 根据数据特点选择方法
```cpp
// 如果数据范围小，可以使用数组代替哈希表
int countOppositeNumbersArray(const std::vector<int>& nums) {
    const int RANGE = 10000;
    int freq[2 * RANGE + 1] = {0};
    int count = 0;

    for (int num : nums) {
        int idx = num + RANGE;
        if (num == 0) {
            freq[idx]++;
        } else {
            int oppositeIdx = -num + RANGE;
            if (freq[oppositeIdx] > 0) {
                count++;
                freq[oppositeIdx]--;
            }
            freq[idx]++;
        }
    }

    count += freq[RANGE] / 2;  // 处理 0

    return count;
}
```

### 10. 总结

#### 解法对比

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 暴力法 | O(n²) | O(1) | 简单直观 | 性能差 |
| 哈希表 | O(n) | O(n) | 性能好 | 需要额外空间 |
| 排序 + 双指针 | O(n log n) | O(1) | 空间少 | 修改原数组 |

#### 推荐方案
- 一般情况：哈希表方法
- 内存受限：排序 + 双指针方法
- 数据范围小：数组计数方法

# 数字信号基础与采样定理

## 题目

1. 什么是采样定理？为什么采样频率必须大于信号最高频率的2倍？
2. 量化精度对信号有什么影响？脑电信号一般用多少位 ADC？

## 考察点

采样定理、奈奎斯特频率、混叠现象、量化误差、ADC 选型。

## 回答要点

### 1. 采样定理（奈奎斯特-香农采样定理）

**定理内容**：要从采样信号中无失真地恢复原始连续信号，采样频率必须大于信号最高频率的2倍喵~

$$f_s \geq 2 \cdot f_{max}$$

- $f_s$：采样频率
- $f_{max}$：信号最高频率分量
- $f_s / 2$：奈奎斯特频率（奈奎斯特极限）

### 2. 为什么必须大于2倍

#### 频域解释

采样在频域中等价于将原始频谱以 $f_s$ 为周期进行复制喵~

```
原始信号频谱：          ┌──┐
                       │  │ 0 ~ fmax
                ───────┘  └───────

采样后（fs > 2fmax）：  ┌──┐     ┌──┐
                       │  │     │  │
                ───────┘  └─────┘  └───
                       0  fmax  fs/2  fs

采样后（fs < 2fmax）：  ┌──┐
                       │  ├───┐  ← 频谱重叠！混叠！
                ───────┘  └───┘
                       0  fmax fs/2
```

当 $f_s < 2f_{max}$ 时，复制频谱与原始频谱重叠，高频分量"折叠"到低频，产生**混叠**，无法恢复喵~

#### 时域解释

```
信号频率 = 10 Hz，采样频率 = 15 Hz（< 2×10）

采样点看起来像 5 Hz 的信号！
这就是混叠：高频被"伪装"成低频

 ×    ×    ×         采样点
  \  / \  / \
   \/   \/   \/      实际10Hz信号
```

### 3. 脑电信号中的采样频率

| 脑电频段 | 频率范围 | 典型采样率 |
|---------|---------|-----------|
| δ (Delta) | 0.5~4 Hz | 250 Hz+ |
| θ (Theta) | 4~8 Hz | 250 Hz+ |
| α (Alpha) | 8~13 Hz | 250 Hz+ |
| β (Beta) | 13~30 Hz | 250 Hz+ |
| γ (Gamma) | 30~100 Hz | 500 Hz+ |
| 高频振荡 | 80~500 Hz | 1000 Hz+ |

**临床 EEG 常用采样率**：250 Hz、500 Hz、1000 Hz 喵~

**选择原则**：
- 研究低频段（δ~β）：250 Hz 足够
- 研究 γ 频段：至少 500 Hz
- 研究高频振荡（HFO）：1000 Hz 或更高
- 实际中通常取 $f_s = 4 \sim 10 \times f_{max}$，留出抗混叠滤波器过渡带

### 4. 抗混叠滤波器

在 ADC 之前必须加**低通滤波器**，滤除高于 $f_s/2$ 的频率分量喵~

```
原始信号 → 抗混叠滤波器 → ADC → 数字信号
              (模拟LPF)
```

| 参数 | 要求 |
|------|------|
| 截止频率 | $f_c < f_s / 2$ |
| 过渡带 | 越窄越好（需要高阶滤波器） |
| 阻带衰减 | 通常 > 40 dB |

### 5. 量化与量化误差

#### 量化精度

| ADC 位数 | 量化级数 | 动态范围 | 信噪比（SNR） |
|---------|---------|---------|--------------|
| 8 bit | 256 | 48 dB | ~48 dB |
| 12 bit | 4096 | 72 dB | ~72 dB |
| 16 bit | 65536 | 96 dB | ~96 dB |
| 24 bit | 16M+ | 144 dB | ~144 dB |

**理论信噪比**：$SNR \approx 6.02 \times N + 1.76$ dB（N 为位数）

#### 脑电 ADC 选型

脑电信号幅度通常为 **5~500 μV**，非常微弱喵~

| 方案 | 位数 | 适用场景 |
|------|------|---------|
| 16 bit ADC | 16 | 一般研究用途 |
| ADS1299 | 24 | 专业 EEG 采集（24位，内置放大器） |
| ADS1115 | 16 | 低成本方案 |

**为什么需要 24 位**：
- 脑电信号动态范围大（μV ~ mV）
- 需要同时分辨微弱信号和较大干扰
- 24 位提供 144 dB 动态范围，无需可变增益放大器

### 6. 量化误差的影响

```c
// 量化误差 = 量化值 - 真实值
// 最大量化误差 = ±(LSB / 2)
// LSB = Vref / (2^N)

// 24位 ADC，参考电压 4.5V
double lsb_24 = 4.5 / 16777216.0;    // ≈ 0.268 μV
double max_error = lsb_24 / 2.0;     // ≈ 0.134 μV

// 16位 ADC
double lsb_16 = 4.5 / 65536.0;       // ≈ 68.66 μV
double max_error_16 = lsb_16 / 2.0;  // ≈ 34.33 μV

// 脑电信号约 5~500 μV
// 16位量化误差（34 μV）可能淹没微弱脑电信号
// 24位量化误差（0.13 μV）远小于脑电信号
```

### 7. 总结

| 概念 | 关键公式/数值 |
|------|-------------|
| 采样定理 | $f_s \geq 2 f_{max}$ |
| 奈奎斯特频率 | $f_N = f_s / 2$ |
| 混叠 | $f_s < 2 f_{max}$ 时高频折叠到低频 |
| 量化信噪比 | $SNR \approx 6.02N + 1.76$ dB |
| 脑电采样率 | 250~1000 Hz |
| 脑电 ADC | 24 位（如 ADS1299） |

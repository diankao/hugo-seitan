# FIR与IIR滤波器设计与应用

## 题目

1. FIR滤波器和IIR滤波器有什么区别？各适合什么场景？
2. 脑电信号预处理中一般用什么滤波器？为什么？

## 考察点

FIR/IIR原理与对比、滤波器选型、脑电预处理中的滤波器应用。

## 回答要点

### 1. FIR 滤波器（有限脉冲响应）

#### 数学表达

$$y[n] = \sum_{k=0}^{N-1} h[k] \cdot x[n-k]$$

- 只依赖当前和过去的输入，**不依赖过去的输出**
- 脉冲响应 $h[k]$ 是有限长的（N 个系数）
- **永远是稳定的**（没有反馈回路）

#### C 语言实现

```c
#define FIR_ORDER  33

float fir_filter(float input, const float *coeffs, float *buffer, int order) {
    for (int i = order - 1; i > 0; i--) {
        buffer[i] = buffer[i - 1];
    }
    buffer[0] = input;

    float output = 0.0f;
    for (int i = 0; i < order; i++) {
        output += coeffs[i] * buffer[i];
    }

    return output;
}

// 33阶 FIR 带通滤波器（8~30 Hz，采样率250Hz）
float fir_bp_8_30hz[FIR_ORDER] = {
    -0.0021f, -0.0054f, -0.0089f, -0.0098f, -0.0052f,
     0.0054f,  0.0191f,  0.0301f,  0.0312f,  0.0185f,
    -0.0089f, -0.0398f, -0.0584f, -0.0503f, -0.0088f,
     0.0525f,  0.1050f,  0.1300f,  0.1050f,  0.0525f,
    -0.0088f, -0.0503f, -0.0584f, -0.0398f, -0.0089f,
     0.0185f,  0.0312f,  0.0301f,  0.0191f,  0.0054f,
    -0.0052f, -0.0098f, -0.0089f
};
```

### 2. IIR 滤波器（无限脉冲响应）

#### 数学表达（直接 II 型）

$$y[n] = \sum_{k=0}^{M} b[k] \cdot x[n-k] - \sum_{k=1}^{N} a[k] \cdot y[n-k]$$

- 同时依赖输入和**过去的输出**（有反馈）
- 脉冲响应理论上是无限长的
- **可能不稳定**（如果极点在单位圆外）

#### C 语言实现（双二阶级联）

```c
typedef struct {
    float b0, b1, b2;
    float a1, a2;
    float x1, x2;
    float y1, y2;
} biquad_t;

float biquad_process(biquad_t *bq, float input) {
    float output = bq->b0 * input
                 + bq->b1 * bq->x1
                 + bq->b2 * bq->x2
                 - bq->a1 * bq->y1
                 - bq->a2 * bq->y2;

    bq->x2 = bq->x1;
    bq->x1 = input;
    bq->y2 = bq->y1;
    bq->y1 = output;

    return output;
}

// 级联多个双二阶实现高阶 IIR
#define IIR_STAGES  4

typedef struct {
    biquad_t stages[IIR_STAGES];
} iir_cascade_t;

float iir_cascade_process(iir_cascade_t *filter, float input) {
    float sample = input;
    for (int i = 0; i < IIR_STAGES; i++) {
        sample = biquad_process(&filter->stages[i], sample);
    }
    return sample;
}
```

### 3. FIR 与 IIR 对比

| 对比项 | FIR | IIR |
|--------|-----|-----|
| 脉冲响应 | 有限长 | 无限长（有反馈） |
| 稳定性 | **永远稳定** | 可能不稳定 |
| 相位特性 | **严格线性相位**（对称系数时） | 非线性相位 |
| 阶数 | 高（相同指标下阶数远大于 IIR） | 低 |
| 计算量 | 大（阶数高） | 小（阶数低） |
| 设计方法 | 窗函数法、等波纹法 | 巴特沃斯、切比雪夫、椭圆 |
| 延迟 | 有群延迟（固定值） | 群延迟不恒定 |
| 内存占用 | 大（需要存 N 个历史样本） | 小 |

### 4. 脑电预处理中的滤波器

#### 典型预处理流程

```
原始EEG → 去直流/基线校正 → 带通滤波 → 陷波(50Hz) → 分段 → 后续分析
```

#### 常用滤波器选型

| 滤波目的 | 推荐类型 | 参数 |
|---------|---------|------|
| 带通滤波（保留脑电频段） | **FIR**（零相位） | 0.5~40 Hz 或 1~50 Hz |
| 陷波（去除工频干扰） | IIR 陷波 | 50 Hz 或 60 Hz |
| 高通（去基线漂移） | FIR 或 IIR | 0.5 Hz 或 1 Hz |
| 低通（去高频噪声） | FIR | 30~100 Hz |

#### 为什么脑电优先用 FIR

```python
# Python scipy 示例
from scipy.signal import firwin, filtfilt

fs = 250
cutoff = [0.5, 40.0]

# FIR 带通滤波器
numtaps = 101
b = firwin(numtaps, cutoff, pass_zero='bandpass', fs=fs)

# filtfilt 实现零相位滤波（正向+反向各滤一次）
filtered = filtfilt(b, [1.0], raw_eeg)
```

**脑电用 FIR 的原因**：

1. **线性相位**：脑电波形的时间关系很重要（如 ERP 峰值潜伏期），非线性相位会扭曲波形喵~
2. **零相位滤波**：用 `filtfilt`（正向+反向滤波）实现零相位延迟，不改变 ERP 峰值时间喵~
3. **稳定性**：FIR 永远稳定，不会因系数量化导致发散喵~
4. **嵌入式实现**：虽然计算量大，但结构简单，适合 MCU 上的 MAC（乘累加）操作喵~

### 6. 嵌入式实时滤波的注意事项

| 注意点 | 说明 |
|--------|------|
| 系数量化 | 浮点系数转为定点时可能改变频率响应，需仿真验证 |
| 阶数选择 | 嵌入式中 FIR 阶数不宜过高（64~128），否则实时性不够 |
| DMA + 双缓冲 | ADC 采集用 DMA，滤波在半传输完成中断中处理 |
| 定点优化 | 用 CMSIS-DSP 的 `arm_fir_f32` 或 `arm_biquad_cascade_df1_f32` |

```c
// CMSIS-DSP FIR 实现（ARM Cortex-M 优化）
#include "arm_math.h"

arm_fir_instance_f32 fir_instance;
float fir_state[BLOCK_SIZE + NUM_TAPS - 1];

arm_fir_init_f32(&fir_instance, NUM_TAPS, fir_coeffs, fir_state, BLOCK_SIZE);

// 在 DMA 半传输完成中断中调用
arm_fir_f32(&fir_instance, input_block, output_block, BLOCK_SIZE);
```

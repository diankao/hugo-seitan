# FFT频谱分析与窗函数

## 题目

1. FFT的原理是什么？频谱分辨率怎么计算？
2. 为什么要加窗函数？常见窗函数怎么选择？

## 考察点

DFT/FFT原理、频谱分辨率、频谱泄漏、窗函数选择。

## 回答要点

### 1. 从 DFT 到 FFT

#### DFT（离散傅里叶变换）

将时域信号变换到频域，分析信号包含哪些频率成分喵~

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-j \frac{2\pi}{N} kn}$$

- $N$ 个输入样本 → $N$ 个频率分量
- 计算量：$O(N^2)$（对每个 k 求和 N 次）

#### FFT（快速傅里叶变换）

利用旋转因子 $e^{-j\frac{2\pi}{N}kn}$ 的对称性和周期性，将 $O(N^2)$ 降到 $O(N \log N)$ 喵~

| N | DFT 运算量 | FFT 运算量 | 加速比 |
|---|-----------|-----------|--------|
| 256 | 65,536 | 2,048 | 32× |
| 1024 | 1,048,576 | 10,240 | 102× |
| 4096 | 16,777,216 | 49,152 | 341× |

**FFT 要求**：$N$ 必须是 2 的幂（基2-FFT），实际中不足时补零（zero-padding）喵~

### 2. 频谱分辨率

$$\Delta f = \frac{f_s}{N}$$

- $\Delta f$：频率分辨率（相邻频率点间距）
- $f_s$：采样频率
- $N$：FFT 点数

| 参数组合 | 频率分辨率 | 分析带宽 |
|---------|-----------|---------|
| fs=250Hz, N=256 | 0.977 Hz | 0~125 Hz |
| fs=250Hz, N=512 | 0.488 Hz | 0~125 Hz |
| fs=500Hz, N=1024 | 0.488 Hz | 0~250 Hz |
| fs=1000Hz, N=2048 | 0.488 Hz | 0~500 Hz |

**提高频率分辨率的方法**：
- 增加 $N$（更长数据段）
- 降低 $f_s$（但受限于奈奎斯特）
- 补零（提高频谱密度，但不增加真实分辨率）

### 3. 频谱泄漏

FFT 假设输入信号是**周期性的**，如果截取的数据不是整数个周期，在边界处会产生跳变，导致频率"泄漏"到邻近频点喵~

```
整数周期截取：          非整数周期截取：
 ┌───┐ ┌───┐          ┌──┐ ┌─┐
 │   │ │   │          │  │ │ | ← 边界跳变
 └───┘ └───┘          └──┘ └─┘
 频谱：尖锐的谱线      频谱：能量泄漏到邻近频率
```

**解决方法**：加窗函数喵~

### 4. 窗函数

窗函数将数据段的两端平滑地衰减到零，减少边界跳变喵~

$$x_{windowed}[n] = x[n] \cdot w[n], \quad n = 0, 1, ..., N-1$$

#### 常见窗函数对比

| 窗函数 | 主瓣宽度 | 旁瓣衰减 | 频率分辨率 | 适用场景 |
|--------|---------|---------|-----------|---------|
| 矩形窗（无窗） | 最窄 | -13 dB（最差） | 最高 | 相干信号、瞬态信号 |
| Hanning 窗 | 1.5×矩形 | -31 dB | 中等 | **脑电/一般信号** |
| Hamming 窗 | 1.5×矩形 | -42 dB | 中等 | 语音处理 |
| Blackman 窗 | 2×矩形 | -58 dB | 较低 | 需要高旁瓣抑制 |
| Flat-top 窗 | 3.5×矩形 | -44 dB | 最低 | 幅度精确测量 |

```c
// Hanning 窗生成
void hanning_window(float *window, int N) {
    for (int n = 0; n < N; n++) {
        window[n] = 0.5f * (1.0f - cosf(2.0f * 3.14159265f * n / (N - 1)));
    }
}

// 加窗 + FFT 流程
void compute_spectrum(float *signal, int N, float *spectrum) {
    float window[N];
    hanning_window(window, N);

    for (int i = 0; i < N; i++) {
        signal[i] *= window[i];
    }

    arm_rfft_fast_instance_f32 fft_inst;
    arm_rfft_fast_init_f32(&fft_inst, N);
    arm_rfft_fast_f32(&fft_inst, signal, spectrum, 0);

    for (int i = 0; i < N / 2; i++) {
        float real = spectrum[2 * i];
        float imag = spectrum[2 * i + 1];
        spectrum[i] = sqrtf(real * real + imag * imag) / N;
    }
}
```

### 5. 脑电频谱分析中的选择

| 场景 | 窗函数 | FFT 点数 | 说明 |
|------|--------|---------|------|
| 静息态脑电频谱 | Hanning | 512~2048 | 平衡分辨率与旁瓣抑制 |
| ERP 频谱 | 矩形窗 | 按段长 | ERP 已分段对齐，边界无跳变 |
| 功率谱密度估计 | Hanning + Welch | 256~512 | 多段平均，降低方差 |
| 实时频谱监测 | Hanning | 256 | 嵌入式资源有限 |

### 6. Welch 法（平均周期图）

单次 FFT 的频谱方差较大，Welch 法将长数据分成多段，分别加窗 FFT 后**平均**，降低方差喵~

```python
from scipy.signal import welch

fs = 250
nperseg = 512
noverlap = 256

freqs, psd = welch(eeg_data, fs=fs, window='hann',
                   nperseg=nperseg, noverlap=noverlap)

# freqs: 频率轴
# psd: 功率谱密度 (μV²/Hz)
```

| 参数 | 典型值 | 说明 |
|------|--------|------|
| nperseg | 256~1024 | 每段长度 |
| noverlap | nperseg / 2 | 重叠量（50%） |
| 窗函数 | Hann | 脑电默认选择 |

### 7. 嵌入式 FFT 实现要点

```c
// 使用 CMSIS-DSP 的 FFT
#include "arm_math.h"

#define FFT_SIZE  256

arm_rfft_fast_instance_f32 fft_instance;
float fft_input[FFT_SIZE];
float fft_output[FFT_SIZE];

void init_fft(void) {
    arm_rfft_fast_init_f32(&fft_instance, FFT_SIZE);
}

void process_fft(float *samples) {
    float window[FFT_SIZE];
    hanning_window(window, FFT_SIZE);

    for (int i = 0; i < FFT_SIZE; i++) {
        fft_input[i] = samples[i] * window[i];
    }

    arm_rfft_fast_f32(&fft_instance, fft_input, fft_output, 0);

    float magnitude[FFT_SIZE / 2];
    for (int i = 0; i < FFT_SIZE / 2; i++) {
        float re = fft_output[2 * i];
        float im = fft_output[2 * i + 1];
        magnitude[i] = sqrtf(re * re + im * im);
    }
}
```

| 注意点 | 说明 |
|--------|------|
| 内存 | 256 点 FFT 需要约 2KB RAM（输入+输出+窗） |
| 计算时间 | Cortex-M4 @ 168MHz，256 点 FFT 约 0.1ms |
| 实时性 | DMA 半传输完成中断中触发 FFT |
| 补零 | 数据不足 $2^n$ 时补零到最近的 2 的幂 |

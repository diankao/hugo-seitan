# 脑电伪迹去除：ICA与回归法

## 题目

1. 脑电中眼电和肌电伪迹怎么去除？
2. ICA去除伪迹的原理是什么？有什么局限性？

## 考察点

伪迹来源、ICA原理、回归法原理、去除方法选择。

## 回答要点

### 1. 主要伪迹类型

| 伪迹 | 频率范围 | 幅度 | 波形特征 |
|------|---------|------|---------|
| 眼电 EOG | < 5 Hz | 可达数百 μV | 前额通道大幅度慢波 |
| 肌电 EMG | 20~300 Hz | 数十~数百 μV | 高频随机噪声 |
| 心电 ECG | ~1 Hz | 数十 μV | 周期性 QRS 波 |
| 工频 | 50/60 Hz | 不定 | 正弦波 |
| 电极pop | 瞬态 | 很大 | 单通道突然跳变 |

### 2. ICA（独立成分分析）

#### 原理

ICA 假设观测信号是多源信号的**线性混合**，通过寻找线性变换将混合信号分解为**统计独立的成分**喵~

$$X = A \cdot S$$

- $X$：观测信号（N 个通道的 EEG）
- $S$：独立成分（脑电源 + 眼电源 + 肌电源 + ...）
- $A$：混合矩阵

**逆变换**：$S = W \cdot X$（$W = A^{-1}$，解混矩阵）

**去除伪迹**：将伪迹成分置零后重构信号喵~

$$X_{clean} = A \cdot S_{zeroed}$$

```
原始 EEG ──→ ICA 分解 ──→ 独立成分
(64通道)     (W矩阵)     ├─ IC1: 脑电 ✓
                          ├─ IC2: 眼电 ✗ → 置零
                          ├─ IC3: 脑电 ✓
                          ├─ IC4: 心电 ✗ → 置零
                          └─ IC5: 肌电 ✗ → 置零
                              │
                          重构 ──→ 干净 EEG
```

#### Python 实现

```python
from sklearn.decomposition import FastICA
import numpy as np

def ica_remove_artifacts(eeg, n_components=None, artifact_indices=[]):
    # eeg: (channels, samples)
    if n_components is None:
        n_components = eeg.shape[0]

    ica = FastICA(n_components=n_components, random_state=42)
    sources = ica.fit_transform(eeg.T).T  # (components, samples)

    mixing_matrix = ica.mixing_

    for idx in artifact_indices:
        sources[idx, :] = 0.0

    eeg_clean = mixing_matrix @ sources

    return eeg_clean, sources, mixing_matrix
```

#### 如何识别伪迹成分

| 特征 | 眼电 IC | 肌电 IC | 心电 IC | 脑电 IC |
|------|---------|---------|---------|---------|
| 头图分布 | 前额集中 | 颞/颈部 | 均匀分布 | 局部分布 |
| 频谱 | 低频主导 | 宽带高频 | 窄带 1Hz | 各节律 |
| 时间特征 | 与 EOG 通道相关 | 持续高频 | 周期性 | 事件相关 |

```python
def identify_eog_components(sources, eog_channel, corr_threshold=0.8):
    artifact_indices = []
    for i in range(sources.shape[0]):
        corr = np.abs(np.corrcoef(sources[i], eog_channel)[0, 1])
        if corr > corr_threshold:
            artifact_indices.append(i)
    return artifact_indices
```

#### ICA 的局限性

| 局限 | 说明 |
|------|------|
| 需要足够数据 | 至少数千个样本点 |
| 不适合实时 | 分解和重构计算量大 |
| 成分识别主观 | 自动识别算法不够可靠，常需人工检查 |
| 线性假设 | 无法处理非线性混合 |
| 信息损失 | 去除伪迹 IC 时可能损失部分脑电信息 |

### 3. 回归法（Regression）

#### 原理

利用参考通道（如 EOG 通道）与 EEG 通道的线性关系，从 EEG 中减去伪迹的估计成分喵~

$$EEG_{clean} = EEG - \beta \cdot EOG_{ref}$$

- $\beta$：回归系数（EOG 对 EEG 的影响权重）
- 通过最小二乘法估计

```python
def regression_remove_eog(eeg, eog_reference):
    # 对每个 EEG 通道
    eeg_clean = np.zeros_like(eeg)

    for ch in range(eeg.shape[0]):
        x = eog_reference
        y = eeg[ch]

        beta = np.dot(x, y) / np.dot(x, x)

        eeg_clean[ch] = y - beta * x

    return eeg_clean
```

#### 回归法的局限

| 局限 | 说明 |
|------|------|
| 需要参考通道 | 必须额外记录 EOG 通道 |
| 残差 | 不完全去除，有残留 |
| 双向污染 | EOG 通道也可能包含脑电信号，去除时会损失脑电 |

### 4. 其他去除方法

#### 4.1 阈值剔除

```python
# 最简单粗暴：幅度超过阈值直接丢弃该段
def amplitude_rejection(eeg, threshold_uv=100):
    mask = np.all(np.abs(eeg) < threshold_uv, axis=0)
    return eeg[:, mask]
```

#### 4.2 模板减法

```python
# 心电去除：平均心电模板后减去
def template_subtraction_ecg(eeg, r_peaks, fs):
    ecg_template = np.zeros(200)
    count = 0

    for peak in r_peaks:
        start = peak - 50
        end = peak + 150
        if start >= 0 and end < eeg.shape[1]:
            ecg_template += eeg[start:end]
            count += 1

    ecg_template /= count

    eeg_clean = eeg.copy()
    for peak in r_peaks:
        start = peak - 50
        end = peak + 150
        if start >= 0 and end < eeg.shape[1]:
            eeg_clean[start:end] -= ecg_template

    return eeg_clean
```

### 5. 方法对比

| 方法 | 伪迹类型 | 需要参考通道 | 信息损失 | 实时性 | 适用场景 |
|------|---------|------------|---------|--------|---------|
| ICA | EOG/EMG/ECG | 否 | 中 | 差 | 离线分析 |
| 回归法 | EOG | 是 | 中 | 好 | 有 EOG 通道时 |
| 阈值剔除 | 所有 | 否 | 大 | 好 | 快速预处理 |
| 模板减法 | ECG | R峰检测 | 小 | 中 | 心电去除 |
| 带通滤波 | 工频/基线 | 否 | 小 | 好 | 所有场景（基础） |

**实际推荐**：带通滤波 + 陷波作为基础，离线分析加 ICA，实时系统用回归法喵~

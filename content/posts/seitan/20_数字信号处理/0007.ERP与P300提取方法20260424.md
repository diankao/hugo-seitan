# ERP与P300提取方法

## 题目

1. 什么是ERP？为什么需要叠加平均才能看到？
2. P300的特点是什么？怎么提取？

## 考察点

事件相关电位原理、叠加平均、P300特征、BCI应用。

## 回答要点

### 1. ERP（事件相关电位）概念

ERP 是大脑对特定事件（刺激）产生的**时间锁定**电生理响应喵~

| 特征 | 说明 |
|------|------|
| 幅度 | 1~10 μV（比自发脑电小一个数量级） |
| 持续时间 | 数十到数百毫秒 |
| 时间锁定 | 相对于刺激/事件的固定时间关系 |
| 极性 | 正（P）或负（N） |

### 2. 为什么需要叠加平均

**问题**：ERP 信号（1~10 μV）被自发脑电（50~100 μV）淹没，单次 trial 中几乎看不到喵~

**解决**：多个 trial 对齐后取平均，自发脑电（随机）趋于零，ERP（锁定）被保留喵~

$$\overline{ERP}(t) = \frac{1}{N}\sum_{i=1}^{N} epoch_i(t)$$

**信噪比改善**：

$$SNR_{avg} = \sqrt{N} \times SNR_{single}$$

| Trial 数 | SNR 改善 |
|----------|---------|
| 10 | 3.16× |
| 50 | 7.07× |
| 100 | 10× |
| 200 | 14.1× |

```python
def extract_erp(epochs):
    # epochs: (n_trials, n_channels, n_samples)
    erp = np.mean(epochs, axis=0)
    return erp
```

### 3. 常见 ERP 成分

| 成分 | 潜伏期 | 极性 | 触发条件 | 功能意义 |
|------|--------|------|---------|---------|
| N100 | ~100 ms | 负 | 听觉/视觉刺激 | 早期感觉加工 |
| P200 | ~200 ms | 正 | 注意力任务 | 注意力分配 |
| N200 | ~200 ms | 负 | 不匹配刺激 | 冲突检测 |
| **P300** | **~300 ms** | **正** | **稀有靶刺激** | **决策/更新** |
| N400 | ~400 ms | 负 | 语义异常 | 语言加工 |
| P600 | ~600 ms | 正 | 语法错误 | 句法重分析 |

### 4. P300 详细特征

#### 经典 Oddball 范式

```
刺激序列：标准(80%)  标准  靶(20%)  标准  靶  标准  标准  靶 ...
                          ↑              ↑              ↑
                      P300 响应     P300 响应     P300 响应
```

- **靶刺激（Target）**：低概率（20%），受试者需要计数/按键
- **标准刺激（Standard）**：高概率（80%），忽略

#### P300 特征

| 特征 | 典型值 |
|------|--------|
| 潜伏期 | 250~500 ms（因难度而变） |
| 最大幅度位置 | Pz（顶叶中央） |
| 幅度 | 5~20 μV |
| 频率特征 | 主要在 δ 和 θ 频段 |

### 5. P300 提取流程

```python
def extract_p300(eeg, events, fs, channel='Pz'):
    # 1. 分段：事件前200ms到事件后800ms
    tmin, tmax = -0.2, 0.8
    baseline_samples = int(abs(tmin) * fs)
    epochs_target = []
    epochs_standard = []

    for event in events:
        start = event['sample'] + int(tmin * fs)
        end = event['sample'] + int(tmax * fs)

        if start < 0 or end >= eeg.shape[1]:
            continue

        epoch = eeg[channel_idx, start:end]

        # 2. 基线校正
        baseline = np.mean(epoch[:baseline_samples])
        epoch = epoch - baseline

        if event['type'] == 'target':
            epochs_target.append(epoch)
        else:
            epochs_standard.append(epoch)

    # 3. 叠加平均
    erp_target = np.mean(epochs_target, axis=0)
    erp_standard = np.mean(epochs_standard, axis=0)

    # 4. 差异波
    difference_wave = erp_target - erp_standard

    return erp_target, erp_standard, difference_wave
```

### 6. P300 特征提取（用于 BCI）

```python
def extract_p300_features(epoch, fs):
    features = {}

    # 1. 时域特征
    # P300 时间窗内的峰值
    p300_window = (int(0.25 * fs), int(0.5 * fs))
    p300_segment = epoch[p300_window[0]:p300_window[1]]

    features['peak_amplitude'] = np.max(p300_segment)
    features['peak_latency'] = (np.argmax(p300_segment) + p300_window[0]) / fs
    features['mean_amplitude'] = np.mean(p300_segment)
    features['area'] = np.trapz(p300_segment)

    # 2. 频域特征
    from scipy.signal import welch
    freqs, psd = welch(epoch, fs=fs, nperseg=64)
    delta_mask = (freqs >= 0.5) & (freqs <= 4)
    theta_mask = (freqs >= 4) & (freqs <= 8)
    features['delta_power'] = np.sum(psd[delta_mask])
    features['theta_power'] = np.sum(psd[theta_mask])

    # 3. 时频特征
    import pywt
    scales = np.arange(1, 50)
    coeffs, _ = pywt.cwt(epoch, scales, 'cmor1.5-1.0',
                          sampling_period=1.0/fs)
    power = np.abs(coeffs) ** 2
    features['tf_energy_p300'] = np.mean(power[:, p300_window[0]:p300_window[1]])

    return features
```

### 7. 影响 P300 的因素

| 因素 | 影响 |
|------|------|
| 靶刺激概率 | 概率越低，P300 越大 |
| 注意力 | 分心时 P300 减小 |
| 任务难度 | 越难，潜伏期越长 |
| 年龄 | 老年人潜伏期延长，幅度降低 |
| 电极位置 | Pz 最大，Oz 几乎没有 |
| 单次 trial | P300 波形变异大，需平均 |

### 8. P300 BCI 系统流程

```
刺激呈现 → EEG 采集 → 预处理 → 分段 → 特征提取 → 分类 → 输出选择

例如：P300 打字机（P300 Speller）
6×6 字符矩阵闪烁，用户注视目标字符
每次闪烁后提取 P300 特征，判断是否为目标字符
```

# 功率谱密度与脑电节律分析

## 题目

1. 功率谱密度怎么计算？Welch法和周期图法有什么区别？
2. 脑电节律能量怎么提取？各频段功率比有什么意义？

## 考察点

PSD估计方法、Welch法、脑电频段能量提取、临床/BCI应用。

## 回答要点

### 1. 功率谱密度（PSD）概念

PSD 描述信号功率在各频率上的分布，单位为 μV²/Hz 喵~

$$PSD(f) = \lim_{T \to \infty} \frac{1}{T} |X(f)|^2$$

### 2. PSD 估计方法

#### 2.1 周期图法（Periodogram）

直接对整段数据做 FFT，取模的平方除以 N 喵~

```python
def periodogram_psd(signal, fs):
    N = len(signal)
    fft_vals = np.fft.rfft(signal)
    psd = (np.abs(fft_vals) ** 2) / (fs * N)
    freqs = np.fft.rfftfreq(N, 1.0/fs)
    return freqs, psd
```

**问题**：方差大，估计不稳定喵~

#### 2.2 Welch 法（推荐）

将数据分成多段（可重叠），每段加窗做 FFT，最后平均喵~

```python
from scipy.signal import welch

freqs, psd = welch(eeg_channel, fs=250, window='hann',
                   nperseg=512, noverlap=256)

# 单位：μV²/Hz
```

| 方法 | 方差 | 偏差 | 频率分辨率 | 适用 |
|------|------|------|-----------|------|
| 周期图 | 大 | 小 | 最高 | 数据短时 |
| Welch | 小 | 稍大 | 降低 | **脑电分析（推荐）** |
| Bartlett | 中 | 中 | 降低 | 教学用途 |

### 3. Welch 法参数选择

```python
fs = 250
nperseg = 512       # 每段 512 点 = 2.048 秒
noverlap = 256      # 50% 重叠

freqs, psd = welch(eeg, fs=fs, nperseg=nperseg, noverlap=noverlap)

# 频率分辨率 = fs / nperseg = 250 / 512 = 0.488 Hz
```

| 参数 | 影响 |
|------|------|
| nperseg ↑ | 频率分辨率 ↑，方差 ↑（段数 ↓） |
| noverlap ↑ | 段数 ↑，方差 ↓ |
| 窗函数 | Hanning 默认，兼顾旁瓣和主瓣 |

### 4. 脑电频段能量提取

```python
def extract_band_power(freqs, psd, band):
    band_mask = (freqs >= band[0]) & (freqs <= band[1])
    band_power = np.trapz(psd[band_mask], freqs[band_mask])
    return band_power

BANDS = {
    'delta': (0.5, 4),
    'theta': (4, 8),
    'alpha': (8, 13),
    'beta':  (13, 30),
    'gamma': (30, 100),
}

def analyze_bands(eeg_channel, fs):
    freqs, psd = welch(eeg_channel, fs=fs, nperseg=512, noverlap=256)

    band_powers = {}
    total_power = np.trapz(psd, freqs)

    for name, band in BANDS.items():
        power = extract_band_power(freqs, psd, band)
        band_powers[name] = {
            'absolute': power,
            'relative': power / total_power * 100
        }

    return band_powers
```

### 5. 常用功率指标

| 指标 | 公式 | 含义 |
|------|------|------|
| 绝对功率 | $\int_{f_1}^{f_2} PSD(f) df$ | 频段内的总功率 |
| 相对功率 | $P_{band} / P_{total} \times 100\%$ | 该频段占总功率的百分比 |
| 功率比 | $P_\alpha / P_\theta$ | 两个频段的比值 |
| 不对称指数 | $(P_{left} - P_{right}) / (P_{left} + P_{right})$ | 左右半球功率差异 |

### 6. 各频段功率比的临床意义

| 指标 | 意义 |
|------|------|
| α/θ 比 | 放松程度，越高越放松 |
| β/α 比 | 紧张/焦虑程度 |
| (θ+α)/β 比 | 镇静水平（麻醉深度监测） |
| δ 相对功率升高 | 可能提示脑损伤或深度睡眠 |
| α 不对称（左 > 右） | 积极情绪倾向 |
| α 功率整体下降 | 阿尔茨海默病早期指标 |

### 7. 实时功率谱监测（嵌入式）

```c
#include "arm_math.h"

#define FS          250
#define FFT_SIZE    512
#define NUM_BANDS   5

typedef struct {
    float delta;
    float theta;
    float alpha;
    float beta;
    float gamma;
} band_power_t;

void compute_band_powers(float *fft_magnitude, int fft_size,
                         float fs, band_power_t *bands) {
    float df = fs / fft_size;

    bands->delta = 0;
    bands->theta = 0;
    bands->alpha = 0;
    bands->beta  = 0;
    bands->gamma = 0;

    for (int i = 0; i < fft_size / 2; i++) {
        float freq = i * df;
        float power = fft_magnitude[i] * fft_magnitude[i];

        if (freq >= 0.5f && freq < 4.0f)  bands->delta += power * df;
        if (freq >= 4.0f && freq < 8.0f)  bands->theta += power * df;
        if (freq >= 8.0f && freq < 13.0f) bands->alpha += power * df;
        if (freq >= 13.0f && freq < 30.0f) bands->beta  += power * df;
        if (freq >= 30.0f && freq < 100.0f) bands->gamma += power * df;
    }
}
```

### 8. 脑电节律分析的应用

| 应用 | 使用的频段/指标 | 方法 |
|------|---------------|------|
| 睡眠分期 | δ、θ、α、梭形波 | 频段功率 + 规则分类 |
| 麻醉深度 | BIS 指数（β/α 比） | 双频谱分析 |
| 癫痫检测 | δ/θ 突然升高 | 功率突变检测 |
| BCI 运动想象 | μ/β 节律 ERD | 时频功率变化 |
| 疲劳检测 | θ/α 比 | 频段功率比 |
| 情绪识别 | α 不对称 | 左右额叶功率差 |

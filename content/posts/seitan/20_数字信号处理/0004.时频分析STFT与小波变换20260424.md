# 时频分析STFT与小波变换

## 题目

1. 为什么FFT不够用？什么时候需要时频分析？
2. STFT和小波变换有什么区别？脑电分析中用哪个？

## 考察点

时频分析动机、STFT原理与局限、小波变换原理、脑电时频特征提取。

## 回答要点

### 1. 为什么 FFT 不够用

FFT 给出的是**整段信号**的频谱，丢失了时间信息喵~

```
信号：前半段10Hz，后半段30Hz

FFT 结果：同时在10Hz和30Hz有峰值
→ 无法知道 10Hz 出现在什么时间
→ 无法分析频率随时间的变化
```

**脑电中需要时频分析的场景**：
- ERP 各成分的时间-频率特征不同
- 癫痫棘波是瞬态事件，需要精确定位时间
- 运动想象 ERD/ERS 是时变的
- 睡眠分期的脑电频率随时间变化

### 2. STFT（短时傅里叶变换）

#### 原理

将信号分成短段（加窗），每段做 FFT，得到时间-频率-幅度的三维表示喵~

$$STFT\{x[n]\}(m, k) = \sum_{n=0}^{N-1} x[n] \cdot w[n-m] \cdot e^{-j\frac{2\pi}{N}kn}$$

```
原始信号: ──────────────────────────────────
            │         │         │         │
            ▼         ▼         ▼         ▼
         ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
         │ 窗1  │ │ 窗2  │ │ 窗3  │ │ 窗4  │
         │ FFT  │ │ FFT  │ │ FFT  │ │ FFT  │
         └──────┘ └──────┘ └──────┘ └──────┘
            │         │         │         │
            ▼         ▼         ▼         ▼
         频谱1     频谱2     频谱3     频谱4
            └─────────┴─────────┘
                  时频图
```

#### 窗长选择（时间-频率分辨率矛盾）

$$\Delta f \cdot \Delta t \geq \frac{1}{4\pi}$$

**不确定性原理**：时间分辨率和频率分辨率不能同时提高喵~

| 窗长 | 时间分辨率 | 频率分辨率 | 适用场景 |
|------|-----------|-----------|---------|
| 短窗（64点） | 高 | 低 | 定位瞬态事件 |
| 中窗（256点） | 中 | 中 | 一般分析 |
| 长窗（1024点） | 低 | 高 | 分析低频成分 |

```python
from scipy.signal import stft

f, t, Zxx = stft(eeg_data, fs=250, window='hann',
                  nperseg=256, noverlap=128)

# f: 频率轴
# t: 时间轴
# Zxx: 时频矩阵 (复数)
```

#### STFT 的局限

- **固定分辨率**：窗长一旦选定，所有频率的时间/频率分辨率相同
- 高频成分变化快，需要短窗（高时间分辨率）
- 低频成分变化慢，需要长窗（高频率分辨率）
- STFT 无法同时满足喵~

### 3. 小波变换（CWT 连续小波变换）

#### 原理

用不同尺度的**小波函数**（而不是固定窗的复指数函数）去匹配信号喵~

$$W(a, b) = \frac{1}{\sqrt{a}} \sum_{n} x[n] \cdot \psi^{*}\left(\frac{n-b}{a}\right)$$

- $a$：尺度（scale），对应频率（$a$ 大 → 低频，$a$ 小 → 高频）
- $b$：平移（时间位置）
- $\psi$：母小波

**核心优势**：尺度可变 → **高频用窄窗，低频用宽窗**，自动适配喵~

```
低频（大尺度）：  ┌────────────────────┐  宽窗，高频率分辨率
中频：           ┌──────────┐          中等窗
高频（小尺度）：  ┌────┐                 窄窗，高时间分辨率
```

#### 常用母小波

| 母小波 | 特点 | 脑电应用 |
|--------|------|---------|
| Morlet | 复数小波，频率定位好 | **ERD/ERS 分析** |
| Mexican Hat | 实数小波，边缘检测 | 棘波检测 |
| Daubechies (db4) | 正交，紧支撑 | 离散小波分解去噪 |
| Haar | 最简单，方波 | 快速计算 |

```python
import pywt

coeffs, freqs = pywt.cwt(eeg_data, scales, 'cmor1.5-1.0',
                          sampling_period=1.0/250)

# coeffs: 时频系数矩阵
# freqs: 对应的频率
```

### 4. STFT vs 小波变换对比

| 对比项 | STFT | 小波变换（CWT） |
|--------|------|----------------|
| 窗口大小 | 固定 | 随尺度变化 |
| 频率分辨率 | 均匀 | 低频高、高频低 |
| 时间分辨率 | 均匀 | 高频高、低频低 |
| 计算量 | 低（FFT 加速） | 较高 |
| 实现复杂度 | 简单 | 中等 |
| 脑电适用 | 频段功率分析 | ERD/ERS、瞬态检测 |

### 5. 脑电中的时频分析应用

#### ERD/ERS 分析（事件相关去同步/同步）

```python
# 运动想象实验中，C3/C4 通道的 mu 节律 ERD
import numpy as np
from scipy.signal import cwt

def compute_erd_ers(eeg_epochs, fs, freq_range, baseline_period,
                    task_period):
    scales = np.arange(freq_range[0], freq_range[1])

    power_baseline = []
    power_task = []

    for epoch in eeg_epochs:
        coeffs, _ = pywt.cwt(epoch, scales, 'cmor1.5-1.0',
                              sampling_period=1.0/fs)
        power = np.abs(coeffs) ** 2

        bl_mean = np.mean(power[:, baseline_period[0]:baseline_period[1]],
                          axis=1, keepdims=True)
        power_baseline.append(bl_mean)

        task_mean = np.mean(power[:, task_period[0]:task_period[1]],
                            axis=1, keepdims=True)
        power_task.append(task_mean)

    bl_avg = np.mean(power_baseline, axis=0)
    task_avg = np.mean(power_task, axis=0)

    erd_percent = (task_avg - bl_avg) / bl_avg * 100

    return erd_percent
```

#### 癫痫棘波检测

```python
# 用 Morlet 小波检测癫痫棘波（瞬态高频事件）
def detect_spikes(eeg, fs, threshold=3.0):
    scales = np.arange(10, 50)
    coeffs, freqs = pywt.cwt(eeg, scales, 'cmor1.5-1.0',
                              sampling_period=1.0/fs)
    power = np.abs(coeffs) ** 2
    mean_power = np.mean(power, axis=0)
    std_power = np.std(mean_power)

    spike_times = np.where(mean_power > threshold * std_power + np.mean(mean_power))

    return spike_times
```

### 6. 嵌入式实时时频分析

嵌入式资源有限，通常用**离散小波变换（DWT）**而非 CWT 喵~

```c
// DWT 分解：信号 → 低频近似 + 高频细节
// 类似于滤波器组：高通得到细节系数，低通得到近似系数

// 嵌入式中用 Haar 小波（加减法，无需乘法）
void haar_dwt_level1(const float *input, float *approx, float *detail, int N) {
    for (int i = 0; i < N / 2; i++) {
        approx[i] = (input[2*i] + input[2*i+1]) / 2.0f;
        detail[i] = (input[2*i] - input[2*i+1]) / 2.0f;
    }
}

// 多级分解
// Level 1: 信号 → A1 + D1
// Level 2: A1 → A2 + D2
// Level 3: A2 → A3 + D3
// 用途：D1/D2 包含高频噪声，可置零后重构实现去噪
```

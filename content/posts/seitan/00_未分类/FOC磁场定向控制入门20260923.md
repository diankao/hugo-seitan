# FOC磁场定向控制入门

## 题目

简单介绍一下 FOC：它是什么、解决什么问题、核心原理和实现链路是怎样的？

## 考察点

FOC 的定义与动机、坐标变换（Clarke/Park）、三环级联控制结构、SVPWM 调制、转子位置获取（有感/无感）、MCU 侧的实现链路（高级定时器+ADC+DSP 运算）、与六步换相的对比。

## 回答要点

### 1. FOC 是什么、为什么需要它

FOC（Field-Oriented Control，磁场定向控制，也叫矢量控制）是**无刷电机（PMSM/BLDC）的精密控制算法**。核心思想一句话：**让定子电流产生的磁场始终与转子磁场保持垂直**——电磁转矩正比于两磁场叉乘，垂直时每一安培都换成转矩，效率最高、转矩最平稳。

传统方波驱动（六步换相）按 60° 步进切换绕组，电流是方波：转矩脉动大、噪声大、低速会"咔咔"震。FOC 输出三相正弦电流，把无刷电机**当直流电机来控**——转矩平滑、转速精确、四象限运行、效率最高。无人机云台为什么能纹丝不动、电动车为什么安静有力、机器人关节为什么能力控，答案都是 FOC。

### 2. 核心原理：两次坐标变换，把交流变直流

三相电流是三路互差 120° 的正弦信号，直接用 PID 控制正弦量有天然的相位滞后难题。FOC 的做法是**换坐标系**：

1. **Clarke 变换**：三相 ia/ib/ic → 两相静止 αβ，少一个变量，物理意义不变
2. **Park 变换**：αβ → 随转子旋转的 dq 坐标系（需要转子电角度 θ）——站在转子上看，正弦的定子电流变成了**直流量**：d 轴分量指向转子磁极（励磁方向），q 轴分量与磁场垂直（转矩方向）

直流量用 PI 控制毫无压力：**让 Id = 0（不励磁不去磁，纯出力），让 Iq = 期望转矩**。控制量 Vd/Vq 经反 Park 变换回 αβ，再由 SVPWM 变成三相 PWM 占空比。整个环路每个 PWM 周期执行一次。

### 3. 控制结构：三个嵌套环

| 环 | 频率（典型） | 输入→输出 | 说明 |
|----|------------|----------|------|
| 电流环 | 10~20kHz（= PWM 频率） | 电流误差→电压 | 最内环，带宽决定转矩响应速度，必须每载波周期执行 |
| 速度环 | 0.5~2kHz | 转速误差→Iq 给定 | 输出就是内环的电流指令 |
| 位置环 | 0.5~1kHz | 位置误差→速度给定 | 伺服应用才有，云台/关节必备 |

级联结构的好处：内环对外环是一个"近似理想的执行器"——电流环把电机变成了"电流跟随器"，速度环看到的是可控电流源，逐层简化。整定顺序从内到外。

### 4. SVPWM：比正弦 PWM 多榨 15% 母线电压

为什么不直接按正弦给三相占空比（SPWM）？因为**相电压幅值只能到母线的一半**。SVPWM 把逆变器 8 种开关状态看成 8 个电压矢量（6 有效 + 2 零），用相邻两个有效矢量加零矢量按时间加权拼出任意方向的参考矢量——母线电压利用率提高约 15%（达 2/√3 倍），同电压下转速上限更高，且谐波更小。实现上就是扇区判断 + 作用时间计算 + 中央对齐 PWM，落成三路带死区的互补输出。

### 5. 转子位置怎么知道：有感与无感

Park 变换需要电角度 θ，获取方式分两派：

| 方式 | 器件 | 特点 |
|------|------|------|
| 编码器 | 增量式/绝对式 | 精度高，伺服标配；绝对式上电即知位置 |
| 霍尔传感器 | 3 个开关霍尔 | 便宜，60° 分辨率，用于粗控或初始定位 |
| 无感观测 | 反电动势观测器（滑模 SMO/磁链/龙伯格） | 无传感器省成本省线，但**零低速反电动势太小观测不到** |

无感方案低速/静止时没信号，标准启动流程是 **IF 启动**：先电流闭环开环强拖（当作同步电机拉起来），反电动势建立后切观测器闭环——切换瞬间是最容易失步的时刻。

### 6. 实现链路：嵌入式的视角

一套 FOC 在 MCU 上跑起来需要的外设组合：

| 资源 | 用途 | 对应硬件 |
|------|------|---------|
| 高级定时器 | 三相互补 PWM + 死区注入 | STM32 TIM1/TIM8，防上下管直通 |
| ADC 注入组 | 相电流采样，由 PWM 计数器触发 | 采样点对齐载波中点，**避开开关瞬间噪声** |
| 运放/比较器 | 采样电阻信号调理 | 部分型号内置（如 STM32 MC 系列） |
| 编码器接口 | QEI/SSI/SPI 读位置 | TIM 编码器模式 / SPI 绝对码盘 |
| FPU/CORDIC | Park 变换 sin/cos、PI 运算 | Cortex-M4F 起；STM32G4/H7 有 CORDIC 硬件加速 |
| 快速中断 | 电流环 10~20kHz 执行预算 | 50~100µs 内完成整环 |

### 7. 电流环骨架代码

```c
// PWM 中心对齐,计数器下溢中断触发,每 50us 执行一次(20kHz)
void TIM1_UP_IRQHandler(void)
{
    // 1. 采两相电流,第三相由基尔霍夫定律补齐
    float ia = adc_to_amp(ADC1->JDR1);
    float ib = adc_to_amp(ADC1->JDR2);

    // 2. Clarke: abc -> αβ
    float ialpha = ia;
    float ibeta  = (ia + 2 * ib) * 0.57735027f;

    // 3. Park: αβ -> dq,用电角度(机械角 x 极对数)
    float s, c;
    sincos_deg(elec_angle, &s, &c);
    float id =  ialpha * c + ibeta * s;
    float iq = -ialpha * s + ibeta * c;

    // 4. 两个 PI:Id 控到 0,Iq 控到转矩指令
    float vd = pi_update(&pi_d, 0.0f, id);
    float vq = pi_update(&pi_q, iq_ref, iq);

    // 5. 反 Park
    float valpha = vd * c - vq * s;
    float vbeta  = vd * s + vq * c;

    // 6. SVPWM 得三相占空比,写比较寄存器
    svpwm(valpha, vbeta, &ha, &hb, &hc);
    TIM1->CCR1 = ha;
    TIM1->CCR2 = hb;
    TIM1->CCR3 = hc;
}
```

这 20~30 行就是 FOC 的心脏，其余工程量在参数整定、观测器、保护和通信。

### 8. FOC vs 六步换相对比

| | 六步换相 | FOC |
|--|--------|-----|
| 电流波形 | 方波 | 正弦 |
| 转矩脉动/噪声 | 大（低速明显） | 小 |
| 效率与电压利用率 | 中 | 高（SVPWM +15%） |
| 位置反馈 | 霍尔（60°） | 编码器/无感观测 |
| 计算需求 | 极低 | 高，需 FPU 更佳 |
| 典型场景 | 风扇、低成本电调 | 无人机、伺服、云台、电动车、机器人关节 |

### 9. 高频坑清单

1. **电角度 vs 机械角度**：Park 变换用的是电角度 = 机械角 × 极对数，混用则电机只会抖
2. **ADC 采样没避开开关沿**：采到开关噪声，电流环振荡——必须用 PWM 硬件触发对齐
3. **死区没加或没补偿**：不加会直通炸管，不补偿会在过零点引入电压畸变
4. **PI 带宽拍脑袋**：电流环带宽一般取载波频率的 1/10~1/5，超出即振荡
5. **无感低速强行闭环**：反电动势不足观测失败，必须 IF 拖动到足够转速再切
6. **无 FPU 的芯片硬跑 float**：20kHz 里塞不下软浮点，换定点或换芯片

### 10. 一句话总结

**FOC 用 Clarke/Park 变换站到转子上，把三相交流控制变成两个直流量控制（Id=0、Iq=转矩），三环级联 + SVPWM 落到三对互补 PWM 上**——无刷电机从此像直流电机一样听话。

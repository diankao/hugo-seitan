# 软件工程师如何检查 PCB 设计

## 概述

软件工程师在参与 PCB 设计评审或接收硬件设计时，需要从软件角度检查硬件设计是否满足软件开发需求。这不仅有助于及时发现潜在问题，还能避免后期因硬件问题导致的软件调试困难。本文将从多个维度提供 PCB 设计的初始检查点。

## 1. 电源设计检查

### 1.1 电源电压与芯片规格

**检查点：**
- [ ] 电源电压是否与 MCU/芯片规格匹配
- [ ] 所有芯片的 VCC 范围是否一致
- [ ] 是否存在不同电压等级的芯片，需要电平转换

**常见问题：**
- 3.3V 芯片和 5V 芯片混用
- 电源电压超出芯片最大额定值
- 未考虑电压容差（±5% 或 ±10%）

### 1.2 电源去耦电容

**检查点：**
- [ ] 每个 VCC/GND 引脚对附近是否有去耦电容
- [ ] 大电容和小电容的组合是否合理
- [ ] 去耦电容的容值是否合适（0.1μF、10μF 等）

**常见问题：**
- MCU 电源引脚没有去耦电容
- 去耦电容距离芯片过远
- 电容值选择不当

### 1.3 电源分配

**检查点：**
- [ ] 电源走线宽度是否足够
- [ ] 是否有完整的电源平面
- [ ] 关键芯片是否有独立的电源走线

**常见问题：**
- 电源走线过窄，压降过大
- 电源平面被信号走线分割
- 多个大电流芯片共享细电源走线

## 2. GPIO 配置检查

### 2.1 GPIO 复用功能

**检查点：**
- [ ] 复用 GPIO 是否与外设冲突（如 UART、SPI、I2C）
- [ ] 复用引脚的配置是否在启动代码中正确设置
- [ ] 复用引脚的默认状态是否合理

**常见问题：**
- GPIO 配置为 UART，但外设连接的是 I2C
- 复用引脚默认配置错误导致外设异常
- 忽略了 BOOT 引脚的复用功能

### 2.2 GPIO 输出模式

**检查点：**
- [ ] 推挽输出和开漏输出是否选择正确
- [ ] I2C 相关 GPIO 是否配置为开漏输出
- [ ] 开漏输出是否有上拉电阻

**常见问题：**
- I2C 使用推挽输出，导致通信失败
- 需要线与功能的 GPIO 配置为推挽
- 开漏输出缺少上拉电阻

### 2.3 GPIO 初始状态

**检查点：**
- [ ] 上电时 GPIO 的默认状态是否安全
- [ ] 避免上电瞬间 LED 闪烁、继电器误动作
- [ ] 按键 GPIO 是否配置为输入模式

**常见问题：**
- 上电时所有 GPIO 默认高电平，导致继电器误吸合
- LED 上电瞬间全亮
- 按键 GPIO 默认输出模式，导致电流消耗

### 2.4 GPIO 驱动能力

**检查点：**
- [ ] 单个 GPIO 驱动的 LED 电流是否超过规格
- [ ] 所有 GPIO 总电流是否超过芯片限制
- [ ] 是否需要三极管扩展驱动能力

**常见问题：**
- 单个 GPIO 驱动多个 LED，电流超限
- 未考虑 GPIO 的最大输出电流（如 20mA）
- 大功率负载直接用 GPIO 驱动

## 3. 通信接口检查

### 3.1 UART 接口

**检查点：**
- [ ] TX 和 RX 是否交叉连接
- [ ] 波特率晶振是否支持（如 11.0592MHz）
- [ ] 流控引脚（RTS/CTS）是否需要
- [ ] 是否有必要的电平转换（3.3V ↔ 5V）

**常见问题：**
- TX 接 TX，RX 接 RX（应该交叉）
- 晶振频率无法生成精确波特率
- 3.3V MCU 与 5V 设备通信未加电平转换

### 3.2 I2C 接口

**检查点：**
- [ ] SDA 和 SCL 是否配置为开漏输出
- [ ] 上拉电阻值是否合适（标准模式 10kΩ，快速模式 2.2kΩ）
- [ ] 是否有上拉电阻
- [ ] I2C 地址是否冲突

**常见问题：**
- I2C 使用推挽输出
- 上拉电阻值不当
- 多个设备 I2C 地址相同

### 3.3 SPI 接口

**检查点：**
- [ ] MOSI、MISO、SCK、CS 连接是否正确
- [ ] SPI 模式（0-3）是否与硬件匹配
- [ ] 时钟极性是否正确（CPOL、CPHA）
- [ ] 是否有片选上拉电阻

**常见问题：**
- MOSI 和 MISO 接反
- SPI 模式配置错误
- 片选信号无上拉，导致悬空

### 3.4 USB 接口

**检查点：**
- [ ] USB Type-C 的 CC1 和 CC2 是否分别接 5.1kΩ 下拉电阻
- [ ] D+ 和 D- 是否有合适的滤波电容
- [ ] VBUS 是否有合适的滤波和保险丝

**常见问题：**
- CC1 和 CC2 短接后用单一电阻
- 缺少必要的滤波电容
- 未加保险丝保护

## 4. 时钟设计检查

### 4.1 晶振配置

**检查点：**
- [ ] 晶振频率是否与软件配置一致
- [ ] 负载电容值是否匹配
- [ ] 晶振类型（有源/无源）是否与硬件匹配
- [ ] HSE 和 LSE 是否都正确配置

**常见问题：**
- 软件配置 8MHz，硬件是 12MHz
- 负载电容值不当导致频率偏差
- 有源晶振接成无源电路

### 4.2 时钟树配置

**检查点：**
- [ ] PLL 分频/倍频系数是否正确
- [ ] 系统时钟频率是否在芯片规格范围内
- [ ] 外设时钟分频是否合理
- [ ] 是否有未使用的时钟源被误使能

**常见问题：**
- PLL 配置错误导致系统时钟异常
- 外设时钟频率超出最大规格
- 未使能的时钟源导致功耗浪费

## 5. 信号完整性检查

### 5.1 高速信号

**检查点：**
- [ ] 高速信号线（如 SPI、UART）是否有合适的终端匹配
- [ ] 是否避免了 90° 直角走线
- [ ] 差分信号线是否等长、等距
- [ ] 参考平面是否完整

**常见问题：**
- 差分信号线不等长导致共模噪声
- 高速信号跨越参考平面分割
- 缺少终端匹配导致反射

### 5.2 关键信号

**检查点：**
- [ ] 复位信号是否走线最短、最直接
- [ ] 晶振信号是否远离干扰源
- [ ] 时钟信号是否远离敏感模拟信号
- [ ] 模拟信号是否有数字信号隔离

**常见问题：**
- 复位信号走线过长，容易受干扰
- 晶振靠近高速数字信号
- 模拟信号与数字信号混布

## 6. EMC 检查

### 6.1 滤波设计

**检查点：**
- [ ] 接口是否有必要的外部滤波（ESD、TVS）
- [ ] 电源输入是否有足够的滤波电容
- [ ] 晶振是否有接地屏蔽
- [ ] 高速接口是否有共模电感

**常见问题：**
- USB、以太网等接口无 ESD 保护
- 电源输入滤波不足
- 晶振外壳未接地

### 6.2 接地设计

**检查点：**
- [ ] 是否有完整的接地平面
- [ ] 模拟地和数字地是否正确分离或连接
- [ ] 关键芯片是否有多个接地过孔
- [ ] 接地回路是否短且宽

**常见问题：**
- 接地平面被信号走线分割
- 模拟地和数字地连接不当
- 关键芯片接地过孔不足

## 7. 机械结构检查

### 7.1 连接器布局

**检查点：**
- [ ] 连接器是否便于焊接和调试
- [ ] 是否有测试点
- [ ] 连接器方向是否合理（便于插拔）
- [ ] 是否有防呆设计

**常见问题：**
- 连接器被元件遮挡，难以焊接
- 缺少必要的测试点
- 连接器方向与外壳冲突

### 7.2 元件布局

**检查点：**
- [ ] MCU 是否放置在中心位置
- [ ] 相关功能元件是否就近放置
- [ ] 散热元件是否有足够空间
- [ ] 是否有足够的维修空间

**常见问题：**
- MCU 放在边缘，走线过长
- 功能元件分散，走线复杂
- 散热元件过于密集

### 7.3 尺寸约束

**检查点：**
- [ ] PCB 尺寸是否符合外壳要求
- [ ] 安装孔位是否正确
- [ ] 元件高度是否满足外壳限制
- [ ] 是否有必要的固定孔

**常见问题：**
- PCB 尺寸与外壳不匹配
- 安装孔位置错误
- 元件高度超过外壳空间

## 8. 可制造性检查

### 8.1 元件封装

**检查点：**
- [ ] 是否优先使用标准封装（0603、0805、SOP8 等）
- [ ] 是否有手工焊接困难的微小封装（如 0201）
- [ ] 元件间距是否满足制造要求
- [ ] 是否有异形封装

**常见问题：**
- 使用非标准封装，增加采购难度
- 元件间距过小，容易短路
- 过多异形封装

### 8.2 走线设计

**检查点：**
- [ ] 走线宽度是否满足电流要求
- [ ] 走线间距是否满足制造规则
- [ ] 是否有过多的过孔
- [ ] 是否有泪滴（teardrop）

**常见问题：**
- 大电流走线过窄
- 走线间距过小，容易短路
- 过孔过多增加成本

### 8.3 层数选择

**检查点：**
- [ ] 层数选择是否合理（成本 vs 性能）
- [ ] 信号层分配是否合理
- [ ] 电源层和地层是否足够
- [ ] 是否有必要的埋孔或盲孔

**常见问题：**
- 层数过多导致成本过高
- 信号层分配不合理，增加串扰
- 缺少必要的电源层

## 9. 可测试性检查

### 9.1 测试点

**检查点：**
- [ ] 关键信号是否有测试点
- [ ] 电源是否有测试点
- [ ] 复位信号是否有测试点
- [ ] 测试点是否便于探针接触

**常见问题：**
- 关键信号无测试点，调试困难
- 测试点被元件遮挡
- 测试点过小，难以接触

### 9.2 调试接口

**检查点：**
- [ ] 是否预留 JTAG/SWD 调试接口
- [ ] 调试接口是否有必要的保护
- [ ] 调试接口是否便于访问
- [ ] 是否有串口调试接口

**常见问题：**
- 无 JTAG/SWD 接口，无法在线调试
- 调试接口被外壳遮挡
- 无串口调试接口，调试信息无法输出

## 10. 软件相关检查

### 10.1 引脚定义一致性

**检查点：**
- [ ] 软件引脚定义是否与硬件原理图一致
- [ ] 头文件中的引脚宏定义是否正确
- [ ] 是否有引脚复用的文档说明
- [ ] 旧版本引脚定义是否更新

**常见问题：**
- 软件引脚定义与硬件不匹配
- 复用引脚未在代码中配置
- 引脚定义文档过时

### 10.2 初始化配置

**检查点：**
- [ ] GPIO 初始化顺序是否合理
- [ ] 是否有未初始化的 GPIO
- [ ] 外设初始化是否完整
- [ ] 是否有配置错误的寄存器

**常见问题：**
- GPIO 未初始化导致随机状态
- 外使能未配置导致异常
- 寄存器配置错误导致功能异常

### 10.3 中断配置

**检查点：**
- [ ] 中断引脚是否配置正确
- [ ] 中断优先级是否合理
- [ ] 中断标志是否正确清除
- [ ] 是否有中断冲突

**常见问题：**
- 中断引脚配置错误
- 中断优先级设置不当
- 中断标志未清除导致死循环

### 常见问题优先级

**高优先级（必须解决）：**
- 电源电压不匹配
- GPIO 复用冲突
- I2C 使用推挽输出
- 时钟配置错误
- 缺少去耦电容

**中优先级（建议解决）：**
- GPIO 初始状态不安全
- 信号完整性问题
- 缺少测试点
- 走线不够规范

**低优先级（可选优化）：**
- 成本优化（层数、封装选择）
- 可制造性优化
- 调试便利性优化

## 常见故障排查

### 1. 丢包、通信错误与时钟有关的问题

**软件现象：**
- UART、SPI、I2C 通信频繁出错
- 数据包丢失或校验失败
- 通信时好时坏，不稳定
- 高波特率时问题更严重

**硬件检查点：**
- [ ] 晶振频率是否与软件配置完全一致
- [ ] 晶振负载电容值是否正确
- [ ] 晶振走线是否过细或过长
- [ ] 晶振下方是否有完整的接地平面
- [ ] 晶振是否靠近高速数字信号（易受干扰）
- [ ] 晶振是否有接地屏蔽
- [ ] 晶振焊盘是否有短路或虚焊
- [ ] 晶振类型（有源/无源）是否正确
- [ ] 是否有多个晶振同时工作（可能相互干扰）
- [ ] 晶振电源滤波是否充足

**常见硬件问题：**
- 晶振走线过长，导致信号衰减
- 晶振靠近高速信号线，受到干扰
- 负载电容值不当，导致频率偏差
- 晶振下方无接地平面，EMI 干扰严重
- 晶振选型不当，精度不够

### 2. 电源纹波问题

**软件现象：**
- ADC 采样值波动大
- 模拟信号噪声严重
- 系统不稳定，偶发异常
- 高速通信误码率高

**硬件检查点：**
- [ ] 电源模块输入/输出是否有滤波电容
- [ ] 去耦电容是否放置在芯片 VCC 引脚附近
- [ ] 大电容和小电容的组合是否合理
- [ ] 电源走线宽度是否足够
- [ ] 是否有完整的电源平面
- [ ] LDO 或 DC-DC 输出电容是否足够
- [ ] 电源走线是否远离敏感信号
- [ ] 电源模块的反馈电阻是否正确
- [ ] 是否有过多的电源走线分割
- [ ] 多个电源轨之间是否有适当的去耦

**常见硬件问题：**
- 缺少去耦电容或电容值不当
- 去耦电容距离芯片过远
- 电源走线过窄，导致压降和纹波
- 大电流器件共享细电源走线
- 电源平面被信号走线分割
- LDO 输出电容不足，导致环路不稳定

### 3. 总是自动复位

**软件现象：**
- 系统运行一段时间后自动重启
- 复位异常频繁
- 无法稳定运行
- 复位时无明确原因

**硬件检查点：**
- [ ] 复位电路电压是否稳定
- [ ] 复位电容值是否合适
- [ ] 复位走线是否最短、最直接
- [ ] 复位走线是否远离干扰源
- [ ] 是否有去耦电容防止误触发
- [ ] 复位引脚是否有上拉/下拉电阻
- [ ] 复位电路是否有外部干扰
- [ ] 电源电压是否稳定（电源波动可能导致复位）
- [ ] 是否有 ESD 或浪涌干扰复位引脚
- [ ] 看门狗电路是否正常
- [ ] 复位芯片（如 MAX809）是否正常工作
- [ ] 复位电路滤波是否足够

**常见硬件问题：**
- 复位走线过长，容易受干扰
- 复位电容值不当，导致复位时序错误
- 复位引脚无滤波，受外部干扰误触发
- 电源纹波过大，触发芯片内部的电源监测复位
- 复位走线靠近高速信号，受到串扰
- 复位芯片选型不当或连接错误
- 复位电路缺少必要的 RC 滤波

### 4. 其他常见硬件相关问题

**GPIO 引脚状态异常：**
- 检查上拉/下拉电阻是否正确
- 检查 GPIO 模式配置（输入/输出）
- 检查是否有多余的焊接桥接

**外设无法初始化：**
- 检查外设时钟是否使能
- 检查外设电源是否正常
- 检查复位引脚是否正确

**程序无法烧录：**
- 检查 JTAG/SWD 接口连接
- 检查 BOOT 引脚配置
- 检查复位电路是否正常
- 检查电源电压是否足够

**温度异常：**
- 检查散热设计
- 检查功耗是否过高
- 检查是否有元件短路

## 总结

软件工程师检查 PCB 设计时，需要从多个维度全面评估：

1. **电源设计**：电压匹配、去耦完整、分配合理
2. **GPIO 配置**：复用正确、模式合适、初始状态安全
3. **通信接口**：连接正确、参数匹配、电平兼容
4. **时钟设计**：频率正确、配置合理、滤波充足
5. **信号完整性**：高速信号、关键信号、参考平面
6. **EMC 设计**：滤波充分、接地完整、屏蔽合理
7. **机械结构**：布局合理、便于焊接、满足约束
8. **可制造性**：封装标准、走线规范、成本合理
9. **可测试性**：测试点完整、调试接口可用
10. **软件相关**：引脚一致、初始化完整、中断正确

通过系统性的检查，可以及早发现硬件设计中的问题，避免后期软件开发和调试中的困难，提高产品开发效率和质量。

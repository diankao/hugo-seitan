# VCC VDD VEE VSS 电源引脚区别

## 命名本质:全来自晶体管电极

| 缩写 | 全称 | 晶体管 | 工艺时代 | 含义 |
|------|------|--------|---------|------|
| **VCC** | Voltage (Common) Collector | 集电极 | TTL/双极性(BJT) | 正电源 |
| **VEE** | Voltage (Common) Emitter | 发射极 | TTL/双极性(BJT) | 负电源 |
| **VDD** | Voltage (Common) Drain | 漏极 | CMOS/MOS | 正电源 |
| **VSS** | Voltage (Common) Source | 源极 | CMOS/MOS | 负电源/地 |

记忆模型:

```
双极性时代(TTL):           CMOS 时代:
        VCC                        VDD
         |                          |
   [C 集电极]                [D 漏极]
   [B 基极] ←信号            [G 栅极] ←信号
   [E 发射极]                [S 源极]
         |                          |
        VEE                        VSS
```

管子接到哪个极的电源,就叫 V + 那个极。

**为什么双写字母(CC 不写 VC)?**

传统约定:单字母 `Vc` 指"某个晶体管集电极的电压"(会变),双写 `VCC` 指"整个电路公共的集电极电源轨"(固定)。双写 = 电源轨,这是老工程师区分"节点电压"和"电源"的方式。

## 历史演变:为什么现在 VCC 和 VDD 都指正电源

| 时代 | 电源结构 | 命名 |
|------|---------|------|
| TTL 时代(70-80年代) | 双电源很常见 | VCC=+5V,VEE=-5V(运放 ±15V、RS232 ±12V) |
| CMOS 兴起(4000 系列) | 单电源为主 | VDD/VSS |
| 现代 | 几乎全单电源 | VCC/VDD 都=正电源,VEE/VSS 都=地 |

现代怎么混用的——看厂商血统,不是技术区别:

| 厂商/芯片 | 习惯命名 | 原因 |
|-----------|---------|------|
| TI 74 系列(74HC245 等) | VCC / GND | TTL 血统 |
| ST(STM32) | VDD / VSS | 摩托罗拉 CMOS 血统 |
| NXP / 飞思卡尔 | VDD / VSS | 同上 |
| 老式 TTL 器件 | VCC / VEE | 真·双电源 |

结论:VCC 和 VDD 在现代芯片里语义等价,都指正电源。读哪家的 datasheet 就跟哪家叫。

## 现代衍生电源引脚(STM32 实战)

| 引脚 | 含义 | 实战要点 |
|------|------|---------|
| VDD / VSS | 数字电源/地 | 3.3V,全部要接,不能只接一个 |
| VDDA / VSSA | 模拟电源/地 | 给 ADC/DAC 用,必须和 VDD 分开滤波(磁珠+电容) |
| VBAT | 备份域电源 | RTC/备份寄存器,不接电池时按手册接 VDD |
| VREF+ / VREF- | ADC 参考电压 | 决定满量程,精度要求高时用独立基准芯片 |
| VDDIO / VDDXL | IO 域电源 | 多电压域芯片(1.8V/3.3V 混合)用来电平转换 |
| VCORE | 内核电源 | 内部 LDO 出的 1.2V 左右,不用外接(要接去耦电容) |

VDDA 为什么要独立——画板子必踩的坑:数字部分开关噪声大,直接污染 ADC 参考。标准做法:

```
VDD ──[磁珠]──┬── VDDA
              │
           [1μF+100nF]
              │
GND ──VSSA────┴── (单点接地)
```

## 和电平标准的关联

VCC=5V、VDD=3.3V 只是常见习惯,不是定义。真正的坑在电平标准:

| 标准 | 电源 | VIH(认高) | VIL(认低) | 备注 |
|------|------|-----------|-----------|------|
| TTL 5V | 5V | 2.0V | 0.8V | 阈值低 |
| CMOS 5V | 5V | 3.5V(70% VDD) | 1.5V(30%) | 阈值高 |
| LVTTL 3.3V | 3.3V | 2.0V | 0.8V | 常见 MCU |
| LVCMOS 3.3V | 3.3V | 2.3V | 0.8V | |

经典坑:5V CMOS 输出高(4.5V)接 3.3V MCU——超过耐压,要电平转换;反过来 3.3V 输出高(3.3V)接 5V CMOS 输入(要 3.5V)——临界不够,可能识别失败。这就是为什么有 PCA9306、TXS0108E 这类电平转换芯片。

## 速记口诀

- C/E 来自三极管(TTL),D/S 来自 MOS 管(CMOS)
- VCC/VDD = 正电源,VEE/VSS = 负电源或地
- 双写字母 = 电源轨(区别于单管的节点电压)
- 现代单电源:VCC ≈ VDD,看厂商习惯(TI 用 VCC,ST 用 VDD)
- VDDA 独立滤波(磁珠+电容),防数字噪声污染 ADC
- VCC=5V/VDD=3.3V 是习惯不是规则,电平是否兼容查 VIH/VIL

## 常见追问

1. **VCC 和 VDD 能同时出现在一个芯片吗?**
   能。有些芯片 VCC 指 IO 电源、VDD 指内核电源,或反之。永远以 datasheet 为准。

2. **VSS 和 GND 什么区别?**
   单电源系统里 VSS=GND。严格说 GND 是"公共参考点",VSS 是"源极电源轨",双电源系统里 VSS 可能是负电压而不是地。

3. **VBAT 不接电池行不行?**
   行,但要按手册接 VDD(有的直连,有的通过二极管)。悬空会导致备份域掉电、RTC 复位。

4. **为什么 STM32 有 4 个 VDD 引脚?**
   每个电源引脚供芯片不同区域,全部要接,且每个都要就近放 100nF 去耦电容——高频电流从最近的电容取,不是从远处绕。

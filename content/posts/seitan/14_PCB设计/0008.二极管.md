# 二极管的原理、分类与应用

## 二极管的基本原理

二极管（Diode）是一种具有单向导电性的半导体器件，它只允许电流从一个方向通过，阻止反向电流。这种特性使其在电路中有着广泛的应用。

### 二极管的结构

二极管由 P 型半导体和 N 型半导体形成 PN 结构成：

**PN 结的工作原理：**
- **正向偏置**：P 端接正极，N 端接负极，势垒降低，电流可以通过
- **反向偏置**：P 端接负极，N 端接正极，势垒升高，电流几乎无法通过

### 二极管的伏安特性

**正向特性：**
- 存在正向导通电压（VF）
- 硅二极管：约 0.6V - 0.7V
- 锗二极管：约 0.2V - 0.3V
- 肖特基二极管：约 0.2V - 0.4V

**反向特性：**
- 反向电流极小（漏电流）
- 存在反向击穿电压（VR）
- 超过击穿电压会损坏普通二极管

## 二极管的分类

### 按功能分类

#### 1. 整流二极管

**作用：**
- 将交流电转换为直流电
- 用于电源整流电路

**常见型号：**
- 1N4007：1A，1000V，最常用
- 1N5408：3A，1000V
- 1N5819：1A，40V，肖特基整流

**应用：**
- 电源适配器
- 电池充电电路
- 电机驱动电路

#### 2. 稳压二极管（齐纳二极管，Zener Diode）

**作用：**
- 在反向击穿状态下稳定电压
- 用于电压基准和稳压电路

**工作原理：**
- 正常工作时截止
- 达到稳定电压（VZ）时反向导通，维持电压恒定

**常见型号：**
- 1N4733：5.1V，1W
- 1N4742：12V，1W
- 1N4751：33V，1W

**应用：**
- 稳压电源
- 电压基准
- 过压保护

#### 3. 发光二极管（LED）

**作用：**
- 将电能转换为光能
- 用于指示、照明、显示

**特点：**
- 单向导电
- 正向电压取决于颜色
- 亮度与电流成正比

**应用：**
- 电源指示灯
- 状态指示
- 照明
- 显示屏

#### 4. 肖特基二极管（Schottky Diode）

**特点：**
- 正向压降低（0.2V - 0.4V）
- 开关速度快
- 反向漏电流较大

**常见型号：**
- 1N5817：1A，20V
- 1N5820：3A，20V
- SS34：3A，40V

**应用：**
- 高频整流
- 开关电源
- 续流二极管
- 电压钳位

#### 5. 快恢复二极管（Fast Recovery Diode）

**特点：**
- 反向恢复时间短（ns 级）
- 适合高频应用

**常见型号：**
- FR107：1A，1000V
- UF4007：1A，1000V
- HER307：3A，1000V

**应用：**
- 开关电源
- 逆变器
- 电机驱动

#### 6. 瞬态电压抑制二极管（TVS）

**作用：**
- 吸收瞬态过电压
- 保护电路免受浪涌损坏

**特点：**
- 响应速度快（ps 级）
- 大功率吸收能力

**应用：**
- ESD 保护
- 电源输入保护
- 接口保护

#### 7. 变容二极管（Varactor Diode）

**作用：**
- 电容随反向电压变化
- 用于调谐电路

**应用：**
- 收音机调谐
- 频率合成
- 压控振荡器（VCO）

### 按封装分类

#### 1. 直插式（THT）

**常见封装：**
- DO-35（小信号二极管）
- DO-41（整流二极管）
- DO-15（功率二极管）
- TO-220（大功率整流）

**特点：**
- 引脚长，便于手工焊接
- 功率较大
- 散热性能好

#### 2. 贴片式（SMD）

**常见封装：**
- SOD-123（小信号）
- SOD-323（微型）
- SMA/SMB/SMC（功率二极管）
- DO-214（标准功率）

**特点：**
- 体积小
- 适合自动化贴装
- 寄生电感小

## 二极管的关键参数

### 1. 正向电压（VF）

**定义：** 二极管导通时的电压降

**典型值：**
- 普通硅二极管：0.6V - 0.7V
- 肖特基二极管：0.2V - 0.4V
- LED：1.8V - 3.4V（取决于颜色）

**影响：**
- VF 越低，功耗越小
- 肖特基二极管适合低压大电流应用

### 2. 最大正向电流（IF）

**定义：** 二极管能承受的最大持续正向电流

**选择原则：**
- 实际工作电流不超过额定值的 50%-70%
- 考虑散热条件
- 脉冲电流可以更高

### 3. 反向击穿电压（VR）

**定义：** 二极管能承受的最大反向电压

**选择原则：**
- 实际反向电压不超过额定值的 60%-80%
- 整流电路考虑峰值电压
- 感性负载考虑反向电动势

### 4. 反向恢复时间（trr）

**定义：** 从正向导通转为反向截止所需时间

**影响：**
- trr 越短，适合高频应用
- 普通二极管：μs 级
- 快恢复二极管：ns 级
- 肖特基二极管：几乎无反向恢复

### 5. 功率损耗（PD）

**计算公式：**
```
PD = VF × IF
```

**影响：**
- VF 越低，功率损耗越小
- 大电流应用选择肖特基二极管

## 二极管的应用电路

### 1. 整流电路

#### 半波整流

```
AC输入 ----[二极管]----+----输出
                      |
                     GND
```

**特点：**
- 只利用半个周期
- 效率低
- 输出电压脉动大

#### 全波整流

**桥式整流：**
```
        +----[D1]----+
        |            |
AC输入 -+            +----输出
        |            |
        +----[D2]----+
        |            |
AC输入 -+            +----输出
        |            |
        +----[D3]----+
        |            |
AC输入 -+            +----输出
        |            |
        +----[D4]----+
```

**特点：**
- 利用整个周期
- 效率高
- 输出电压脉动小
- 需要 4 个二极管

### 2. 续流二极管

**应用：** 电感性负载（如电机、继电器）的续流

```
GPIO ----[三极管]----[电机]----GND
                     |
                   [二极管]
```

**作用：**
- 防止感性负载关断时的反向电动势损坏器件
- 为感性电流提供续流路径
- 保护三极管或 MOSFET

**选择：**
- 肖特基二极管（快速）
- 反向电压大于电源电压
- 电流大于负载电流

### 3. 钳位二极管

**应用：** 保护电路免受高压损坏

```
信号输入 ----[电阻]----+----MCU
                      |
                   [二极管]----VCC
                      |
                   [二极管]----GND
```

**作用：**
- 限制输入电压范围
- 防止静电损坏（ESD）
- TVS 二极管用于瞬态保护

### 4. 稳压电路

```
输入 ----[电阻]----+----输出
                  |
               [稳压二极管]----GND
```

**工作原理：**
- 稳压二极管反向击穿
- 维持输出电压恒定
- 电阻限制电流

**选择：**
- 稳压值等于所需电压
- 功率足够（PZ = VZ × IZ）
- 精度等级（±5% 或 ±2%）

### 5. 倍压电路

**二倍压整流：**
```
        +----[C1]----+
AC输入 -+            +----输出
        |            |
        +----[D1]----+
        |            |
AC输入 -+            +----输出
        |            |
        +----[C2]----+
```

**特点：**
- 输出电压约为输入电压的 2 倍
- 适用于高压小电流场合

### 6. 逻辑门

**与门：**
```
A ----[二极管]----+----输出
B ----[二极管]----+
```

**或门：**
```
        +----[二极管]----+
A ----+               +----输出
        +----[二极管]----+
B ----+
```

## 二极管选型指南

### 整流二极管选型

**考虑因素：**
1. **电压等级**：VR ≥ 1.5 × 实际反向电压
2. **电流等级**：IF ≥ 2 × 实际工作电流
3. **封装类型**：根据功率选择（DO-41/DO-15 等）
4. **反向恢复时间**：高频应用选快恢复

**推荐型号：**
| 应用 | 电压 | 电流 | 推荐型号 |
|------|-------|-------|---------|
| 小功率整流 | 1000V | 1A | 1N4007 |
| 中功率整流 | 1000V | 3A | 1N5408 |
| 低压高频 | 40V | 1A | 1N5819 |
| 开关电源 | 600V | 3A | UF5408 |

### 稳压二极管选型

**考虑因素：**
1. **稳定电压**：VZ = 所需稳定电压
2. **功率等级**：PZ ≥ VZ × IZ × 1.5
3. **精度**：±5%（普通）或 ±2%（精密）
4. **温度系数**：5V 以上温度系数为正

**推荐型号：**
| 稳压值 | 精度 | 功率 | 推荐型号 |
|--------|-------|-------|---------|
| 5.1V | ±5% | 1W | 1N4733 |
| 12V | ±5% | 1W | 1N4742 |
| 33V | ±5% | 1W | 1N4751 |

### 肖特基二极管选型

**适用场景：**
- 低压大电流整流
- 开关电源输出
- 续流应用
- 效率要求高的场合

**推荐型号：**
| 电压 | 电流 | 推荐型号 |
|------|-------|---------|
| 20V | 1A | 1N5817 |
| 20V | 3A | 1N5820 |
| 40V | 3A | SS34 |
| 60V | 5A | SB560 |

## 二极管与 LED 的极性识别

### 直插二极管

**识别方法：**

1. **色环标记**
   - 色环端为阴极（负极）
   - 无色环端为阳极（正极）

2. **引脚长度**
   - 长引脚为阳极（正极）
   - 短引脚为阴极（负极）

3. **外壳标记**
   - 直线或缺口端为阴极（负极）
   - 对面为阳极（正极）

### 贴片二极管

**识别方法：**

1. **横线标记**
   - 有横线一端为阴极（负极）

2. **字符标记**
   - 查阅数据手册确认

### 直插 LED

**识别方法：**

1. **引脚长度**
   - 长引脚为正极
   - 短引脚为负极

2. **内部结构**
   - 大金属片一侧为负极
   - 小金属片一侧为正极

3. **边缘标记**
   - 有缺口或平边一侧为负极

### 贴片 LED

**识别方法：**

1. **标记点**
   - 绿色、黄色或白色标记点为负极（阴极）
   - 对面为正极（阳极）

2. **T 形标记**
   - T 形的底部为负极
   - 顶部为正极

3. **字符**
   - 查阅数据手册确认

## PCB 布局注意事项

### 1. 二极管放置

**位置选择：**
- 整流二极管靠近电源输入
- 续流二极管靠近感性负载
- 稳压二极管靠近被稳压节点
- TVS 二极管靠近接口

**方向：**
- 严格注意极性方向
- 用丝印标明极性（二极管符号）
- 常用符号：三角形+竖线

### 2. 走线设计

**电流能力：**
- 大电流二极管：走线加宽（20mil - 50mil）
- 小信号二极管：8mil - 10mil 即可

**散热考虑：**
- 大功率二极管铺铜散热
- 使用多个过孔连接到背面铺铜
- 必要时加散热片

**寄生电感：**
- 高频应用减小走线长度
- 使用贴片二极管（寄生电感小）
- 并联多个二极管降低 ESL

### 3. 参考平面

**回流路径：**
- 大电流需要完整的参考平面
- 避免跨越分割的参考平面

**地平面：**
- TVS 二极管要直接接到地平面
- 续流二极管的地回路要短

### 4. 散热设计

**铺铜散热：**
- 大功率二极管周围大面积铺铜
- 使用散热焊盘（Thermal Pad）

**过孔散热：**
- 散热焊盘下方打过孔到背面
- 多个过孔增强散热

**间距：**
- 多个二极管保持间距
- 避免热集中

## 常见问题与解决

### 1. 二极管发热严重

**可能原因：**
- 电流过大
- 正向压降过高
- 散热不良

**解决方法：**
- 降低工作电流
- 更换肖特基二极管（低压降）
- 改善散热（铺铜、加散热片）

### 2. 整流效果差

**可能原因：**
- 二极管损坏
- 滤波电容不足
- 负载过大

**解决方法：**
- 更换二极管
- 增大滤波电容
- 检查负载电流

### 3. 稳压不稳定

**可能原因：**
- 负载电流变化大
- 限流电阻值不当
- 稳压二极管功率不足

**解决方法：**
- 增大限流电阻
- 使用更大功率的稳压二极管
- 考虑使用稳压芯片

### 4. 反向击穿

**可能原因：**
- 反向电压过高
- 浪涌电压
- 极性接反

**解决方法：**
- 选择更高反向电压的二极管
- 增加 TVS 保护
- 检查极性

### 5. 高频性能差

**可能原因：**
- 反向恢复时间过长
- 寄生电感过大

**解决方法：**
- 使用快恢复二极管
- 使用肖特基二极管
- 使用贴片封装

## 总结

二极管是电子电路中最基础的器件之一，合理选型和使用需要注意：

1. **类型选择**：根据功能需求选择整流、稳压、肖特基等类型
2. **参数匹配**：电压、电流、功率等参数要留有裕量
3. **极性识别**：正确识别正负极，避免接反损坏
4. **散热设计**：大功率二极管注意散热，铺铜或加散热片
5. **布局优化**：二极管放置合理，走线规范，考虑寄生参数
6. **保护措施**：必要时增加 TVS、RC 网络等保护电路

掌握二极管的特性和应用，能够设计出更可靠、高效的电子电路。

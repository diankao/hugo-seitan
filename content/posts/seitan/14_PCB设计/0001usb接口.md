# 为什么 CC1 和 CC2 要分别用 5.1kΩ 电阻下拉

## 概述

在 USB Type-C 接口设计中，CC（Configuration Channel）引脚的电阻配置是一个关键的硬件设计细节。USB-IF 规范明确规定，当设备使用 Type-C 接口并且需要从主机获取电源时，必须给 CC1 和 CC2 分别串联一个 5.1kΩ 电阻接地。这个看似简单的设计背后，涉及 USB Type-C 协议的核心机制。

## CC 引脚的作用

USB Type-C 接口有两个 CC 引脚（CC1 和 CC2），它们的主要功能包括：

1. **设备识别**：告诉主机当前连接的是 UFP（Upstream Facing Port，如手机、U盘等）还是 DFP（Downstream Facing Port，如充电器、电脑）
2. **供电协商**：确定供电能力（USB 2.0 的 5V/500mA，还是 USB PD 的更高功率）
3. **插头方向检测**：Type-C 接口支持正反插，CC 引脚用于检测插入方向
4. **模式选择**：判断是否进入 Alternate Mode（如显示输出、雷电等）

## 5.1kΩ 下拉电阻的原理

### 为什么是 5.1kΩ？

USB-IF 规范中定义了通过 CC 引脚上的电压来识别设备类型：

- **DFP（主机端）**：在 CC 引脚上通过 Rd = 5.1kΩ 电阻接电源（通常上拉到 5V）
- **UFP（设备端）**：在 CC 引脚上通过 Rp = 5.1kΩ 电阻接地（下拉）

当 UFP 连接到 DFP 时，会形成一个电阻分压网络。主机通过检测 CC 引脚上的电压来判断连接状态和供电能力。

### CC1 和 CC2 的分别配置

Type-C 接口支持正反插，因此有两个 CC 引脚。正确的做法是：

```
设备端设计：
CC1 --- 5.1kΩ --- GND
CC2 --- 5.1kΩ --- GND
```

**为什么不能短接 CC1 和 CC2 后再用一个电阻接地？**

一些开源项目可能会采用错误的接法：
```
错误接法：
CC1 ----+
        +--- 5.1kΩ --- GND
CC2 ----+
```

这种接法看似节省了一个电阻，但会带来严重问题。

## 错误接法的潜在风险

### 1. 设备识别错误

当 CC1 和 CC2 短接后，某些主机可能会将设备误识别为**音频配件适配器（Audio Adapter Accessory Mode）**。这是因为音频配件模式要求 CC1 和 CC2 上有特定的电阻组合，短接后的阻值特征可能触发这种识别。

### 2. 供电失败

如果主机将设备识别为音频设备而不是普通 USB 设备：
- 主机可能不会提供预期的供电能力
- USB PD（Power Delivery）协商可能失败
- 设备可能无法正常启动或工作不稳定
- 某些严格的充电器可能直接拒绝供电

### 3. 协议不兼容

现代 USB Type-C 支持多种模式和功率等级：
- USB 2.0/3.x 数据传输
- USB PD 快充（最高 240W）
- DisplayPort Alt Mode
- Thunderbolt 3/4

错误的 CC 引脚配置可能导致设备无法进入正确的模式，或无法与主机协商出合适的功率。

## 正确的设计实践

### 标准接法

```
设备端正确接法：
CC1 ---[5.1kΩ ±1%]--- GND
CC2 ---[5.1kΩ ±1%]--- GND
```

**关键要点：**
- 电阻精度建议使用 1% 或更高
- 两个电阻必须分别接地，不能共享
- PCB 布线时注意 CC 引脚的信号完整性

### 电源需求场景

当设备需要从主机获取电源时（如手机、U盘、传感器等）：
- 必须在 CC1 和 CC2 上分别配置 5.1kΩ 下拉电阻
- 主机检测到正确的阻值后，会提供默认的 5V/500mA 或更高电流

### 仅供电场景（如充电器）

如果设备只作为电源提供者（不接收数据）：
- CC 引脚配置为上拉电阻（Rp）
- 通过检测 UFP 的下拉电阻来确定供电能力
- 根据 USB PD 协议协商电压和电流

## 实际应用中的注意事项

### 1. 电阻选择

- **阻值**：5.1kΩ ±1%
- **功率**：1/16W 或 1/10W 足够（功率消耗很小）
- **封装**：0402 或 0603 常见，根据 PCB 空间选择

### 2. PCB 布局

- CC 信号线尽量短
- 避免走线过长导致噪声干扰
- 如果空间允许，可以在 CC 引脚附近加小电容滤波（可选）

### 3. 测试验证

- 使用万用表测量 CC 引脚对地阻值
- 连接不同主机进行兼容性测试
- 使用 USB PD 分析器检查供电协商过程

### 4. 认证要求

如果产品需要通过 USB-IF 认证：
- 必须严格遵守 USB Type-C 规范
- CC 引脚配置是认证测试的重点项目
- 建议使用通过认证的 Type-C 连接器

## 总结

USB Type-C 接口的 CC 引脚配置虽然看似简单，但直接关系到设备的供电兼容性和功能正常性。**CC1 和 CC2 必须分别使用独立的 5.1kΩ 电阻接地**，这是 USB-IF 规范的强制要求。

错误的短接接法可能导致：
- 设备被误识别为音频配件
- 供电失败或功率不足
- 兼容性问题

遵循规范进行设计，不仅能确保产品在各种场景下正常工作，也是通过 USB-IF 认证的必要条件。在实际设计中，建议参考 USB Type-C 规范的最新版本，并进行充分的兼容性测试。

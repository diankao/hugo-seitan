# 晶振的类型、选型与应用

## 两种晶振类型

很多 MCU 都支持无源和有源两种晶振，它们在结构、工作原理和使用方式上都有显著差异。

### 无源晶振

无源晶振的内部就是一个石英片，两侧贴着金属极板。它必须依赖外部电路的支持才能进行稳定的震动，这个由无源晶振和外部电路组成的整体称为**时钟电路**。

#### 皮尔斯振荡器

无源晶振一般采用皮尔斯振荡器接法与 MCU 内部电路配合：

```
         C1
         |
XTAL1 --+--[晶振]--+-- XTAL2
         |          |
         C2         (反馈到MCU内部)
```

- **XTAL1**：晶振信号输入引脚
- **XTAL2**：晶振信号输出引脚
- **C1、C2**：起振电容（负载电容）
- **反馈**：皮尔斯振荡器需要用 XTAL2 的输出作为反馈信号，维持晶振持续震动

#### 无源晶振的特点

**优点：**
- 成本低
- 功耗低
- 灵活性高（可以通过调整电容微调频率）
- 尺寸小

**缺点：**
- 需要外部电路支持
- 起振时间较长
- 容易受外部干扰

### 有源晶振

有源晶振内部不仅有石英晶片，还有相关的 IC 和阻容电路，内部自成一个完整的时钟电路。常见封装有 3 个或 4 个引脚（4 引脚封装中有一个是空引脚，仅起固定作用）。

#### 有源晶振的接法

```
VCC --+-- [有源晶振] -- OUT -- XTAL1
      |                  |
GND --+----------------+ (XTAL2悬空)
```

**引脚定义：**
- **VCC**：电源输入（通常 3.3V 或 5V）
- **GND**：接地
- **OUT**：时钟信号输出
- **NC**：空引脚（仅用于固定）

当使用有源晶振为 MCU 提供时钟信号时：
- 有源晶振的 OUT 引脚连接 MCU 的 XTAL1
- MCU 的 XTAL2 引脚悬空
- 只需连接 VCC 和 GND 即可工作

#### 有源晶振的特点

**优点：**
- 无需外部电路，使用简单
- 起振快
- 频率精度高
- 抗干扰能力强
- 驱动能力强

**缺点：**
- 成本较高
- 功耗较大
- 尺寸相对较大
- 频率不可调

### 无源与有源晶振对比

| 特性 | 无源晶振 | 有源晶振 |
|------|---------|---------|
| 外部电路 | 需要 | 不需要 |
| 成本 | 低 | 高 |
| 功耗 | 低 | 高 |
| 起振时间 | 较长 | 快 |
| 频率精度 | 一般 | 高 |
| 抗干扰 | 较弱 | 强 |
| 使用复杂度 | 较高 | 低 |
| 尺寸 | 小 | 较大 |

## 为什么选择 11.0592MHz 的晶振

### 1. 市场和兼容性

最早的 8051 单片机使用 1MHz 到 12MHz 之间的晶振，但后来 11.0592MHz 成为最广泛使用的规格，主要是因为这个频率在通信方面非常方便。

随着时间的推移，越来越多的开发者和厂商选择 11.0592MHz 作为标准频率，许多外围设备和模块也都支持这个频率。这种普遍的使用使得单片机系统的兼容性和稳定性得到了极大的提升。

### 2. 方便通信

单片机经常需要与其他设备进行通信，如电脑、传感器等。通信时，两个设备之间需要指定准确的数据传输速度，称为**波特率**。

11.0592MHz 这个频率特别适合生成常见的通信波特率，如 9600、19200、57600、115200 等。

**数学原理：**

波特率的计算公式通常为：
```
波特率 = 晶振频率 / (分频系数 × 定时器预分频)
```

以 9600 波特率为例：
- 使用 11.0592MHz 晶振：`11059200 / 9600 = 1152`（整数，无误差）
- 使用 12MHz 晶振：`12000000 / 9600 = 1250`（需要近似，存在误差）

**常见波特率的精确性：**

| 波特率 | 11.0592MHz | 12MHz |
|-------|-----------|-------|
| 9600 | 完全精确 | 有误差 |
| 19200 | 完全精确 | 有误差 |
| 57600 | 完全精确 | 有误差 |
| 115200 | 完全精确 | 有误差 |

因此，11.0592MHz 能够被许多常见波特率的整数倍整除，从而产生精确且稳定的波特率，减少通信误差，使单片机与其他设备之间的通信更加稳定和可靠。

## 晶振电路参考设计

### MCU 数据手册的参考

官方数据手册通常提供无源晶振的接法和电容选型参考。例如某款 MCU 的推荐：

| 晶振频率 | 负载电容 |
|---------|---------|
| 4 MHz - 6 MHz | 47pF - 100pF |
| 6 MHz - 12 MHz | 30pF - 68pF |
| 12 MHz - 25 MHz | 15pF - 47pF |

这只是一个参考建议，实际应用中还需要根据晶振厂家的参数进行调整。

### 负载电容的含义

在立创商城等平台搜索 11.0592MHz 晶振时，会看到一个参数叫**负载电容**（Load Capacitance），很多厂家标注为 20pF。

**负载电容指的是：**
- 晶振正常工作所需的外部电容值
- 这是晶振厂家为使其在标称频率下稳定工作而提供的电容参考值
- 包括了晶振引脚的寄生电容和 PCB 走线电容

**实际电容的计算：**

如果晶振的负载电容为 CL，则两个起振电容 C1 和 C2 的值大约为：
```
C1 = C2 = 2 × CL - C_stray
```

其中 C_stray 是线路寄生电容（通常 3pF - 10pF）。

### 最终选型原则

因为 20pF 负载电容的晶振更加常见，实际设计时通常选择：
- **晶振**：负载电容 20pF
- **起振电容**：C1 = C2 = 22pF 或 30pF

**当厂家建议值与数据手册冲突时：**
- 晶振厂家的参考值更具权威性
- 初版设计按厂家建议选型
- 测试时如发现不稳定，可更换电容进行调整

## 晶振的外壳接地

晶振外壳接地是一个重要的 EMC 设计：

**作用：**
- 使晶振更稳定地震动
- 屏蔽外部电磁干扰
- 防止晶振产生的辐射干扰其他电路
- 提供接地参考，减少共模噪声

**实现方法：**
- 将晶振金属外壳连接到 PCB 接地平面
- 使用接地焊盘或金属夹固定
- 确保低阻抗连接

## STM32 晶振推荐实践

### STM32 晶振类型

STM32 系列通常有两种晶振输入：

1. **主晶振（HSE，High Speed External）**：通常 8MHz - 25MHz
2. **低速晶振（LSE，Low Speed External）**：32.768kHz（用于 RTC）

### STM32 主晶振推荐配置

#### 晶振频率选择

**常见主晶振频率：**
- **8MHz**：常用，通过 PLL 倍频到系统时钟
- **12MHz**：兼容性好
- **16MHz**：性能平衡
- **25MHz**：高性能需求

**STM32 系列推荐：**
- STM32F1/F4：8MHz 或 12MHz
- STM32F7/H7：25MHz
- STM32L4：8MHz 或 16MHz

#### 负载电容推荐

**STM32 主晶振（HSE）：**
```
晶振频率     负载电容    起振电容（C1=C2）
8 MHz        20pF        22pF - 30pF
12 MHz       18pF        18pF - 22pF
16 MHz       15pF        15pF - 18pF
25 MHz       12pF        12pF - 15pF
```

**STM32 低速晶振（LSE - 32.768kHz）：**
- 负载电容：12.5pF
- 起振电容：6pF - 10pF
- 建议使用专门的 RTC 晶振（如 EPSON、TXC 品牌）

### STM32 有源晶振方案

对于某些应用，STM32 也可以使用有源晶振：

**适用场景：**
- 需要更高频率精度
- EMC 要求严格
- 希望简化电路设计
- 高速接口需求（如 USB、以太网）

**推荐有源晶振：**
- STM32F4/F7：25MHz 有源晶振
- STM32H7：25MHz 或 50MHz 有源晶振

**连接方式：**
```
有源晶振 OUT -> MCU 的 PH0-OSC_IN
MCU 的 PH1-OSC_OUT 悬空
```

### STM32 晶振电路布局要点

#### 1. 晶振放置位置

- 晶振应尽可能靠近 MCU 的晶振引脚
- 优先放置在 MCU 附近，避免长走线
- 不要将晶振放在 PCB 边缘或靠近干扰源

#### 2. 走线原则

- 晶振走线尽可能短
- 两条晶振线（XTAL_IN 和 XTAL_OUT）应等长
- 走线宽度：8mil - 10mil
- 避免直角走线，使用 45° 或圆弧
- 不要跨越分割的参考平面

#### 3. 接地处理

- 晶振下方铺设完整的接地平面
- 起振电容的地端就近连接到地平面
- 晶振外壳接地（如果适用）

#### 4. 隔离保护

- 不要在晶振附近走高速信号线
- 不要让晶振线穿过信号密集区域
- 必要时可以使用接地保护线

### STM32 时钟树配置示例

以 STM32F103 为例，使用 8MHz 外部晶振：

```
外部晶振：8MHz
  ↓
HSE 分频器：/1 = 8MHz
  ↓
PLL 倍频：×9 = 72MHz
  ↓
系统时钟 (SYSCLK)：72MHz
  ↓
AHB 分频：/1 = 72MHz
  ↓
APB1 分频：/2 = 36MHz
  ↓
APB2 分频：/1 = 72MHz
```

这种配置可以充分利用 STM32 的性能，同时保持各个外设在合适的时钟频率下工作。

### STM32 晶振常见问题与解决

#### 1. 晶振不起振

**可能原因：**
- 负载电容不匹配
- 晶振质量问题
- 走线过长或干扰严重
- MCU 配置错误

**解决方法：**
- 更换起振电容值（尝试 15pF - 33pF）
- 使用示波器检查晶振输出
- 检查 MCU 时钟配置寄存器
- 优化 PCB 布局

#### 2. 频率偏差过大

**可能原因：**
- 晶振精度等级不够
- 负载电容不匹配
- 温度影响

**解决方法：**
- 选择更高精度的晶振（±10ppm 或 ±20ppm）
- 调整负载电容
- 考虑温度补偿

#### 3. EMC 测试失败

**可能原因：**
- 晶振辐射超标
- 走线不合理

**解决方法：**
- 优化晶振电路布局
- 添加 EMI 滤波器
- 使用有源晶振
- 屏蔽晶振电路

## 总结

晶振的选择和设计是 PCB 设计中的关键环节。合理选择晶振类型、频率和配套电路需要注意：

1. **类型选择**：根据成本、精度、功耗需求选择无源或有源晶振
2. **频率选择**：11.0592MHz 适合串口通信，8/12/25MHz 适合 STM32
3. **电容匹配**：按晶振厂家的负载电容参数选择起振电容
4. **布局优化**：晶振靠近 MCU，走线短且等长，良好的接地
5. **EMC 考量**：外壳接地，远离干扰源，必要时使用有源晶振

对于 STM32 系列，推荐使用 8MHz 或 25MHz 主晶振 + 32.768kHz 低速晶振的组合，并严格按照厂商的布局建议进行设计。

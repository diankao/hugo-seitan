# 数字电路竞争与冒险

## 竞争与冒险是什么

| 术语 | 定义 | 关系 |
|------|------|------|
| **竞争(Race)** | 同一信号经过**不同路径**到达同一个门,路径延迟不同,到达有先后 | 原因 |
| **冒险(Hazard)** | 由于竞争,输出出现**不该有的毛刺(glitch)** | 结果 |

竞争不一定产生冒险,但冒险必然源于竞争。

## 产生本质:门延迟

任何门都有传播延迟(几 ns)。同一个信号走两条路,一条路过一个门、另一条路过三个门,到达终点的时间就错开了几 ns——这几 ns 里,逻辑上"不该变"的输出会瞬间跳一下。

### 经典例子:`Y = A + A'`(或门)

```
A ──────┐
        ├─[OR]── Y = A + A' ≡ 1(逻辑上恒为1)
A ─[NOT]┘

时序:
A:      ──────┐┌──────┐┌─────
               ││      ││
A'(延迟):─────┐┌──────┐┌────
               ││      ││
Y:      ──┐  ┌─┘└──┐  ┌─┘  ───   ← 中间出现 0 毛刺!
            │  │     │  │
            └──┘     └──┘
            ↑毛刺:逻辑上 Y 应该恒 1,
              但 A 已变 0、A' 还没变 1 的瞬间,Y = 0
```

**静态-1 冒险**:输出应该保持 1,却瞬间掉到 0。

对偶例子:`Y = A · A'`(与门)——逻辑上恒 0,反相器延迟期间两输入同时为 1,输出窜出 1 毛刺,叫**静态-0 冒险**。

## 冒险分类

| 类型 | 现象 | 例子 |
|------|------|------|
| **静态-1 冒险** | 应保持 1,瞬间出 0 毛刺 | `A + A'` |
| **静态-0 冒险** | 应保持 0,瞬间出 1 毛刺 | `A · A'` |
| **动态冒险** | 应跳变**一次**(0→1),却跳了**多次**(0→1→0→1) | 多级路径延迟叠加,少见但存在 |

静态冒险是单一门的"两级路径"竞争;动态冒险是三个及以上路径竞争,输出在稳定前反复振荡。

## 判断方法

### 方法一:代数法

**令其他变量取遍所有组合,若函数能化简成 `X + X'` 或 `X · X'` 形式,则存在冒险。**

经典例:`F = AB + A'C`

```
B=1, C=1 时:F = A·1 + A'·1 = A + A'   ← 冒险!
B=1, C=0 时:F = A            ← 无
B=0, C=1 时:F = A'           ← 无
B=0, C=0 时:F = 0            ← 无
```

结论:当 B=C=1 时 A 的变化会产生冒险。

### 方法二:卡诺图法(更快)

**卡诺圈"相切"(相邻但无公共圈覆盖)→ 有冒险;相交或隔开 → 无冒险。**

```
F = AB + A'C 的卡诺图:

       A'      A
      ┌───┬───┐
B'=0  │ 0 │ 0 │
      ├───┼───┤
B =1  │ 1 │ 1 │ ←── 圈2:AB(右边两格)
      │ 1 ├───┤
      └───┘   ↑
        圈1:A'C(左下角起)
```

圈 `AB` 和圈 `A'C` 在 B=1 行**相切**——A 在 0/1 之间切换时,信号从一个圈"移交"到另一个圈,移交瞬间两个乘积项同时为 0 → 毛刺。

## 消除方法(按工程常用度排)

### 1. 加冗余项(理论最优)

在相切处加一个圈把"移交路径"盖住:

```
F = AB + A'C + BC
             ↑冗余项

验证:B=C=1 时:F = AB + A' + B = 1(恒1,无冒险)
```

卡诺图上就是在两个相切圈之间再画一个覆盖公共边的圈。代价:多一个逻辑项,可能多一级门。

### 2. 输出端加滤波电容(低速适用)

毛刺通常只有几 ns,一个小电容(几十 pF)就滤掉了。代价:边沿变缓,高速系统不能用。

### 3. 加选通信号(Strobe / 取样法)

毛刺只出现在输入变化后的短暂窗口里。等信号稳定后再用选通信打开输出门,取样时刻避开毛刺。代价:需要精确的时序控制,牺牲速度。

### 4. 寄存器打一拍(现代数字设计的标准做法)⭐

**毛刺只存在于组合逻辑中**。只要毛刺在**下一个时钟沿到来之前**稳定下来(setup time 满足),寄存器采样到的就是稳定值——毛刺被寄存器"过滤"了。

```
组合逻辑(有毛刺) ──→ [D触发器] ──→ 干净输出
                       ↑
                    时钟沿采样(毛刺已稳定)
```

这就是为什么现代同步设计(FPGA/IC)不怕组合逻辑毛刺——满屏毛刺无所谓,只要时钟沿前稳住。

## 实战关联

### 毛刺的三条"高压线"

组合逻辑有毛刺本身没事,但毛刺碰到这三样就是事故:

| 高压线 | 后果 |
|--------|------|
| **毛刺当时钟** | 时钟线绝对不能接组合逻辑输出,会造成假时钟沿 → 计数乱跳 |
| **毛刺当异步复位** | 复位被毛刺误触发 |
| **毛刺做锁存使能** | 锁存器锁到中间态 |

### 格雷码:冒险的最大受益者

二进制计数 0111→1000 时**四位同时变**,各位路径延迟不同 → 译码输出必炸毛刺。**格雷码相邻状态只变一位**,天然无竞争 → 无冒险:

| 二进制 | 格雷码 | 变化位数 |
|--------|--------|---------|
| 011 | 010 | — |
| 100 | 110 | 格雷码只变 1 位 |

这就是跨时钟域 FIFO 指针用格雷码的根本原因:指针被另一个时钟采样时,即使采样到变化瞬间,结果也只是"旧值或新值",不会是乱码。

### 亚稳态 ≠ 冒险(别混)

| | 冒险 | 亚稳态 |
|--|------|--------|
| 场景 | 组合逻辑内部 | 异步信号进触发器(违反 setup/hold) |
| 表现 | 短暂毛刺 | 触发器输出长时间不确定(0/1 之间振荡) |
| 解法 | 冗余项/打一拍 | 两级同步器 |

## 速记口诀

- **竞争是原因(路径延迟差),冒险是结果(输出毛刺)**
- **静态冒险**:该 1 出 0、该 0 出 1;**动态**:跳变多次
- **代数判断**:化简出 `X + X'` 或 `X · X'` → 有冒险
- **卡诺图判断**:圈相切 → 有冒险
- **消除**:加冗余项 / 滤波电容 / 选通 / 打一拍(现代标准)
- **毛刺三高压线**:时钟、异步复位、锁存使能
- **格雷码只变一位 → 无竞争 → 跨时钟域标配**

## 常见追问

1. **F = (A+B)(A'+C) 有没有冒险?**
   B=C=0 时 F = A·A',静态-0 冒险。消除:加冗余项 (B+C) → F = (A+B)(A'+C)(B+C)。和 F = AB+A'C+BC 是对偶的。

2. **为什么同步电路不怕毛刺?**
   寄存器只在时钟沿采样,只要毛刺在沿前稳定(setup 满足),采样值就是干净的。毛刺只在组合逻辑传播,过不了寄存器。

3. **打一拍能消除亚稳态吗?**
   不能"消除",只能降低概率。两级同步器把亚稳态传播概率降到近似零(每级衰减几个数量级),但永远不为零。

4. **实际项目中怎么处理冒险?**
   写 RTL 时保证"寄存器输出 → 组合 → 寄存器"结构,毛刺不出模块;唯一要防的是组合逻辑输出直接出模块/当时钟/进异步端口。

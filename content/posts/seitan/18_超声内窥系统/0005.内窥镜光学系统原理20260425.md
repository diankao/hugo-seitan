# 内窥镜光学系统原理

## 题目

请介绍内窥镜光学系统的基本组成和工作原理。内窥镜的物镜系统、照明系统和光纤传像束各自承担什么角色？在设计中需要考虑哪些光学参数？

## 考察点

- 内窥镜光学系统的整体架构理解
- 物镜系统的成像原理与关键参数（视场角、焦距、F数）
- 照明系统的设计（LED/光纤照明、均匀性）
- 光纤传像束的结构与传像原理
- 硬镜与软镜的光学差异
- 临床需求对光学设计的约束（直径、弯曲、分辨率）

## 回答要点

### 1. 内窥镜光学系统整体架构

内窥镜的光学系统可分为三大子系统：**照明系统**、**物镜成像系统**和**图像传输系统**。

```
┌─────────────────────────────────────────────────┐
│                 内窥镜光学系统                     │
│                                                   │
│  ┌──────────┐   ┌──────────┐   ┌──────────────┐  │
│  │ 照明系统  │   │ 物镜系统  │   │ 图像传输系统  │  │
│  │          │   │          │   │              │  │
│  │ LED/卤素灯│──▶│ 物镜镜头  │──▶│ 光纤束/棱镜  │  │
│  │ + 导光光纤│   │ (成像)   │   │ (传像)      │  │
│  └──────────┘   └──────────┘   └──────────────┘  │
│       │                              │            │
│       ▼                              ▼            │
│   照亮腔体内壁                   传输图像到       │
│   提供观察条件                   目视镜/摄像头    │
└─────────────────────────────────────────────────┘
```

光路工作流程：
1. **光源**发出的光经**导光光纤束**传导至内窥镜前端，照亮观察目标
2. 目标反射光经**物镜系统**成像
3. 成像光线通过**传像光纤束**（软镜）或**柱状透镜组**（硬镜）传输到目镜端
4. 目镜端可直接目视观察，也可接摄像头转为电子图像

### 2. 照明系统

#### 2.1 光源类型

| 光源类型 | 优点 | 缺点 | 典型应用 |
|---------|------|------|---------|
| LED | 寿命长、功耗低、即亮即用 | 光通量相对较低 | 便携式内窥镜、一次性内窥镜 |
| 氙气灯 | 光通量高、色温接近日光 | 寿命短、发热大、需滤红外 | 高端手术内窥镜 |
| 卤素灯 | 成本低、光谱连续 | 发热严重、寿命短 | 早期内窥镜（已逐渐淘汰） |
| 激光光纤 | 单色性好、耦合效率高 | 成本高、需安全防护 | 特种荧光内窥镜 |

#### 2.2 导光光纤束

导光光纤束负责将光源发出的光传导到内窥镜前端：

- **材料**：通常采用多模石英光纤或塑料光纤（POF）
- **排列**：随机排列，无需保序（只传光不传像）
- **数值孔径（NA）**：决定集光能力，一般 NA = 0.5~0.65
- **直径**：单根光纤芯径 25~50μm，整束直径根据镜体规格确定

```
光源端                         内窥镜前端
  🔆 ──▶ ┌─────────────────────────┐ ──▶ 💡
         │   导光光纤束（随机排列）  │
         │   ██████████████████████ │
         │   ██████████████████████ │
         │   只传光，不要求保序     │
         └─────────────────────────┘
```

#### 2.3 照明均匀性设计

腔体内壁的照明均匀性直接影响成像质量：

- **环形照明**：光纤出光端环绕物镜排列，形成均匀的环形光场
- **偏心照明**：适用于侧视内窥镜（如超声内窥镜），光纤偏置于一侧
- **漫射器**：在光纤出光面加微透镜阵列或磨砂面，改善均匀性
- **照明视场匹配**：照明角度需覆盖物镜的视场范围

### 3. 物镜成像系统

#### 3.1 物镜功能

物镜是内窥镜光学系统的核心，负责将腔体内壁的目标区域成像到像面上。

关键要求：
- **小直径**：需装入镜体前端（通常 2~10mm）
- **大视场角**：覆盖足够大的观察范围（通常 80°~140°）
- **高分辨率**：能分辨组织细节
- **大景深**：适应不同观察距离（通常 3~100mm）
- **低畸变**：减少图像失真

#### 3.2 关键光学参数

| 参数 | 含义 | 典型值 |
|------|------|--------|
| 焦距 f | 物镜的聚焦能力 | 1~5mm |
| 视场角 FOV | 可观察的角度范围 | 80°~140°（胃镜可达 140°） |
| F数 (F/#) | 相对孔径的倒数，影响进光量和景深 | F/2~F/5.6 |
| 数值孔径 NA | 集光能力和分辨能力的综合指标 | 0.1~0.3 |
| 畸变 | 像与物的形状偏差 | < 5%（需校正） |
| 景深 DOF | 能清晰成像的物距范围 | 3~100mm |

#### 3.3 物镜结构

内窥镜物镜通常采用**反远距（逆望远）结构**，以在短焦距下获得大视场角：

```
          前组（负光焦度）        后组（正光焦度）
              │                     │
              ▼                     ▼
  ○────── ◉ ─────────────── ◉ ── ◉ ────▶ 像面
  光阑    负透镜              正透镜组    (光纤束端面)
```

- **前组**：负透镜，发散光线，扩大视场角
- **后组**：正透镜组，聚焦成像
- **优点**：能在短焦距下获得大视场角，同时使主光线在像面处角度较小，有利于与光纤束耦合

#### 3.4 景深与超焦距设计

内窥镜需要在很宽的物距范围内清晰成像，景深公式：

```
DOF ≈ 2 × f² × F/# / (f² ± F/# × c × f)

简化估算：DOF ≈ 2 × c × N × (1 + M²/M)

其中：
- c：容许弥散圆直径
- N：F数
- M：放大率
```

实际设计中通过以下方式增大景深：
- 选择适当的 F数（F/4~F/5.6）
- 采用非球面透镜减小像差
- 电子后处理中的景深扩展（多帧融合）

### 4. 图像传输系统

#### 4.1 光纤传像束（软镜）

光纤传像束是软性内窥镜的核心传输部件：

```
光纤传像束截面示意（端面）

  ┌─────────────────┐
  │ ○○○○○○○○○○○○○○ │
  │ ○○○○○○○○○○○○○○ │    每根光纤对应一个像素
  │ ○○○○○○○○○○○○○○ │    两端排列严格一一对应
  │ ○○○○○○○○○○○○○○ │
  │ ○○○○○○○○○○○○○○ │
  └─────────────────┘

  物镜端                      目镜端
  A ───────────────────────── A
  B ───────────────────────── B
  C ───────────────────────── C   严格保序排列
  D ───────────────────────── D
```

关键参数：
- **像素数**：由光纤数量决定，典型 10,000~50,000 根
- **单丝直径**：6~10μm（越细分辨率越高，但光损耗越大）
- **填充系数**：有效传光面积占总面积的比例，约 60%~90%
- **数值孔径**：NA ≈ 0.5，决定与物镜的耦合效率

光纤传像束的局限性：
- 分辨率受光纤数量限制（远低于电子内窥镜的百万像素级）
- 存在"网格效应"（像素间的暗间隙）
- 长度增加会导致光损耗和对比度下降

#### 4.2 柱状透镜组（硬镜）

硬性内窥镜使用**Hopkins 柱状透镜系统**传输图像：

```
  传统透镜组（长光路中像差严重）：
  ( )──( )──( )──( )──( )──( )──▶   像差累积，成像差

  Hopkins 柱状透镜系统：
  ║──( )──║──( )──║──( )──║──▶     像差校正，成像好

  ║ = 柱状玻璃棒（长光程在玻璃中传播）
  ( ) = 空气间隔中的薄透镜（校正像差）
```

Hopkins 系统的优势：
- **高透光率**：光在玻璃中传播损耗小
- **大数值孔径**：进光量大，图像更明亮
- **宽视角**：可达 120° 以上
- **优秀分辨率**：远超光纤传像束

| 对比项 | 光纤传像束 | Hopkins柱状透镜 |
|--------|-----------|----------------|
| 分辨率 | 中等（受光纤数限制） | 高 |
| 亮度 | 一般 | 高 |
| 可弯曲 | ✅ 可以 | ❌ 不可以 |
| 制造成本 | 高 | 中等 |
| 典型应用 | 胃镜、肠镜等软镜 | 腹腔镜、关节镜等硬镜 |

### 5. 现代电子内窥镜的光学变化

传统光纤内窥镜正被**电子内窥镜（Video Endoscope）**取代：

```
传统光纤内窥镜：               电子内窥镜：
                              
物镜 → 传像光纤束 → 目镜      物镜 → CMOS/CCD → 电信号
                     👁                            │
                  人眼观察                    数字处理 → 显示器
                  （医生直接看）              （高分辨率、可记录）
```

- **CCD/CMOS 传感器**直接放置在内窥镜前端（物镜之后），取代传像光纤束
- 信号通过电缆传至外部处理器，不再依赖光纤传像
- 分辨率从光纤束的数万像素提升至百万像素级
- 物镜设计从"配合光纤束"变为"配合传感器"，设计自由度更大

### 6. 内窥镜光学系统设计约束

内窥镜光学设计面临多方面的工程约束：

| 约束维度 | 具体限制 | 设计应对 |
|---------|---------|---------|
| 直径 | 胃镜 ≤ 10mm，血管镜 ≤ 1mm | 微型光学元件、非球面透镜 |
| 工作长度 | 胃镜 ~1m，肠镜 ~1.7m | 光纤传像束或微型传感器 |
| 弯曲 | 前端弯曲段需 ±180° | 软性光纤束，光学系统需抗弯 |
| 景深 | 3~100mm 内均需清晰 | 小光圈 + 非球面设计 |
| 防水 | 需耐受体液浸泡 | 光学密封、防水窗设计 |
| 生物相容 | 接触人体组织 | 光学窗口材料选择（蓝宝石等） |
| 耐消毒 | 高温高压或化学消毒 | 耐高温胶合、金属结构 |

### 7. 超声内窥镜的光学特殊性

超声内窥镜（EUS）在光学系统上有其特殊之处：

- **侧视光学系统**：超声内窥镜通常采用侧视（90°）观察，而非前视
- **超声换能器与光学系统共存**：镜体前端需同时容纳超声探头和光学镜头
- **空间更紧凑**：前端直径通常 10~14mm，需同时容纳光学和超声模块
- **水囊耦合**：超声需要水囊耦合，光学窗口需透过水囊观察
- **多模态融合**：光学图像与超声图像的空间配准需要精确的光学参数标定

```
超声内窥镜前端截面示意：

        ┌──────────────────┐
        │  ○ 照明光纤      │
        │  □ 物镜（侧视）  │  ← 侧向 90° 观察
        │  ◎ 超声换能器    │  ← 侧向扇形扫描
        │  ○ 照明光纤      │
        │  □ 器械通道      │
        └──────────────────┘
              ↓
        光学和超声并排安装在前端
        共享同一个弯曲机构
```

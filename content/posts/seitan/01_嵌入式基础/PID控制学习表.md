# PID控制学习表

## 标签
#嵌入式 #控制理论 #PID #算法 #面试题

## 一句话本质

> **PID = "看误差,算补偿":让实际值跟上目标值。**

误差 = 目标值 - 实际值。PID 根据误差的**现在(P)、过去(I)、将来(D)** 算出控制量,驱动执行机构消除误差。

---

## 一、P / I / D 三项对照表

| 项 | 含义 | 看的是 | 作用 | 单独用的问题 |
|----|------|--------|------|-------------|
| **P 比例** | 误差大就猛推 | 现在 | 加快响应 | 有**稳态误差**(永远差一点) |
| **I 积分** | 累积历史误差 | 过去 | 消除稳态误差 | 响应慢、容易**超调振荡** |
| **D 微分** | 误差变化率 | 将来 | 抑制超调、预判 | 放大**噪声**,轻易别用 |

**口诀**:**P 管快、I 管准、D 管稳**。

```
误差 e(t) = 目标 r(t) − 实际 y(t)

         ┌───────────┐
目标 r ──→│  −  (e)   │──→ [P + I + D] ──→ 控制量 u ──→ 执行机构 ──→ 实际 y
         │           │                                  │
         └───── 反馈 ←───────────────────────────────────┘
```

---

## 二、连续 → 离散(代码实现)

### 连续形式

$$
u(t) = K_p \cdot e(t) + K_i \int_0^t e(\tau)d\tau + K_d \frac{de(t)}{dt}
$$

### 离散化(采样周期 T)

两种工程写法:

#### 1. 位置式 PID(直接输出 u)

```c
typedef struct {
    float Kp, Ki, Kd;
    float integral;     // 积分累积
    float prev_error;   // 上次误差
    float out_max, out_min;  // 输出限幅(抗饱和)
} PID_t;

float pid_calc(PID_t *p, float target, float actual) {
    float error = target - actual;
    p->integral += error;
    float derivative = error - p->prev_error;
    p->prev_error = error;

    float out = p->Kp * error
              + p->Ki * p->integral
              + p->Kd * derivative;

    // 输出限幅
    if (out > p->out_max) out = p->out_max;
    if (out < p->out_min) out = p->out_min;
    return out;
}
```

#### 2. 增量式 PID(输出增量 Δu)

```c
// 只输出变化量,执行机构自己累加(步进电机、伺服驱动器常用)
float pid_inc(PID_t *p, float target, float actual) {
    float error = target - actual;
    float du = p->Kp * (error - p->prev_error)
             + p->Ki * error
             + p->Kd * (error - 2*p->prev_error + p->prev_error2);
    p->prev_error2 = p->prev_error;
    p->prev_error = error;
    return du;  // 调用方自己累加
}
```

| 对比 | 位置式 | 增量式 |
|------|--------|--------|
| 输出 | 绝对值 u | 增量 Δu |
| 积分饱和 | 需要额外处理 | 天然抗饱和 |
| 切换冲击 | 大 | 小 |
| 典型场景 | 一般执行机构 | 步进/伺服驱动器 |

## 三、调参方法

### 1. 试凑法(最常用)

先 P 后 I,最后 D(如果需要):

1. **Ki=0, Kd=0**,只调 Kp。从大到小或从小到大,直到响应快但不严重振荡。
2. **加 Ki**:从很小开始,慢慢增大,直到稳态误差消除,但不要引起大超调。
3. **加 Kd**(可选):小量加,抑制超调。噪声大就别用。

### 2. 临界比例法(Ziegler-Nichols)

1. Ki=0, Kd=0,只加 Kp。
2. Kp 从小到大,直到系统出现**等幅振荡**。
3. 记下此时的 Kp = **Ku**(临界增益),振荡周期 = **Tu**。
4. 查表:

| 控制器 | Kp | Ti | Td |
|--------|-----|-----|-----|
| P | 0.5 Ku | — | — |
| PI | 0.45 Ku | 0.83 Tu | — |
| PID | 0.6 Ku | 0.5 Tu | 0.125 Tu |

> 注意:Z-N 法在系统**不能容忍振荡**时(机械臂、医疗设备)慎用!

### 3. 经验口诀

- **振荡过猛** → 减小 Kp、增大 Kd
- **稳态有差** → 增大 Ki
- **响应太慢** → 增大 Kp
- **超调严重** → 减小 Ki、增大 Kd
- **高频抖动** → Kd 太大或没滤波,去掉 Kd

## 四、工程上的坑(面试高频)

### 1. 积分饱和(Anti-Windup)⭐ 最重要

**现象**:误差长时间存在(如电机堵转),积分项越积越大。等误差消除时,积分项释放不出来,导致**严重超调**。

**解决**:
- 输出限幅(上面代码里有)
- 积分项也限幅
- **遇限停止积分**:输出到限就别再往那个方向积
- **积分分离**:误差大时(>阈值)关掉 I,误差小时才开

```c
// 积分分离
if (fabs(error) < threshold) {
    p->integral += error;  // 误差小时才积分
}
```

### 2. 微分项噪声

D 项对高频噪声极度敏感(微分 = 放大高频)。

**解决**:
- 对**测量值**微分,不对**误差**微分(避免设定值突变冲击)
- 加低通滤波:`derivative = α*derivative + (1-α)*(error-prev_error)`

### 3. 设定值突变冲击

目标值突然跳变 → 误差突变 → D 项炸、I 项猛冲。

**解决**:
- 目标值**斜坡化**(渐变到目标)
- 微分项用测量值

### 4. 采样周期

- 太快:噪声放大、计算浪费
- 太慢:控制精度差
- **经验**:采样周期 ≈ 系统响应时间的 1/10

## 五、进阶:串级 PID / 前馈

### 串级 PID(电机控制标配)

```
位置环(外环) → 速度环(内环) → 电流环(最内)
   ↓P            ↓PI            ↓PI
位置误差     速度误差       电流误差
```

外环输出作为内环的设定值。**电机控制几乎都是三环串级**。

### 前馈控制(Feedforward)

PID 是"事后补救"(有误差才动),前馈是"事前预判":
- 已知系统模型 → 直接给个预估控制量
- PID 只补残差 → 误差小很多
- **轨迹跟踪**(写字机!)用前馈 + PID 效果极佳

## 六、脑机接口 / 写字机里的 PID 落地 ★

### 脑机接口(BCI)场景

> 只要 BCI 接了"物理外设"或"闭环调节",几乎必然有 PID。纯解码层没有,但从意图到执行全是控制。

| 场景 | PID 角色 |
|------|---------|
| 解码意图驱动机械臂/外骨骼 | 关节角度环 PID(位置+速度串级) |
| 光标/轮椅速度控制 | PID 平滑解码出的噪声速度,跟踪目标速度 |
| 电极微驱动找神经元 | PID 维持电极阻抗在目标范围(自动寻优植入深度) |
| 闭环神经刺激 | 检测脑状态 → PID 调刺激电流,维持生理指标 |
| fNIRS/光学头架 | 光路防抖、机械稳定平台 PID |
| 实验范式反馈 | 屏幕光标 PID 平滑,避免直接跳变让被试眩晕 |

### 写字机场景(按电机类型判断)

| 你的写字机是... | PID 需求 | 学 PID 的切入点 |
|----------------|---------|----------------|
| 步进电机 + 皮带/丝杆 | ❌ 开环即可,用梯形/S 曲线加减速 | 想练 PID,把一个轴换伺服+编码器 |
| 直流伺服 + 编码器 | ✅ 位置环 PID(内速度+外位置) | 经典练手场景 |
| 有笔尖压力控制 | ✅ 力控 PID | 下笔力度恒定,线条均匀 |
| 机械臂持笔 | ✅ 每关节一个 PID | 最接近 BCI 机械臂的场景 |

**练手建议**:写字机是学 PID 的完美载体——把笔尖轨迹歪不歪、抖不抖当反馈,调参效果肉眼可见。建议:
1. 一个轴改伺服 + 编码器
2. 加前馈(已知轨迹) + PID(补残差)
3. 笔尖画圆/画直线,看 PID 调参对圆度的影响

## 七、面试速记口诀

- **P 管快、I 管准、D 管稳**
- **调参顺序:P → I → D**
- **积分必抗饱和**(遇限停止 / 积分分离)
- **微分必滤波**,噪声大就别用 D
- **设定值突变** → 微分用测量值,或目标斜坡化
- **电机控制 = 三环串级**(位置/速度/电流)
- **轨迹跟踪 = 前馈 + PID**(不是纯 PID)

## 八、常见追问 & 坑

1. **Q:为什么 PID 这么老还能统治工业?**
   A:模型无关(不需要精确数学模型)、实现简单、鲁棒性强。90% 工业回路用 PID。

2. **Q:位置式和增量式怎么选?**
   A:执行机构能累加(步进/伺服驱动器)→ 增量式;一般执行机构(电机直接 PWM)→ 位置式。

3. **Q:Ki 太大会怎样?**
   A:积分饱和 → 严重超调 → 反复振荡 → 系统失稳。

4. **Q:什么情况不用 D?**
   A:噪声大(如流量、压力传感器)、纯滞后大的系统。

5. **Q:PID 和状态空间控制区别?**
   A:PID 是经典控制(单入单出、频域);状态空间是现代控制(多入多出、时域)。BCI 解码(如 Kalman 滤波、线性解码)更接近状态空间,PID 在外设执行层。

# 上下拉电阻学习表

## 标签
#嵌入式 #硬件基础 #GPIO #电路设计 #面试题

## 一句话本质

> **上拉/下拉电阻 = 给引脚一个"默认电平"，避免悬空（floating）。**

引脚悬空时电平不确定（受干扰随机跳变），上下拉就是给它一个稳定的"默认值"。

---

## 一、核心概念对照表

| 概念 | 上拉（Pull-Up） | 下拉（Pull-Down） |
|------|-----------------|-------------------|
| 电阻接法 | 引脚 → 电阻 → VCC | 引脚 → 电阻 → GND |
| 默认电平 | 高（1） | 低（0） |
| 常见配合 | 按键接 GND（按下变低） | 按键接 VCC（按下变高） |
| 典型应用 | I2C、中断线、复位脚 | 使能脚、MOS 栅极、NPN 基极 |
| MCU 内部支持 | 普遍有（~40kΩ） | 普遍有（~40kΩ） |

---

## 二、内部 vs 外部电阻

### 内部上拉/下拉

- **位置**：MCU 内部，通过寄存器配置（STM32 是 `GPIOx_PUPDR`）
- **阻值**：弱上拉，通常 **30kΩ~50kΩ**
- **优点**：省一个外部元件，BOM 简化
- **缺点**：阻值大、驱动弱、不能精确控制

### 各芯片内部上拉支持情况

| 芯片 | 内部上拉 | 典型阻值 | 配置方式 |
|------|---------|---------|----------|
| STM32 (F1/F4/H7) | ✅ 有 | ~40kΩ | `GPIO_PullUp` |
| ESP32 / ESP8266 | ✅ 有 | ~45kΩ | `GPIO_PULLUP_ENABLE` |
| AVR (Arduino Uno) | ✅ 有 | ~20-50kΩ | `INPUT_PULLUP` |
| GD32 / 国产 MCU | ✅ 普遍有 | 类似 STM32 | 同 STM32 |
| 树莓派 (BCM2835) | ✅ 有 | ~50kΩ | `GPIO_PUD_UP` |

---

## 三、什么时候内部够用？什么时候必须外部？

### ✅ 内部够用的场景

| 场景 | 原因 |
|------|------|
| 按键、矩阵键盘 | 负载小、速度慢 |
| 拨码开关、状态输入 | 静态信号，无时序要求 |
| 简单 GPIO 输入 | 默认电平稳定即可 |

### ❌ 必须外部的场景

| 场景 | 必须外部的原因 | 典型阻值 |
|------|---------------|---------|
| **I2C / SMBus** | 速度要求高 + 总线电容大，内部 RC 太慢 | 4.7kΩ（标准）/ 1kΩ（快速+） |
| **1-Wire (DS18B20)** | 时序严格，spec 明确要求 | 4.7kΩ |
| **SPI 的 CS（部分场景）** | 多设备共享、抗干扰 | 10kΩ |
| **中断信号线 IRQ（开漏共享）** | 多设备线与，可靠拉高 | 4.7kΩ~10kΩ |
| **复位脚 NRST** | 抗干扰、上电时序 | 10kΩ |
| **长走线信号** | 抗噪声、防反射 | 1kΩ~10kΩ |
| **未用引脚（NC）** | 防悬空、降功耗 | 10kΩ（上拉或下拉） |
| **MOS 栅极 / 三极管基极** | 防误开通 | 10kΩ 下拉 |

## 四、没有内部上下拉的常见芯片

> **"有内部上拉"是 MCU 的福利,不是芯片界的常识。**
> 离开 MCU 进入逻辑芯片、电源芯片、比较器、FPGA、模拟电路的地盘,默认就得自己加电阻。datasheet 里 `Pull-Up: Yes/No` 那一行一定先看。

### 1. 老 8051 的 P0 口(经典坑!)

| 端口 | 内部上拉 | 说明 |
|------|---------|------|
| **P0** | ❌ 没有 | 开漏输出,必须外部上拉 |
| P1 / P2 / P3 | ✅ 有(弱上拉) | 准双向口 |

8051 用 P0 口接外设时,**必须外接 10kΩ 上拉电阻排**,否则输出不了高电平。新手常踩。

### 2. 纯数字逻辑芯片(74 / 4000 系列)

`74HC00`、`74HC244`、`CD4060` 等:

- **输入引脚无任何上下拉**
- 悬空 = 高阻 = 噪声触发 = 输出乱跳
- datasheet 明确要求"未使用输入脚必须接 VCC 或 GND"

老工程师常踩的坑:**电路时好时坏,查半天发现是某逻辑门输入悬空**。

### 3. 比较器 / 开漏输出运放

`LM393`、`LM339` 等:

- 输出是开漏(OC)结构
- **必须外部上拉(1k~10kΩ)**
- 不接 → 永远是低电平

### 4. 电源芯片 EN 脚(高频踩坑区)

| 芯片 | EN 内部上拉 |
|------|------------|
| LM2596 | ✅ 有(内部上拉到 Vin) |
| **TPS5430 / TPS54xxx** | ❌ 没有,必须外部 |
| **MP1584 / MP2359** | ❌ 没有(国产常用,新手常忘接) |
| SY8120 / SY8009 | 部分有,看 datasheet |
| LM7805 | 无 EN 脚(线性电源不需要) |

**实战建议**:用 Buck/Boost 芯片时,EN 脚**一律外部加 100kΩ 上拉到 Vin**,不管 datasheet 说有没有内部,稳。

### 5. FPGA / CPLD

| 系列 | 内部上下拉 |
|------|-----------|
| 老 Spartan / Cyclone II | ❌ 多数没有 |
| 现代 Spartan-7 / Artix-7 | ✅ 有,可配置 |
| Lattice MachXO2 | ✅ 有 |
| 国产紫光同创 / 高云 | 高端有,低端无 |

关键信号(复位、使能)在 **bitstream 加载前**状态不确定,**外部电阻不能省**。

### 6. 有内部也不能用的场景

| 场景 | 原因 |
|------|------|
| ADC / DAC 引脚 | 内部上下拉注入电流,破坏精度 |
| 高阻传感器(pH / 心电电极) | 内部 40kΩ 直接拉死信号 |
| 1-Wire 单总线 | 内部太弱,上升时间不达标,必须外部 4.7kΩ |

### 本章速查口诀

| 看到这种芯片 | 默认动作 |
|-------------|---------|
| 8051 的 P0 口 | 外部上拉,没商量 |
| 74 / 4000 系列逻辑芯片 | 未用引脚必须接 VCC / GND |
| 比较器 LM393 / 339 | 输出必须外部上拉 |
| 电源芯片 EN 脚 | 一律外部 100kΩ 上拉,稳 |
| FPGA 关键信号 | bitstream 加载前外部兜底 |
| 模拟引脚 / 传感器 | 严禁内部上下拉 |

## 五、关键概念深入

### 1. 总线电容（Bus Capacitance）

**任何导线、引脚都存在寄生电容。**

```
VCC
 |
 R(上拉)
 |
─+───+───+───  SDA 一根线，挂多个设备
 |   |   |
[A] [B] [C]   每个引脚约 10pF
```

- 每个设备引脚 ≈ 10pF
- PCB 走线 ≈ 几 pF/cm
- **I2C spec：总线电容最大 400pF**

**电容 + 上拉电阻 = RC 充电电路**：
- R 越小 → 上升越快 → 能跑高速
- R 越大 → 上升越慢 → 速度上不去

**类比**：电容是水桶，电阻是水管。水管粗（R 小）→ 装满快。但水管太粗（R 太小）→ 设备拉低时灌电流浪费功耗。需要权衡。

### 2. I2C 上拉电阻计算公式

$$
R_{max} = \frac{t_r}{0.8473 \times C_b}
$$

$$
R_{min} = \frac{V_{CC} - 0.4}{I_{OL}}
$$

- `t_r`：允许的上升时间（标准模式 1000ns，快速模式 300ns）
- `C_b`：总线总电容
- `I_{OL}`：设备开漏吸电流能力（通常 3mA）

**速查表**：

| I2C 模式 | 频率 | 推荐 R | 最大总线电容 |
|---------|------|--------|-------------|
| 标准 | 100kHz | 4.7kΩ | 400pF |
| 快速 | 400kHz | 2.2kΩ | 400pF |
| 快速+ | 1MHz | 1kΩ | 400pF |

### 3. 中断信号线（IRQ）

**外设主动通知 MCU 的引脚**，避免 MCU 轮询。

```
MCU                      传感器
 ├── GPIO(IRQ) ←─────────┤ INT 引脚
 │                       │ (开漏输出)
 └── 检测下降沿 ─────────┘ 有事件就拉低
```

**为什么 IRQ 常用上拉 + 开漏？** 支持多设备共享一根线（**线与 wired-AND**）：

```
                VCC
                 |
                 R (上拉)
                 |
  MCU IRQ ───────+────────+────────+
                 |        |        |
               [设备A]  [设备B]  [设备C]   (都开漏)
```

任意设备拉低 → 整线变低 → MCU 知道"有事"，再去逐个查谁触发的。
**USB INT / PCI INTx / 按键芯片 IRQ** 都是这个套路。

### 4. 线与（Wired-AND）原理

开漏输出 + 上拉 = 多设备共线时，**任何一个拉低，总线就低**。逻辑上等价于 AND（全高才高）。

这就是为什么 I2C、中断共享线必须开漏 + 上拉。
**如果用推挽输出共线 → 一个输出高一个输出低 → 短路！💥**

---

## 六、推挽 vs 开漏（顺便复习）

| 对比项 | 开漏（Open-Drain） | 推挽（Push-Pull） |
|--------|-------------------|-------------------|
| 输出高 | ❌ 不能（靠外部上拉） | ✅ 内部 PMOS 驱动 |
| 输出低 | ✅ NMOS 拉低 | ✅ NMOS 拉低 |
| 线与 | ✅ 支持 | ❌ 不支持（会短路） |
| 电平转换 | ✅ 上拉到任意电压 | ❌ 不方便 |
| 典型场景 | I2C / 1-Wire / IRQ 共享 | SPI / UART / LED 驱动 |

## 七、面试速记口诀

- **悬空引脚必加电阻**（上下拉择一，或定义成 GPIO 输出）
- **总线/高速/多设备 → 外部；按键/低速 → 内部**
- **I2C = 4.7kΩ 外部上拉**（标准模式默认值）
- **MOS 栅极 = 下拉到 GND**（防误开）
- **开漏 + 上拉 = 线与**（共线安全）
- **推挽不能共线**（短路警告）
- **非 MCU 芯片默认无内部上拉**（电源 EN、比较器、8051 P0、FPGA 关键信号 → 一律外部）

## 八、常见追问 & 坑

1. **Q：I2C 用内部上拉行不行？**
   A：不行。内部 40kΩ + 总线电容 → 上升时间不满足 spec。

2. **Q：上拉电阻越小越好吗？**
   A：不是。太小 → 设备拉低时灌电流大，功耗高，甚至烧管子。

3. **Q：为什么复位脚 NRST 通常是低有效？**
   A：上电瞬间电源未稳定，低电平复位更可靠（默认安全状态）。需要外部 10kΩ 上拉 + 0.1μF 去耦。

4. **Q：按键为什么常加上拉而不是下拉？**
   A：MCU 内部上拉普遍存在，省个外部电阻。硬件上两者完全对称。

5. **Q：未用引脚怎么处理？**
   A：配置为输出低，或输入加上拉/下拉。**绝对不要悬空**，会因浮空增大静态功耗和噪声。

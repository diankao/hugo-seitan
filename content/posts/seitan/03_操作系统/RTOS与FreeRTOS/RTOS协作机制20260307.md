# RTOS协作机制

## 标签
#操作系统 #面试题 #RTOS #任务调度 #中断 #定时器

## 问题描述
在RTOS中任务、线程、定时器、中断之间如何协作？

## 参考答案

### 基本概念

#### 任务与线程

**任务（Task）**：
- RTOS中的基本执行单元
- 拥有独立的栈空间和上下文
- 通过任务调度器进行切换
- 在FreeRTOS中就是线程

**线程（Thread）**：
- 更通用的概念，任务是一种特殊的线程
- 可以共享或拥有独立的资源
- 不同OS中实现方式不同

**关系**：
- 在RTOS中，任务和线程通常指同一个概念
- 都需要调度器管理
- 都有优先级和状态

### RTOS中的实体

#### 1. 任务

**任务状态**：
```
运行态 (Running)  ←→  就绪态 (Ready)
    ↓                   ↑
    ↓                   ↑
阻塞态 (Blocked)  ←→  挂起态 (Suspended)
```

**任务切换时机**：
- 高优先级任务就绪
- 当前任务主动让出CPU
- 时间片轮转（如果启用）
- 中断服务程序结束

#### 2. 定时器

**软件定时器**：
```c
TimerHandle_t xTimer;

void vTimerCallback(TimerHandle_t xTimer) {
    LED_Toggle();  // 定时器回调函数
}

void main(void) {
    xTimer = xTimerCreate(
        "LED Timer",           // 定时器名称
        pdMS_TO_TICKS(500),    // 周期500ms
        pdTRUE,                // 自动重载
        NULL,                  // 参数
        vTimerCallback         // 回调函数
    );
    xTimerStart(xTimer, 0);    // 启动定时器
}
```

**硬件定时器**：
```c
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim) {
    if (htim == &htim3) {
        BaseType_t xHigherPriorityTaskWoken = pdFALSE;
        xSemaphoreGiveFromISR(xBinarySemaphore, &xHigherPriorityTaskWoken);
        portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
    }
}
```

#### 3. 中断

**中断优先级配置**：
```c
void EXTI_Init(void) {
    GPIO_InitTypeDef GPIO_InitStruct = {0};
    
    GPIO_InitStruct.Pin = GPIO_PIN_0;
    GPIO_InitStruct.Mode = GPIO_MODE_IT_RISING;
    GPIO_InitStruct.Pull = GPIO_NOPULL;
    HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
    
    HAL_NVIC_SetPriority(EXTI0_IRQn, 5, 0);  // 优先级5
    HAL_NVIC_EnableIRQ(EXTI0_IRQn);
}

void EXTI0_IRQHandler(void) {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;
    
    if (__HAL_GPIO_EXTI_GET_IT(GPIO_PIN_0)) {
        __HAL_GPIO_EXTI_CLEAR_IT(GPIO_PIN_0);
        
        xSemaphoreGiveFromISR(xSemaphore, &xHigherPriorityTaskWoken);
        portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
    }
}
```

### 协作机制

#### 1. 中断与任务协作

**中断唤醒任务**：
```c
SemaphoreHandle_t xSemaphore;

void main(void) {
    xSemaphore = xSemaphoreCreateBinary();
    
    xTaskCreate(Task1, "Task1", 128, NULL, 2, NULL);
}

void EXTI0_IRQHandler(void) {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;
    
    xSemaphoreGiveFromISR(xSemaphore, &xHigherPriorityTaskWoken);
    portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
}

void Task1(void *param) {
    while(1) {
        xSemaphoreTake(xSemaphore, portMAX_DELAY);
        ProcessInterrupt();  // 处理中断事件
    }
}
```

#### 2. 定时器与任务协作

**软件定时器触发任务**：
```c
SemaphoreHandle_t xTimerSemaphore;

void TimerCallback(TimerHandle_t xTimer) {
    xSemaphoreGive(xTimerSemaphore);
}

void Task2(void *param) {
    while(1) {
        xSemaphoreTake(xTimerSemaphore, portMAX_DELAY);
        PeriodicTask();  // 周期性任务
    }
}
```

#### 3. 任务间协作

**使用消息队列**：
```c
QueueHandle_t xQueue;

void Producer_Task(void *param) {
    int data = 0;
    while(1) {
        xQueueSend(xQueue, &data, portMAX_DELAY);
        data++;
        vTaskDelay(100);
    }
}

void Consumer_Task(void *param) {
    int data;
    while(1) {
        xQueueReceive(xQueue, &data, portMAX_DELAY);
        ProcessData(data);
    }
}
```

### 优先级设计原则

#### 优先级分配策略

**高优先级（5-7）**：
- 中断处理任务
- 实时性要求高的任务
- 短时间执行的任务

**中优先级（3-4）**：
- 数据处理任务
- 通信任务
- 控制逻辑任务

**低优先级（1-2）**：
- 后台任务
- 日志记录
- 状态监测

**空闲任务（0）**：
- 系统空闲时运行
- 释放内存等维护工作

#### 避免优先级反转

**优先级继承**：
```c
xSemaphore = xSemaphoreCreateMutex();  // 互斥锁自动启用优先级继承
```

**优先级天花板**：
```c
xSemaphore = xSemaphoreCreateMutex();
vTaskPriorityInherit(NULL);  // 手动设置优先级天花板
```

### 典型应用场景

#### 场景1：按键处理

```
外部中断 → 信号量 → 任务1消抖 → 任务2逻辑处理 → 任务3UI更新
```

#### 场景2：数据采集

```
定时器中断 → ADC采集 → DMA传输 → 任务数据处理 → 网络上传
```

#### 场景3：通信协议

```
串口中断 → 接收数据 → 任务协议解析 → 任务业务处理 → 任务响应
```

### 注意事项

1. **中断服务程序（ISR）要短**：
   - 快速处理紧急事件
   - 复杂处理交给任务
   - 使用FromISR版本的API

2. **避免任务优先级反转**：
   - 合理设计优先级
   - 使用优先级继承机制
   - 避免高优先级任务阻塞

3. **合理使用延时**：
   - 避免忙等待
   - 使用vTaskDelay()
   - 节省CPU资源

4. **注意栈溢出**：
   - 合理设置栈大小
   - 启用栈溢出检测
   - 监控栈使用情况

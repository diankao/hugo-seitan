# 信号量、互斥锁、消息队列

## 标签
#操作系统 #面试题 #FreeRTOS #信号量 #互斥锁 #消息队列

## 问题描述
什么是信号量、互斥锁、消息队列？分别用在什么场景？

## 参考答案

### 1. 信号量（Semaphore）

#### 基本概念

**定义**：信号量是一种同步机制，用于控制多个任务对共享资源的访问，或者用于任务间的通知。

**分类**：
- **二值信号量**：只有0和1两种状态，类似开关
- **计数信号量**：可以计数的信号量，用于资源管理
- **互斥信号量**：特殊的二值信号量，支持优先级继承

#### 二值信号量

**应用场景**：任务同步、中断通知

```c
SemaphoreHandle_t xBinarySemaphore;

void main(void) {
    xBinarySemaphore = xSemaphoreCreateBinary();
    
    xTaskCreate(Task1, "Task1", 128, NULL, 2, NULL);
}

void EXTI0_IRQHandler(void) {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;
    xSemaphoreGiveFromISR(xBinarySemaphore, &xHigherPriorityTaskWoken);
    portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
}

void Task1(void *param) {
    while(1) {
        xSemaphoreTake(xBinarySemaphore, portMAX_DELAY);
        ProcessInterrupt();
    }
}
```

#### 计数信号量

**应用场景**：资源计数、生产者-消费者模型

```c
SemaphoreHandle_t xCountingSemaphore;

void main(void) {
    xCountingSemaphore = xSemaphoreCreateCounting(10, 0);  // 最大值10，初始值0
    
    xTaskCreate(Producer_Task, "Producer", 128, NULL, 2, NULL);
    xTaskCreate(Consumer_Task, "Consumer", 128, NULL, 2, NULL);
}

void Producer_Task(void *param) {
    while(1) {
        ProduceData();
        xSemaphoreGive(xCountingSemaphore);  // 增加计数
        vTaskDelay(100);
    }
}

void Consumer_Task(void *param) {
    while(1) {
        xSemaphoreTake(xCountingSemaphore, portMAX_DELAY);  // 等待资源
        ConsumeData();
    }
}
```

#### 使用场景

| 场景 | 使用类型 | 说明 |
|------|---------|------|
| 中断通知任务 | 二值信号量 | 中断中释放，任务中获取 |
| 任务间同步 | 二值信号量 | 一个任务通知另一个任务 |
| 资源管理 | 计数信号量 | 限制同时访问资源的数量 |
| 生产者-消费者 | 计数信号量 | 缓冲区可用空间管理 |

### 2. 互斥锁（Mutex）

#### 基本概念

**定义**：互斥锁是一种特殊的信号量，用于保护共享资源，确保同一时刻只有一个任务可以访问资源。

**特性**：
- **互斥性**：同一时刻只能有一个持有者
- **所有权**：只有锁的持有者才能释放锁
- **优先级继承**：防止优先级反转
- **递归锁**：同一任务可多次获取同一个锁

#### 互斥锁使用

**应用场景**：保护共享资源

```c
SemaphoreHandle_t xMutex;

void main(void) {
    xMutex = xSemaphoreCreateMutex();
    
    xTaskCreate(Task1, "Task1", 128, NULL, 2, NULL);
    xTaskCreate(Task2, "Task2", 128, NULL, 2, NULL);
}

void Task1(void *param) {
    while(1) {
        if (xSemaphoreTake(xMutex, portMAX_DELAY) == pdTRUE) {
            AccessSharedResource();
            xSemaphoreGive(xMutex);
        }
        vTaskDelay(100);
    }
}

void Task2(void *param) {
    while(1) {
        if (xSemaphoreTake(xMutex, portMAX_DELAY) == pdTRUE) {
            AccessSharedResource();
            xSemaphoreGive(xMutex);
        }
        vTaskDelay(100);
    }
}
```

#### 递归互斥锁

**应用场景**：函数递归调用时需要多次获取锁

```c
SemaphoreHandle_t xRecursiveMutex;

void RecursiveFunction(int depth) {
    if (depth <= 0) return;
    
    xSemaphoreTake(xRecursiveMutex, portMAX_DELAY);
    
    CriticalOperation();
    RecursiveFunction(depth - 1);  // 递归调用
    
    xSemaphoreGive(xRecursiveMutex);
}

void main(void) {
    xRecursiveMutex = xSemaphoreCreateRecursiveMutex();
    RecursiveFunction(5);
}
```

#### 互斥锁 vs 信号量

| 特性 | 互斥锁 | 信号量 |
|------|--------|--------|
| 所有权 | 有 | 无 |
| 释放者 | 必须是持有者 | 任何任务都可以释放 |
| 优先级继承 | 支持 | 不支持 |
| 用途 | 保护资源 | 同步、计数 |
| 递归 | 支持 | 不支持 |

#### 使用场景

| 场景 | 使用类型 | 说明 |
|------|---------|------|
| 保护全局变量 | 互斥锁 | 防止数据竞争 |
| 保护硬件资源 | 互斥锁 | 防止多个任务同时访问硬件 |
| 递归函数保护 | 递归互斥锁 | 允许同任务多次获取 |
| 临时资源访问 | 互斥锁 | 短时间保护资源 |

### 3. 消息队列（Queue）

#### 基本概念

**定义**：消息队列是一种任务间通信机制，用于在任务间传递数据。

**特性**：
- **FIFO**：先进先出
- **阻塞**：队满时发送者阻塞，队空时接收者阻塞
- **大小固定**：创建时指定队列长度和元素大小

#### 消息队列使用

**应用场景**：任务间数据传递

```c
QueueHandle_t xQueue;

void main(void) {
    xQueue = xQueueCreate(10, sizeof(int));  // 10个int元素的队列
    
    xTaskCreate(Sender_Task, "Sender", 128, NULL, 2, NULL);
    xTaskCreate(Receiver_Task, "Receiver", 128, NULL, 2, NULL);
}

void Sender_Task(void *param) {
    int data = 0;
    while(1) {
        if (xQueueSend(xQueue, &data, 100) == pdTRUE) {
            data++;
        }
        vTaskDelay(100);
    }
}

void Receiver_Task(void *param) {
    int data;
    while(1) {
        if (xQueueReceive(xQueue, &data, portMAX_DELAY) == pdTRUE) {
            ProcessData(data);
        }
    }
}
```

#### 结构体消息

**应用场景**：传递复杂结构数据

```c
typedef struct {
    int id;
    float value;
    uint32_t timestamp;
} SensorData_t;

QueueHandle_t xSensorQueue;

void main(void) {
    xSensorQueue = xQueueCreate(20, sizeof(SensorData_t));
    
    xTaskCreate(Sensor_Task, "Sensor", 128, NULL, 2, NULL);
    xTaskCreate(Process_Task, "Process", 256, NULL, 2, NULL);
}

void Sensor_Task(void *param) {
    SensorData_t data;
    while(1) {
        data.id = 1;
        data.value = ReadSensor();
        data.timestamp = GetTimestamp();
        
        xQueueSend(xSensorQueue, &data, portMAX_DELAY);
        vTaskDelay(100);
    }
}

void Process_Task(void *param) {
    SensorData_t data;
    while(1) {
        xQueueReceive(xSensorQueue, &data, portMAX_DELAY);
        ProcessSensorData(data);
    }
}
```

#### 队列在中断中的使用

```c
QueueHandle_t xQueue;

void UART_IRQHandler(void) {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;
    uint8_t data = UART_ReceiveByte();
    
    xQueueSendFromISR(xQueue, &data, &xHigherPriorityTaskWoken);
    portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
}
```

#### 使用场景

| 场景 | 使用类型 | 说明 |
|------|---------|------|
| 数据采集传递 | 消息队列 | 传感器数据传递给处理任务 |
| 命令执行 | 消息队列 | UI命令传递给执行任务 |
| 事件通知 | 消息队列 | 携带事件参数的通知 |
| 日志记录 | 消息队列 | 多个任务发送日志到记录任务 |

### 选择建议

#### 选择信号量
- 需要任务间同步
- 中断通知任务
- 资源计数管理

#### 选择互斥锁
- 保护共享资源
- 需要优先级继承
- 可能需要递归获取

#### 选择消息队列
- 需要传递数据
- 任务间解耦
- 缓冲处理

### 注意事项

1. **避免死锁**：
   - 按相同顺序获取多个锁
   - 设置获取超时时间
   - 不要在临界区内调用阻塞函数

2. **优先级反转**：
   - 使用互斥锁自动继承优先级
   - 合理设计任务优先级
   - 避免长时间持有锁

3. **资源泄漏**：
   - 确保在所有路径释放锁
   - 使用goto或防御性编程
   - 检查函数返回值

4. **性能考虑**：
   - 锁的持有时间要短
   - 避免在循环中频繁获取锁
   - 考虑使用无锁数据结构

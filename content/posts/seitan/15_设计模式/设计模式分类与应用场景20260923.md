# 设计模式分类与应用场景

## 题目

了解哪些设计模式？

## 考察点

设计模式、软件架构

## 回答要点

### 1. 设计模式分类

#### 三大类设计模式
```
创建型模式（5种）：
├── 工厂方法模式
├── 抽象工厂模式
├── 单例模式
├── 建造者模式
└── 原型模式

结构型模式（7种）：
├── 适配器模式
├── 装饰器模式
├── 代理模式
├── 外观模式
├── 桥接模式
├── 组合模式
└── 享元模式

行为型模式（11种）：
├── 策略模式
├── 观察者模式
├── 模板方法模式
├── 迭代器模式
├── 责任链模式
├── 命令模式
├── 备忘录模式
├── 状态模式
├── 访问者模式
├── 中介者模式
└── 解释器模式
```

### 2. 创建型模式

#### 单例模式（Singleton）
```cpp
// 饿汉式单例
class EagerSingleton {
private:
    static EagerSingleton* instance;
    EagerSingleton() {}

public:
    static EagerSingleton* getInstance() {
        return instance;
    }

    EagerSingleton(const EagerSingleton&) = delete;
    EagerSingleton& operator=(const EagerSingleton&) = delete;
};

// 在类外初始化
EagerSingleton* EagerSingleton::instance = new EagerSingleton();

// 使用
auto singleton = EagerSingleton::getInstance();
```

```cpp
// 懒汉式单例（线程不安全）
class LazySingleton {
private:
    static LazySingleton* instance;
    LazySingleton() {}

public:
    static LazySingleton* getInstance() {
        if (instance == nullptr) {
            instance = new LazySingleton();
        }
        return instance;
    }
};

LazySingleton* LazySingleton::instance = nullptr;
```

```cpp
// 懒汉式单例（线程安全）
class ThreadSafeSingleton {
private:
    static ThreadSafeSingleton* instance;
    static std::mutex mutex;
    ThreadSafeSingleton() {}

public:
    static ThreadSafeSingleton* getInstance() {
        std::lock_guard<std::mutex> lock(mutex);
        if (instance == nullptr) {
            instance = new ThreadSafeSingleton();
        }
        return instance;
    }
};

ThreadSafeSingleton* ThreadSafeSingleton::instance = nullptr;
std::mutex ThreadSafeSingleton::mutex;
```

```cpp
// 双重检查锁（推荐）
class DoubleCheckSingleton {
private:
    static DoubleCheckSingleton* instance;
    static std::mutex mutex;
    DoubleCheckSingleton() {}

public:
    static DoubleCheckSingleton* getInstance() {
        if (instance == nullptr) {
            std::lock_guard<std::mutex> lock(mutex);
            if (instance == nullptr) {
                instance = new DoubleCheckSingleton();
            }
        }
        return instance;
    }
};

DoubleCheckSingleton* DoubleCheckSingleton::instance = nullptr;
std::mutex DoubleCheckSingleton::mutex;
```

```cpp
// C++11 简化版本（推荐）
class ModernSingleton {
private:
    ModernSingleton() {}
    ModernSingleton(const ModernSingleton&) = delete;
    ModernSingleton& operator=(const ModernSingleton&) = delete;

public:
    static ModernSingleton& getInstance() {
        static ModernSingleton instance;
        return instance;
    }
};

// 使用
auto& singleton = ModernSingleton::getInstance();
```

#### 工厂方法模式（Factory Method）
```cpp
// 产品接口
class Product {
public:
    virtual void use() = 0;
    virtual ~Product() {}
};

// 具体产品
class ConcreteProductA : public Product {
public:
    void use() override {
        std::cout << "Using Product A" << std::endl;
    }
};

class ConcreteProductB : public Product {
public:
    void use() override {
        std::cout << "Using Product B" << std::endl;
    }
};

// 工厂接口
class Factory {
public:
    virtual Product* createProduct() = 0;
    virtual ~Factory() {}
};

// 具体工厂
class ConcreteFactoryA : public Factory {
public:
    Product* createProduct() override {
        return new ConcreteProductA();
    }
};

class ConcreteFactoryB : public Factory {
public:
    Product* createProduct() override {
        return new ConcreteProductB();
    }
};

// 使用
Factory* factoryA = new ConcreteFactoryA();
Product* productA = factoryA->createProduct();
productA->use();

Factory* factoryB = new ConcreteFactoryB();
Product* productB = factoryB->createProduct();
productB->use();
```

### 3. 结构型模式

#### 适配器模式（Adapter）
```cpp
// 目标接口
class Target {
public:
    virtual void request() = 0;
    virtual ~Target() {}
};

// 适配者
class Adaptee {
public:
    void specificRequest() {
        std::cout << "Specific request" << std::endl;
    }
};

// 适配器
class Adapter : public Target {
private:
    Adaptee* adaptee;

public:
    Adapter(Adaptee* a) : adaptee(a) {}

    void request() override {
        adaptee->specificRequest();
    }
};

// 使用
Adaptee* adaptee = new Adaptee();
Target* adapter = new Adapter(adaptee);
adapter->request();
```

#### 代理模式（Proxy）
```cpp
// 抽象主题
class Subject {
public:
    virtual void request() = 0;
    virtual ~Subject() {}
};

// 真实主题
class RealSubject : public Subject {
public:
    void request() override {
        std::cout << "Real request" << std::endl;
    }
};

// 代理
class Proxy : public Subject {
private:
    RealSubject* realSubject;

public:
    Proxy() : realSubject(nullptr) {}

    void request() override {
        if (realSubject == nullptr) {
            realSubject = new RealSubject();
        }

        // 附加功能
        std::cout << "Proxy: Before request" << std::endl;
        realSubject->request();
        std::cout << "Proxy: After request" << std::endl;
    }
};

// 使用
Subject* proxy = new Proxy();
proxy->request();
```

### 4. 行为型模式

#### 观察者模式（Observer）
```cpp
#include <vector>
#include <functional>

// 观察者接口
class Observer {
public:
    virtual void update(const std::string& message) = 0;
    virtual ~Observer() {}
};

// 主题
class Subject {
private:
    std::vector<Observer*> observers;

public:
    void attach(Observer* observer) {
        observers.push_back(observer);
    }

    void detach(Observer* observer) {
        observers.erase(
            std::remove(observers.begin(), observers.end(), observer),
            observers.end()
        );
    }

    void notify(const std::string& message) {
        for (auto observer : observers) {
            observer->update(message);
        }
    }
};

// 具体观察者
class ConcreteObserver : public Observer {
private:
    std::string name;

public:
    ConcreteObserver(const std::string& n) : name(n) {}

    void update(const std::string& message) override {
        std::cout << name << " received: " << message << std::endl;
    }
};

// 使用
Subject subject;
subject.attach(new ConcreteObserver("Observer 1"));
subject.attach(new ConcreteObserver("Observer 2"));

subject.notify("Hello, observers!");
```

#### 策略模式（Strategy）
```cpp
// 策略接口
class Strategy {
public:
    virtual void execute() = 0;
    virtual ~Strategy() {}
};

// 具体策略
class ConcreteStrategyA : public Strategy {
public:
    void execute() override {
        std::cout << "Strategy A" << std::endl;
    }
};

class ConcreteStrategyB : public Strategy {
public:
    void execute() override {
        std::cout << "Strategy B" << std::endl;
    }
};

// 上下文
class Context {
private:
    Strategy* strategy;

public:
    Context(Strategy* s) : strategy(s) {}

    void setStrategy(Strategy* s) {
        strategy = s;
    }

    void executeStrategy() {
        if (strategy) {
            strategy->execute();
        }
    }
};

// 使用
Context context(new ConcreteStrategyA());
context.executeStrategy();

context.setStrategy(new ConcreteStrategyB());
context.executeStrategy();
```

### 5. 设计模式的应用场景

#### 单例模式
```cpp
// 配置管理器
class ConfigManager {
private:
    std::map<std::string, std::string> configs;
    ConfigManager() {}

public:
    static ConfigManager& getInstance() {
        static ConfigManager instance;
        return instance;
    }

    void set(const std::string& key, const std::string& value) {
        configs[key] = value;
    }

    std::string get(const std::string& key) {
        return configs[key];
    }
};

// 日志管理器
class Logger {
private:
    Logger() {}

public:
    static Logger& getInstance() {
        static Logger instance;
        return instance;
    }

    void log(const std::string& message) {
        std::cout << "[LOG] " << message << std::endl;
    }
};
```

#### 工厂模式
```cpp
// 设备工厂
class Device {
public:
    virtual void initialize() = 0;
    virtual ~Device() {}
};

class Camera : public Device {
public:
    void initialize() override {
        std::cout << "Camera initialized" << std::endl;
    }
};

class Sensor : public Device {
public:
    void initialize() override {
        std::cout << "Sensor initialized" << std::endl;
    }
};

class DeviceFactory {
public:
    enum DeviceType { CAMERA, SENSOR };

    static Device* createDevice(DeviceType type) {
        switch (type) {
            case CAMERA:
                return new Camera();
            case SENSOR:
                return new Sensor();
            default:
                return nullptr;
        }
    }
};

// 使用
Device* camera = DeviceFactory::createDevice(DeviceFactory::CAMERA);
Device* sensor = DeviceFactory::createDevice(DeviceFactory::SENSOR);
```

#### 观察者模式
```cpp
// 事件系统
class EventSystem {
private:
    std::map<std::string, std::vector<std::function<void()>>> events;

public:
    void on(const std::string& eventName, std::function<void()> callback) {
        events[eventName].push_back(callback);
    }

    void emit(const std::string& eventName) {
        if (events.find(eventName) != events.end()) {
            for (auto& callback : events[eventName]) {
                callback();
            }
        }
    }
};

// 使用
EventSystem eventSystem;
eventSystem.on("click", []() {
    std::cout << "Button clicked" << std::endl;
});

eventSystem.emit("click");
```

### 6. 设计模式的优缺点

#### 优点
- 提高代码复用性
- 提高代码可维护性
- 提高代码可扩展性
- 促进良好的架构设计

#### 缺点
- 增加代码复杂度
- 增加系统类的数量
- 过度设计导致性能下降
- 学习成本高

### 7. 设计模式的选择原则

- **简单优于复杂**：优先选择简单的解决方案
- **按需设计**：不要为了用模式而用模式
- **重构引入**：先写代码，遇到问题再引入模式
- **结合实际**：考虑具体的应用场景和需求

# 线程安全的单例模式

## 题目

分别写出饿汉和懒汉线程安全的单例模式。

## 答案

### 单例模式概述

单例模式确保一个类只有一个实例，并提供全局访问点。

### 饿汉式（线程安全）

```cpp
#include <iostream>
#include <mutex>

class EagerSingleton {
private:
    static EagerSingleton* instance;
    static std::mutex mutex;
    
    EagerSingleton() {
        std::cout << "EagerSingleton created" << std::endl;
    }
    
public:
    EagerSingleton(const EagerSingleton&) = delete;
    EagerSingleton& operator=(const EagerSingleton&) = delete;
    
    static EagerSingleton* getInstance() {
        return instance;
    }
    
    void doSomething() {
        std::cout << "EagerSingleton doing something" << std::endl;
    }
};

EagerSingleton* EagerSingleton::instance = new EagerSingleton();
std::mutex EagerSingleton::mutex;

int main() {
    EagerSingleton* s1 = EagerSingleton::getInstance();
    EagerSingleton* s2 = EagerSingleton::getInstance();
    
    std::cout << "s1 == s2: " << (s1 == s2) << std::endl;
    
    s1->doSomething();
    
    return 0;
}
```

### 懒汉式（非线程安全）

```cpp
#include <iostream>

class LazySingletonUnsafe {
private:
    static LazySingletonUnsafe* instance;
    
    LazySingletonUnsafe() {
        std::cout << "LazySingletonUnsafe created" << std::endl;
    }
    
public:
    LazySingletonUnsafe(const LazySingletonUnsafe&) = delete;
    LazySingletonUnsafe& operator=(const LazySingletonUnsafe&) = delete;
    
    static LazySingletonUnsafe* getInstance() {
        if (instance == nullptr) {
            instance = new LazySingletonUnsafe();
        }
        return instance;
    }
    
    void doSomething() {
        std::cout << "LazySingletonUnsafe doing something" << std::endl;
    }
};

LazySingletonUnsafe* LazySingletonUnsafe::instance = nullptr;
```

### 懒汉式（线程安全 - 双重检查锁定）

```cpp
#include <iostream>
#include <mutex>

class LazySingletonSafe {
private:
    static LazySingletonSafe* instance;
    static std::mutex mutex;
    
    LazySingletonSafe() {
        std::cout << "LazySingletonSafe created" << std::endl;
    }
    
public:
    LazySingletonSafe(const LazySingletonSafe&) = delete;
    LazySingletonSafe& operator=(const LazySingletonSafe&) = delete;
    
    static LazySingletonSafe* getInstance() {
        if (instance == nullptr) {
            std::lock_guard<std::mutex> lock(mutex);
            if (instance == nullptr) {
                instance = new LazySingletonSafe();
            }
        }
        return instance;
    }
    
    void doSomething() {
        std::cout << "LazySingletonSafe doing something" << std::endl;
    }
};

LazySingletonSafe* LazySingletonSafe::instance = nullptr;
std::mutex LazySingletonSafe::mutex;
```

### 模板单例

```cpp
#include <iostream>
#include <mutex>

template<typename T>
class Singleton {
protected:
    Singleton() = default;
    virtual ~Singleton() = default;
    
public:
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
    
    static T& getInstance() {
        static T instance;
        return instance;
    }
};

class MyService : public Singleton<MyService> {
    friend class Singleton<MyService>;
    
private:
    MyService() {
        std::cout << "MyService created" << std::endl;
    }
    
public:
    void process() {
        std::cout << "MyService processing" << std::endl;
    }
};

int main() {
    MyService& service = MyService::getInstance();
    service.process();
    
    return 0;
}
```

### 多线程测试

```cpp
#include <iostream>
#include <thread>
#include <vector>
#include <mutex>

class ThreadSafeSingleton {
private:
    static ThreadSafeSingleton* instance;
    static std::mutex mutex;
    static int count;
    
    ThreadSafeSingleton() {
        std::cout << "ThreadSafeSingleton created, count: " << count << std::endl;
    }
    
public:
    ThreadSafeSingleton(const ThreadSafeSingleton&) = delete;
    ThreadSafeSingleton& operator=(const ThreadSafeSingleton&) = delete;
    
    static ThreadSafeSingleton* getInstance() {
        if (instance == nullptr) {
            std::lock_guard<std::mutex> lock(mutex);
            if (instance == nullptr) {
                count++;
                instance = new ThreadSafeSingleton();
            }
        }
        return instance;
    }
    
    void doSomething() {
        std::cout << "ThreadSafeSingleton doing something" << std::endl;
    }
};

ThreadSafeSingleton* ThreadSafeSingleton::instance = nullptr;
std::mutex ThreadSafeSingleton::mutex;
int ThreadSafeSingleton::count = 0;

void worker() {
    ThreadSafeSingleton* instance = ThreadSafeSingleton::getInstance();
    instance->doSomething();
}

int main() {
    std::vector<std::thread> threads;
    
    for (int i = 0; i < 10; i++) {
        threads.emplace_back(worker);
    }
    
    for (auto& thread : threads) {
        thread.join();
    }
    
    std::cout << "Final count: " << ThreadSafeSingleton::count << std::endl;
    
    return 0;
}
```

### 封装单例的关键点

把一个类封装成单例，需要确保以下要素：

#### 1. 构造函数私有化

防止外部通过构造函数创建新实例。

```cpp
class Singleton {
private:
    Singleton() {}
};
```

#### 2. 拷贝和赋值禁用

防止通过拷贝或赋值产生额外实例。

```cpp
Singleton(const Singleton&) = delete;
Singleton& operator=(const Singleton&) = delete;
```

#### 3. 提供全局访问点

通过静态方法返回唯一实例。

```cpp
static Singleton& getInstance() {
    static Singleton instance;
    return instance;
}
```

#### 4. 析构函数的处理

单例的析构时机需要特别注意。如果使用静态局部变量，程序结束时自动析构。如果使用 `new`，需要考虑何时释放。

```cpp
// 静态局部变量：程序结束时自动析构
static Singleton& getInstance() {
    static Singleton instance;
    return instance;
}

// 如果使用 new，可通过 atexit 注册清理函数
class Singleton {
    static Singleton* instance;
    static void destroy() { delete instance; }
public:
    static Singleton* getInstance() {
        if (!instance) {
            instance = new Singleton();
            std::atexit(destroy);
        }
        return instance;
    }
};
```

#### 5. 线程安全

C++11 起静态局部变量的初始化是线程安全的，推荐直接使用。如果需要双重检查锁定，必须配合内存屏障或 `std::atomic`。

```cpp
#include <atomic>
#include <mutex>

class Singleton {
    static std::atomic<Singleton*> instance;
    static std::mutex mtx;
public:
    static Singleton* getInstance() {
        Singleton* tmp = instance.load(std::memory_order_acquire);
        if (!tmp) {
            std::lock_guard<std::mutex> lock(mtx);
            tmp = instance.load(std::memory_order_relaxed);
            if (!tmp) {
                tmp = new Singleton();
                instance.store(tmp, std::memory_order_release);
            }
        }
        return tmp;
    }
};
```

#### 关键点总结

| 关键点 | 做法 | 目的 |
|--------|------|------|
| 私有构造函数 | `private: Singleton() {}` | 禁止外部实例化 |
| 禁用拷贝赋值 | `= delete` | 防止复制出新实例 |
| 静态访问方法 | `static Singleton& getInstance()` | 提供全局唯一访问点 |
| 静态实例 | 静态局部变量（推荐） | 保证唯一性 |
| 线程安全 | C++11 保证 / 双重检查锁定 | 多线程环境下安全 |

### 单例模式对比

| 实现方式 | 线程安全 | 延迟加载 | 性能 | 复杂度 |
|---------|---------|---------|------|--------|
| 饿汉式 | 是 | 否 | 高 | 低 |
| 懒汉式（非线程安全） | 否 | 是 | 高 | 低 |
| 懒汉式（双重检查锁定） | 是 | 是 | 中 | 中 |
| 静态局部变量 | 是 | 是 | 高 | 低 |

### 单例创建时机

#### 饿汉式：程序启动时创建

```cpp
class EagerSingleton {
private:
    static EagerSingleton* instance;
    EagerSingleton() {}
public:
    static EagerSingleton* getInstance() {
        return instance;
    }
};

EagerSingleton* EagerSingleton::instance = new EagerSingleton();
```

在 `main()` 执行之前，静态成员初始化阶段就已创建。如果单例构造耗时或依赖其他组件，可能导致启动变慢或初始化顺序问题。

#### 懒汉式：首次使用时创建

```cpp
class LazySingleton {
private:
    static LazySingleton* instance;
    LazySingleton() {}
public:
    static LazySingleton* getInstance() {
        if (instance == nullptr) {
            instance = new LazySingleton();
        }
        return instance;
    }
};

LazySingleton* LazySingleton::instance = nullptr;
```

第一次调用 `getInstance()` 时才创建，延迟了资源占用，但需要注意线程安全。

#### 静态局部变量：首次调用时创建（推荐）

```cpp
class ModernSingleton {
public:
    static ModernSingleton& getInstance() {
        static ModernSingleton instance;
        return instance;
    }
private:
    ModernSingleton() {}
};
```

C++11 保证静态局部变量的初始化是线程安全的，且只在首次执行到该语句时初始化。

#### 各实现方式的创建时机对比

| 实现方式 | 创建时机 | 适用场景 |
|---------|---------|---------|
| 饿汉式 | `main()` 之前（静态初始化阶段） | 单例构造轻量、无外部依赖 |
| 懒汉式 | 首次调用 `getInstance()` | 单例构造耗时或依赖运行时环境 |
| 静态局部变量 | 首次调用 `getInstance()` | 通用场景（推荐） |

#### 选择原则

- **构造快、无依赖** → 饿汉式，简单可靠
- **构造慢、有依赖、延迟加载** → 懒汉式或静态局部变量
- **避免静态初始化顺序问题** → 懒汉式，因为饿汉式多个单例之间的初始化顺序不确定

```cpp
class A {
public:
    static A& getInstance() {
        static A instance;
        return instance;
    }
};

class B {
public:
    static B& getInstance() {
        static B instance;
        return instance;
    }
    void useA() {
        A::getInstance();
    }
};

B::getInstance().useA();
```

如果 B 的初始化依赖 A，使用懒加载可以保证 A 在 B 需要时已经初始化，避免饿汉式中因静态初始化顺序不确定导致的问题。

### 使用建议

1. **简单场景**：使用C++11静态局部变量
2. **需要延迟加载**：懒汉式
3. **需要线程安全**：双重检查锁定或静态局部变量
4. **避免单例**：优先考虑依赖注入

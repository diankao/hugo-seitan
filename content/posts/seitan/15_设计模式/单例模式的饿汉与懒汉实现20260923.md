# 单例模式的饿汉与懒汉实现

## 题目

单例模式的 2 种区别？

## 考察点

设计模式、线程安全、初始化时机

## 回答要点

### 1. 单例模式概述

#### 定义
单例模式确保一个类只有一个实例，并提供一个全局访问点。

#### UML 类图
```
┌─────────────────┐
│   Singleton     │
├─────────────────┤
│ - instance      │
│ - Singleton()   │
├─────────────────┤
│ + getInstance() │
└─────────────────┘
```

### 2. 饿汉式单例

#### 基本实现
```cpp
class EagerSingleton {
private:
    static EagerSingleton* instance;
    EagerSingleton() {
        std::cout << "EagerSingleton constructed" << std::endl;
    }

public:
    static EagerSingleton* getInstance() {
        return instance;
    }

    EagerSingleton(const EagerSingleton&) = delete;
    EagerSingleton& operator=(const EagerSingleton&) = delete;

    void doSomething() {
        std::cout << "Doing something" << std::endl;
    }
};

// 在类外初始化（程序启动时就创建）
EagerSingleton* EagerSingleton::instance = new EagerSingleton();

// 使用
int main() {
    auto singleton = EagerSingleton::getInstance();
    singleton->doSomething();
    return 0;
}
```

#### 饿汉式特点
```cpp
// 1. 初始化时机
// 在程序启动时，main() 函数执行之前就创建实例
// 即使不使用也会创建

// 2. 线程安全
// 不需要额外的同步机制
// 因为在 main() 执行前就完成了初始化

// 3. 内存占用
// 程序运行期间一直占用内存
// 如果单例对象很大，会浪费内存

// 4. 初始化顺序问题
// 如果多个单例相互依赖，初始化顺序不确定
```

#### 使用场景
```cpp
// 适合：一定会使用的单例
class Logger {
private:
    static Logger* instance;
    Logger() {}

public:
    static Logger& getInstance() {
        return *instance;
    }

    void log(const std::string& message) {
        std::cout << "[LOG] " << message << std::endl;
    }
};

Logger* Logger::instance = new Logger();

// 适合：轻量级的单例
class AppInfo {
private:
    static AppInfo* instance;
    std::string appName;
    std::string version;

    AppInfo() : appName("MyApp"), version("1.0.0") {}

public:
    static AppInfo& getInstance() {
        return *instance;
    }

    std::string getName() const { return appName; }
    std::string getVersion() const { return version; }
};

AppInfo* AppInfo::instance = new AppInfo();
```

### 3. 懒汉式单例

#### 基本实现（线程不安全）
```cpp
class LazySingleton {
private:
    static LazySingleton* instance;
    LazySingleton() {
        std::cout << "LazySingleton constructed" << std::endl;
    }

public:
    static LazySingleton* getInstance() {
        // 第一次调用时才创建
        if (instance == nullptr) {
            instance = new LazySingleton();
        }
        return instance;
    }

    LazySingleton(const LazySingleton&) = delete;
    LazySingleton& operator=(const LazySingleton&) = delete;

    void doSomething() {
        std::cout << "Doing something" << std::endl;
    }
};

LazySingleton* LazySingleton::instance = nullptr;

// 使用
int main() {
    // 第一次调用时才创建实例
    auto singleton = LazySingleton::getInstance();
    singleton->doSomething();
    return 0;
}
```

#### 懒汉式特点
```cpp
// 1. 初始化时机
// 第一次调用 getInstance() 时才创建
// 延迟初始化，节省资源

// 2. 线程安全问题
// 多线程环境下可能创建多个实例
// 需要额外的同步机制

// 3. 内存占用
// 只在使用时才占用内存
// 如果不使用，不会创建实例

// 4. 初始化顺序
// 控制更灵活，可以按需初始化
```

### 4. 线程安全的懒汉式

#### 方法 1：加锁
```cpp
class ThreadSafeLazySingleton {
private:
    static ThreadSafeLazySingleton* instance;
    static std::mutex mutex;
    ThreadSafeLazySingleton() {}

public:
    static ThreadSafeLazySingleton* getInstance() {
        std::lock_guard<std::mutex> lock(mutex);
        if (instance == nullptr) {
            instance = new ThreadSafeLazySingleton();
        }
        return instance;
    }

    ThreadSafeLazySingleton(const ThreadSafeLazySingleton&) = delete;
    ThreadSafeLazySingleton& operator=(const ThreadSafeLazySingleton&) = delete;
};

ThreadSafeLazySingleton* ThreadSafeLazySingleton::instance = nullptr;
std::mutex ThreadSafeLazySingleton::mutex;

// 问题：每次获取实例都要加锁，性能较差
```

#### 方法 2：双重检查锁（推荐）
```cpp
class DoubleCheckSingleton {
private:
    static DoubleCheckSingleton* instance;
    static std::mutex mutex;
    DoubleCheckSingleton() {}

public:
    static DoubleCheckSingleton* getInstance() {
        // 第一次检查（无锁）
        if (instance == nullptr) {
            std::lock_guard<std::mutex> lock(mutex);
            // 第二次检查（有锁）
            if (instance == nullptr) {
                instance = new DoubleCheckSingleton();
            }
        }
        return instance;
    }

    DoubleCheckSingleton(const DoubleCheckSingleton&) = delete;
    DoubleCheckSingleton& operator=(const DoubleCheckSingleton&) = delete;
};

DoubleCheckSingleton* DoubleCheckSingleton::instance = nullptr;
std::mutex DoubleCheckSingleton::mutex;

// 优点：只在第一次创建时加锁，后续访问无锁
```

#### 方法 3：C++11 静态局部变量（推荐）
```cpp
class ModernSingleton {
private:
    ModernSingleton() {
        std::cout << "ModernSingleton constructed" << std::endl;
    }

public:
    static ModernSingleton& getInstance() {
        // C++11 保证线程安全的静态局部变量初始化
        static ModernSingleton instance;
        return instance;
    }

    ModernSingleton(const ModernSingleton&) = delete;
    ModernSingleton& operator=(const ModernSingleton&) = delete;

    void doSomething() {
        std::cout << "Doing something" << std::endl;
    }
};

// 使用
int main() {
    auto& singleton = ModernSingleton::getInstance();
    singleton.doSomething();
    return 0;
}

// 优点：
// 1. C++11 保证线程安全
// 2. 自动销毁
// 3. 代码简洁
```

### 5. 两种方式的对比

#### 对比表
| 特性 | 饿汉式 | 懒汉式 |
|------|--------|--------|
| 初始化时机 | 程序启动时 | 第一次使用时 |
| 线程安全 | 天然线程安全 | 需要额外处理 |
| 内存占用 | 一直占用 | 按需占用 |
| 性能 | 无额外开销 | 首次有开销 |
| 初始化顺序 | 不确定 | 可控 |
| 适用场景 | 一定会用 | 可能不用 |

#### 代码对比
```cpp
// 饿汉式
class Eager {
private:
    static Eager* instance;
    Eager() {}
public:
    static Eager* getInstance() {
        return instance;  // 直接返回
    }
};
Eager* Eager::instance = new Eager();  // 启动时创建

// 懒汉式（现代版）
class Lazy {
private:
    Lazy() {}
public:
    static Lazy& getInstance() {
        static Lazy instance;  // 首次调用时创建
        return instance;
    }
};
```

### 7. 注意事项

#### 拷贝构造和赋值
```cpp
class Singleton {
private:
    Singleton() {}

public:
    static Singleton& getInstance() {
        static Singleton instance;
        return instance;
    }

    // 禁止拷贝构造
    Singleton(const Singleton&) = delete;

    // 禁止拷贝赋值
    Singleton& operator=(const Singleton&) = delete;

    // 禁止移动构造
    Singleton(Singleton&&) = delete;

    // 禁止移动赋值
    Singleton& operator=(Singleton&&) = delete;
};
```

#### 析构顺序
```cpp
// 懒汉式使用静态局部变量，自动析构
// 饿汉式需要手动管理析构

class EagerWithCleanup {
private:
    static EagerWithCleanup* instance;
    EagerWithCleanup() {}

public:
    static EagerWithCleanup& getInstance() {
        return *instance;
    }

    ~EagerWithCleanup() {
        std::cout << "EagerWithCleanup destroyed" << std::endl;
    }

    static void cleanup() {
        delete instance;
        instance = nullptr;
    }
};

EagerWithCleanup* EagerWithCleanup::instance = new EagerWithCleanup();

// 使用后需要手动清理
int main() {
    auto& singleton = EagerWithCleanup::getInstance();
    // ...
    EagerWithCleanup::cleanup();
    return 0;
}
```

### 8. 最佳实践

#### 推荐使用方式
```cpp
// 1. 优先使用懒汉式（C++11 静态局部变量）
class BestPracticeSingleton {
private:
    BestPracticeSingleton() {}

public:
    static BestPracticeSingleton& getInstance() {
        static BestPracticeSingleton instance;
        return instance;
    }

    BestPracticeSingleton(const BestPracticeSingleton&) = delete;
    BestPracticeSingleton& operator=(const BestPracticeSingleton&) = delete;
};

// 2. 返回引用而不是指针
auto& singleton = BestPracticeSingleton::getInstance();

// 3. 提供清晰的接口
class Config {
private:
    Config() {}

public:
    static Config& getInstance() {
        static Config instance;
        return instance;
    }

    // 清晰的接口
    std::string get(const std::string& key) const;
    void set(const std::string& key, const std::string& value);
    bool has(const std::string& key) const;
};
```

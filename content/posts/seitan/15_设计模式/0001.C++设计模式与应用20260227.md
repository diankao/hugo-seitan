## 参考答案
### 1. 常用设计模式分类

#### 1.1 创建型模式

**单例模式（Singleton）：**
- 确保一个类只有一个实例
- 嵌入式中常用于硬件驱动管理、配置管理等
- **示例：设备管理器**
```cpp
class DeviceManager {
private:
    static DeviceManager* instance;
    DeviceManager() {}
    
public:
    static DeviceManager* getInstance() {
        if (instance == nullptr) {
            instance = new DeviceManager();
        }
        return instance;
    }
    
    void init() { /* 初始化设备 */ }
    void deinit() { /* 反初始化设备 */ }
};

DeviceManager* DeviceManager::instance = nullptr;

// 使用
DeviceManager::getInstance()->init();
```

**工厂模式（Factory）：**
- 封装对象创建逻辑
- 适用于创建不同类型对象
- **示例：传感器工厂**
```cpp
class Sensor {
public:
    virtual ~Sensor() {}
    virtual void read() = 0;
};

class TemperatureSensor : public Sensor {
public:
    void read() override { /* 读温度 */ }
};

class HumiditySensor : public Sensor {
public:
    void read() override { /* 读湿度 */ }
};

class SensorFactory {
public:
    static Sensor* createSensor(int type) {
        switch (type) {
            case TEMP_SENSOR: return new TemperatureSensor();
            case HUMI_SENSOR: return new HumiditySensor();
            default: return nullptr;
        }
    }
};

// 使用
Sensor* sensor = SensorFactory::createSensor(TEMP_SENSOR);
sensor->read();
```

#### 1.2 结构型模式

**适配器模式（Adapter）：**
- 将一个类的接口转换成客户希望的另一个接口
- 常用于硬件抽象层
- **示例：硬件驱动适配器**
```cpp
class UARTDriver {
public:
    virtual void send(uint8_t* data, int len) = 0;
    virtual void receive(uint8_t* data, int* len) = 0;
};

class STM32UART : public UARTDriver {
public:
    void send(uint8_t* data, int len) override {
        HAL_UART_Transmit(&huart1, data, len, 100);
    }
    void receive(uint8_t* data, int* len) override {
        HAL_UART_Receive(&huart1, data, 64, len, 100);
    }
};

// 使用
UARTDriver* uart = new STM32UART();
uart->send(data, len);
```

**装饰器模式（Decorator）：**
- 动态地给对象添加额外职责
- 不修改原有类的情况下扩展功能
- **示例：数据流装饰器**
```cpp
class DataStream {
public:
    virtual void write(uint8_t* data, int len) = 0;
};

class BaseStream : public DataStream {
public:
    void write(uint8_t* data, int len) override {
        // 基本写入操作
    }
};

class CompressedStream : public DataStream {
private:
    DataStream* stream;
public:
    CompressedStream(DataStream* s) : stream(s) {}
    
    void write(uint8_t* data, int len) override {
        uint8_t compressed[len];
        int comp_len = compress(data, compressed, len);
        stream->write(compressed, comp_len);
    }
};

// 使用
DataStream* stream = new BaseStream();
stream = new CompressedStream(stream);
stream->write(data, len);
```

#### 1.3 行为型模式

**观察者模式（Observer）：**
- 定义对象间的一对多依赖关系
- 一个对象状态改变，所有依赖者得到通知
- **示例：事件通知系统**
```cpp
class Observer {
public:
    virtual void onEvent(int event) = 0;
};

class Subject {
private:
    std::vector<Observer*> observers;
    
public:
    void attach(Observer* obs) {
        observers.push_back(obs);
    }
    
    void detach(Observer* obs) {
        observers.erase(std::remove(observers.begin(), observers.end(), obs), 
                   observers.end());
    }
    
    void notify(int event) {
        for (auto obs : observers) {
            obs->onEvent(event);
        }
    }
};

class Button : public Subject {
public:
    void onClick() {
        notify(BUTTON_CLICKED);
    }
};

class LED : public Observer {
public:
    void onEvent(int event) override {
        if (event == BUTTON_CLICKED) {
            toggle();
        }
    }
    void toggle() { /* 切换LED */ }
};

// 使用
Button button;
LED led;
button.attach(&led);
button.onClick();
```

**策略模式（Strategy）：**
- 定义一系列算法，封装起来，使它们可以互相替换
- **示例：滤波算法策略**
```cpp
class FilterStrategy {
public:
    virtual float filter(float value) = 0;
};

class MovingAverageFilter : public FilterStrategy {
private:
    std::queue<float> buffer;
    int window_size;
public:
    MovingAverageFilter(int size) : window_size(size) {}
    
    float filter(float value) override {
        buffer.push(value);
        if (buffer.size() > window_size) {
            buffer.pop();
        }
        
        float sum = 0;
        std::queue<float> temp = buffer;
        while (!temp.empty()) {
            sum += temp.front();
            temp.pop();
        }
        return sum / buffer.size();
    }
};

class KalmanFilter : public FilterStrategy {
private:
    float q, r, x, p, k;
public:
    KalmanFilter(float process_noise, float measurement_noise) 
        : q(process_noise), r(measurement_noise), x(0), p(0), k(0) {}
    
    float filter(float measurement) override {
        p = p + q;
        k = p / (p + r);
        x = x + k * (measurement - x);
        p = (1 - k) * p;
        return x;
    }
};

class Sensor {
private:
    FilterStrategy* filter;
public:
    void setFilter(FilterStrategy* f) { filter = f; }
    
    float read() {
        float raw = read_raw();
        return filter->filter(raw);
    }
};

// 使用
Sensor sensor;
sensor.setFilter(new MovingAverageFilter(5));
float value = sensor.read();
```

**状态模式（State）：**
- 允许对象在内部状态改变时改变它的行为
- **示例：设备状态机**
```cpp
class DeviceState {
public:
    virtual void onPowerOn() {}
    virtual void onPowerOff() {}
    virtual void onError() {}
};

class IdleState : public DeviceState {
public:
    void onPowerOn() override {
        // 切换到工作状态
    }
};

class WorkingState : public DeviceState {
public:
    void onError() override {
        // 切换到错误状态
    }
};

class ErrorState : public DeviceState {
public:
    void onPowerOff() override {
        // 切换到空闲状态
    }
};

class Device {
private:
    DeviceState* state;
public:
    Device() : state(new IdleState()) {}
    
    void setState(DeviceState* s) {
        delete state;
        state = s;
    }
    
    void powerOn() { state->onPowerOn(); }
    void powerOff() { state->onPowerOff(); }
    void error() { state->onError(); }
};
```

### 2. 嵌入式开发中常用模式

#### 2.1 硬件抽象层（HAL）模式
- 统一不同硬件平台的接口
- 便于移植和维护

#### 2.2 中断回调模式
- 注册回调函数处理中断
- 解耦中断处理和业务逻辑

#### 2.3 消息队列模式
- 任务间通信
- 解耦生产者和消费者

#### 2.4 资源池模式
- 复用资源（内存池、连接池）
- 减少分配释放开销

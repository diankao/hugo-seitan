### 项目二：INTAN256_MAIN - 256通道神经信号采集系统

**项目角色**：全栈开发负责人（上位机 + 下位机）

**项目背景**：
基于STM32H7的256通道神经信号采集系统，用于科研和医疗领域的神经信号采集。支持USB、WiFi、SD卡三种数据传输模式。**独立完成整个系统的软硬件开发，包括下位机固件和上位机应用程序**。

**技术栈**：
- **下位机**：STM32H7 / HAL库 / SPI / UART / USB CDC / SDMMC / DMA / MDMA / ARM GCC
- **上位机**：Qt / C++ / 串口通信 / 数据可视化 / SD卡文件解析

**核心贡献**：

- **全栈系统开发**
  - 独立完成下位机固件和上位机应用的全栈开发
  - 设计上下位机通信协议，确保数据传输可靠性和实时性
  - 实现端到端的系统联调，从硬件采集到上位机显示的完整数据流
  - 开发SD卡文件解析工具，支持录制数据的回放和分析

- **下位机开发（STM32H7）**
  - 设计模块化架构，分离数据采集、处理、传输三个核心模块
  - 实现命令处理器，支持UART6和USB CDC双接口命令解析
  - 设计自定义通信协议，支持设备模式切换、采集控制、通道配置等功能
  - 设计模块化架构，分离数据采集、处理、传输三个核心模块
  - 实现命令处理器，支持UART6和USB CDC双接口命令解析
  - 设计自定义通信协议，支持设备模式切换、采集控制、通道配置等功能

- **高性能环形缓冲区**
  - 设计二级指针结构的块式环形缓冲区（160KB）
  - 实现10块×32扇区的管理模式，适配SD卡批量写入
  - 提供零拷贝接口，优化数据传输性能

- **多模式数据传输**
  - **WiFi模式**：实现SPI5 DMA异步传输，支持高实时性数据流
  - **SD卡模式**：实现SD卡DMA批量写入（32 blocks/次），异步非阻塞
  - **USB模式**：USB CDC虚拟串口（待实现）

- **实时数据采集**
  - 使用TIM3定时器实现可配置采样率（1-10000 Hz）
  - 设计UART6 DMA + IDLE中断接收机制，高效处理命令
  - 实现DCache一致性管理，确保DMA数据正确性

- **SD卡文件系统**
  - 设计自定义文件格式，包含文件头、数据块、文件尾
  - 实现信息块固定位置（32768块）存储机制
  - 支持UTC时间戳、采样率、通道数等元数据存储

- **上位机应用开发**
  - 使用Qt开发上位机应用程序，提供设备配置和控制界面
  - 实现串口通信模块，支持UART和USB CDC双接口
  - 开发实时波形显示组件，可视化256通道神经信号
  - 实现SD卡录制文件解析功能，支持数据回放和导出
  - 设计参数配置界面，支持采样率、通道数、传输模式等动态配置

- **硬件驱动开发**
  - SPI5驱动WiFi模块通信
  - SDMMC1驱动SD卡接口
  - USART6命令接收接口（DMA + IDLE中断）
  - GPIO、定时器、DMA/MDMA等外设配置

**技术难点与解决方案**：
- **DMA缓存一致性**：实现SCB_DCache失效机制，确保DMA数据正确性
- **中断优先级**：合理配置UART IDLE中断优先级，避免命令丢失
- **WiFi传输同步**：通过WIFI_DATA_EN引脚和SPI状态双重确认机制
- **缓冲区溢出保护**：在采集循环中实现剩余空间检查

**项目成果**：
- 独立完成端到端全栈开发，包括下位机固件和上位机应用
- 成功实现WiFi模式异步SPI传输，数据传输稳定
- SD卡模式稳定写入，支持长时间连续录制
- 命令响应稳定，支持动态配置采样率和通道数
- 完成上下位机联调，实现完整的数据采集-传输-显示流程

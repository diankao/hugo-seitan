# 常用的Qt布局有几种如何自适应缩放

## 题目

布局是 UI 设计的核心，Qt 里常用布局有哪些？它们的区别和适用场景是什么？Qt 如何实现界面自适应缩放？

## 考察点

- 掌握 Qt 四大布局管理器的特点和用法
- 理解布局嵌套组合实现复杂界面
- 了解自适应缩放和布局策略

## 回答要点

### 1. 四大核心布局

| 布局类 | 排列方式 | 典型场景 |
|--------|---------|---------|
| `QHBoxLayout` | 水平排列，从左到右 | 工具栏按钮行、标签+输入框 |
| `QVBoxLayout` | 垂直排列，从上到下 | 表单字段堆叠、对话框主体 |
| `QGridLayout` | 网格排列，行×列 | 登录表单、设置面板、计算器 |
| `QFormLayout` | 标签-字段两列 | 设置表单、属性编辑器 |

此外还有 `QStackedLayout`（堆栈布局，同一位置只显示一个控件，用于向导页面切换）和 `QFlowLayout`（流式布局，Qt 没有内置，需自定义实现）。

### 2. 各布局详解与代码示例

**QHBoxLayout（水平布局）：**

```cpp
QHBoxLayout *hLayout = new QHBoxLayout();

QPushButton *btn1 = new QPushButton("Button 1");
QPushButton *btn2 = new QPushButton("Button 2");
QPushButton *btn3 = new QPushButton("Button 3");

hLayout->addWidget(btn1);
hLayout->addWidget(btn2);
hLayout->addWidget(btn3);

hLayout->setSpacing(10);
hLayout->setContentsMargins(10, 10, 10, 10);
```

**QVBoxLayout（垂直布局）：**

```cpp
QVBoxLayout *vLayout = new QVBoxLayout();

QLabel *titleLabel = new QLabel("Title");
QLineEdit *inputField = new QLineEdit();
QPushButton *submitBtn = new QPushButton("Submit");

vLayout->addWidget(titleLabel);
vLayout->addWidget(inputField);
vLayout->addWidget(submitBtn);
```

**QGridLayout（网格布局）：**

```cpp
QGridLayout *gridLayout = new QGridLayout();

QLabel *userLabel = new QLabel("Username:");
QLineEdit *userInput = new QLineEdit();
QLabel *passLabel = new QLabel("Password:");
QLineEdit *passInput = new QLineEdit();
QPushButton *loginBtn = new QPushButton("Login");

gridLayout->addWidget(userLabel, 0, 0);
gridLayout->addWidget(userInput, 0, 1);
gridLayout->addWidget(passLabel, 1, 0);
gridLayout->addWidget(passInput, 1, 1);
gridLayout->addWidget(loginBtn, 2, 0, 1, 2);

gridLayout->setColumnStretch(1, 1);
```

**QFormLayout（表单布局）：**

```cpp
QFormLayout *formLayout = new QFormLayout();

QLineEdit *nameEdit = new QLineEdit();
QLineEdit *emailEdit = new QLineEdit();
QSpinBox *ageSpin = new QSpinBox();

formLayout->addRow("Name:", nameEdit);
formLayout->addRow("Email:", emailEdit);
formLayout->addRow("Age:", ageSpin);
```

### 3. 布局关键属性

| 属性/方法 | 说明 | 示例 |
|----------|------|------|
| `setSpacing(int)` | 控件之间的间距 | `layout->setSpacing(10)` |
| `setContentsMargins(l,t,r,b)` | 布局外边距 | `layout->setContentsMargins(5,5,5,5)` |
| `setStretch(index, stretch)` | 设置拉伸因子 | `layout->setStretch(0, 2)` |
| `addWidget(widget, stretch)` | 添加控件时指定拉伸 | `layout->addWidget(btn, 1)` |
| `addStretch()` | 添加弹性空白 | 将控件推向一侧 |
| `setAlignment(widget, align)` | 控件对齐方式 | `Qt::AlignTop` |

### 4. 布局嵌套实现复杂界面

实际项目中很少单一布局，通常嵌套组合：

```cpp
QWidget *window = new QWidget;

QVBoxLayout *mainLayout = new QVBoxLayout(window);

QHBoxLayout *headerLayout = new QHBoxLayout();
QLabel *logo = new QLabel("MyApp");
QPushButton *settingsBtn = new QPushButton("Settings");
headerLayout->addWidget(logo);
headerLayout->addStretch();
headerLayout->addWidget(settingsBtn);

QGridLayout *contentLayout = new QGridLayout();
contentLayout->addWidget(new QLabel("Name:"), 0, 0);
contentLayout->addWidget(new QLineEdit(), 0, 1);
contentLayout->addWidget(new QLabel("Email:"), 1, 0);
contentLayout->addWidget(new QLineEdit(), 1, 1);

QHBoxLayout *footerLayout = new QHBoxLayout();
footerLayout->addStretch();
footerLayout->addWidget(new QPushButton("OK"));
footerLayout->addWidget(new QPushButton("Cancel"));

mainLayout->addLayout(headerLayout);
mainLayout->addLayout(contentLayout);
mainLayout->addStretch();
mainLayout->addLayout(footerLayout);

window->show();
```

### 5. 自适应缩放策略

**拉伸因子（Stretch Factor）：**

```cpp
QHBoxLayout *layout = new QHBoxLayout();
QPushButton *left = new QPushButton("Left");
QPushButton *right = new QPushButton("Right");

layout->addWidget(left, 1);
layout->addWidget(right, 3);
```

左侧占 1/4，右侧占 3/4，窗口缩放时按比例自动调整。

**尺寸策略（Size Policy）：**

| 策略 | 说明 | 典型控件 |
|------|------|---------|
| `Fixed` | 固定尺寸，不随布局变化 | 图标、固定宽度按钮 |
| `Minimum` | 最小尺寸保底，可拉伸 | QLineEdit |
| `Maximum` | 最大尺寸封顶，可缩小 | QLabel（短文本） |
| `Preferred` | 有理想尺寸，可伸缩 | 大多数控件默认值 |
| `Expanding` | 尽量占据剩余空间 | QTextEdit、表格视图 |
| `MinimumExpanding` | 最小尺寸保底，尽量扩展 | 进度条 |

```cpp
QTextEdit *editor = new QTextEdit();
editor->setSizePolicy(QSizePolicy::Expanding, QSizePolicy::Expanding);

QPushButton *btn = new QPushButton("OK");
btn->setSizePolicy(QSizePolicy::Fixed, QSizePolicy::Fixed);
btn->setFixedSize(80, 30);
```

**最小/最大尺寸约束：**

```cpp
widget->setMinimumSize(400, 300);
widget->setMaximumSize(800, 600);

QLineEdit *edit = new QLineEdit();
edit->setMinimumWidth(200);
```

### 6. 对比总结

| 布局类型 | 复杂度 | 灵活性 | 适用场景 |
|---------|--------|--------|---------|
| QHBoxLayout | 低 | 单方向排列 | 工具栏、按钮行 |
| QVBoxLayout | 低 | 单方向排列 | 表单堆叠、对话框 |
| QGridLayout | 中 | 行列精确控制 | 表格类表单、计算器 |
| QFormLayout | 低 | 标签+字段 | 设置对话框 |
| QStackedLayout | 低 | 页面切换 | 向导、Tab页内容 |
| 嵌套组合 | 高 | 任意复杂界面 | 实际项目 |

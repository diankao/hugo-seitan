# 自定义控件流程

## 题目

自定义控件一般怎么做？paintEvent 重绘你用过吗？什么叫自定义控件？你觉得自定义控件的方法主要是哪些？

## 考察点

- 自定义控件的几种实现方式
- paintEvent + QPainter 的使用能力
- 控件提升（Promote）在 Designer 中的用法

## 回答要点

### 1. 自定义控件概述

当 Qt 内置控件无法满足需求时，需要通过继承、组合或重绘等方式创建自定义控件。

**自定义控件的两大方向：**

| 方向 | 方法 | 说明 |
|------|------|------|
| 外观设计 | QSS、paintEvent 重绘、QStyle 重绘、组合拼装 | 改变控件外观 |
| 功能行为 | 重写事件函数、添加/修改信号和槽 | 改变控件行为 |

### 2. 方法一：QSS 样式美化

最简单的方式，适合外观调整，不需要继承：

```cpp
QPushButton *btn = new QPushButton("Custom");
btn->setStyleSheet(R"(
    QPushButton {
        background-color: #4CAF50;
        color: white;
        border-radius: 20px;
        padding: 10px;
    }
    QPushButton:hover { background-color: #45a049; }
    QPushButton:pressed { background-color: #3d8b40; }
)");
```

**局限：** 无法实现复杂绘制（如圆弧进度条、仪表盘等）。

### 3. 方法二：继承 + paintEvent 重绘

最核心的自定义控件方式，通过重写 `paintEvent` 使用 QPainter 自由绘制。

**示例：圆形进度条控件**

```cpp
class CircularProgress : public QWidget {
    Q_OBJECT
    Q_PROPERTY(int value READ value WRITE setValue NOTIFY valueChanged)

public:
    explicit CircularProgress(QWidget *parent = nullptr)
        : QWidget(parent), m_value(0), m_maxValue(100) {
        setMinimumSize(120, 120);
    }

    int value() const { return m_value; }

    void setValue(int v) {
        if (m_value != v) {
            m_value = qBound(0, v, m_maxValue);
            update();
            emit valueChanged(m_value);
        }
    }

signals:
    void valueChanged(int value);

protected:
    void paintEvent(QPaintEvent *) override {
        QPainter painter(this);
        painter.setRenderHint(QPainter::Antialiasing);

        int side = qMin(width(), height());
        painter.setViewport((width() - side) / 2, (height() - side) / 2,
                            side, side);
        painter.setWindow(0, 0, 200, 200);

        int penWidth = 12;
        int margin = penWidth / 2;
        QRectF arcRect(margin, margin, 200 - penWidth, 200 - penWidth);

        QPen bgPen(QColor(230, 230, 230), penWidth, Qt::SolidLine, Qt::RoundCap);
        painter.setPen(bgPen);
        painter.drawArc(arcRect, 0, 360 * 16);

        QPen fgPen(QColor(76, 175, 80), penWidth, Qt::SolidLine, Qt::RoundCap);
        painter.setPen(fgPen);
        int spanAngle = static_cast<int>(-360.0 * m_value / m_maxValue * 16);
        painter.drawArc(arcRect, 90 * 16, spanAngle);

        painter.setPen(Qt::black);
        QFont font;
        font.setPixelSize(40);
        font.setBold(true);
        painter.setFont(font);
        painter.drawText(arcRect, Qt::AlignCenter,
                         QString::number(m_value) + "%");
    }

private:
    int m_value;
    int m_maxValue;
};
```

**使用方式：**

```cpp
CircularProgress *progress = new CircularProgress();
progress->setValue(75);
```

### 4. 方法三：组合现有控件

将多个现有控件组合到一个容器中，封装为独立组件：

```cpp
class SearchBox : public QWidget {
    Q_OBJECT

public:
    explicit SearchBox(QWidget *parent = nullptr) : QWidget(parent) {
        QHBoxLayout *layout = new QHBoxLayout(this);
        layout->setContentsMargins(0, 0, 0, 0);

        m_iconLabel = new QLabel();
        m_iconLabel->setPixmap(QPixmap(":/icons/search.png").scaled(
            16, 16, Qt::KeepAspectRatio, Qt::SmoothTransformation));

        m_lineEdit = new QLineEdit();
        m_lineEdit->setPlaceholderText("Search...");

        m_clearBtn = new QPushButton("x");
        m_clearBtn->setFixedSize(20, 20);
        m_clearBtn->hide();

        layout->addWidget(m_iconLabel);
        layout->addWidget(m_lineEdit);
        layout->addWidget(m_clearBtn);

        connect(m_lineEdit, &QLineEdit::textChanged, this, [this](const QString &text) {
            m_clearBtn->setVisible(!text.isEmpty());
            emit textChanged(text);
        });

        connect(m_clearBtn, &QPushButton::clicked, this, [this]() {
            m_lineEdit->clear();
        });
    }

    QString text() const { return m_lineEdit->text(); }

signals:
    void textChanged(const QString &text);

private:
    QLabel *m_iconLabel;
    QLineEdit *m_lineEdit;
    QPushButton *m_clearBtn;
};
```

### 5. 方法四：继承 QStyle

适合需要深度定制原生控件外观的场景，复杂度最高：

```cpp
class CustomStyle : public QProxyStyle {
public:
    void drawPrimitive(PrimitiveElement element, const QStyleOption *option,
                       QPainter *painter, const QWidget *widget) const override {
        if (element == PE_PanelButtonCommand) {
            painter->save();
            painter->setRenderHint(QPainter::Antialiasing);
            painter->setBrush(QColor(100, 150, 200));
            painter->setPen(Qt::NoPen);
            painter->drawRoundedRect(option->rect, 6, 6);
            painter->restore();
        } else {
            QProxyStyle::drawPrimitive(element, option, painter, widget);
        }
    }
};

QApplication::setStyle(new CustomStyle());
```

### 6. 在 Qt Designer 中使用自定义控件（提升控件）

**步骤：**

1. 在 Designer 中放置一个基础控件（如 QWidget）
2. 右键 → "Promote to..."
3. 填写自定义类名（如 `CircularProgress`）和头文件路径
4. 点击 "Add" → "Promote"
5. 编译时 Designer 会自动使用自定义类替代原控件

### 7. paintEvent 常用绘制操作

| 操作 | 方法 | 说明 |
|------|------|------|
| 抗锯齿 | `painter.setRenderHint(QPainter::Antialiasing)` | 必须开启 |
| 画线 | `painter.drawLine(QPointF, QPointF)` | 直线 |
| 画矩形 | `painter.drawRect(QRectF)` | 矩形 |
| 画圆角矩形 | `painter.drawRoundedRect(QRectF, rx, ry)` | 圆角 |
| 画圆/椭圆 | `painter.drawEllipse(QRectF)` | 椭圆 |
| 画弧 | `painter.drawArc(QRectF, startAngle, spanAngle)` | 弧线，角度单位 1/16度 |
| 画文字 | `painter.drawText(QRectF, alignment, text)` | 居中等对齐 |
| 画图片 | `painter.drawPixmap(QRectF, QPixmap)` | 图片 |
| 填充路径 | `painter.fillPath(QPainterPath, QBrush)` | 复杂形状 |
| 渐变 | `QRadialGradient` / `QLinearGradient` | 渐变填充 |

**paintEvent 注意事项：**
- 只能在 `paintEvent` 中创建 QPainter，或用 `QPainter::begin()` / `end()`
- 调用 `update()` 触发重绘（异步，可合并），`repaint()` 立即重绘（同步）
- 避免在 paintEvent 中执行耗时操作
- 使用双缓冲时，Qt 默认已开启（`Qt::WA_PaintOnScreen` 为 false）

### 8. 四种方法对比

| 方法 | 复杂度 | 灵活性 | 适用场景 |
|------|--------|--------|---------|
| QSS 美化 | 低 | 有限 | 简单外观调整 |
| paintEvent 重绘 | 中 | 高 | 自定义图形、仪表盘、图表 |
| 组合控件 | 中 | 中 | 复合输入控件、搜索框 |
| QStyle 重写 | 高 | 最高 | 全局风格统一替换 |

**面试建议：** 优先回答 paintEvent 重绘和组合控件两种方式，这是实际项目中最常用的。

# Qt样式表QSS使用技巧

## 题目

Qt样式表QSS有哪些高级用法？如何解决样式表不生效的问题？

## 答案

### QSS基本语法

**选择器和属性：**

```cpp
//设置按钮样式
QPushButton {
    background-color: #4CAF50;
    color: white;
    border: none;
    padding: 10px 20px;
    border-radius: 5px;
}

//悬停状态

    background-color: #45a049;

//按下状态

    background-color: #3e8e41;

//禁用状态

    background-color: #cccccc;

```

### 自定义控件样式表

**问题：继承QWidget的控件样式表不生效**

**方法一：设置WA_StyledBackground属性（推荐）：**

```cpp
class CustomWidget : public QWidget {
    Q_OBJECT

public:
    CustomWidget(QWidget *parent = nullptr) : QWidget(parent) {
        this->setAttribute(Qt::WA_StyledBackground, true);
        
        this->setStyleSheet(
            "CustomWidget {"
            "   background-color: #f0f0f0;"
            "   border: 2px solid #333;"
            "   border-radius: 10px;"
            "}"
        );
    }
};
```

**方法二：继承QFrame：**

```cpp
class CustomWidget : public QFrame {
    Q_OBJECT

public:
    CustomWidget(QWidget *parent = nullptr) : QFrame(parent) {
        this->setStyleSheet(
            "CustomWidget {"
            "   background-color: #f0f0f0;"
            "   border: 2px solid #333;"
            "}"
        );
    }
};
```

**方法三：重写paintEvent：**

```cpp
class CustomWidget : public QWidget {
    Q_OBJECT

public:
    CustomWidget(QWidget *parent = nullptr) : QWidget(parent) {}

protected:
    void paintEvent(QPaintEvent *) override {
        QStyleOption option;
        option.initFrom(this);
        QPainter painter(this);
        style()->drawPrimitive(QStyle::PE_Widget, &option, &painter, this);
    }
};
```

### 动态修改样式

```cpp
class MainWindow : public QMainWindow {
    Q_OBJECT

public:
    MainWindow(QWidget *parent = nullptr) : QMainWindow(parent) {
        QPushButton *button = new QPushButton("Change Style", this);
        
        connect(button, &QPushButton::clicked, this, [this]() {
            static bool isDark = false;
            
            if (isDark) {
                this->setStyleSheet(lightTheme());
            } else {
                this->setStyleSheet(darkTheme());
            }
            
            isDark = !isDark;
        });
    }

private:
    QString lightTheme() {
        return R"(
            QMainWindow {
                background-color: #f5f5f5;
            }
            QPushButton {
                background-color: #2196F3;
                color: white;
                border-radius: 5px;
                padding: 8px 16px;
            }
        )";
    }

    QString darkTheme() {
        return R"(
            QMainWindow {
                background-color: #2d2d2d;
            }
            QPushButton {
                background-color: #4CAF50;
                color: white;
                border-radius: 5px;
                padding: 8px 16px;
            }
        )";
    }
};
```

### 从文件加载QSS

```cpp
void MainWindow::loadStyleSheet() {
    QFile file(":/qss/style.qss");
    
    if (file.open(QFile::ReadOnly)) {
        QTextStream in(&file);
        
        QStringList list;
        while (!in.atEnd()) {
            QString line;
            in >> line;
            list << line;
        }
        
        QString qss = list.join("\n");
        
        //提取主题色
        QString paletteColor = qss.mid(20, 7);
        qApp->setPalette(QPalette(QColor(paletteColor)));
        qApp->setStyleSheet(qss);
        
        file.close();
    }
}
```

### 自定义委托样式

```cpp
class CustomDelegate : public QStyledItemDelegate {
    Q_OBJECT

public:
    void paint(QPainter *painter, 
               const QStyleOptionViewItem &option,
               const QModelIndex &index) const override {
        
        QStyleOptionViewItem opt = option;
        initStyleOption(&opt, index);
        
        //自定义绘制
        if (index.column() == 0) {
            painter->fillRect(option.rect, QColor("#f0f0f0"));
        }
        
        QStyledItemDelegate::paint(painter, opt, index);
    }
};
```

### 总结

**QSS使用要点：**
- 自定义QWidget需要设置WA_StyledBackground属性
- 使用QTextStream加载QSS文件避免编码问题
- 动态修改样式需要unpolish和polish
- 使用属性可以实现动态样式切换

**最佳实践：**
- 统一使用一个QSS文件管理所有样式
- 使用属性机制实现主题切换
- QLCDNumber需要设置segmentstyle为flat
- 去除焦点虚边框使用outline:0px
- viewport()控件需要对其设置样式

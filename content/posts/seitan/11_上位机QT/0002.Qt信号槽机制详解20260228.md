# Qt信号槽机制详解

## 题目

Qt的信号槽机制是如何工作的？如何在多层窗体间传递信号？

## 答案

### 信号槽基本概念

**信号槽是Qt的核心机制：**
- 信号（Signal）：当对象状态改变时发射
- 槽（Slot）：用于响应信号的函数
- 连接（connect）：建立信号和槽的关联

### 基本用法

```cpp
class MyWidget : public QWidget {
    Q_OBJECT

public:
    MyWidget(QWidget *parent = nullptr) : QWidget(parent) {
        QPushButton *button = new QPushButton("Click me", this);
        
        //连接按钮点击信号到槽函数
        connect(button, &QPushButton::clicked, 
                this, &MyWidget::onButtonClicked);
    }

private slots:
    void onButtonClicked() {
        qDebug() << "Button clicked!";
    }
};
```

### 信号槽连接方式

**Qt::AutoConnection（自动）：**

```cpp
//默认连接方式，自动选择
connect(sender, &Sender::signal, receiver, &Receiver::slot);
//等同于
connect(sender, &Sender::signal, receiver, &Receiver::slot, 
         Qt::AutoConnection);
```

**Qt::DirectConnection（直接连接）：**

```cpp
//直接在发送者线程中调用槽函数
connect(sender, &Sender::signal, receiver, &Receiver::slot, 
         Qt::DirectConnection);
```

**Qt::QueuedConnection（队列连接）：**

```cpp
//在接收者线程的事件循环中调用槽函数
connect(sender, &Sender::signal, receiver, &Receiver::slot, 
         Qt::QueuedConnection);
```

**Qt::BlockingQueuedConnection（阻塞队列连接）：**

```cpp
//阻塞发送者线程，直到槽函数执行完毕
connect(sender, &Sender::signal, receiver, &Receiver::slot, 
         Qt::BlockingQueuedConnection);
```

### 自定义信号和槽

```cpp
class MyObject : public QObject {
    Q_OBJECT

public:
    MyObject(QObject *parent = nullptr) : QObject(parent) {}

    //自定义信号
signals:
    void valueChanged(int newValue);
    void dataReady(const QString &data, double value);

    //自定义槽函数
public slots:
    void setValue(int value) {
        m_value = value;
        emit valueChanged(value);
    }

private:
    int m_value;
};

//使用自定义信号和槽
MyObject *obj = new MyObject;
connect(obj, &MyObject::valueChanged, [](int value) {
    qDebug() << "Value changed to:" << value;
});

obj->setValue(42);
```

### 多层窗体信号传递

**传统方式（逐层传递）：**

```cpp
//窗体A -> 窗体B -> 窗体C -> 窗体D
//需要逐层连接，代码冗余

//在窗体A中
connect(this, &FormA::someSignal, formB, &FormB::someSlot);

//在窗体B中
connect(this, &FormB::forwardSignal, formC, &FormC::someSlot);

//在窗体C中
connect(this, &FormC::forwardSignal, formD, &FormD::someSlot);
```

**使用全局事件类（推荐）：**

```cpp
//全局单例事件类
class AppEvent : public QObject {
    Q_OBJECT

public:
    static AppEvent *instance() {
        static AppEvent instance;
        return &instance;
    }

signals:
    void logMessage(const QString &message);
    void statusChanged(int status);
    void dataUpdated(const QByteArray &data);

private:
    AppEvent() = default;
};

//在窗体A中发送信号
AppEvent::instance()->logMessage("User clicked button");

//在窗体D中接收信号
connect(AppEvent::instance(), &AppEvent::logMessage,
        [](const QString &msg) {
    qDebug() << "Received log:" << msg;
});
```

### 自动关联信号槽

**Qt支持自动关联：**

```cpp
//按钮名称：pushButton
//槽函数命名：on_控件名_信号(参数)

class MyWidget : public QWidget {
    Q_OBJECT

public:
    MyWidget(QWidget *parent = nullptr) : QWidget(parent) {
        setupUi(this);
        //不需要手动connect，会自动关联
    }

private slots:
    //自动关联到 pushButton 的 clicked 信号
    void on_pushButton_clicked() {
        qDebug() << "Button clicked!";
    }

    //自动关联到 lineEdit 的 textChanged 信号
    void on_lineEdit_textChanged(const QString &text) {
        qDebug() << "Text changed:" << text;
    }
};
```

### 信号槽的参数传递

```cpp
class DataProcessor : public QObject {
    Q_OBJECT

public:
    DataProcessor(QObject *parent = nullptr) : QObject(parent) {}

signals:
    //多个参数的信号
    void processData(int id, const QString &name, double value);

public slots:
    void onNewData(int id, const QString &name, double value) {
        qDebug() << "ID:" << id << "Name:" << name << "Value:" << value;
    }
};

//连接信号槽
DataProcessor *processor = new DataProcessor;
connect(processor, &DataProcessor::processData,
        processor, &DataProcessor::onNewData);

//发射信号
emit processor->processData(1, "Test", 3.14);
```

### Lambda表达式作为槽

```cpp
QPushButton *button = new QPushButton("Click me");

//使用lambda表达式
connect(button, &QPushButton::clicked, [](bool checked) {
    qDebug() << "Button clicked, checked:" << checked;
});

//捕获上下文变量
int counter = 0;
connect(button, &QPushButton::clicked, [counter]() mutable {
    qDebug() << "Counter:" << ++counter;
});

//捕获this指针
connect(button, &QPushButton::clicked, [this]() {
    this->handleButtonClicked();
});
```

### 断开信号槽连接

```cpp
//断开所有连接
disconnect(sender, &Sender::signal, receiver, &Receiver::slot);

//断开指定对象的所有连接
disconnect(sender, 0, 0, 0);

//断开特定信号的所有连接
disconnect(sender, &Sender::signal, 0, 0);

//使用QMetaObject::Connection
QMetaObject::Connection connection = 
    connect(sender, &Sender::signal, receiver, &Receiver::slot);

disconnect(connection);
```

### 信号槽的线程安全

```cpp
//跨线程信号槽自动使用队列连接
QThread *workerThread = new QThread;
Worker *worker = new Worker;

worker->moveToThread(workerThread);

connect(worker, &Worker::finished, workerThread, &QThread::quit);
connect(worker, &Worker::finished, worker, &QObject::deleteLater);
connect(workerThread, &QThread::finished, workerThread, &QThread::deleteLater);

connect(this, &MainWindow::startWork, worker, &Worker::doWork);

workerThread->start();
emit startWork();
```

### 总结

**信号槽机制特点：**
- 解耦：发送者和接收者不需要知道对方
- 类型安全：编译时检查参数类型
- 灵活：支持多种连接方式
- 跨线程：自动处理线程安全问题

**最佳实践：**
- 多层窗体间传递信号使用全局事件类
- 使用lambda表达式简化简单槽函数
- 跨线程时注意连接方式
- 及时断开不需要的连接
- 合理使用自动关联机制

# Qt中文乱码与编码处理

## 题目

Qt中如何解决中文乱码问题？有哪些编码处理的最佳实践？

## 答案

### 编码设置三步法

**第一步：代码文件使用UTF-8编码**

```cpp
//在代码文件顶部添加
#pragma execution_character_set("utf-8")
```

**第二步：设置编译器编码**

```cpp
//在main函数中设置编码
void QtHelper::setCode()
{
#if (QT_VERSION <= QT_VERSION_CHECK(5,0,0))
#if _MSC_VER
    //MSVC编译器使用GBK
    QTextCodec *codec = QTextCodec::codecForName("gbk");
#else
    //其他编译器使用UTF-8
    QTextCodec *codec = QTextCodec::codecForName("utf-8");
#endif
    QTextCodec::setCodecForLocale(codec);
    QTextCodec::setCodecForCStrings(codec);
    QTextCodec::setCodecForTr(codec);
#else
    //Qt5默认UTF-8，只需要设置locale
    QTextCodec *codec = QTextCodec::codecForName("utf-8");
    QTextCodec::setCodecForLocale(codec);
#endif
}
```

**第三步：配置文件编码设置**

```cpp
//INI配置文件支持中文
void App::readConfig()
{
    QSettings set(App::ConfigFile, QSettings::IniFormat);
    //设置编码为UTF-8
    set.setIniCodec("utf-8");

    set.beginGroup("AppConfig1");
    App::Company = set.value("Company", App::Company).toString();
    set.endGroup();
}

void App::writeConfig()
{
    QSettings set(App::ConfigFile, QSettings::IniFormat);
    //设置编码为UTF-8
    set.setIniCodec("utf-8");

    set.beginGroup("AppConfig1");
    set.setValue("Company", App::Company);
    set.endGroup();
}
```

### QString与const char*转换

**推荐方法：**

```cpp
//推荐：使用toStdString().c_str()
QString str = "测试中文";
const char *cstr = str.toStdString().c_str();

//不推荐：使用toLocal8Bit()
QString str = "测试中文";
const char *cstr = str.toLocal8Bit().constData();
//中文可能不正确，英文正常
```

//SQLite数据库中文处理
QSqlDatabase db = QSqlDatabase::addDatabase("QSQLITE");

if (db.open()) {
    QSqlQuery query;

    }

### 文件读写编码处理

```cpp
//写入文件
void writeToFile(const QString &filename, const QString &content)
{
    QFile file(filename);
    if (file.open(QIODevice::WriteOnly | QIODevice::Text)) {
        QTextStream out(&file);
        out.setCodec("UTF-8");
        out << content;
        file.close();
    }
}

//读取文件
QString readFromFile(const QString &filename)
{
    QFile file(filename);
    if (file.open(QIODevice::ReadOnly | QIODevice::Text)) {
        QTextStream in(&file);
        in.setCodec("UTF-8");
        QString content = in.readAll();
        file.close();
        return content;
    }
    return QString();
}
```

### QSS文件加载

```cpp
void loadStyleSheet()
{
    QString qss;
    QFile file(":/qss/style.css");
    
    if (file.open(QFile::ReadOnly)) {
        //使用QTextStream读取，不区分文件编码
        QStringList list;
        QTextStream in(&file);
        in.setCodec("utf-8");
        
        while (!in.atEnd()) {
            QString line;
            in >> line;
            list << line;
        }
        
        qss = list.join("\n");
        qApp->setStyleSheet(qss);
        file.close();
    }
}
```

### 字符串编码转换

```cpp
//UTF-8转GBK
QString utf8ToGbk(const QString &utf8Str)
{
    QTextCodec *gbk = QTextCodec::codecForName("GBK");
    QTextCodec *utf8 = QTextCodec::codecForName("UTF-8");
    
    QString gbkStr = gbk->toUnicode(utf8->fromUnicode(utf8Str));
    return gbkStr;
}

//GBK转UTF-8
QString gbkToUtf8(const QString &gbkStr)
{
    QTextCodec *gbk = QTextCodec::codecForName("GBK");
    QTextCodec *utf8 = QTextCodec::codecForName("UTF-8");
    
    QString utf8Str = utf8->toUnicode(gbk->fromUnicode(gbkStr));
    return utf8Str;
}

//本地编码转UTF-8
QString localToUtf8(const QString &localStr)
{
    QTextCodec *utf8 = QTextCodec::codecForName("UTF-8");
    QTextCodec *local = QTextCodec::codecForLocale();
    
    QString utf8Str = utf8->toUnicode(local->fromUnicode(localStr));
    return utf8Str;
}
```

### 宽字符处理

```cpp
//宽字符到QString
QString wideCharToString(const wchar_t *wstr)
{
    return QString::fromWCharArray(wstr);
}

//QString到宽字符
QStringList stringToWideChar(const QString &str)
{
    QVector<QChar> vec = str.toWCharArray();
    QStringList result;
    foreach (QChar ch, vec) {
        result << QString(ch);
    }
    return result;
}
```

### 总结

**中文乱码解决要点：**
1. 代码文件使用UTF-8编码
2. 设置#pragma execution_character_set("utf-8")
3. 在main函数中设置编码
4. INI配置文件设置setIniCodec
5. QString转const char*用toStdString().c_str()

**最佳实践：**
- 统一使用UTF-8编码
- 使用QTextStream处理文件读写
- 网络传输时URL转码中文
- 数据库设置编码为UTF-8
- qDebug().noquote()去除转义字符
- 推荐使用标准C++的字符串处理

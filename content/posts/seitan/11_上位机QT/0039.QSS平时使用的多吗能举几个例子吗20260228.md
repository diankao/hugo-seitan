# QSS平时使用的多吗能举几个例子吗

## 题目

你在项目里是怎么用 QSS 实现自定义样式的？举一个按钮/输入框美化的例子。QSS 平时使用的多吗？能举几个例子吗？

## 考察点

- QSS 语法掌握程度
- 能否用 QSS 实现实际 UI 美化需求
- 了解 QSS 加载方式和注意事项

## 回答要点

### 1. QSS 简介

QSS（Qt Style Sheet）类似于网页开发中的 CSS，用于控制 Qt 控件的外观样式。支持选择器、属性、伪状态等机制。

**QSS 加载方式：**

| 方式 | 代码 | 适用场景 |
|------|------|---------|
| 外部文件加载 | `app.setStyleSheet(fileContent)` | 全局主题，最常用 |
| 代码内联字符串 | `widget.setStyleSheet("...")` | 单个控件快速样式 |
| Qt Designer 填写 | 在属性编辑器中填写 | 原型设计 |
| qrc 资源文件嵌入 | `:/styles/theme.qss` | 打包分发 |

```cpp
QFile file(":/styles/theme.qss");
if (file.open(QFile::ReadOnly | QFile::Text)) {
    QString styleSheet = QTextStream(&file).readAll();
    qApp->setStyleSheet(styleSheet);
}
```

### 2. 按钮美化示例

**基础按钮美化：**

```css
QPushButton {
    background-color: #4CAF50;
    color: white;
    border: none;
    border-radius: 5px;
    padding: 8px 24px;
    font-size: 14px;
    font-weight: bold;
}

QPushButton:hover {
    background-color: #45a049;
}

QPushButton:pressed {
    background-color: #3d8b40;
    padding-top: 10px;
    padding-bottom: 6px;
}

QPushButton:disabled {
    background-color: #cccccc;
    color: #666666;
}
```

**渐变背景按钮：**

```css
QPushButton#loginBtn {
    background: qlineargradient(x1:0, y1:0, x2:1, y2:0,
        stop:0 #667eea, stop:1 #764ba2);
    color: white;
    border: none;
    border-radius: 20px;
    padding: 10px 40px;
    font-size: 16px;
}

QPushButton#loginBtn:hover {
    background: qlineargradient(x1:0, y1:0, x2:1, y2:0,
        stop:0 #5a6fd6, stop:1 #6a4296);
}
```

**带图标按钮：**

```cpp
QPushButton *btn = new QPushButton("Save");
btn->setIcon(QIcon(":/icons/save.png"));
btn->setIconSize(QSize(20, 20));
btn->setStyleSheet(R"(
    QPushButton {
        background-color: #2196F3;
        color: white;
        border: none;
        border-radius: 4px;
        padding: 6px 16px;
        text-align: left;
        padding-left: 36px;
    }
    QPushButton:hover { background-color: #1976D2; }
    QPushButton:pressed { background-color: #0D47A1; }
)");
```

### 4. 常用 QSS 属性速查

| 属性 | 说明 | 示例 |
|------|------|------|
| `background-color` | 背景色 | `#4CAF50` |
| `color` | 文字颜色 | `white` / `#333` |
| `border` | 边框 | `1px solid #ccc` |
| `border-radius` | 圆角 | `8px` |
| `padding` | 内边距 | `8px 16px` |
| `margin` | 外边距 | `4px` |
| `font-size` | 字号 | `14px` |
| `font-weight` | 字重 | `bold` |
| `min-height` | 最小高度 | `36px` |
| `selection-background-color` | 选中背景色 | `#4CAF50` |

### 5. QSS 选择器与伪状态

**选择器类型：**

| 选择器 | 示例 | 说明 |
|--------|------|------|
| 通用选择器 | `*` | 匹配所有控件 |
| 类型选择器 | `QPushButton` | 匹配该类及其子类 |
| 类选择器 | `.QPushButton` | 仅匹配该类，不含子类 |
| ID 选择器 | `QPushButton#loginBtn` | 匹配指定 objectName |
| 属性选择器 | `QPushButton[class="primary"]` | 匹配指定属性值 |
| 后代选择器 | `QDialog QPushButton` | 匹配后代控件 |

**常用伪状态：**

| 伪状态 | 说明 |
|--------|------|
| `:hover` | 鼠标悬停 |
| `:pressed` | 鼠标按下 |
| `:checked` | 勾选状态 |
| `:focus` | 获得焦点 |
| `:disabled` | 禁用状态 |
| `:selected` | 选中状态 |
| `:first` / `:last` | 列表首/末项 |

### 6. QSS 使用注意事项

- **样式继承：** 父控件的 QSS 会传递到子控件，除非子控件重新设置。一般只对子控件单独设置样式。
- **min-height 陷阱：** 父控件用 QSS 设置 `min-height` 后，子控件的 `setFixedHeight()` 无效，必须用 QSS 重新设置子控件高度。
- **性能考虑：** 避免在频繁刷新的控件上使用过于复杂的 QSS（如大量渐变）。
- **平台差异：** 某些 QSS 属性在不同平台表现不同，需要实际测试。
- **QSS 与 palette 冲突：** QSS 优先级高于 QPalette，同时设置时 QSS 生效。

# Qt高分屏适配解决方案

## 题目

Qt应用程序如何适配高分屏？有哪些方法可以解决高分屏下的显示问题？

## 答案

### 方法一：启用高DPI缩放

```cpp
int main(int argc, char *argv[])
{
#if (QT_VERSION >= QT_VERSION_CHECK(5,6,0))
    QGuiApplication::setAttribute(Qt::AA_EnableHighDpiScaling);
    //开启高缩放支持以后图片可能发虚还要开启下面这个属性
    QCoreApplication::setAttribute(Qt::AA_UseHighDpiPixmaps);
#endif

    QApplication a(argc, argv);
    return a.exec();
}
```

### 方法二：使用qt.conf配置文件

```ini
[Platforms]
WindowsArguments = dpiawareness=0, fontengine=freetype
```

**说明：**
- `dpiawareness=0`：启用DPI感知
- `fontengine=freetype`：解决Qt高DPI下文字显示有锯齿的问题
- 文件位置：可执行文件同目录

### 方法三：设置环境变量

```cpp
int main(int argc, char *argv[])
{
    //方法1：设置自动缩放因子
    qputenv("QT_AUTO_SCREEN_SCALE_FACTOR", "1.5");
    
    //方法2：启用高DPI缩放
    qputenv("QT_ENABLE_HIGHDPI_SCALING", "1");
    
    QApplication a(argc, argv);
    
    //方法4：新版本Qt5.14支持非整数缩放
#if (QT_VERSION >= QT_VERSION_CHECK(5,14,0))
    QGuiApplication::setHighDpiScaleFactorRoundingPolicy(
        Qt::HighDpiScaleFactorRoundingPolicy::PassThrough
    );
#endif

    return a.exec();
}
```

### 禁用缩放的方法

```cpp
int main(int argc, char *argv[])
{
    //方法1：使用96 DPI
#if (QT_VERSION >= QT_VERSION_CHECK(5,0,0))
    QApplication::setAttribute(Qt::AA_Use96Dpi);
#endif

    //方法2：新版本Qt
#if (QT_VERSION >= QT_VERSION_CHECK(5,14,0))
    QGuiApplication::setHighDpiScaleFactorRoundingPolicy(
        Qt::HighDpiScaleFactorRoundingPolicy::Floor
    );
#endif

    QApplication a(argc, argv);
    return a.exec();
}
```

**Qt6中禁用缩放：**

```cpp
int main(int argc, char *argv[])
{
    //Qt6中AA_Use96Dpi没效果必须用环境变量
    qputenv("QT_FONT_DPI", "96");
```

### 动态检测和适应DPI

```cpp
class MainWindow : public QMainWindow {
    Q_OBJECT

public:
    MainWindow(QWidget *parent = nullptr) : QMainWindow(parent) {
        //获取当前DPI
        qreal dpi = logicalDpiX();
        qDebug() << "Current DPI:" << dpi;
        
        //计算缩放比例
        qreal scale = dpi / 96.0;
        qDebug() << "Scale factor:" << scale;
        
        //根据DPI调整字体大小
        QFont font = this->font();
        font.setPointSizeF(font.pointSizeF() * scale);
        this->setFont(font);
    }
    
protected:
    bool event(QEvent *event) override {
        if (event->type() == QEvent::ApplicationFontChange ||
            event->type() == QEvent::PaletteChange) {
            //处理DPI变化
            handleDpiChange();
        }
        return QMainWindow::event(event);
    }

private:
    void handleDpiChange() {
        qreal dpi = logicalDpiX();
        qreal scale = dpi / 96.0;
        
        QFont font = this->font();
        font.setPointSizeF(font.pointSizeF() * scale);
        this->setFont(font);
    }
};
```

### 不同平台的高分屏适配

**Windows平台：**

```cpp
#if defined(Q_OS_WIN)
    QGuiApplication::setAttribute(Qt::AA_EnableHighDpiScaling);
    QGuiApplication::setAttribute(Qt::AA_UseHighDpiPixmaps);
#endif
```

**macOS平台：**

```cpp
#if defined(Q_OS_MAC)
    //macOS通常自动支持Retina显示屏
    QGuiApplication::setAttribute(Qt::AA_EnableHighDpiScaling);
#endif
```

**Linux平台：**

```cpp
#if defined(Q_OS_LINUX)
    //Linux可能需要手动设置
    qputenv("QT_AUTO_SCREEN_SCALE_FACTOR", "1");
#endif
```

### Qt6中的高分屏适配

```cpp
int main(int argc, char *argv[])
{
    //Qt6默认支持高分屏，但仍可配置
    
    //设置DPI缩放策略
    QGuiApplication::setHighDpiScaleFactorRoundingPolicy(
        Qt::HighDpiScaleFactorRoundingPolicy::PassThrough
    );
    
    //可选策略：
    // - PassThrough：不四舍五入（推荐）
    // - Round：四舍五入到整数
    // - Ceil：向上取整
    // - Floor：向下取整
    
    QApplication a(argc, argv);
    return a.exec();
}
```

### 总结

**高分屏适配方法：**
1. 启用AA_EnableHighDpiScaling属性
2. 使用qt.conf配置文件
3. 设置环境变量QT_ENABLE_HIGHDPI_SCALING
4. 使用AA_UseHighDpiPixmaps避免图片发虚

**注意事项：**
- Qt5.14支持非整数缩放
- Qt6需要使用QT_FONT_DPI环境变量
- 注意不同Qt版本的兼容性
- 处理DPI动态变化事件

**最佳实践：**
- 在main函数最前面设置DPI属性
- 使用qt.conf文件统一配置
- 测试不同缩放比例下的显示效果
- 注意字体和图片的清晰度

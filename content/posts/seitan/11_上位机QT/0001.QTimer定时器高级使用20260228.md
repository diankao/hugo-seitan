# QTimer定时器高级使用

## 题目

QTimer有哪些高级使用方式？如何解决窗体初始化时加载耗时操作导致界面卡顿的问题？

## 答案

### QTimer::singleShot 单次定时器

**基本用法：**

```cpp
//延时10毫秒执行load函数
QTimer::singleShot(10, this, SLOT(load()));

//使用lambda表达式
QTimer::singleShot(10, [&]() {
    load();
});
```

### 解决界面卡顿问题

**场景：窗体初始化时加载耗时操作**

```cpp
//方法一：异步执行load函数
QMetaObject::invokeMethod(this, "load", Qt::QueuedConnection);

//方法二：延时执行
QTimer::singleShot(10, this, SLOT(load()));

//方法三：lambda表达式
QTimer::singleShot(10, [&]() {
    load();
});
```

**示例代码：**

```cpp
class MainWindow : public QMainWindow {
    Q_OBJECT

public:
    MainWindow(QWidget *parent = nullptr) {
        setupUi();
        
        //延时加载，避免卡顿
        QTimer::singleShot(10, this, &MainWindow::loadHeavyData);
    }

private:
    void setupUi() {
        //设置UI
    }

    void loadHeavyData() {
        //耗时的数据加载
        //比如QStackWidget堆栈窗体加载一些子窗体
    }
};
```

### 单次定时器对象方式

```cpp
QTimer *timer = new QTimer(this);
timer->setSingleShot(true);
connect(timer, &QTimer::timeout, this, [timer, this] {
    qDebug() << "一次性任务执行";
    //执行完会自动停止
});
timer->start(5000);
```

### 定时器精度设置

**Qt提供三种定时器精度：**

```cpp
QTimer *timer = new QTimer(this);

//精确的定时器，尽量保持毫秒精度
timer->setTimerType(Qt::PreciseTimer);

//粗略的定时器，精度在所需时间间隔5%范围内
timer->setTimerType(Qt::CoarseTimer);

//很粗略的定时器，只保留完整的第二精度
timer->setTimerType(Qt::VeryCoarseTimer);

//默认是CoarseTimer
timer->start(1000);
```

**应用场景：**

```cpp
//精确计时器：需要高精度的场景
QTimer *preciseTimer = new QTimer(this);
preciseTimer->setTimerType(Qt::PreciseTimer);
preciseTimer->start(10);

//粗略计时器：一般的定时任务，比如每分钟保存一次
QTimer *coarseTimer = new QTimer(this);
coarseTimer->setTimerType(Qt::CoarseTimer);
coarseTimer->start(60000);
```

### QObject定时器事件

```cpp
class MyWidget : public QWidget {
    Q_OBJECT

public:
    MyWidget(QWidget *parent = nullptr) : QWidget(parent) {
        //启动定时器，返回定时器ID
        timerId = startTimer(1000, Qt::PreciseTimer);
    }

protected:
    void timerEvent(QTimerEvent *event) override {
        if (event->timerId() == timerId) {
            qDebug() << "定时器触发";
        }
    }

private:
    int timerId;
};
```

### 定时器与线程

```cpp
//在工作线程中使用定时器
class Worker : public QObject {
    Q_OBJECT

public:
    Worker(QObject *parent = nullptr) : QObject(parent) {
        timer = new QTimer(this);
        connect(timer, &QTimer::timeout, this, &Worker::doWork);
    }

    void start() {
        timer->start(1000);
    }

private slots:
    void doWork() {
        qDebug() << "工作线程定时任务";
    }

private:
    QTimer *timer;
};

//在主线程中创建工作线程
QThread *thread = new QThread;
Worker *worker = new Worker;
worker->moveToThread(thread);

connect(thread, &QThread::started, worker, &Worker::start);
connect(thread, &QThread::finished, worker, &QObject::deleteLater);

thread->start();
```

### 定时器清理

```cpp
class MainWindow : public QMainWindow {
    Q_OBJECT

public:
    MainWindow(QWidget *parent = nullptr) : QMainWindow(parent) {
        timer = new QTimer(this);
        timer->start(1000);
    }

    ~MainWindow() {
        //析构时定时器会自动停止和删除
    }

private:
    QTimer *timer;
};
```

### 总结

**QTimer使用要点：**
- 使用singleShot实现单次延迟执行
- 使用QMetaObject::invokeMethod异步调用解决界面卡顿
- 根据需求选择合适的定时器精度
- 定时器对象应该设置父对象，自动管理生命周期

**最佳实践：**
- 界面初始化时的耗时操作使用延迟加载
- 高精度场景使用PreciseTimer
- 一般定时任务使用CoarseTimer节省资源
- 定时器在对象销毁时会自动停止

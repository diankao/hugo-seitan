# Qt字符串操作与性能优化

## 题目

Qt中QString有哪些高效的字符串操作方法？如何优化字符串拼接和查找操作？

## 答案

### 字符串查找优化

```cpp
class StringSearchOptimizer : public QObject {
    Q_OBJECT

public:
    StringSearchOptimizer(QObject *parent = nullptr) : QObject(parent) {}

    int findChar(const QString &str, QChar ch) {
        return str.indexOf(ch);
    }

    int findString(const QString &str, const QString &subStr) {
        return str.indexOf(subStr);
    }

    bool containsChar(const QString &str, QChar ch) {
        return str.indexOf(ch) >= 0;
    }

    bool containsString(const QString &str, const QString &subStr) {
        return str.contains(subStr);
    }
};
```

### 字符串分割

```cpp
class StringSplitter : public QObject {
    Q_OBJECT

public:
    StringSplitter(QObject *parent = nullptr) : QObject(parent) {}

    QStringList splitByChar(const QString &str, QChar separator) {
        return str.split(separator);
    }

    QStringList splitByString(const QString &str, const QString &separator) {
        return str.split(separator);
    }

    QString sectionByChar(const QString &str, QChar separator, int start, int end = -1) {
        return str.section(separator, start, end);
    }

    QString sectionByString(const QString &str, const QString &separator, int start, int end = -1) {
        return str.section(separator, start, end);
    }

    QString extractIP(const QString &ip, int octet) {
        return ip.section('.', octet - 1, octet - 1);
    }

    QString modifyIPOctet(const QString &ip, int octet, const QString &value) {
        QStringList parts = ip.split('.');
        parts[octet - 1] = value;
        return parts.join('.');
    }
};
```

### 字符串截取

```cpp
class StringSlicer : public QObject {
    Q_OBJECT

public:
    StringSlicer(QObject *parent = nullptr) : QObject(parent) {}

    QString midToEnd(const QString &str, int position) {
        return str.mid(position);
    }

    QString leftN(const QString &str, int n) {
        return str.left(n);
    }

    QString rightN(const QString &str, int n) {
        return str.right(n);
    }

    QString between(const QString &str, const QString &start, const QString &end) {
        int startPos = str.indexOf(start);
        if (startPos < 0) return QString();

        startPos += start.length();
        int endPos = str.indexOf(end, startPos);
        if (endPos < 0) return QString();

        return str.mid(startPos, endPos - startPos);
    }
};
```

```cpp
    QString appendOptimized(const QString &str1, const QString &str2) {
```

### 大小写转换

```cpp
class StringCaseConverter : public QObject {
    Q_OBJECT

public:
    StringCaseConverter(QObject *parent = nullptr) : QObject(parent) {}

    QString toUpper(const QString &str) {
        return str.toUpper();
    }

    QString toLower(const QString &str) {
        return str.toLower();
    }

    QString toTitleCase(const QString &str) {
        QString result;
        bool newWord = true;

        for (int i = 0; i < str.length(); i++) {
            QChar ch = str[i];
            
            if (ch.isLetter()) {
                if (newWord) {
                    result += ch.toUpper();
                    newWord = false;
                } else {
                    result += ch.toLower();
                }
            } else {
                result += ch;
                newWord = true;
            }
        }

        return result;
    }
};
```

### 字符串去除空格

```cpp
class StringTrimmer : public QObject {
    Q_OBJECT

public:
    StringTrimmer(QObject *parent = nullptr) : QObject(parent) {}

    enum TrimType {
        TrimLeft = -1,
        TrimAll = 0,
        TrimRight = 1,
        TrimBoth = 2,
        TrimSimplify = 3
    };

    QString trim(const QString &text, TrimType type = TrimBoth) {
        QString temp = text;
        QString pattern;

        switch (type) {
            case TrimLeft:
                pattern = "^ +\\s*";
                break;
            case TrimAll:
                pattern = "\\s";
                temp.remove(QRegularExpression(pattern));
                return temp;
            case TrimRight:
                pattern = "\\s* +$";
                break;
            case TrimBoth:
                return temp.trimmed();
            case TrimSimplify:
                return temp.simplified();
        }

        temp.remove(QRegularExpression(pattern));
        return temp;
    }
};
```

### 总结

**查找优化：**
- 单字符查找使用indexOf(',')
- 多字符查找使用indexOf("xxx")
- 使用contains代替indexOf >= 0

**分割操作：**
- section适合固定位置提取
- split适合灵活处理
- section性能更高

**截取技巧：**
- mid(position)截取到末尾
- left/right快速获取两端
- 使用between提取中间内容

**拼接优化：**
- 预先reserve空间
- 使用join替代手动拼接
- 避免多次重新分配

**性能要点：**
- 优先使用字符参数而非字符串参数
- 避免不必要的中间变量
- 使用正则表达式处理复杂模式
- 注意字符串的隐式共享

**最佳实践：**
- 根据场景选择合适的方法
- 注意性能优化
- 使用正则表达式处理复杂匹配
- 合理使用QString的共享机制

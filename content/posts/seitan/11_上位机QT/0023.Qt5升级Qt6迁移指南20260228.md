# Qt5升级Qt6迁移指南

## 题目

从Qt5升级到Qt6有哪些主要的API变更？如何处理这些变更？升级过程中需要注意哪些问题？

## 答案

### 模块变化

Qt6对核心模块进行了拆分，增加了新的模块。

```cpp
//pro文件模块引入
greaterThan(QT_MAJOR_VERSION, 4): QT += widgets
greaterThan(QT_MAJOR_VERSION, 5): QT += core5compat

//代码中头文件引入
#if (QT_VERSION >= QT_VERSION_CHECK(5,0,0))
#include <QtWidgets>
#endif
#if (QT_VERSION >= QT_VERSION_CHECK(6,0,0))
#include <QtCore5Compat>
#endif
```

### 高分屏处理

```cpp
class HighDpiHandler : public QObject {
    Q_OBJECT

public:
    HighDpiHandler(QObject *parent = nullptr) : QObject(parent) {}

    void setupHighDpi() {
#if (QT_VERSION >= QT_VERSION_CHECK(6,0,0))
        QGuiApplication::setHighDpiScaleFactorRoundingPolicy(
            Qt::HighDpiScaleFactorRoundingPolicy::Floor
        );
#endif
    }

    qreal getDevicePixelRatio(QWidget *widget) {
#if (QT_VERSION >= QT_VERSION_CHECK(6,0,0))
        return widget->devicePixelRatio();
#else
        return widget->devicePixelRatioF();
#endif
    }
};
```

### 随机数生成

```cpp
class RandomGenerator : public QObject {
    Q_OBJECT

public:
    RandomGenerator(QObject *parent = nullptr) : QObject(parent) {}

    int getRandom(int max) {
#if (QT_VERSION >= QT_VERSION_CHECK(6,0,0))
        return QRandomGenerator::global()->bounded(max);
#else
        return qrand() % max;
#endif
    }

    void seedRandom() {
#if (QT_VERSION >= QT_VERSION_CHECK(6,0,0))
        QRandomGenerator::global()->seed(time(nullptr));
#else
        qsrand(time(nullptr));
#endif
    }
};
```

### 鼠标滚轮事件

```cpp
class WheelEventFilter : public QObject {
    Q_OBJECT

public:
    WheelEventFilter(QObject *parent = nullptr) : QObject(parent) {}

    bool eventFilter(QObject *watched, QEvent *event) override {
        if (event->type() == QEvent::Wheel) {
            QWheelEvent *wheelEvent = static_cast<QWheelEvent *>(event);
            
#if (QT_VERSION >= QT_VERSION_CHECK(6,0,0))
            QPoint delta = wheelEvent->angleDelta();
            int deltaValue = delta.y();
            QPoint pos = wheelEvent->position().toPoint();
#else
            int deltaValue = wheelEvent->delta();
            QPoint pos = wheelEvent->pos();
#endif
            
            qDebug() << "Wheel delta:" << deltaValue << "at" << pos;
        }
        
        return QObject::eventFilter(watched, event);
    }
};
```

### 总结

**模块变化：**
- 核心模块拆分：core5compat
- svg模块拆分：svgwidgets
- opengl模块拆分：openglwidgets

**API变更：**
- QColor：light/dark → lighter/darker
- QFontMetricsF：width → horizontalAdvance
- QWheelEvent：delta → angleDelta().y()
- 随机数：qrand → QRandomGenerator
- 排序：qSort → std::sort

**类型变化：**
- QMatrix → QTransform
- QTime → QElapsedTimer
- int → qreal（devicePixelRatio）

**枚举变更：**
- QPalette：Foreground → WindowText
- QPalette：Background → Window
- WA_NoBackground → WA_OpaquePaintEvent

**迁移建议：**
- 使用条件编译兼容版本
- 优先使用Qt5新增的API
- 查看源码中的废弃提示
- 测试各个平台的兼容性
- 关注Qt6的新特性

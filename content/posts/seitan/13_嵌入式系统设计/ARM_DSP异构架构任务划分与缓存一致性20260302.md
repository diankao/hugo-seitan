# ARM+DSP异构架构任务划分与缓存一致性

## 题目

ARM + DSP 异构架构下，视频任务如何划分？如何处理缓存一致性？

## 考察点

异构架构编程、缓存一致性

## 回答要点

### 1. 异构架构概述

**SoC 架构**：
```
┌─────────────────────────────┐
│  ARM（应用处理器）         │
│  - 控制逻辑              │
```

### 2. 任务划分原则

#### ARM 职责
**控制逻辑**：
- 系统启动和初始化

**用户交互**：
- UI 渲染
- 按键处理

**网络通信**：
- WiFi/BT 协议栈
- HTTP/WebSocket
- 数据包封装

**文件系统**：
- 文件读写
- 目录管理
- 缓存策略

#### DSP 职责
**图像处理**：
- ISP 算法
- 滤镜处理
- 格式转换

**视频编码**：
- H.264/H.265 编码
- 帧内/帧间预测
- 环路滤波

**复杂算法**：
- 防抖算法

- AI 推理

### 3. 任务间通信

#### 共享内存
```c
// 共享缓冲区
typedef struct {
    volatile int write_index;
    volatile int read_index;
    frame_t frames[BUFFER_COUNT];
} shared_buffer_t;

// ARM 写入
void arm_write_frame(frame_t* frame) {
    int index = buffer->write_index;
    memcpy(&buffer->frames[index], frame, sizeof(frame_t));

    // 同步写入
    __sync_synchronize();

    // 更新索引
    buffer->write_index = (index + 1) % BUFFER_COUNT;
}

// DSP 读取
frame_t* dsp_read_frame() {
    int index = buffer->read_index;

    // 同步读取
    __sync_synchronize();

    return &buffer->frames[index];
}
```

```c
// 消息定义
typedef struct {

void arm_send_command(int cmd, void* data, int size) {
    message_t msg = { .msg_id = cmd, .data = data, .size = size };
    mq_send(dsp_queue, &msg, sizeof(msg), 0);

// DSP 接收命令
void dsp_receive_command() {
    message_t msg;
    mq_receive(arm_queue, &msg, sizeof(msg), NULL);

    switch (msg.msg_id) {
        case CMD_START_ENCODE:
            start_encode(msg.data);
            break;
        case CMD_STOP_ENCODE:
            stop_encode();
            break;
    }
}
```

### 4. 缓存一致性处理

#### 缓存一致性问题
```
问题场景：
1. ARM 写入共享内存到 Cache
2. DSP 读取内存，但 Cache 未刷新
3. DSP 读到旧数据

或：
1. DSP 写入数据到 Cache
2. ARM 读取内存，但 Cache 无效
3. ARM 读到旧数据
```

#### 解决方案

**1. 内存屏障（Memory Barrier）**
```c
// ARM 侧：写后刷新 Cache
void arm_write_and_sync(void* addr, void* data, int size) {
    memcpy(addr, data, size);

    // 数据内存屏障
    __sync_synchronize();

    // 刷新 Cache
    __builtin___clear_cache(addr, addr + size);
}

// ARM 侧：读前无效 Cache
void arm_read_and_sync(void* addr, void* data, int size) {
    // 无效 Cache
    __builtin___clear_cache(addr, addr + size);

    // 数据内存屏障
    __sync_synchronize();

    memcpy(data, addr, size);
}
```

**2. 一致性协议**
```c
// SCU（Snoop Control Unit）
void enable_coherency() {
    // 启用 SCU
    SCU->CONTROL |= SCU_ENABLE;

    // 配置 Cache 策略
    configure_cache_policy();
}
```

**3. 非缓存内存**
```c
// 分配非缓存内存
void* allocate_uncached(int size) {
    // 使用 DMA 内存
    void* ptr = dma_alloc_coherent(size);

    return ptr;
}

// 共享内存使用非缓存
shared_buffer_t* buffer = allocate_uncached(sizeof(shared_buffer_t));
```

#### DSP 侧处理
```c
// DSP 写入后同步
void dsp_write_and_sync(void* addr, void* data, int size) {
    memcpy(addr, data, size);

    // 刷新 DSP Cache
    CACHE_wb(addr, size);  // Write Back
    CACHE_inv(addr, size);  // Invalidate
}

// DSP 读取前同步
void dsp_read_and_sync(void* addr, void* data, int size) {
    // 无效 DSP Cache
    CACHE_inv(addr, size);

    memcpy(data, addr, size);
}
```

### 5. 性能优化

#### 减少缓存失效
```
策略：
1. 明确划分访问边界
2. 避免跨核访问同一行
3. 使用缓存行对齐
4. 批量处理减少访问次数
```

### 6. 调试技巧

#### 缓存一致性调试
```c
// 添加调试标记
typedef struct {
    uint32_t magic;
    uint32_t sequence;
    uint32_t checksum;
    data_t data;
} debug_data_t;

// 写入时标记
void write_with_debug(void* addr, data_t* data) {
    debug_data_t* dbg = (debug_data_t*)addr;
    dbg->magic = 0xDEADBEEF;
    dbg->sequence = ++sequence;
    dbg->checksum = calc_checksum(data);
    dbg->data = *data;

    __sync_synchronize();
}

// 读取时验证
bool read_with_debug(void* addr, data_t* data) {
    __sync_synchronize();

    debug_data_t* dbg = (debug_data_t*)addr;

    if (dbg->magic != 0xDEADBEEF) {
        // 缓存一致性问题！
        log_error("Cache coherency issue detected");
        return false;
    }

    if (calc_checksum(&dbg->data) != dbg->checksum) {
        log_error("Checksum mismatch");
        return false;
    }

    *data = dbg->data;
    return true;
}
```

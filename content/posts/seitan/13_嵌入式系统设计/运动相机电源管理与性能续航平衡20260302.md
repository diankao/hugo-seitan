# 运动相机电源管理与性能续航平衡

## 题目

运动相机的电源管理如何设计？如何平衡性能与续航？

## 考察点

电源管理设计、功耗优化

## 回答要点

### 1. 电源管理架构

#### 电源域划分
```
核心域：
- SoC（包含 ARM、DSP、GPU）
- ISP（图像信号处理器）
- 传感器（Sensor）

外设域：
- WiFi/BT 模块
- 存储模块（SD Card、UFS）
- 显示屏/OLED
- LED 指示灯
- 麦克风

模拟域：
- 电源管理芯片（PMIC）
- 充电电路
- 电池管理
```

#### 独立供电控制
- 每个电源域独立开关
- 按需供电
- 休眠时关闭不必要的域

### 2. DVFS（动态电压频率调节）

#### 原理
- 根据负载动态调整频率和电压
- 功耗 ≈ CV²f（C 是电容，V 是电压，f 是频率）
- 降低频率和电压可大幅降低功耗

#### 实现
```c
// 设置 DVFS 策略
void set_dvfs_policy(policy_t policy) {
    switch (policy) {
        case POLICY_PERFORMANCE:
            set_freq(MAX_FREQ);
            set_voltage(MAX_VOLTAGE);
            break;
        case POLICY_BALANCED:
            set_freq(NORMAL_FREQ);
            set_voltage(NORMAL_VOLTAGE);
            break;
        case POLICY_POWERSAVE:
            set_freq(MIN_FREQ);
            set_voltage(MIN_VOLTAGE);
            break;
    }
}

// 根据负载动态调整
void adjust_dvfs(int cpu_usage) {
    if (cpu_usage > 80%) {
        set_dvfs_policy(POLICY_PERFORMANCE);
    } else if (cpu_usage > 40%) {
        set_dvfs_policy(POLICY_BALANCED);
    } else {
        set_dvfs_policy(POLICY_POWERSAVE);
    }
}
```

#### 频率等级
- 性能模式：最高频率
- 平衡模式：中等频率
- 省电模式：最低频率
- 智能模式：根据场景自动调整

### 3. 功耗模式设计

#### 性能模式
**特点**：
- 最高频率和电压
- 4K 60fps 编码
- 所有功能开启

**使用场景**：
- 需要最高画质
- 充电使用
- 户外固定拍摄

#### 省电模式
**特点**：
- 降低频率
- 降低帧率（如 1080p 30fps）
- 降低编码质量
- 关闭不必要的功能

**使用场景**：
- 电池电量低
- 长时间录制
- 移动拍摄

#### 智能模式
**特点**：
- 根据场景自动切换
- 电池电量监测
- 用户习惯学习

**切换条件**：
- 电池 < 20%：强制省电
- 电池 20-50%：智能平衡
- 电池 > 50%：性能优先

### 4. 低功耗模式

#### 休眠模式
- 屏幕关闭
- 降低主频
- 关闭 WiFi
- 传感器保持待机

#### 深度休眠
- 仅保留关键功能
- 定期唤醒检测
- 快速唤醒能力

```c
// 进入休眠
void enter_sleep_mode() {
    // 保存上下文
    save_context();

    // 关闭外设
    disable_wifi();
    disable_display();

    // 降低频率
    set_freq(IDLE_FREQ);

    // 进入低功耗状态
    __WFI();  // Wait For Interrupt
}

// 唤醒
void wakeup_from_sleep() {
    // 恢复频率
    set_freq(WAKEUP_FREQ);

    // 开启外设
    enable_wifi();
    enable_display();

    // 恢复上下文
    restore_context();
}
```

### 5. 热管理策略

#### 温度监控
- 多个温度传感器
- SoC 温度
- 电池温度
- 环境温度

#### 分级处理
```
一级（50-55°C）：
- 降低频率
- 提示用户

二级（55-60°C）：
- 进一步降低频率
- 降低帧率
- 降低编码质量

三级（60-65°C）：
- 停止录制
- 强制散热
- 警告用户

四级（>65°C）：
- 自动关机保护
- 防止损坏
```

### 6. 续航优化技巧

#### 硬件优化
- 选择低功耗芯片
- 优化电源电路效率
- 使用高效 DC-DC

#### 软件优化
- 减少 CPU 空转
- 优化算法复杂度
- 批量处理减少唤醒

#### 用户体验
- 预计剩余时间显示
- 智能模式推荐
- 电量不足提前提示

### 7. 充电管理

#### 快充支持
- USB PD（Power Delivery）
- QC（Quick Charge）
- 自定义快充协议

#### 充电安全
- 温度监控
- 过充保护
- 充电截止

### 8. 性能与续航平衡

#### 策略

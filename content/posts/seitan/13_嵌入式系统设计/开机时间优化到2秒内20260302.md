# 开机时间优化到2秒内

## 题目

如何优化开机时间到 2 秒以内？关键路径如何分析？

## 考察点

启动优化、性能分析

## 回答要点

### 1. 开机时间分解

#### 完整启动链路
```
上电 → Bootloader → 内核启动 → 文件系统 → 应用启动 → UI 显示

各阶段时间分配（目标）：
- Bootloader：100ms
- 内核启动：500ms
- 文件系统挂载：200ms
- 应用启动：800ms
- UI 显示：400ms
─────────────────────
总计：2 秒
```

### 2. 关键路径分析

#### 时间统计
```c
// 时间戳统计
typedef struct {
    uint64_t bootloader_start;
    uint64_t bootloader_end;
    uint64_t kernel_start;
    uint64_t kernel_end;
    uint64_t fs_mount_start;
    uint64_t fs_mount_end;
    uint64_t app_start;
    uint64_t ui_ready;
} boot_timeline_t;

// 记录时间点
void record_timestamp(boot_timeline_t* tl, const char* name) {
    uint64_t now = get_time_us();
    printf("[%s] Time: %lu us\n", name, now);
}

// 计算各阶段耗时
void analyze_boot_time(boot_timeline_t* tl) {
    uint64_t bootloader_time = tl->bootloader_end - tl->bootloader_start;
    uint64_t kernel_time = tl->kernel_end - tl->kernel_start;
    uint64_t fs_time = tl->fs_mount_end - tl->fs_mount_start;
    uint64_t app_time = tl->ui_ready - tl->app_start;

    printf("Bootloader: %lu us\n", bootloader_time);
    printf("Kernel: %lu us\n", kernel_time);
    printf("FS Mount: %lu us\n", fs_time);
    printf("App Start: %lu us\n", app_time);
    printf("Total: %lu us\n", tl->ui_ready - tl->bootloader_start);
}
```

### 6. 应用启动优化

#### 并行初始化

```c
// 多线程初始化
void* init_network(void* arg) {

void* init_camera(void* arg) {
    init_sensor();
    init_isp();
    return NULL;

void* init_storage(void* arg) {
    mount_data_partition();
    scan_files();
    return NULL;
}

// 主线程并行启动
void parallel_init() {
    pthread_t threads[3];

    pthread_create(&threads[0], NULL, init_network, NULL);
    pthread_create(&threads[1], NULL, init_camera, NULL);
    pthread_create(&threads[2], NULL, init_storage, NULL);

    // 等待初始化完成
    for (int i = 0; i < 3; i++) {
        pthread_join(threads[i], NULL);
    }
}
```

#### 内存优化
```c
// 预分配内存池
typedef struct {
    void* pool[POOL_SIZE];
    int used[POOL_SIZE];
} mempool_t;

mempool_t* create_mempool(int block_size, int count) {
    mempool_t* mp = malloc(sizeof(mempool_t));

    for (int i = 0; i < count; i++) {
        mp->pool[i] = malloc(block_size);
        mp->used[i] = 0;
    }

    return mp;
}

// 快速分配
void* fast_alloc(mempool_t* mp) {
    for (int i = 0; i < POOL_SIZE; i++) {
        if (!mp->used[i]) {
            mp->used[i] = 1;
            return mp->pool[i];
        }
    }
    return NULL;  // 池满
}
```

# 旋转数组查找

## 题目

平移之后的升序序列。nums = [4, 5, 6, 7, 0, 1, 2]，target = 0，输出4，输出查找到的target的下标，若找不到，返回-1。

## 答案

### 题目描述

在一个旋转有序数组中查找目标值，返回其下标，如果不存在返回-1。

### 解法1：二分查找

```cpp
#include <vector>
#include <iostream>

class Solution {
public:
    int search(std::vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (nums[mid] == target) {
                return mid;
            }
            
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }
        
        return -1;
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {4, 5, 6, 7, 0, 1, 2};
    int target = 0;
    
    int result = solution.search(nums, target);
    std::cout << "Array: [";
    for (int i = 0; i < nums.size(); i++) {
        std::cout << nums[i];
        if (i < nums.size() - 1) std::cout << ", ";
    }
    std::cout << "]" << std::endl;
    
    std::cout << "Target: " << target << std::endl;
    std::cout << "Result: " << result << std::endl;
    
    return 0;
}
```

**时间复杂度：** O(log n)
**空间复杂度：** O(1)

### 解法3：先找旋转点

```cpp
#include <vector>
#include <iostream>

class Solution {
public:
    int findPivot(std::vector<int>& nums) {
        int left = 0;
        int right = nums.size() - 1;
        
        while (left < right) {
            int mid = left + (right - left) / 2;
            
            if (nums[mid] > nums[right]) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        
        return left;
    }
    
    int binarySearch(std::vector<int>& nums, int target, int left, int right) {
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        return -1;
    }
    
    int search(std::vector<int>& nums, int target) {
        if (nums.empty()) return -1;
        
        int pivot = findPivot(nums);
        
        std::cout << "Pivot index: " << pivot << std::endl;
        std::cout << "Pivot value: " << nums[pivot] << std::endl;
        
        if (nums[pivot] == target) {
            return pivot;
        }
        
        int n = nums.size();
        
        if (pivot == 0) {
            return binarySearch(nums, target, 0, n - 1);
        }
        
        if (target >= nums[0] && target < nums[pivot]) {
            return binarySearch(nums, target, 0, pivot - 1);
        } else {
            return binarySearch(nums, target, pivot, n - 1);
        }
    }
};

int main() {
    Solution solution;
    std::vector<int> nums = {4, 5, 6, 7, 0, 1, 2};
    int target = 0;
    
    std::cout << "Array: [";
    for (int i = 0; i < nums.size(); i++) {
        std::cout << nums[i];
        if (i < nums.size() - 1) std::cout << ", ";
    }
    std::cout << "]" << std::endl;
    std::cout << "Target: " << target << std::endl << std::endl;
    
    int result = solution.search(nums, target);
    std::cout << "Result: " << result << std::endl;
    
    return 0;
}
```

```cpp
class Solution {
```

```cpp
        return -1;
    }
    
    int rotatedBinarySearch(std::vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (nums[mid] == target) {
                return mid;
            }
            
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;

                }

                } else {
                    right = mid - 1;
                }
            }

        return -1;

        std::vector<int> nums;
        for (int i = 0; i < 100000; i++) {
```

### 总结

**解题思路：**
1. 旋转数组特点：两段有序数组
2. 二分查找：根据mid和边界关系确定搜索方向
3. 时间复杂度：O(log n)

**关键点：**
- 判断哪一半是有序的
- 根据target和有序部分关系确定搜索方向
- 处理边界条件：空数组、单元素、完全有序

**算法复杂度：**
- 时间复杂度：O(log n)
- 空间复杂度：O(1)

**边界情况：**
- 空数组：返回-1
- 单元素：直接比较
- 完全有序：退化为普通二分查找
- 目标不存在：返回-1

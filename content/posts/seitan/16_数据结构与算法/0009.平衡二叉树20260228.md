# 判断平衡二叉树

## 题目

判断一棵树是否是平衡二叉树。

## 答案

### 题目描述

平衡二叉树是指任意节点的左右子树高度差不超过1的二叉树。

### 解法1：自顶向下（暴力法）

```cpp
#include <iostream>
#include <algorithm>
#include <cmath>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    int height(TreeNode* root) {
        if (root == nullptr) {
            return 0;
        }
        return 1 + std::max(height(root->left), height(root->right));
    }
    
    bool isBalanced(TreeNode* root) {
        if (root == nullptr) {
            return true;
        }
        
        int leftHeight = height(root->left);
        int rightHeight = height(root->right);
        
        if (std::abs(leftHeight - rightHeight) > 1) {
            return false;
        }
        
        return isBalanced(root->left) && isBalanced(root->right);
    }
};

TreeNode* createTree() {
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);
    
    return root;
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    Solution solution;
    
    TreeNode* tree = createTree();
    bool result = solution.isBalanced(tree);
    std::cout << "Is balanced: " << (result ? "Yes" : "No") << std::endl;
    
    deleteTree(tree);
    
    return 0;
}
```

**时间复杂度：** O(n²)
**空间复杂度：** O(n)

### 解法2：自底向上（优化法）

### 解法3：使用pair返回

```cpp
#include <iostream>
#include <algorithm>
#include <cmath>
#include <utility>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    std::pair<bool, int> checkBalanced(TreeNode* root) {
        if (root == nullptr) {
            return {true, 0};
        }
        
        auto [leftBalanced, leftHeight] = checkBalanced(root->left);
        if (!leftBalanced) {
            return {false, 0};
        }
        
        auto [rightBalanced, rightHeight] = checkBalanced(root->right);
        if (!rightBalanced) {
            return {false, 0};
        }
        
        if (std::abs(leftHeight - rightHeight) > 1) {
            return {false, 0};
        }
        
        return {true, 1 + std::max(leftHeight, rightHeight)};
    }
    
    bool isBalanced(TreeNode* root) {
        return checkBalanced(root).first;
    }
};

TreeNode* createTree() {
    TreeNode* root = new TreeNode(1);
    root->left = new TreeNode(2);
    root->right = new TreeNode(3);
    root->left->left = new TreeNode(4);
    root->left->right = new TreeNode(5);
    
    return root;
}

void deleteTree(TreeNode* root) {
    if (root == nullptr) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    Solution solution;
    
    TreeNode* tree = createTree();
    bool result = solution.isBalanced(tree);
```

```cpp
class Solution {
public:
    int checkHeight(TreeNode* root, bool& balanced) {
        if (root == nullptr) {
            std::cout << "  Node: nullptr, Height: 0" << std::endl;
            return 0;
        }
        
        std::cout << "Checking node: " << root->val << std::endl;
        
        int leftHeight = checkHeight(root->left, balanced);
        if (!balanced) {
            std::cout << "  Left subtree not balanced" << std::endl;
            return -1;
        }
        
        int rightHeight = checkHeight(root->right, balanced);
        if (!balanced) {
            std::cout << "  Right subtree not balanced" << std::endl;
            return -1;
        }
        
        int heightDiff = std::abs(leftHeight - rightHeight);
        std::cout << "  Left height: " << leftHeight 
                  << ", Right height: " << rightHeight 
                  << ", Diff: " << heightDiff << std::endl;
        
        if (heightDiff > 1) {
            balanced = false;
            std::cout << "  Node " << root->val << " not balanced!" << std::endl;
            return -1;
        }
        
        int height = 1 + std::max(leftHeight, rightHeight);
        std::cout << "  Node " << root->val << " balanced, Height: " << height << std::endl;
        return height;
    }
    
    bool isBalanced(TreeNode* root) {
        bool balanced = true;
        std::cout << "=== Checking if tree is balanced ===" << std::endl;
```

### 总结

**解题思路：**
1. 自顶向下：递归检查每个节点的左右子树高度差
2. 自底向上：递归返回高度，同时检查平衡性，剪枝优化

**关键点：**
- 平衡二叉树定义：任意节点左右子树高度差不超过1
- 优化思路：自底向上，发现不平衡立即返回
- 时间复杂度：O(n) vs O(n²)

**自顶向下问题：**
- 重复计算子树高度
- 时间复杂度O(n²)

**自底向上优势：**
- 每个节点只计算一次高度
- 时间复杂度O(n)
- 提前剪枝，提高效率

# C++容器vector与list对比

## 标签
#嵌入式 #面试题 #C++ #STL #容器

## 问题描述
1. C++容器中vector和list的差异？
2. vector的底层实现原理？扩容机制？如何避免反复扩容？
3. vector是存储在堆上还是栈上？好像是元数据在栈上，实际元素在堆上。

## 参考答案
### 1. vector vs list 对比

| 特性 | vector | list |
|------|---------|------|
| **底层结构** | 连续内存数组 | 双向链表 |
| **随机访问** | O(1) | O(n) |
| **插入/删除（头部）** | O(n) | O(1) |
| **插入/删除（尾部）** | 均摊O(1) | O(1) |
| **插入/删除（中间）** | O(n) | O(1)（已知位置） |
| **内存连续性** | 连续 | 不连续 |
| **缓存友好性** | 高（局部性好） | 低 |
| **迭代器失效** | 插入删除后可能失效 | 仅指向被删元素失效 |
| **内存开销** | 小（仅容量和大小） | 大（每个节点前后指针） |
| **适用场景** | 随机访问、尾插 | 频繁插入删除 |

### 2. vector底层实现原理

#### 2.1 内存布局

```cpp
template <typename T>
class vector {
private:
    T* start;        // 指向数据起始位置
    T* finish;       // 指向最后一个元素的下一个位置
    T* end_of_storage; // 指向分配内存的末尾

public:
    size_t size() const { return finish - start; }
    size_t capacity() const { return end_of_storage - start; }
};
```

**内存布局：**
```
栈（函数调用帧）：
┌─────────────────────────┐
│ vector对象 (24字节)    │
│ - start (8字节指针)    │ ────┐
│ - finish (8字节指针)   │      │
│ - end_of_storage (8字节)│      │
└─────────────────────────┘      │
                             │ 堆内存：
                             │ ┌─────────────────────────┐
                             │ │ 实际元素数据         │
                             │ │ [0][1][2][3]...[n]  │
                             │ │                     │
                             │ └─────────────────────────┘
                             │   capacity = end_of_storage - start
                             │   size = finish - start
```

**结论：**
- vector对象本身在栈上（元数据）
- 元素数据在堆上（动态分配）

#### 2.2 扩容机制

**扩容策略：**
1. 当`size() == capacity()`时触发扩容
2. 重新分配更大的内存（通常是当前容量的1.5倍或2倍）
3. 将旧数据拷贝到新内存
4. 释放旧内存
5. 更新指针指向新内存

**扩容示例：**
```cpp
#include <vector>
#include <iostream>

int main() {
    std::vector<int> v;
    
    for (int i = 0; i < 10; i++) {
        v.push_back(i);
        std::cout << "size: " << v.size() 
                  << ", capacity: " << v.capacity() << std::endl;
    }
    
    return 0;
}

// 输出（GCC实现）：
// size: 1, capacity: 1
// size: 2, capacity: 2
// size: 3, capacity: 4    // 扩容1.5倍
// size: 4, capacity: 4
// size: 5, capacity: 6    // 扩容1.5倍
// size: 6, capacity: 6
// size: 7, capacity: 9    // 扩容1.5倍
// size: 8, capacity: 9
// size: 9, capacity: 9
// size: 10, capacity: 13   // 扩容1.5倍
```

**不同实现的扩容倍数：**
- GCC libstdc++：1.5倍
- MSVC STL：1.5倍
- Clang libc++：2倍

#### 2.3 扩容性能分析

**时间复杂度：**
- 单次push_back：
  - 不扩容时：O(1)
  - 扩容时：O(n)（拷贝数据）
- 均摊复杂度：O(1)

**扩容开销示例：**
```cpp
std::vector<int> v;
for (int i = 0; i < 1000000; i++) {
    v.push_back(i);  // 大约发生log2(n)次扩容
}

// 扩容次数：约20次（1000000的log2）
// 总拷贝次数：约1000000 + 500000 + 250000 + ... = 2000000次
// 均摊每次push_back：2次拷贝操作
```

### 3. 如何避免反复扩容

#### 3.1 预留容量（推荐）

**使用reserve()：**
```cpp
std::vector<int> v;
v.reserve(1000);  // 预先分配1000个元素的空间

for (int i = 0; i < 1000; i++) {
    v.push_back(i);  // 不会扩容，O(1)
}
```

**性能对比：**
```cpp
// 不使用reserve
void test_without_reserve() {
    std::vector<int> v;
    auto start = std::chrono::high_resolution_clock::now();
    
    for (int i = 0; i < 1000000; i++) {
        v.push_back(i);
    }
    
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);
    std::cout << "Without reserve: " << duration.count() << "ms" << std::endl;
}

// 使用reserve
void test_with_reserve() {
    std::vector<int> v;
    v.reserve(1000000);  // 预分配
    
    auto start = std::chrono::high_resolution_clock::now();
    
    for (int i = 0; i < 1000000; i++) {
        v.push_back(i);
    }
    
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);
    std::cout << "With reserve: " << duration.count() << "ms" << std::endl;
}

// 结果（示例）：
// Without reserve: 15ms
// With reserve: 5ms  （快3倍）
```

#### 3.2 使用resize()

**区别：**
- `reserve(n)`：只分配容量，不改变size
- `resize(n)`：改变size，可能扩容，新增元素用默认值

```cpp
std::vector<int> v;

v.reserve(100);  // capacity=100, size=0
std::cout << v.size() << ", " << v.capacity() << std::endl;
// 输出：0, 100

v.resize(50);  // capacity=100, size=50（如果50 <= 100）
std::cout << v.size() << ", " << v.capacity() << std::endl;
// 输出：50, 100

v.resize(150);  // capacity=200, size=150（扩容）
std::cout << v.size() << ", " << v.capacity() << std::endl;
// 输出：150, 200
```

#### 3.3 使用emplace_back()代替push_back()

**区别：**
- `push_back()`：构造临时对象，再拷贝/移动
- `emplace_back()`：直接在容器中构造对象

**性能对比：**
```cpp
class Data {
public:
    Data(int a, int b) : x(a), y(b) {
        std::cout << "Data constructed" << std::endl;
    }
    
    Data(const Data& other) : x(other.x), y(other.y) {
        std::cout << "Data copied" << std::endl;
    }
    
    Data(Data&& other) : x(other.x), y(other.y) {
        std::cout << "Data moved" << std::endl;
    }
    
private:
    int x, y;
};

std::vector<Data> v;

// push_back：构造+拷贝/移动
v.push_back(Data(1, 2));
// 输出：
// Data constructed (临时对象)
// Data moved (移动到容器)

// emplace_back：直接构造
v.emplace_back(1, 2);
// 输出：
// Data constructed (直接在容器中构造)
```

### 4. list底层实现原理

#### 4.1 双向链表结构

```cpp
template <typename T>
class list {
private:
    struct Node {
        T data;
        Node* prev;
        Node* next;
    };
    
    Node* head;
    Node* tail;
    size_t size_;
    
public:
    void push_back(const T& value) {
        Node* new_node = new Node{value, tail, nullptr};
        if (tail) {
            tail->next = new_node;
        } else {
            head = new_node;
        }
        tail = new_node;
        size_++;
    }
};
```

**内存布局：**
```
堆内存：
┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐
│ node1 │ ──>│ node2 │ ──>│ node3 │ ──>│ node4 │
│ prev │ <── │ prev │ <── │ prev │ <── │ prev │
└──────┘    └──────┘    └──────┘    └──────┘
   │          │            │            │
   v          v            v            v
[1]        [2]          [3]          [4]

栈（list对象）：
┌───────────────────────┐
│ list对象 (24字节)    │
│ - head (8字节)      │ ────> 堆内存
│ - tail (8字节)      │
│ - size (8字节)      │
└───────────────────────┘
```

### 5. 使用场景选择

#### 5.1 使用vector的场景

```cpp
// 场景1：需要随机访问
std::vector<int> scores = {90, 85, 95, 88, 92};
int max_score = scores[0];
for (int i = 1; i < scores.size(); i++) {
    if (scores[i] > max_score) {
        max_score = scores[i];
    }
}

// 场景2：主要在尾部插入删除
std::vector<Data> data_stream;
while (receiving_data) {
    data_stream.push_back(receive());  // 尾部插入O(1)
}

// 场景3：需要缓存友好
std::vector<float> signal_data;
process_signal(signal_data.data(), signal_data.size());
```

#### 5.2 使用list的场景

```cpp
// 场景1：频繁在中间插入删除
std::list<Task> task_queue;

auto it = task_queue.begin();
std::advance(it, 5);  // 移动到第5个位置
task_queue.insert(it, high_priority_task);  // O(1)插入

// 场景3：大对象，避免拷贝

```

### 6. 嵌入式开发建议

在嵌入式开发中，STL容器的使用需注意：

**注意事项：**
1. **避免动态分配**：实时系统中慎用STL
2. **使用固定容量容器**：`std::array`替代`vector`
3. **自定义内存池**：控制内存分配
4. **禁用异常**：嵌入式系统可能不支持异常

**替代方案：**
```cpp
// 使用静态数组
constexpr int MAX_SIZE = 100;
int data[MAX_SIZE];
int size = 0;

// 使用自定义环形缓冲区
template <typename T, int N>
class RingBuffer {
    T buffer[N];
    int head = 0, tail = 0;
public:
    bool push(const T& value) {
        if ((tail + 1) % N == head) return false;
        buffer[tail] = value;
        tail = (tail + 1) % N;
        return true;
    }
    bool pop(T& value) {
        if (head == tail) return false;
        value = buffer[head];
        head = (head + 1) % N;
        return true;
    }
};
```

## 参考答案
### 1. SPI协议基础

**SPI（Serial Peripheral Interface）**是一种同步串行通信协议，由Motorola公司开发。

**SPI信号线（4根）：**

1. **SCLK（Serial Clock）**：
   - 时钟信号，由主机输出
   - 决定数据传输速率
   - 支持多种时钟极性和相位（CPOL、CPHA）

2. **MOSI（Master Out Slave In）**：
   - 主机输出，从机输入数据线
   - 主机通过此线发送数据到从机

3. **MISO（Master In Slave Out）**：
   - 主机输入，从机输出数据线
   - 从机通过此线发送数据到主机

4. **CS/SS（Chip Select/Slave Select）**：
   - 片选信号，由主机控制
   - 低电平有效，用于选择特定的从机设备
   - 每个从机需要独立的CS线

**SPI工作模式（4种）：**
```
CPOL=0, CPHA=0: 时钟空闲为低电平，第一个边沿采样
CPOL=0, CPHA=1: 时钟空闲为低电平，第二个边沿采样
CPOL=1, CPHA=0: 时钟空闲为高电平，第一个边沿采样
CPOL=1, CPHA=1: 时钟空闲为高电平，第二个边沿采样
```

**SPI数据传输过程：**
```c
uint8_t spi_transfer(uint8_t data) {
    // 发送数据
    SPI->DR = data;
    
    // 等待传输完成
    while (!(SPI->SR & SPI_SR_TXE));
    while (!(SPI->SR & SPI_SR_RXNE));
    
    // 接收数据
    return SPI->DR;
}

// 配置SPI
void spi_init() {
    // 使能时钟
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_SPI1, ENABLE);
    
    // 配置GPIO
    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_5 | GPIO_Pin_6 | GPIO_Pin_7;
    GPIO_Init(GPIOA, &GPIO_InitStructure);
    
    // 配置SPI
    SPI_InitTypeDef SPI_InitStructure;
    SPI_InitStructure.SPI_Direction = SPI_Direction_2Lines_FullDuplex;
    SPI_InitStructure.SPI_Mode = SPI_Mode_Master;
    SPI_InitStructure.SPI_DataSize = SPI_DataSize_8b;
    SPI_InitStructure.SPI_CPOL = SPI_CPOL_Low;
    SPI_InitStructure.SPI_CPHA = SPI_CPHA_1Edge;
    SPI_InitStructure.SPI_NSS = SPI_NSS_Soft;
    SPI_InitStructure.SPI_BaudRatePrescaler = SPI_BaudRatePrescaler_4;
    SPI_InitStructure.SPI_FirstBit = SPI_FirstBit_MSB;
    SPI_Init(SPI1, &SPI_InitStructure);
    
    SPI_Cmd(SPI1, ENABLE);
}
```

### 2. 菊花链通信

**菊花链定义：**
菊花链（Daisy Chain）是一种设备连接方式，设备首尾相连形成环形或链形拓扑。

**菊花链与SPI的关系：**
- **可以用SPI实现**：菊花链是拓扑结构，SPI是通信协议
- **串行级联**：多个设备通过SPI串联，数据逐级传递
- **减少控制线**：所有设备共用CS线，减少GPIO占用

**20片DAC菊花链SPI实现：**

```
主机 → [DAC1] → [DAC2] → ... → [DAC20]
       MISO    MISO         MISO
       ↓       ↓            ↓
       MOSI    MOSI         MOSI
       ↓       ↓            ↓
```

**菊花链拓扑结构：**
```
主机
  │
  ├─ CS (共用)
  │
  ├─ MOSI ──→ DAC1 ──→ DAC2 ──→ ... ──→ DAC20
  │               ↓           ↓              ↓
  ├─ MISO ←───── MISO ←───── MISO ←───── MISO
  │
  └─ SCLK ──→ 所有DAC共用时钟
```

**菊花链实现代码：**
```c
#define DAC_COUNT 20

// 配置DAC菊花链
void dac_daisy_chain_init() {
    // 所有DAC共用一个CS
    CS_LOW();
    
    // 传输配置数据
    for (int i = 0; i < DAC_COUNT; i++) {
        spi_transfer(DAC_CONFIG_CMD);
        spi_transfer(DAC_CONFIG_DATA);
    }
    
    CS_HIGH();
}

// 设置DAC输出值
void dac_daisy_chain_set(uint8_t dac_values[]) {
    CS_LOW();
    
    // 传输所有DAC的值
    for (int i = 0; i < DAC_COUNT; i++) {
        spi_transfer(DAC_WRITE_CMD | i);  // 写命令 + DAC地址
        spi_transfer(dac_values[i]);      // DAC值
    }
    
    CS_HIGH();
}

// 读取所有DAC值
void dac_daisy_chain_read(uint8_t dac_values[]) {
    CS_LOW();
    
    // 发送读命令
    for (int i = 0; i < DAC_COUNT; i++) {
        spi_transfer(DAC_READ_CMD | i);
        spi_transfer(0x00);  // 哑数据
    }
    
    CS_HIGH();
    
    // 接收数据（需要第二次传输）
    CS_LOW();
    for (int i = 0; i < DAC_COUNT; i++) {
        dac_values[i] = spi_transfer(0x00);
    }
    CS_HIGH();
}
```

### 3. 菊花链特点

**优点：**
1. **节省IO资源**：所有设备共用CS线，大幅减少GPIO占用
2. **布线简单**：串行连接，减少PCB走线复杂度
3. **扩展性强**：容易增加或减少设备数量
4. **成本较低**：减少芯片引脚和PCB层数

**缺点：**
1. **延迟累积**：数据需要逐级传递，延迟随设备数量增加
2. **访问复杂**：不能直接访问特定设备，需要级联传输
3. **故障影响**：单个设备故障可能影响整个链路
4. **速度限制**：传输速度受设备数量限制

**应用场景：**
- 多路DAC/ADC阵列
- LED灯带控制（如WS2812）
- 移位寄存器级联
- 多片传感器采集

### 4. SPI与菊花链的选择

**独立SPI模式：**
- 适用：设备数量少（<5个）、需要独立控制、高速访问
- 优点：响应快、独立控制、故障隔离
- 缺点：GPIO占用多、布线复杂

**菊花链SPI模式：**
- 适用：设备数量多（>10个）、同时访问、IO资源有限
- 优点：节省IO、布线简单、成本低
- 缺点：延迟大、访问复杂、故障传播

**混合模式：**
```c
// 将20个DAC分为4组，每组5个菊花链
#define DAC_GROUPS 4
#define DAC_PER_GROUP 5

void dac_mixed_mode_set(uint8_t dac_values[]) {
    for (int group = 0; group < DAC_GROUPS; group++) {
        CS_SELECT(group);  // 选择组
        
        for (int i = 0; i < DAC_PER_GROUP; i++) {
            int index = group * DAC_PER_GROUP + i;
            spi_transfer(DAC_WRITE_CMD | i);
            spi_transfer(dac_values[index]);
        }
        
        CS_DESELECT(group);
    }
}
```

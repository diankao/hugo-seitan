# RS485 总线设计与差分信号

RS-485（TIA/EIA-485）是工业与嵌入式领域最常见的多点串行总线：差分传输带来强抗干扰与远距离能力，组网简单、成本低。本文整理其电气标准、与 RS-232 的辨析、组网设计要点、收发器选型与典型故障排查。

## 差分传输原理

RS-485 用 **A/B 两根线的电压差**表示逻辑：接收器只看差值（阈值 ±200mV），共模噪声同时耦合到两线上被相减抵消，因此抗干扰强、传输距离远。

```
发送端                          接收端
   A ────╳────────────╳──── A
   B ────╳────────────╳──── B    双绞线 + 两端 120Ω 终端电阻
  (驱动器输出差分 ±2~3V)    (接收器看 V_A − V_B，阈值 ±200mV)
```

## 电气参数

| 参数 | RS-485 实际标准 | 常见混淆 |
| --- | --- | --- |
| 差分输出幅值 | **≥ ±1.5V**（54Ω 负载上），典型 2~3V | ❌ "±5V 标准"——那是 RS-232 单端电平（±3~15V）的量级 |
| 接收灵敏度 | 差分 ±200mV | |
| 共模范围 | -7V ~ +12V | |
| 拓扑 | 多点总线（差分） | RS-232 只能点对点 |

一个常见误区是把 RS-485 的差分幅值记成 ±5V——这个量级属于 RS-232 的单端电平体系，RS-485 从未如此规定。

## 波特率与距离

信号经长线衰减与色散，速率与距离必须互相妥协（经验曲线，非硬性标准）：

| 波特率 | 可靠距离（约） | 说明 |
| --- | --- | --- |
| 10 Mbps | 15 m | 高速短线，必须端接 |
| 1 Mbps | 100 m | |
| 115.2 kbps | 800 m | |
| 9.6 kbps | 1200 m | 经典低速远传 |

降低速率可换距离：位时间拉长后，边沿色散占位时间的比例下降，采样窗口更可靠。

## 组网设计要点

- **拓扑**：手拉手菊花链总线，**禁止星形/树形分支**——分支的 Stub 会产生多点反射；节点短支线越短越好（<0.3m 量级）；
- **终端电阻**：总线**两端**各并 **120Ω**（匹配双绞线特性阻抗，通常 100~130Ω），吸收反射；短距离低速可不加；
- **半双工方向控制**：两线制下收发共用一对线，MCU 需用 GPIO 控制 **DE/RE 引脚**切换收发方向，发送完毕及时释放（否则总线锁死）；
- **节点数**：标准单位负载（Unit Load，1UL 输入阻抗 12kΩ）下 **32 个节点**；用 1/2、1/4、1/8 UL 的芯片可扩展到 64/128/**256** 个——上限由驱动芯片驱动能力决定；
- **失效保护（fail-safe bias）**：总线空闲或所有节点都收听时，A/B 悬空差分≈0V，落在接收器阈值 ±200mV 内，输出不定。需要偏置电阻把空闲电平拉到确定状态：

```
VCC ──[Rb1]── A ──…总线…── B ──[Rb2]── GND
      (560Ω)              (560Ω，与两端 120Ω 分压)
空闲时 V_A−V_B ≈ +200mV 以上 → 接收器稳定输出逻辑1（空闲态）
```

  新一代收发器（如 MAX13487、SP3485 部分型号）片内集成 fail-safe，可省外部偏置。

## 收发器选型

| 型号 | 特点 | 适用 |
| --- | --- | --- |
| MAX485 | 5V 经典，20Mbps 档 | 老设计、5V 系统 |
| SP3485 | 3.3V 供电，10Mbps | 现代 MCU 直连 |
| MAX13487 | **自动方向控制**（无需 DE/RE 脚） | 简化软件，怕方向切换时序出错的场合 |
| ADM2483 / ISO3082 | 磁耦/光电**隔离** + 隔离电源 | 强干扰/长距离/跨设备电位差大 |
| THVD1550 等 1/8 负载 | 256 节点、20Mbps、±70V 共模耐压 | 大网络与工业现场 |

选型关注：供电电压（3.3/5V 是否直连 MCU）、是否隔离、负载等级（决定节点数）、共模耐压。

## 常见故障排查

| 现象 | 多半原因 | 验证手段 |
| --- | --- | --- |
| 通信偶尔丢帧、随负载恶化 | 缺终端电阻（波形振铃） | 示波器看边沿振铃；两端补 120Ω |
| 完全不通 | A/B 接反 | 万用表量空闲偏压极性；对调试试 |
| 数据乱码 | 波特率/格式两端不一致、干扰 | 示波器量 1 位时间反推波特率 |
| 长距离时好时坏 | 共模超限（-7~12V 之外）、未隔离 | 量 A/B 对地直流；加隔离收发器 |
| 总线"死锁"某节点独占 | DE 未释放（方向控制代码时序错） | 逻辑分析仪抓 DE 脚与 TX 的相对时序 |
| 空闲收到随机数据 | 无 fail-safe 偏置 | 加偏置电阻或换 fail-safe 收发器 |

## 与 CAN 的对比

同为差分总线、都在工业场景，选型时容易混：

| | RS-485 | CAN |
| --- | --- | --- |
| 仲裁 | 无（主从问答为主，靠应用层） | **硬件非破坏性仲裁**（ID 小者胜） |
| 错误处理 | 物理层不管，靠校验 | **CRC + 自动重发 + 错误计数器/故障隔离** |
| 帧结构 | 无（承载 UART 字节流） | 标准帧（ID/DLC/CRC/ACK） |
| 典型应用层 | Modbus RTU | CANopen/J1939/UDS |
| 节点角色 | 通常一主多从 | 多主平等 |

简单说：RS-485 是"电气层标准 + 自由协议"，CAN 是"电气 + 链路层完整方案"，可靠性要求高、多主竞争的现场选 CAN。参见 [多主总线仲裁机制对比以太网CAN与I2C](../05_通信协议/多主总线仲裁机制对比以太网CAN与I2C20260520.md)。

## 工程补充

- 多机通信常配合 **Modbus RTU**（地址+CRC16）做应用层：一主轮询，从站地址 1~247，3.5 字符静默时间作帧边界；
- 隔离场合用磁耦/光耦 + 隔离电源（B0505S），防止地环路把共模干扰引进系统；
- 四线制（全双工）需要一对专收、一对专发，仍然共地；
- 线缆选 120Ω 特性阻抗的**双绞线**（屏蔽层单点接地），别拿普通平行线凑合。

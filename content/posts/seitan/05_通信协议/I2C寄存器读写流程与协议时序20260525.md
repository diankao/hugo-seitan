# I2C寄存器读写流程与协议时序

## 题目

1. I2C怎么找到从机并开始通信？
2. I2C写寄存器的完整流程是什么？
3. I2C读寄存器的完整流程是什么？
4. I2C的START、STOP、ACK、NACK分别是什么？
5. 单字节读写和多字节连续读写有什么区别？

## 考察点

I2C协议基本时序信号理解、寄存器读写流程（面试最常考的通用知识）、单次传输与连续传输的区别。

## 回答要点

### 1. I2C协议基本信号

I2C只用了两根线（SCL + SDA），所有通信都通过电平变化来表示信号喵~

#### 四种基本信号

| 信号 | SCL | SDA变化 | 说明 |
|------|-----|---------|------|
| START | 高电平 | 高→低 | 主机发起通信 |
| STOP | 高电平 | 低→高 | 主机结束通信 |
| ACK | 第9个时钟 | 接收方拉低 | "收到了" |
| NACK | 第9个时钟 | 接收方保持高 | "没收到/不需要了" |

```
START信号：          STOP信号：
       ___               ___
SCL  _|   \___       ___|   \___
SDA  __|    \___     _________|  \___
         高→低            低→高
         (SCL为高时)       (SCL为高时)
```

#### 数据有效性规则

- SCL为**高电平**期间，SDA必须**稳定**（数据有效）
- SCL为**低电平**期间，SDA可以**改变**（准备下一位数据）
- 每次传输8位数据，MSB先发

```
       ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐  ┌──┐
SCL    │  │  │  │  │  │  │  │  │  │  │  │  │  │  │  │  │  │  │
    ───┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘  └──┘
       D7    D6    D5    D4    D3    D2    D1    D0   ACK/NACK
SDA ──┤     ├─────┤     ├─────┤     ├─────┤     ├─────┤     ├──
      ↑     ↑     ↑     ↑     ↑     ↑     ↑     ↑     ↑
    采样  采样  采样  采样  采样  采样  采样  采样  第9位应答
```

#### 设备地址格式

7位地址模式下，主机发送的第一个字节：

```
Bit7  Bit6  Bit5  Bit4  Bit3  Bit2  Bit1  Bit0
├─────────── 7位从机地址 ──────────┤ ├─ R/W ─┤
                                     0 = 写
                                     1 = 读
```

例如MPU6050地址0x68：
- 写地址：0x68 << 1 = 0xD0（1101 000**0**）
- 读地址：(0x68 << 1) | 1 = 0xD1（1101 000**1**）

### 2. I2C写寄存器流程

#### 写单个寄存器

最常用的操作：向从机的某个寄存器写入1字节数据。

```
主机:  [START] [ADDR+W] [ACK] [REG] [ACK] [DATA] [ACK] [STOP]
从机:                  [ACK]        [ACK]        [ACK]
```

```c
HAL_StatusTypeDef I2C_Write_Reg(I2C_HandleTypeDef *hi2c,
                                 uint8_t dev_addr, uint8_t reg_addr,
                                 uint8_t data)
{
    return HAL_I2C_Mem_Write(hi2c, dev_addr << 1, reg_addr,
                              I2C_MEMADD_SIZE_8BIT, &data, 1, 100);
}
```

#### 写多个连续寄存器

很多传感器支持自动递增寄存器地址，可以一次性写入多个连续寄存器。

```
主机:  [START] [ADDR+W] [ACK] [REG] [ACK] [D0] [ACK] [D1] [ACK] [D2] [ACK] [STOP]
从机:                  [ACK]        [ACK]       [ACK]       [ACK]       [ACK]
```

```c
uint8_t buf[3] = {0x12, 0x34, 0x56};
HAL_I2C_Mem_Write(hi2c, dev_addr << 1, 0x1A,
                   I2C_MEMADD_SIZE_8BIT, buf, 3, 100);
```

写入后：寄存器0x1A=0x12，0x1B=0x34，0x1C=0x56。

### 3. I2C读寄存器流程

读寄存器是面试最高频的考点，因为流程比写复杂——需要先"告诉从机要读哪个寄存器"，再切换方向读取数据。

#### 读单个寄存器

```
主机:  [START] [ADDR+W] [ACK] [REG] [ACK] [RESTART] [ADDR+R] [ACK]         [NACK] [STOP]
从机:                  [ACK]        [ACK]                   [ACK] [DATA]
```

分两个阶段：
1. **写阶段**：START → 设备地址+W → 寄存器地址 → RESTART
2. **读阶段**：设备地址+R → 从机输出1字节 → NACK → STOP

```c
uint8_t I2C_Read_Reg(I2C_HandleTypeDef *hi2c,
                      uint8_t dev_addr, uint8_t reg_addr)
{
    uint8_t data;
    HAL_I2C_Mem_Read(hi2c, dev_addr << 1, reg_addr,
                      I2C_MEMADD_SIZE_8BIT, &data, 1, 100);
    return data;
}
```

#### 读多个连续寄存器

面试最爱考的通用模式——从寄存器地址reg开始连续读取N字节。

```
主机:  [START] [ADDR+W] [ACK] [REG] [ACK] [RESTART] [ADDR+R] [ACK]             [NACK] [STOP]
从机:                  [ACK]        [ACK]                   [ACK] [D0] [ACK] [D1] ... [DN-1]
                       └─── 写阶段 ───┘     └────────── 读阶段 ──────────┘
```

读取过程中：
- 前 N-1 个字节：主机回 **ACK**，告诉从机"继续发"
- 第 N 个字节：主机回 **NACK**，告诉从机"够了，停下"

```c
HAL_StatusTypeDef I2C_Read_Burst(I2C_HandleTypeDef *hi2c,
                                  uint8_t dev_addr, uint8_t reg_addr,
                                  uint8_t *buf, uint16_t len)
{
    return HAL_I2C_Mem_Read(hi2c, dev_addr << 1, reg_addr,
                             I2C_MEMADD_SIZE_8BIT, buf, len, 1000);
}
```

#### 16位寄存器地址的读取

有些器件（如EEPROM AT24C256）使用16位寄存器地址：

```c
HAL_I2C_Mem_Read(hi2c, dev_addr << 1, reg_addr_16bit,
                  I2C_MEMADD_SIZE_16BIT, buf, len, 1000);
```

时序上只是把寄存器地址从1字节变成2字节，其余不变。

### 4. 读写流程对比

| 对比项 | 写寄存器 | 读寄存器 |
|--------|---------|---------|
| 通信方向 | 主机→从机（单向） | 先写后读（双向） |
| START次数 | 1次 | 2次（START + RESTART） |
| 地址帧 | ADDR+W 1次 | ADDR+W + ADDR+R 各1次 |
| 数据来源 | 主机发送 | 从机发送 |
| ACK方向 | 从机回ACK | 主机回ACK（最后NACK） |
| 典型耗时（400kHz） | 写1字节约 45μs | 读1字节约 67.5μs |

### 5. 单字节 vs 多字节连续读写

#### 为什么连续读写更高效？

```
单字节读3个寄存器（低效）：
  [START→ADDR+W→REG0→RESTART→ADDR+R→DATA0→NACK→STOP]  ← 第1次
  [START→ADDR+W→REG1→RESTART→ADDR+R→DATA1→NACK→STOP]  ← 第2次
  [START→ADDR+W→REG2→RESTART→ADDR+R→DATA2→NACK→STOP]  ← 第3次
  总计：3次完整通信，每次 ~67.5μs = ~202.5μs

连续读3个寄存器（高效）：
  [START→ADDR+W→REG0→RESTART→ADDR+R→DATA0→ACK→DATA1→ACK→DATA2→NACK→STOP]
  总计：1次通信 ~90μs
```

连续读写的优势：
- 减少了START/STOP和地址帧的开销
- 从机内部地址指针自动递增，无需每次重新指定
- 总线占用时间更短，减少对其他设备的影响

#### 从机地址自动递增

大多数I2C从器件（传感器、EEPROM等）内部有地址指针，连续读写时指针自动+1：

```
写入REG0后，内部指针自动指向REG1
读取REG0后，继续读就自动读到REG1、REG2...
```

部分器件通过寄存器地址最高位控制是否自动递增（如PCF8574），使用时需查阅数据手册。

### 6. HAL库常用I2C函数速查

| 函数 | 用途 | 典型场景 |
|------|------|---------|
| `HAL_I2C_Mem_Write` | 写寄存器（自动处理ADDR+REG） | 配置传感器寄存器 |
| `HAL_I2C_Mem_Read` | 读寄存器（自动处理写地址+读数据） | 读取传感器数据 |
| `HAL_I2C_Master_Transmit` | 纯发送（不带寄存器地址） | 发送简单命令 |
| `HAL_I2C_Master_Receive` | 纯接收 | 从指定从机读取原始数据 |
| `HAL_I2C_Mem_Write_DMA` | DMA方式写寄存器 | 大批量数据写入 |
| `HAL_I2C_Mem_Read_DMA` | DMA方式读寄存器 | 高频采集不阻塞CPU |

#### 通用读写封装

```c
typedef struct {
    I2C_HandleTypeDef *hi2c;
    uint8_t dev_addr;
} I2C_Device_t;

HAL_StatusTypeDef I2CDev_Write(const I2C_Device_t *dev,
                                uint8_t reg, const uint8_t *data, uint16_t len)
{
    return HAL_I2C_Mem_Write(dev->hi2c, dev->dev_addr << 1, reg,
                              I2C_MEMADD_SIZE_8BIT, (uint8_t *)data, len, 1000);
}

HAL_StatusTypeDef I2CDev_Read(const I2C_Device_t *dev,
                               uint8_t reg, uint8_t *buf, uint16_t len)
{
    return HAL_I2C_Mem_Read(dev->hi2c, dev->dev_addr << 1, reg,
                             I2C_MEMADD_SIZE_8BIT, buf, len, 1000);
}

HAL_StatusTypeDef I2CDev_WriteReg8(const I2C_Device_t *dev,
                                    uint8_t reg, uint8_t val)
{
    return I2CDev_Write(dev, reg, &val, 1);
}

uint8_t I2CDev_ReadReg8(const I2C_Device_t *dev, uint8_t reg)
{
    uint8_t val = 0;
    I2CDev_Read(dev, reg, &val, 1);
    return val;
}
```

使用示例：

```c
I2C_Device_t mpu6050 = {&hi2c1, 0x68};
I2C_Device_t eeprom  = {&hi2c1, 0x50};

I2CDev_WriteReg8(&mpu6050, 0x6B, 0x00);

uint8_t who_am_i = I2CDev_ReadReg8(&mpu6050, 0x75);

uint8_t sensor_data[6];
I2CDev_Read(&mpu6050, 0x3B, sensor_data, 6);

uint8_t eeprom_buf[16];
I2CDev_Read(&eeprom, 0x00, eeprom_buf, 16);
```

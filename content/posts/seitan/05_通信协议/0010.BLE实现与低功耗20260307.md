### BLE基本概念

#### 1. BLE简介

**定义**：Bluetooth Low Energy（BLE）是一种低功耗蓝牙技术，专为短距离、低带宽、低功耗的物联网设备设计。

**特点**：
- 低功耗：工作电流极低（几毫安到微安级）
- 低成本：硬件和协议栈成本低
- 短距离：典型通信距离10-100米
- 低带宽：传输速率最高1Mbps
- 快速连接：连接建立时间短
- 广泛兼容：几乎所有现代设备支持

#### 2. BLE架构

**协议栈层次**：
```
┌─────────────────────────────────┐
│     应用层 (Application)         │
├─────────────────────────────────┤

│     链路层 (Link Layer)          │

```

#### 3. BLE角色

**中心设备**：主动扫描和连接
```c
// 中心设备初始化
void Central_Init(void) {
    BLE_Init();
    
    设置扫描参数
    BLE_Scan_Params_t scan_params = {
        .interval = 100,
        .window = 50,
        .active = true
    };
    BLE_SetScanParams(&scan_params);
    
    开始扫描
    BLE_StartScan(Scan_Callback);
}

void Scan_Callback(BLE_AdvReport_t *adv_report) {
    printf("Found device: %s\n", adv_report->device_name);
    
    if (strcmp(adv_report->device_name, "TargetDevice") == 0) {
        BLE_StopScan();
        BLE_Connect(&adv_report->addr);
    }
}
```

### BLE低功耗实现

#### 1. 低功耗原理

**功耗来源**：
- **接收功耗**：接收数据时功耗较高（~10-20mA）
- **发送功耗**：发送数据时功耗最高（~15-30mA）
- **空闲功耗**：空闲时功耗很低（~1-10μA）
- **CPU功耗**：处理数据时的功耗

**低功耗策略**：
- 减少收发时间
- 增加睡眠时间
- 降低发射功率
- 优化数据包大小

#### 2. 连接参数优化

**连接参数**：
- **连接间隔**：两次连接事件之间的时间
- **从设备延迟**：设备可以跳过的连接事件数
- **监督超时**：连接丢失前的超时时间

```c
// 设置连接参数
BLE_ConnParams_t conn_params = {
    .min_interval = 100,    // 最小间隔 100 * 1.25ms = 125ms
    .max_interval = 200,    // 最大间隔 200 * 1.25ms = 250ms
    .slave_latency = 4,     // 从设备延迟 4 个连接事件
    .supervisor_timeout = 600  // 超时 600 * 10ms = 6s
};

BLE_SetConnParams(&conn_params);
```

**参数选择**：
- **低延迟应用**：连接间隔7.5-30ms，从设备延迟0
- **低功耗应用**：连接间隔500-4000ms，从设备延迟4-9
- **平衡应用**：连接间隔100-200ms，从设备延迟0-4

#### 3. 广播参数优化

```c
// 优化广播参数
BLE_Adv_Params_t adv_params = {
```

#### 4. 硬件低功耗模式

**睡眠模式**：
```c
void BLE_SleepMode(void) {
    等待BLE空闲
    while(BLE_IsBusy()) {
        vTaskDelay(1);
    }
    
    关闭未使用的外设
    GPIO_DeInit();
    UART_DeInit();
    
    进入低功耗模式
    BLE_EnterSleepMode();
    System_EnterLowPowerMode();
}

void BLE_Wakeup(void) {
    从低功耗模式唤醒
    System_Wakeup();
    BLE_Wakeup();
    
    重新初始化外设
    GPIO_Init();
    UART_Init();
}
```

### 功耗优化技巧

#### 1. 数据优化

**减少数据传输量**：
```c
// 不好的做法：发送完整数据
void SendFullData(void) {
    uint8_t full_data[100];
    FillFullData(full_data);
    BLE_Send(full_data, 100);
}

// 好的做法：只发送变化数据
void SendDeltaData(void) {
    static uint8_t last_data[100];
    uint8_t current_data[100];
    uint8_t delta_data[100];
    uint16_t delta_len = 0;
    
    GetCurrentData(current_data);
    
    计算差分
    for (int i = 0; i < 100; i++) {
        if (current_data[i] != last_data[i]) {
            delta_data[delta_len++] = i;
            delta_data[delta_len++] = current_data[i];
        }
    }
    
    if (delta_len > 0) {
        BLE_Send(delta_data, delta_len);
        memcpy(last_data, current_data, 100);
    }
}
```

**数据压缩**：
```c
// 简单RLE压缩
uint16_t RLE_Compress(uint8_t *input, uint8_t *output, uint16_t len) {
    uint16_t output_len = 0;
    uint8_t count = 1;
    
    for (uint16_t i = 1; i < len; i++) {
        if (input[i] == input[i-1] && count < 255) {
            count++;
        } else {
            output[output_len++] = count;
            output[output_len++] = input[i-1];
            count = 1;
        }
    }
    
    output[output_len++] = count;
    output[output_len++] = input[len-1];
    
    return output_len;
}
```

```c
// 根据数据量调整连接间隔
void UpdateConnectionParams(uint16_t data_rate) {
    BLE_ConnParams_t conn_params;
    
    if (data_rate > 100) {
        // 高数据率，低延迟
        conn_params.min_interval = 6;   // 7.5ms
        conn_params.max_interval = 6;   // 7.5ms
        conn_params.slave_latency = 0;
    } else if (data_rate > 10) {
        // 中等数据率，平衡
        conn_params.min_interval = 80;  // 100ms
        conn_params.max_interval = 80;  // 100ms
        conn_params.slave_latency = 0;
    } else {
        // 低数据率，低功耗
        conn_params.min_interval = 800; // 1000ms
        conn_params.max_interval = 800; // 1000ms
        conn_params.slave_latency = 4;
    }
    
    BLE_UpdateConnParams(&conn_params);
}
```

```c
// 根据距离调整发射功率
void AdjustTxPower(int8_t rssi) {
    int8_t tx_power;
    
    if (rssi > -40) {
        // 距离很近，降低发射功率
        tx_power = -20;  // -20dBm
    } else if (rssi > -60) {
        // 距离中等，中等发射功率
        tx_power = -10;  // -10dBm
    } else {
        // 距离较远，最大发射功率
        tx_power = 0;    // 0dBm
    }
    
    BLE_SetTxPower(tx_power);
}
```

### 功耗测量

#### 1. 功耗分析方法

**平均功耗计算**：
```c
typedef struct {
    uint32_t sleep_time;
    uint32_t active_time;
    float sleep_current;
    float active_current;
} PowerProfile_t;

float CalculateAveragePower(PowerProfile_t *profile) {
    uint32_t total_time = profile->sleep_time + profile->active_time;
    
    float sleep_energy = profile->sleep_time * profile->sleep_current;
    float active_energy = profile->active_time * profile->active_current;
    
    return (sleep_energy + active_energy) / total_time;
}
```

**功耗监测**：
```c
void MonitorPowerConsumption(void) {
    static uint32_t last_time = 0;
    static uint32_t sleep_count = 0;
    static uint32_t active_count = 0;
    
    uint32_t current_time = GetTick();
    
    if (BLE_IsSleeping()) {
        sleep_count += (current_time - last_time);
    } else {
        active_count += (current_time - last_time);
    }
    
    last_time = current_time;
    
    printf("Active time: %d ms\n", active_count);
    printf("Sleep time: %d ms\n", sleep_count);
    printf("Duty cycle: %.2f%%\n", 
           (float)active_count / (active_count + sleep_count) * 100);
}
```

### 注意事项

1. **连接参数协商**：确保与中心设备的连接参数协商成功
2. **功耗与性能平衡**：根据应用需求权衡功耗和性能
3. **协议栈版本**：使用最新版本的BLE协议栈以获得更好的功耗优化
4. **硬件设计**：注意硬件设计的功耗影响，如电源管理、阻抗匹配等
5. **测试验证**：使用功耗分析仪实际测量设备功耗

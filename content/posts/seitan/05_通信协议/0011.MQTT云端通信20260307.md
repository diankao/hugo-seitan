### MQTT基本概念

#### 1. MQTT简介

**定义**：MQTT（Message Queuing Telemetry Transport）是一种轻量级的发布/订阅消息传输协议，专为低带宽、高延迟网络环境设计。

**特点**：
- **轻量级**：协议头部仅2字节，适合资源受限设备
- **发布/订阅**：解耦通信双方，支持一对多通信
- **QoS等级**：支持3种消息服务质量
- **可靠性**：支持消息持久化和会话保持
- **安全性**：支持TLS加密和认证

#### 2. MQTT架构

```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│   设备A     │         │   设备B     │         │   设备C     │
```

### MQTT协议基础

#### 1. MQTT消息类型

**控制报文类型**：
- **CONNECT**：客户端连接到服务器
- **CONNACK**：连接确认
- **PUBLISH**：发布消息
- **PUBACK**：发布确认（QoS 1）
- **PUBREC**：发布收到（QoS 2）
- **PUBREL**：发布释放（QoS 2）
- **PUBCOMP**：发布完成（QoS 2）
- **SUBSCRIBE**：订阅主题
- **SUBACK**：订阅确认
- **UNSUBSCRIBE**：取消订阅
- **UNSUBACK**：取消订阅确认
- **PINGREQ**：心跳请求
- **PINGRESP**：心跳响应
- **DISCONNECT**：断开连接

#### 2. QoS等级

**QoS 0 - 最多一次**：
```c
// 发布QoS 0消息
mqtt_client_publish(&client, "sensor/temp", "25.5", strlen("25.5"), 0, 0);
```
- 消息最多发送一次
- 不保证送达
- 最快，最不可靠

**QoS 1 - 至少一次**：
```c
// 发布QoS 1消息
mqtt_client_publish(&client, "sensor/temp", "25.5", strlen("25.5"), 1, 0);
```
- 消息至少发送一次
- 保证送达，可能重复
- 需要确认机制

**QoS 2 - 恰好一次**：
```c
// 发布QoS 2消息
mqtt_client_publish(&client, "sensor/temp", "25.5", strlen("25.5"), 2, 0);
```
- 消息恰好发送一次
- 保证送达且不重复
- 最慢，最可靠

### MQTT客户端实现

#### 1. MQTT客户端初始化

```c
#include "mqtt_client.h"

mqtt_client_t client;

void MQTT_Init_Client(void) {
    配置MQTT客户端
    mqtt_client_init(&client);
    
    设置连接参数
    client.username = "device_001";
    client.password = "password";
    client.client_id = "device_001";
    client.keep_alive = 60;
    
    设置回调函数
    client.on_connect = on_connect;
    client.on_message = on_message;
    client.on_publish = on_publish;
    client.on_disconnect = on_disconnect;
}

void on_connect(mqtt_client_t *client) {
    printf("Connected to MQTT broker\n");
    
    连接成功后订阅主题
    mqtt_subscribe(client, "device/cmd", 1);
    mqtt_subscribe(client, "device/config", 1);
}

void on_message(mqtt_client_t *client, const char *topic, 
                const char *payload, size_t len) {
    printf("Received message on topic %s: %.*s\n", topic, len, payload);
    
    if (strcmp(topic, "device/cmd") == 0) {
        ProcessCommand(payload, len);
    } else if (strcmp(topic, "device/config") == 0) {
        UpdateConfig(payload, len);
    }
}

void on_publish(mqtt_client_t *client, uint16_t packet_id) {
    printf("Message published with packet id %d\n", packet_id);
}

void on_disconnect(mqtt_client_t *client) {
    printf("Disconnected from MQTT broker\n");
    
    重新连接
    MQTT_Reconnect();
}
```

#### 2. MQTT连接

```c
void MQTT_Connect(void) {
    连接到MQTT Broker
    int ret = mqtt_client_connect(&client, "broker.example.com", 1883);
    
    if (ret == MQTT_SUCCESS) {
        printf("MQTT connect success\n");
    } else {
        printf("MQTT connect failed: %d\n", ret);
        
        延迟后重试
        osDelay(5000);
        MQTT_Connect();
    }
}

void MQTT_Reconnect(void) {
    while(1) {
        int ret = mqtt_client_connect(&client, "broker.example.com", 1883);
        
        if (ret == MQTT_SUCCESS) {
            printf("MQTT reconnect success\n");
            break;
        }
        
        printf("MQTT reconnect failed, retrying...\n");
        osDelay(5000);
    }
}
```

```c
typedef struct {
    float temperature;
    float humidity;
    float pressure;
    uint32_t timestamp;
} SensorData_t;

void MQTT_Publish_SensorData(SensorData_t *data) {
    char payload[128];
    
    格式化JSON数据
    snprintf(payload, sizeof(payload), 
             "{\"temp\":%.2f,\"hum\":%.2f,\"pres\":%.2f,\"time\":%u}",
             data->temperature, data->humidity, 
             data->pressure, data->timestamp);
    
    发布数据到云端
    mqtt_client_publish(&client, "device/sensor/data", 
                        payload, strlen(payload), 1, 0);
}

void MQTT_Publish_Status(void) {
```

#### 4. 订阅主题

```c
void MQTT_Subscribe_Topics(void) {
    订阅设备命令主题
    mqtt_subscribe(&client, "device/cmd", 1);
    
    订阅配置主题
    mqtt_subscribe(&client, "device/config", 1);
    
    订阅固件升级主题
    mqtt_subscribe(&client, "device/ota/update", 1);
    
    订阅时间同步主题
    mqtt_subscribe(&client, "device/sync/time", 1);
}

void Process_Command(const char *payload, size_t len) {
    解析JSON命令
    cJSON *json = cJSON_Parse(payload);
    if (json == NULL) {
        return;
    }
    
    cJSON *cmd = cJSON_GetObjectItem(json, "cmd");
    cJSON *param = cJSON_GetObjectItem(json, "param");
    
    if (cmd != NULL && param != NULL) {
        执行命令
        if (strcmp(cmd->valuestring, "reboot") == 0) {
            printf("Reboot command received\n");
            NVIC_SystemReset();
        } else if (strcmp(cmd->valuestring, "led") == 0) {
            SetLED(param->valueint);
        }
    }
    
    cJSON_Delete(json);
}
```

#### 2. 消息缓冲

```c
typedef struct {
    char topic[64];
    char payload[256];
    uint8_t qos;
    uint8_t retain;
} MessageBuffer_t;

#define MSG_BUFFER_SIZE 10

MessageBuffer_t msg_buffer[MSG_BUFFER_SIZE];
volatile uint8_t msg_head = 0;
volatile uint8_t msg_tail = 0;

void MQTT_Buffer_Publish(const char *topic, const char *payload, 
                          size_t len, uint8_t qos, uint8_t retain) {
    if ((msg_head + 1) % MSG_BUFFER_SIZE == msg_tail) {
        缓冲区满，丢弃最旧的消息
        msg_tail = (msg_tail + 1) % MSG_BUFFER_SIZE;
    }
    
    strcpy(msg_buffer[msg_head].topic, topic);
    strncpy(msg_buffer[msg_head].payload, payload, 
            sizeof(msg_buffer[msg_head].payload) - 1);
    msg_buffer[msg_head].payload[sizeof(msg_buffer[msg_head].payload) - 1] = '\0';
    msg_buffer[msg_head].qos = qos;
    msg_buffer[msg_head].retain = retain;
    
    msg_head = (msg_head + 1) % MSG_BUFFER_SIZE;
}

void MQTT_Flush_Buffer(void) {
    while (msg_tail != msg_head) {
        mqtt_client_publish(&client, 
                           msg_buffer[msg_tail].topic, 
                           msg_buffer[msg_tail].payload, 
                           strlen(msg_buffer[msg_tail].payload), 
                           msg_buffer[msg_tail].qos, 
                           msg_buffer[msg_tail].retain);
        
        msg_tail = (msg_tail + 1) % MSG_BUFFER_SIZE;
    }
}
```

### 注意事项

1. **网络稳定性**：考虑网络中断和重连机制
2. **消息顺序**：QoS 1可能导致消息乱序
3. **资源限制**：注意内存和CPU资源使用
4. **安全性**：使用TLS加密和强密码
5. **性能优化**：合理设置QoS等级和心跳间隔

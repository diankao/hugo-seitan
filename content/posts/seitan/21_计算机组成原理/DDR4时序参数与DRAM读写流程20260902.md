# DDR4 时序参数与 DRAM 读写流程

看内存条标签上的 `22-22-22-52` 时序数字，对应的是 DRAM 内部"激活行—列读写—预充电"流程的四个时间约束。本文从 DRAM 的层级结构讲起，整理一次完整访问的时序、四大参数语义、刷新机制、行命中对性能的影响，以及世代对比与带宽计算。

## DRAM 的组织层级

```
内存控制器 ─ 通道 Channel（64bit 数据宽度）
               └─ Rank（通道上的一组芯片，同选同动作；双面内存条 = 2 个 rank）
                    └─ Chip（颗粒，贡献 64bit 中的一部分，如 8 颗 ×8bit）
                         └─ Bank Group（DDR4 新增，组间可流水）
                              └─ Bank（独立的感觉放大阵列，可并行工作）
                                   └─ Row × Column（行 × 列，行 = 数 KB 的页）
```

并行度来自三个维度：**多通道**（带宽翻倍）、**多 rank**（总线利用率）、**多 bank**（行缓冲互相独立，一个 bank 预充电时另一个 bank 可以读写）——内存控制器会尽量把访问分散到不同 bank/channel 上调度。

## DRAM 的存储单元与"行"概念

存储单元是 1 个晶体管 + 1 个电容（1T1C），电容漏电需要周期性刷新。寻址分**行地址 + 列地址**两次送入：访问某个单元前，必须先"激活"它所在的行——把整行数据读入灵敏放大器（行缓冲 Row Buffer），之后对该行内任意列的读写都很快；换行访问（row miss）就必须先关闭当前行再开新行。

## 一次完整访问的时序

```
ACTIVATE(行激活)
   │  ←── tRCD ──→
   ▼
READ/WRITE(列操作)  ←── CL 决定数据何时出现在总线上
   │
   │  ←──────── tRAS（行必须保持打开的最短时间）────────→
   ▼
PRECHARGE(预充电，关闭行、灵敏放大器回写)
   │  ←── tRP ──→
   ▼
下次 ACTIVATE
```

## 四大时序参数

| 参数 | 含义 | 记忆 |
| --- | --- | --- |
| CL | 列选通到数据输出的延迟 | 读延迟（如 DDR4-3200 CL=22） |
| tRCD | 行激活 → 列操作 | "开行后多久能读" |
| tRP | 预充电 → 下次行激活 | "关行要多久" |
| **tRAS** | **行激活 → 预充电** | **"一行至少开多久"** |

其中 tRAS 最容易混淆：它不是某个单步延迟，而是行从激活到允许被预充电关闭的**最短保持时间**——电容充电（激活）到回写（预充电）需要足够时间完成灵敏放大。内存条标注的时序 `22-22-22-52` 依次就是 **CL-tRCD-tRP-tRAS**。

此外还有约束并发调度的几个参数：tRRD（相邻 ACTIVATE 的最小间隔）、tFAW（四激活窗口时间）、tCCD（列命令间隔，DDR4 按 bank group 分 tCCD_S/tCCD_L）。

## 行命中与性能

| 场景 | 流程 | 代价 |
| --- | --- | --- |
| 行命中 | 行已开，直接列操作 | CL 即可，最快 |
| 行空（row miss，行缓冲闭） | ACTIVATE → 列操作 | + tRCD |
| 行冲突（缓冲有别的行） | PRECHARGE → ACTIVATE → 列操作 | + tRP + tRCD，最慢 |

顺序访问大多行命中，随机跨行访问频繁吃 tRP+tRCD——这是内存访问局部性在硬件层的直接体现，也是缓存友好的数据布局能提速的原因之一。攻击者甚至反过来利用它：Rowhammer 就是用相邻行的疯狂激活干扰物理邻行的电荷。

## 刷新：漏电的代价

电容漏电，每行必须周期性读出重写：

- **tREFI**：平均刷新间隔，标准要求 64ms 内刷完所有行（DDR4-3200 下平均约 7.8µs 一条刷新命令）；温度升高到 85°C 以上时要求减半到 3.9µs；
- **tRFC**：每条刷新命令的耗时（期间该 rank 不能响应普通命令），容量越大越长——数十到数百 ns；
- 刷新是"纯开销"（约 3~5% 带宽），DDR4 引入 Fine Granularity Refresh（把大刷新拆小）、刷新管理（RFM）等机制缓解；
- **自刷新（Self-Refresh）**：DRAM 自带时钟刷自己，控制器可休眠——低功耗模式的基石。

## 世代对比

| | DDR3 | DDR4 | DDR5 |
| --- | --- | --- | --- |
| 电压 | 1.5V | 1.2V | 1.1V |
| 速率 | 800~2133 MT/s | 1600~3200+ | 4800~8000+ |
| Bank Group | 无 | 4 BG × 4 bank | 8 BG（容量型） |
| 预取 | 8n | 8n | 16n |
| 通道 | 64bit | 64bit | **2×32bit 子通道** |
| 片上 ECC | 无 | 无（部分有 on-die CRC） | **有（提升频率余量）** |
| 其他 | — | DBI、tCCD 分档 | on-PIM 起步、决策反馈均衡 |

LPDDR 系列是同代架构的移动版（更深功耗管理、BGA 封装、速率更激进），MCU/手机/嵌入式主控常用 LPDDR4/5。

## 带宽计算

理论带宽 = 数据速率 × 总线宽度：

```
DDR4-3200，单通道 64bit：
3200 MT/s × 64 bit ÷ 8 = 25600 MB/s = 25.6 GB/s
双通道即 51.2 GB/s（核显/嵌入式 SoC 的内存共享带宽常这么算）
```

注意 MT/s（每秒百万次传输）与 MHz 的区别：DDR 一个时钟传两次，DDR4-3200 的时钟是 1600MHz。"等效频率"营销话术里说的 3200MHz 其实是 MT/s。

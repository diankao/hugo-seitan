# 51单片机中断系统与优先级嵌套

## 题目

围绕 8051 系列单片机中断系统的系列问题：

1. STC89C52RC 相比传统 8051 增加了定时器 2 中断，它总共有多少个中断源？支持几级中断优先级？
2. 中断嵌套的规则是什么？正在执行的中断服务程序能被哪些中断打断？

## 考察点

8051/STC89C52 的中断源组成与数量、两级中断优先级机制、中断嵌套的基本规则（并与 ARM Cortex-M 的多级抢占优先级对比）。

## 回答要点

### 1. 中断源数量与优先级级数

传统 8051 有 5 个中断源，STC89C52RC 增加了定时器 2 中断，共 **6 个**：

| 中断源 | 中断号 | 触发条件 | 默认自然优先级（同级内查询顺序） |
|--------|--------|---------|--------------------------------|
| 外部中断 0（INT0，P3.2） | 0 | 低电平或下降沿（IT0 选择） | 1（最高） |
| 定时器 0 溢出（T0） | 1 | 计数溢出 | 2 |
| 外部中断 1（INT1，P3.3） | 2 | 低电平或下降沿（IT1 选择） | 3 |
| 定时器 1 溢出（T1） | 3 | 计数溢出 | 4 |
| 串口中断（UART） | 4 | 发送/接收完成（TI/RI） | 5 |
| 定时器 2 溢出（T2，52 系列新增） | 5 | 计数溢出 | 6（最低） |

优先级方面，51 内核只有**两级**：IP 寄存器每位把对应中断设为高或低优先级。所以是"6 个中断源、2 个优先级"——注意**中断源个数 ≠ 优先级级数**，52 系列加了中断源但没扩优先级层级。不要与 ARM Cortex-M 的 16 级抢占优先级混淆，那是另一套硬件机制（见第 3 节）。

两个易混点：

- **两级优先级是 51 的天花板**：想让某中断能打断别人，只能把它设为高优先级；
- **自然优先级只在"同时到达"时起作用**：同一优先级内若多个中断同时申请，按上表顺序响应；一旦先响应了一个，同级后来的都得等它执行完（见下节）。

### 2. 中断嵌套规则

8051 的嵌套规则可以概括为一句话：**高可打断低，同级不嵌套，低永不能打断高**——正在执行的中断服务程序**只能被更高优先级的中断打断**。

两个常见误区正好对应这句话的两头：

- **以为同级可以互相打断**：不行。51 响应中断后会自动屏蔽同级和低级申请，同级中断即便在服务期间置位标志，也要等 RETI 之后才会被重新查询响应——这也是为什么 ISR 里要注意清标志；
- **以为一旦进入中断就"绝对安全"、任何中断都进不来**：也不是。高优先级中断到来时会立即嵌套，这正是"中断嵌套"的意义。

硬件实现上，51 在响应中断时会把"当前正在服务"的优先级记录下来（触发器锁存），只有**更高**优先级的申请才能再次触发嵌套。

### 3. 平台差异：51 vs ARM Cortex-M

中断嵌套规则有明显的平台差异，需要显式区分：

| 对比项 | 8051/STC89C52 | ARM Cortex-M（NVIC） |
|--------|---------------|---------------------|
| 优先级级数 | 2 级（IP 寄存器） | 最多 256 级（Cortex-M3/4 常用 4 位 = 16 级） |
| 抢占规则 | 只有高级能打断低级 | 抢占优先级更高的可打断低的，级数更多、更灵活 |
| 同级嵌套 | 不允许 | 抢占优先级相同则不允许互相抢占 |
| 子优先级 | 无 | 可分组：抢占优先级 + 子优先级（子优先级只决定同时挂起时的响应顺序） |
| 压栈方式 | 硬件只压 PC 等少部分现场，其余靠编译器 | 硬件自动压 8 个寄存器，嵌套零软件开销 |

所以"当前中断只能被更高优先级打断"在两个平台上都成立，但"更高级"的粒度完全不同：51 只有高一档，Cortex-M 可以细分出很多档。

### 4. 示例：两级优先级的典型配置

```c
#include <reg52.h>

void main(void)
{
    IT0 = 1;
    EX0 = 1;

    IT1 = 1;
    EX1 = 1;

    PX0 = 1;

    EA = 1;
    while (1) {
    }
}

void INT0_ISR(void) interrupt 0
{
}

void INT1_ISR(void) interrupt 2
{
}
```

执行效果：INT0 服务程序运行期间，INT1 的申请不会打断它；反过来，若 INT1 的服务程序正在执行，INT0 到来会立即嵌套进入 INT0 服务程序。

### 5. 小结

- STC89C52RC = 传统 8051 的 5 个中断源（INT0、T0、INT1、T1、串口）+ T2 = **6 个**，优先级仍是**2 级**；
- 嵌套规则一句话：**只有更高优先级才能打断正在执行的中断服务程序**，同级互不打断、低级更不可能；
- 对比记忆：51 是 2 级优先级 + 自然优先级排队，Cortex-M 是 NVIC 多级抢占优先级，规则同源但粒度差很远。

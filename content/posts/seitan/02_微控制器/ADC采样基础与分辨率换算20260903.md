# ADC 采样基础与分辨率换算

ADC（模数转换器）把连续的模拟电压变成离散的数字量，是传感器世界的入口。本文整理 ADC 的量化原理、分辨率与换算公式、参考电压的影响、常见 ADC 架构的选型，以及 MCU 上的实践要点。

## 量化原理

ADC 的三步：**采样 → 保持 → 量化编码**。

```
模拟输入 Vin ──► [采样/保持 S/H] ──► [量化] ──► [编码] ──► N 位数字量 D
                  （瞬时采样并保持）    （比对到最近级）
```

- **采样**：按采样率 fs 抓瞬时值。fs 必须满足奈奎斯特准则（fs ≥ 2×信号最高频率），否则混叠——详见 [数字信号基础与采样定理](../20_数字信号处理/0001.数字信号基础与采样定理20260424.md)；
- **量化**：把连续电压归到最近的离散级， inherent 引入 ±½LSB 的量化误差；
- **编码**：输出 N 位二进制数。

## 分辨率与换算

**N 位 ADC 有 2^N 个量化级**，最小分辨单位 LSB（Least Significant Bit）：

```
1 LSB = Vref / 2^N
Vin   = D × Vref / 2^N        （D 为转换结果）
```

两种约定并存：分母用 `2^N` 或 `2^N - 1`（满量程对应 D=2^N-1 时恰好等于 Vref）。两者差异小于 1/N，工程上常忽略，但读数直接比对时要知道用的哪种。

**例 1（8 位）**：2^8 = 256 级，分辨率即 **1/256 满量程**。

**例 2（12 位，Vref=3.3V）**：4096 级，1 LSB = 3.3/4096 ≈ 0.806mV。读到 0x7FF = 2047：

```
Vin = 2047 / 4095 × 3.3V ≈ 1.649V ≈ 1.65V（约满量程一半）
```

## 参考电压 Vref

Vref 是换算的"尺子"，它的精度和稳定性直接决定系统精度：

- **片内参考**：方便但温漂大（±100ppm/℃ 级）；
- **外部基准芯片**（TL431、REF3033 等）：高精度场景必选；
- Vref 不稳 → 读数整体漂移，与被测信号无关；
- 被测电压超过 Vref 会被削顶（clamp），要先做分压或前端调理；远小于 Vref 则有效位数下降——**量程要匹配**，小信号先放大。

## 常见 ADC 架构

| 架构 | 原理 | 速度 | 精度 | 典型用途 |
| --- | --- | --- | --- | --- |
| **SAR**（逐次逼近） | 二分比较，逐位确定 | 中（MHz 级） | 8~18 位 | MCU 片上 ADC 的主流（STM32 全系） |
| **Sigma-Delta (Σ-Δ)** | 过采样 + 噪声整形 | 慢（kHz 级） | 16~24 位 | 电子秤、生理信号（脑电采集前端） |
| **Flash（并行）** | 2^N-1 个比较器一拍出结果 | 极快 | 6~8 位 | 示波器前端、高速采集 |
| 流水线（Pipeline） | 多级低分辨率级联 | 快 | 12~16 位 | 视频/通信中速高精 |

## MCU 上的实践要点

**采样时间与输入阻抗**：采样电容充电需要时间，信号源内阻大、采样窗短会导致读数偏低。高内阻信号源（分压电阻、pH 电极）要么加运放缓冲，要么把采样周期调长（STM32 的 SMPR 位）。

**多通道扫描 + DMA**：多路轮询用扫描模式 + DMA 搬运，避免每个转换都进中断；规则组 + 注入组可插队。

**均值与过采样**：白噪声背景下过采样 + 抽取可白赚分辨率——每提高 1 位有效分辨率需要 4 倍采样率（12 位过采样到 16 位要 256 次平均），前提是噪声近似随机。

**布线**：模拟地/数字地单点连接，Vref 并大容量 + 0.1µF 去耦，模拟走线远离时钟/开关信号。

```c
// STM32 HAL 典型序列：校准 → 启动 → 取值
HAL_ADCEx_Calibration_Start(&hadc1);          // F3/G4/L4 系列需要
HAL_ADC_Start(&hadc1);
HAL_ADC_PollForConversion(&hadc1, 100);
uint16_t raw = HAL_ADC_GetValue(&hadc1);
float vin = raw * 3.3f / 4095.0f;              // 注意 Vref 实测值更准
```

# STM32 PWM驱动LED呼吸灯 & 舵机 & 直流电机 笔记

## 一、PWM初始化步骤（5步）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 开启时钟 | RCC开启TIM外设和GPIO外设的时钟 |
| 2 | 配置时基单元 | 选择时钟源 + 配置PSC预分频器和ARR计数周期 |
| 3 | 配置输出比较单元 | 用`TIM_OCInit`结构体配置OC模式、极性、使能、CCR值 |
| 4 | 配置GPIO | 将PWM对应的GPIO口初始化为**复用推挽输出**（`GPIO_Mode_AF_PP`） |
| 5 | 启动定时器 | `TIM_Cmd`使能定时器，开始运行 |

### 为什么GPIO要配置为复用推挽输出？

- **普通推挽输出**：引脚控制权来自**输出数据寄存器**（ODR）
- **复用推挽输出**：引脚控制权交给**片上外设**（如定时器）
- PWM波形由定时器产生，所以必须用复用模式

### 定时器通道与GPIO引脚的对应关系

引脚定义表决定了哪个定时器通道对应哪个GPIO引脚（**固定的，不能任意更改**）：

| TIM2通道 | 默认引脚 |
|----------|----------|
| CH1 (OC1) | PA0 |
| CH2 (OC2) | PA1 |
| CH3 (OC3) | PA2 |
| CH4 (OC4) | PA3 |

> 可以通过AFIO重映射改变引脚位置，但不能任意选择。

## 二、PWM频率和占空比的计算

### 计算公式

```
PWM频率 = 72MHz / (PSC + 1) / (ARR + 1)
占空比   = CCR / (ARR + 1)       （PWM模式1，向上计数）
```

### 同一定时器不同通道的特点

- **频率相同**：不同通道共用一个计数器
- **占空比各自独立**：由各自的CCR决定
- **相位同步**：计数器更新时所有PWM同时跳变

## 三、输出比较库函数

### 重要函数（必须掌握）

| 函数 | 用途 |
|------|------|
| `TIM_OCxInit()` | 用结构体初始化输出比较通道（x=1,2,3,4） |
| `TIM_OCStructInit()` | 给OC结构体赋默认值（避免未赋值成员导致的问题） |
| `TIM_SetComparex()` | 运行时单独更改CCR值（改变占空比） |

### OC结构体关键成员

| 成员 | 说明 | 常用值 |
|------|------|--------|
| `TIM_OCMode` | 输出比较模式 | `TIM_OCMode_PWM1`（PWM模式1） |
| `TIM_OCPolarity` | 输出极性 | `TIM_OCPolarity_High`（不翻转）/ `Low`（取反） |
| `TIM_OutputState` | 输出使能 | `TIM_OutputState_Enable` |
| `TIM_Pulse` | CCR初始值 | 0~65535 |

### TIM_OCStructInit 的重要性

如果结构体没有给所有成员赋值，未赋值的成员值不确定，可能导致高级定时器输出PWM时出现奇怪的问题（如初始化函数位置不同导致PWM能否输出）。**建议先调用`TIM_OCStructInit`赋默认值，再修改需要的成员。**

## 四、舵机驱动

### 舵机PWM要求

| 参数 | 要求 |
|------|------|
| 频率 | 50Hz（周期20ms） |
| 高电平时间 | 0.5ms（0°）~ 2.5ms（180°） |

### 参数计算

```
PSC + 1 = 72    → 预分频后时钟 = 72MHz / 72 = 1MHz（1μs计数一次）
ARR + 1 = 20000 → 周期 = 20000 × 1μs = 20ms = 50Hz ✓

CCR = 500  → 高电平 500μs = 0.5ms → 0°
CCR = 2500 → 高电平 2500μs = 2.5ms → 180°
CCR = 1500 → 高电平 1500μs = 1.5ms → 90°
```

> ARR=20000对应20ms，所以CCR值直接等于高电平的微秒数，非常直观。

### 角度到CCR的映射公式

```c
CCR = Angle / 180 * 2000 + 500
```

验证：
- Angle=0 → 0/180×2000+500 = 500 ✓
- Angle=180 → 180/180×2000+500 = 2500 ✓
- Angle=90 → 90/180×2000+500 = 1500 ✓

### 舵机接线

| 线色 | 连接 |
|------|------|
| 棕色（GND） | 面包板GND |
| 红色（VCC 5V） | ST-Link的5V输出引脚（不是面包板3.3V！功率不够） |
| 橙色（PWM信号） | PA1（TIM2 CH2） |

### 模块化设计

```
PWM.c（底层） → Servo.c（应用层）
PWM_Init()      Servo_Init() → 调用PWM_Init()
PWM_SetCompare2 Servo_SetAngle(Angle) → 内部调用PWM_SetCompare2，做角度到CCR的映射
```

> Servo模块把不直观的CCR参数（500~2500）封装为直观的角度参数（0~180），体现了模块化编程的好处。

## 五、直流电机驱动（TB6612）

### TB6612接线

| 引脚 | 连接 | 说明 |
|------|------|------|
| VM | ST-Link 5V | 电机电源 |
| VCC | 面包板3.3V | 逻辑电源 |
| GND | 面板GND | 电源地 |
| AO1/AO2 | 电机两根线 | 电机输出（接反则反转） |
| PWMA | PA2（TIM2 CH3） | PWM速度控制 |
| AIN1 | PB4 | 方向控制1 |
| AIN2 | PB5 | 方向控制2 |
| STBY | 3.3V | 待机控制（接高电平=正常工作） |

### 速度与方向控制

```
AIN1=0, AIN2=1 → 正转
AIN1=1, AIN2=0 → 反转
AIN1=0, AIN2=0 → 停止（滑行）
AIN1=1, AIN2=1 → 停止（刹车）

PWM占空比 → 控制速度（0~100%）
```

### PWM频率对电机的影响

- 频率太低（如1kHz）→ 低速时电机会发出"吱吱"声
- 解决方案：**加大PWM频率到20kHz以上**（超出人耳听觉范围）
- 通过减小PSC值来提高频率，不影响占空比

## 六、重映射（AFIO引脚重定义）

### 用途
当两个外设的默认引脚冲突时，可以通过重映射将外设引脚挪到备用位置。

### 操作步骤
1. 开启AFIO时钟：`RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE)`
2. 调用重映射：`GPIO_PinRemapConfig(重映射方式, ENABLE)`

### 调试端口注意事项

| 引脚 | 默认复用 | 解除方法 |
|------|----------|----------|
| PA15 | JTAG（TDI） | `GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE)` |
| PB3 | JTAG（TDO） | 同上 |
| PB4 | JTAG（NTRST） | 同上 |
| PA13 | SWD（SWDIO） | `GPIO_PinRemapConfig(GPIO_Remap_SWJ_Disable, ENABLE)` ⚠️ 慎用！ |
| PA14 | SWD（SWCLK） | 同上 ⚠️ 慎用！ |

> `GPIO_Remap_SWJ_Disable` 会解除所有调试端口，之后ST-Link无法下载程序，只能用串口恢复！

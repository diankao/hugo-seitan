# STM32 EXTI外部中断（下）—— 结构详解、硬件模块与编程笔记

## 八、EXTI完整结构

### 整体结构图解读

```
GPIO外设（16个引脚×多个端口）          EXTI模块（20个输入）           输出
┌─────────────┐              ┌──────────────────┐
│ GPIOA Pin0~15│──┐          │                  ├──→ NVIC（中断响应）
│ GPIOB Pin0~15│──┤ AFIO ──→ │ 边缘检测控制电路  │
│ GPIOC Pin0~15│──┤ 选择器   │                  ├──→ 其他外设（事件响应）
│ ...          │──┘          │                  │
│              │             └──────────────────┘
│  蹭网外设(4个)│─────────────────────↑
└─────────────┘    (PVD/RTC/USB/以太网唤醒)
```

### AFIO——复用功能I/O

AFIO就是一个**数据选择器（多路复用器）**：

- 每个GPIO端口有16个引脚，多个端口同一Pin号的引脚通过AFIO选择其中一个连接到EXTI通道
- 例如 PA0、PB0、PC0 通过AFIO选择，只有其中一个能接到EXTI0
- **这就是相同Pin号不能同时触发中断的根本原因**

AFIO的两个主要功能：
1. **复用功能引脚重映射** — 把默认复用功能引脚换到备用位置
2. **中断引脚选择** — 选择哪个端口的Pin连接到EXTI通道

### EXTI内部框图详解

```
输入线(20根)
    │
    ↓
┌──────────────┐
│ 边缘检测电路  │ ← 上升沿选择寄存器 / 下降沿选择寄存器
└──────┬───────┘
       │
       ↓
    ┌──┴──┐
    │ 或门 │ ← 软件中断寄存器
    └──┬──┘
       │
    ┌──┴──────────────┐
    │                 │
    ↓ (中断响应)      ↓ (事件响应)
┌────────┐        ┌────────┐
│挂起寄存器│       │事件屏蔽 │
│(标志位) │        │ 寄存器  │
└────┬───┘        └────┬───┘
     │                 │
  ┌──┴──┐           ┌──┴──┐
  │ 与门 │           │与门  │ ← 开关控制
  └──┬──┘           └──┬──┘
     ↑                  │
中断屏蔽寄存器      ┌──┴──┐
     │              │脉冲  │
     ↓              │发生器│
   NVIC             └──┬──┘
                        ↓
                    其他外设(ADC/DMA等)
```

#### 关键逻辑门说明

| 符号 | 名称 | 功能 |
|------|------|------|
| 弯弧形 | **或门** | 任一输入为1 → 输出1 |
| 直边带圆点 | **与门** | 任一输入为0 → 输出0；全为1才输出1 |
| 三角+圈 | **非门** | 输入取反 |
| 梯形 | **数据选择器** | 根据控制端选择一个输入接到输出 |

#### 与门的开关作用

```
中断屏蔽寄存器 = 1 → 与门打开 → 挂起信号直接通过（允许中断）
中断屏蔽寄存器 = 0 → 与门关闭 → 无论挂起信号是什么，输出都是0（屏蔽中断）
```

> x & 0 = 0（屏蔽），x & 1 = x（放行）。这就是中断屏蔽寄存器的原理。

### 中断响应 vs 事件响应

| 响应方式 | 去向 | 用途 |
|----------|------|------|
| **中断响应** | → NVIC → CPU执行中断函数 | 正常流程，处理紧急事件 |
| **事件响应** | → 脉冲发生器 → 其他外设 | 不触发中断，而是触发ADC转换、DMA等外设操作 |

> 事件响应属于外设之间的联合工作，不经过CPU。

### EXTI的20个输入源

| 编号 | 来源 |
|------|------|
| 0~15 | GPIO引脚（经AFIO选择） |
| 16 | PVD电源电压监测（蹭网） |
| 17 | RTC闹钟 / 秒 / 溢出（蹭网） |
| 18 | USB唤醒（蹭网） |
| 19 | 以太网唤醒（蹭网） |

### NVIC通道合并

- EXTI0~4 → 各自独立中断函数
- EXTI5~9 → 合并为 `EXTI9_5_IRQHandler`（需在中断函数内通过标志位区分具体哪个线）
- EXTI10~15 → 合并为 `EXTI15_10_IRQHandler`（同上）

> ST公司为了节省NVIC通道资源做的合并，编程时需注意。

## 九、外部中断的适用场景

### 适合用外部中断的信号特征

> **外部驱动的、很快的、突发信号**

| 特征 | 说明 |
|------|------|
| 外部驱动 | STM32只能被动读取，不知道信号什么时候来 |
| 突发信号 | 可能很久没信号，一来就是一连串脉冲 |
| 很快 | 稍微晚一点处理就会错过波形 |

### 典型应用

| 模块 | 是否适合外部中断 | 原因 |
|------|-----------------|------|
| **旋转编码器** | ✅ 适合 | 旋转时产生快速脉冲，不旋转时无信号 |
| **红外遥控接收** | ✅ 适合 | 接收数据时输出波形，转瞬即逝 |
| **对射式红外传感器** | ✅ 适合 | 遮挡/透光产生下降沿，需要计数 |
| **按键** | ⚠️ 不推荐 | 外部中断不好处理消抖和松手检测，且信号不快 |

### 按键为什么不太适合外部中断？

1. 机械按键有抖动 → 中断会多次触发
2. 中断里不方便做延时消抖（中断应尽量短）
3. 松手检测在中断中不好处理
4. 按键信号不是"转瞬即逝"的，轮询完全来得及

> 替代方案：定时器中断读取按键（后台读取、不阻塞主程序、方便消抖）。

## 十、旋转编码器

### 基本原理

旋转编码器用来测量**位置、速度或旋转方向**。旋转时输出与旋转速度和方向对应的方波信号。

### 编码器类型

| 类型 | 特点 |
|------|------|
| 机械触点式 | 金属触点通断，适合手动调节（如音量旋钮），不适合高速 |
| 霍尔传感器式 | 非接触，磁铁+霍尔元件，适合电机测速 |
| 光栅式 | 非接触，红外对管+光栅盘，适合电机测速 |

### 单路输出 vs 正交输出

#### 单路输出（只能测速度/位置，不能测方向）
```
编码盘转动 → 红外光遮挡/透过 → 方波输出
- 方波个数 = 转过的角度
- 方波频率 = 转速
- 但正转和反转输出波形一样，无法区分方向
```

#### 正交输出（能测速度+方向）
```
        ┌─┐   ┌─┐   ┌─┐
A相  ──┘ └───┘ └───┘ └──   （方波）
          ┌─┐   ┌─┐   ┌─┐
B相  ─────┘ └───┘ └───┘ └── （滞后90° = 正转）

        ┌─┐   ┌─┐   ┌─┐
A相  ──┘ └───┘ └───┘ └──   （方波）
     ┌─┐   ┌─┐   ┌─┐
B相 ─┘ └───┘ └───┘ └───── （超前90° = 反转）
```

- 两路输出相位差**90度**
- 正转时B滞后A 90°
- 反转时B超前A 90°
- 这种相位差90°的波形叫**正交波形**

### 旋转编码器模块电路（机械触点式）

```
         VCC
          │
         [10k上拉电阻]
          │
     内部触点开关 ←→ 编码盘旋转时交替通断
          │
         [限流电阻] → A端口输出（接STM32引脚）
          │
         [滤波电容]
          │
         GND

B端口同理（另一组触点，相位差90°）
C端口 = 按键（按下短路，松手断开，本节未使用）
```

- 上拉电阻：默认输出高电平
- 触点导通 → 拉低到GND → 输出低电平
- 限流电阻：防止引脚电流过大
- 滤波电容：防止信号抖动

### 接线

| 模块引脚 | 连接 |
|----------|------|
| VCC | 接电源 |
| GND | 接地 |
| A相输出 | 接STM32引脚（如PB0） |
| B相输出 | 接STM32引脚（如PB1） |
| C（按键） | 接地（本节不用） |

## 十一、相关手册资源

### 查找NVIC信息
- NVIC是**内核外设** → 在 **Cortex-M3编程手册** 中查找
- 包含：NVIC寄存器说明（使能、清除、挂起、优先级等）

### 查找EXTI/AFIO信息
- EXTI和AFIO是**STM32外设** → 在 **STM32F10x参考手册** 中查找
- 用库函数编程时，寄存器细节由库函数封装，不需要直接操作寄存器

### 常用NVIC寄存器一览

| 寄存器 | 功能 |
|--------|------|
| 使能寄存器 | 开启某个中断通道 |
| 清除使能寄存器 | 关闭某个中断通道 |
| 设置挂起寄存器 | 手动挂起某个中断 |
| 清除挂起寄存器 | 手动清除挂起状态 |
| 活动位寄存器 | 查看某个中断是否正在执行 |
| 优先级寄存器 | 设置每个中断的优先级 |

> 用标准库函数编程时，这些寄存器由库函数封装，直接调用函数即可。

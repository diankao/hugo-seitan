## J-Link V9 烧录器配置

### Keil MDK 配置步骤

1. **Debug 配置**
   - 打开魔术棒 → Debug → 选择 `J-LINK/J-TRACE cortex`
   - 点击Settings → Port 选择 `SW` 模式
   - Max 时钟选择 `10MHz`
   - 等待识别成功

2. **Flash 下载配置**
   - 魔术棒 → Utilities → 勾选 `Use Debug Driver`
   - 点击 Settings 进入 Flash 算法设置
   - Programming Algorithm 会根据目标器件自动设置
   - 选中 `Reset and Run`（编程后自动启动）

3. **注意事项**
   - STM32F103RCT6（256KB Flash）使用 `STM32F10x High-density Flash` 算法
   - 如果没有 Flash 算法，点击 Add 按钮手动添加
   - 256KB 和 512KB 共用同一个算法

## SWD 接口接线

### 必接引脚

| 引脚 | 功能 | 说明 |
|------|------|------|
| **SWDIO** | 数据线 | DIO/TMS 引脚 |
| **SWCLK** | 时钟线 | CLK/TCK 引脚 |
| **VREF** | 电压参考 | 接开发板 3.3V（输入脚） |
| **GND** | 地 | 任意 GND 引脚 |

### 接线示意图

```
J-Link          STM32开发板
-------------------------
VREF   ----->  3.3V
SWDIO  ----->  SWDIO (PA13)
SWCLK  ----->  SWCLK (PA14)
GND    ----->  GND
```

> **注意**：不同批次的 STM32 最小系统板，引脚编号缩写可能不同，以下同一行的标号均表示同一个引脚：

| 引脚 | 常用别名 |
|------|----------|
| 电源正极 | 3.3V / 3V3 / VCC |
| 时钟线 | SWCLK / DCLK / TCK |
| 数据线 | SWDIO / DIO / SWIO / TMS |
| 地 | GND / G |

## 杜邦线颜色规范

| 颜色 | 含义 | 用途 |
|------|------|------|
| **红色** | 电源正极 | 3.3V、5V 电源 |
| **黑色** | 电源负极 | GND 接地 |
| **黄色** | 时钟信号 | SCK、CLK、I2C_SCL |
| **蓝色** | 数据信号 | MOSI、MISO、I2C_SDA |
| **绿色** | 控制信号 | CS、RST、INT |
| **白色** | 通用信号 | 其他功能引脚 |

### 使用建议
1. 严格按照颜色规定接线，避免电源接反
2. 长距离传输时使用屏蔽线减少干扰
3. 高频信号（如 SPI 时钟）尽量缩短线长
4. 电源和地使用较粗的导线（22AWG 以上）
5. 信号线上拉/下拉电阻靠近芯片端放置

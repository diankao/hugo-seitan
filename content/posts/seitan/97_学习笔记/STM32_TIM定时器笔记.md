# STM32 TIM定时器（6-1 定时中断 / 6-2 内外时钟 / 6-3 输出比较）笔记

---

## 一、定时器概述

### 基本功能
定时器可以对输入的时钟进行计数，并在计数值达到设定值时触发中断。

本质：**定时器 = 计数器**。当输入是准确的基准时钟时，计数 = 计时。

### 定时时间计算
```
定时频率 = 72MHz / (PSC + 1) / (ARR + 1)
最大定时 = 72MHz / 65536 / 65536 ≈ 59.65秒
```

### STM32F103C8T6的定时器资源

| 类型 | 编号 | 总线 | 功能 |
|------|------|------|------|
| **高级定时器** | TIM1, TIM8 | APB2 | 通用全部功能 + 重复计数器 + 死区生成 + 互补输出 + 刹车输入 |
| **通用定时器** | TIM2~TIM5 | APB1 | 基本全部功能 + 内外时钟源选择 + 输入捕获 + 输出比较 + 编码器接口 + 主从触发模式 |
| **基本定时器** | TIM6, TIM7 | APB1 | 仅定时中断 + 主模式触发DAC |

> 向下兼容：高级 → 通用 → 基本。课程主要讲通用定时器（TIM2~TIM4）。

## 二、时基单元（定时器核心）

### 三个关键寄存器

| 寄存器 | 位数 | 功能 |
|--------|------|------|
| **PSC（预分频器）** | 16位 | 对72MHz基准时钟分频。值+1 = 分频系数。如PSC=71 → 72分频 → 1MHz |
| **CNT（计数器）** | 16位 | 对分频后的时钟计数，每个上升沿+1。范围0~65535 |
| **ARR（自动重装寄存器）** | 16位 | 计数目标值。CNT计数到ARR时：清零 + 产生更新中断/事件 |

### 计数模式

| 模式 | 说明 | 支持的定时器 |
|------|------|-------------|
| **向上计数** | 0→ARR→清零→中断→循环 | 全部 |
| 向下计数 | ARR→0→重装→中断→循环 | 通用、高级 |
| 中央对齐 | 0→ARR→中断→ARR→0→中断→循环 | 通用、高级 |

> 最常用的是**向上计数模式**。

### 预分频器的工作原理

```
PSC = 0  → 1分频（不分频） → 输出72MHz
PSC = 1  → 2分频           → 输出36MHz
PSC = 71 → 72分频          → 输出1MHz（1μs计数一次）
PSC = 7199 → 7200分频      → 输出10kHz（0.1ms计数一次）
```

> 实际分频系数 = PSC + 1

### 更新中断 vs 更新事件

| 类型 | 去向 | 用途 |
|------|------|------|
| **更新中断（UI）** | → NVIC → CPU执行中断函数 | 软件响应 |
| **更新事件（UE）** | → 触发内部其他电路（DAC等） | 硬件自动化 |

## 三、基本定时器结构

```
内部时钟(72MHz) → PSC预分频器 → CNT计数器 → 与ARR比较
                                              ↓ CNT == ARR
                                         清零CNT + 产生UI/UE
                                              ↓ UI
                                           → NVIC → CPU中断
                                              ↓ UE
                                     → 主模式 → TRGO → 触发DAC
```

### 主模式触发DAC
- 不需要软件参与，硬件自动完成
- 定时器更新事件 → TRGO → 直接触发DAC转换
- 减轻CPU负担，不需要频繁进入中断

## 四、通用定时器结构

在基本定时器基础上增加了：

### 内外时钟源选择

| 时钟源 | 说明 |
|--------|------|
| **内部时钟** | RCC提供的72MHz（默认） |
| ETR外部引脚 | 外部引脚输入方波（可分频、滤波、极性选择） |
| ITR其他定时器 | 其他定时器的输出作为本定时器时钟（级联） |
| TIx捕获通道 | 捕获通道的引脚输入信号 |

> 外部时钟模式1（从模式触发）和外部时钟模式2（ETR直接）对于ETR输入是等效的。

### 外部时钟的用途
- 提供更精确的时钟源
- 把定时器当做**计数器**使用（对外部事件计数）

## 五、定时器定时中断初始化步骤（6步）

| 步骤 | 操作 | 库函数 |
|------|------|--------|
| 1 | 开启时钟 | `RCC_APB1PeriphClockCmd`（TIM2~4在APB1） |
| 2 | 选择时钟源 | `TIM_InternalClockConfig`（选内部时钟，默认可省略） |
| 3 | 配置时基单元 | `TIM_TimeBaseInit`（结构体配置PSC、ARR、计数模式等） |
| 4 | 配置中断输出 | `TIM_ITConfig`（使能更新中断输出到NVIC） |
| 5 | 配置NVIC | `NVIC_Init`（开启定时器中断通道，设置优先级） |
| 6 | 启动定时器 | `TIM_Cmd`（使能计数器，开始运行） |

### 时基单元结构体参数

| 成员 | 说明 | 示例（1秒定时） |
|------|------|-----------------|
| `TIM_ClockDivision` | 滤波器时钟分频（不影响时基功能） | `TIM_CKD_DIV1` |
| `TIM_CounterMode` | 计数模式 | `TIM_CounterMode_Up` |
| `TIM_Period` | ARR值 | 10000 - 1 |
| `TIM_Prescaler` | PSC值 | 7200 - 1 |
| `TIM_RepetitionCounter` | 重复计数器（仅高级定时器） | 0 |

> 72MHz / 7200 / 10000 = 1Hz = 1秒

### 关键库函数

| 函数 | 用途 |
|------|------|
| `TIM_TimeBaseInit` | 时基单元初始化（重要） |
| `TIM_TimeBaseStructInit` | 给结构体赋默认值 |
| `TIM_ITConfig` | 使能/失能中断输出 |
| `TIM_Cmd` | 启动/停止计数器 |
| `TIM_PrescalerConfig` | 运行时单独修改PSC |
| `TIM_SetAutoreload` | 运行时单独修改ARR |
| `TIM_SetCounter` | 手动设置CNT值 |
| `TIM_GetCounter` | 获取当前CNT值 |

## 六、输出比较（Output Compare）

### 基本原理
输出比较电路通过比较 **CNT计数器** 与 **CCR捕获比较寄存器** 的值的关系，来对输出电平进行置1、置0或翻转的操作，从而输出PWM波形。

```
CNT计数器 ──┐
            ├→ 比较器 → 输出模式控制器 → OCxREF → 极性选择 → 输出使能 → CHx引脚
CCR寄存器 ──┘
```

### PWM基础概念

| 参数 | 定义 | 说明 |
|------|------|------|
| **频率** | 1/Ts | PWM周期Ts的倒数，一般几千~几十千Hz |
| **占空比** | Ton/Ts | 高电平时间占周期的比例 |
| **分辨率** | 占空比变化步距 | 如1%或0.1%，步距越小越细腻 |

> PWM的本质：在惯性系统中（LED余晖、电机惯性），通过快速通断来等效模拟量输出。
>
> **LED余晖（视觉暂留）**：人眼有视觉暂留效应，当闪烁频率>50Hz时无法分辨单次亮灭，大脑会将快速闪烁"平滑"为平均亮度。占空比越大 → 亮的时间比例越大 → 人眼感知的等效亮度越高。
>
> **电机惯性（机械惯性）**：电机断电后不会立刻停转，而是缓慢减速。PWM以高频率给电机通电/断电，电机转速就会稳定在一个由占空比决定的中间速度上。占空比越大 → 通电时间比例越大 → 等效转速越高。

### 输出比较的8种模式

输出比较的核心逻辑：CNT计数器不断自增，CCR是我们设定的比较值，两者的大小关系决定了REF输出引脚是高电平还是低电平。

| 模式 | 说明 | 用途 |
|------|------|------|
| 冻结 | CNT=CCR时REF保持原状态不变 | 暂停PWM输出，保持暂停瞬间的电平 |
| 匹配时置有效电平 | CNT=CCR瞬间，REF变高，之后不再变化 | 一次性触发高电平（不常用） |
| 匹配时置无效电平 | CNT=CCR瞬间，REF变低，之后不再变化 | 一次性触发低电平（不常用） |
| 匹配时电平翻转 | 每次CNT=CCR时，REF高低电平翻转一次 | 输出占空比固定50%的方波，频率可调 |
| 强制为无效电平 | 不管CNT和CCR的关系，REF强制输出低 | 暂停PWM并强制输出低电平 |
| 强制为有效电平 | 不管CNT和CCR的关系，REF强制输出高 | 暂停PWM并强制输出高电平 |
| **PWM模式1** | CNT<CCR→REF高, CNT≥CCR→REF低 | **最常用，输出频率和占空比都可调的PWM** |
| **PWM模式2** | CNT<CCR→REF低, CNT≥CCR→REF高 | 与PWM模式1完全相反（输出取反） |

> **"有效电平"和"无效电平"**：在STM32文档中，"有效"一般指高电平，"无效"指低电平。但实际高低由极性配置决定，所以用"有效/无效"表述更严谨。
>
> **只需要重点掌握PWM模式1**，这是99%场景下使用的模式。其他模式了解即可。PWM模式2本质上就是PWM模式1的输出取反，配合极性选择可以实现相同效果。

### PWM模式1的工作过程（向上计数）

```
CNT:  0 → 1 → 2 → ... → CCR → ... → ARR → 0（清零）
REF:  高高 高  高        ↓低    低  低    低  ↓高

          |← CCR个高 →|← (ARR-CCR)个低 →|
          |←——— 一个PWM周期 (ARR+1) ———→|
```

- CNT < CCR → REF = 高电平（有效）
- CNT ≥ CCR → REF = 低电平（无效）
- CNT计到ARR时清零，开始下一周期

### PWM频率和占空比公式

```
PWM频率 = 72MHz / (PSC + 1) / (ARR + 1)
占空比   = CCR / (ARR + 1)       （PWM模式1，向上计数，高极性）
```

### 同一定时器不同通道的特点

- **频率相同**：共用一个CNT计数器
- **占空比各自独立**：由各自的CCR决定
- **相位同步**：CNT更新时所有通道同时跳变

> 一个定时器可以同时输出4路频率相同、占空比不同的PWM。

### 极性选择

| 设置 | 效果 |
|------|------|
| `TIM_OCPolarity_High` | REF信号直接输出（不翻转） |
| `TIM_OCPolarity_Low` | REF信号取反输出 |

> PWM模式1+高极性 = PWM模式2+低极性（最终输出相同）

## 七、定时中断代码流程（6-2）

### 定时器定时中断（1秒自动+1）

```
初始化：RCC → 内部时钟 → 时基单元(PSC=7199, ARR=9999) → 中断输出 → NVIC → TIM_Cmd
中断函数：TIM2_IRQHandler → 判断更新中断标志 → Number++ → 清除标志位
主函数：while(1) { OLED显示Number }
```

### 定时器外部时钟（对射式红外传感器计数）

```
与内部时钟的区别：
- GPIO初始化：PB14上拉输入
- AFIO引脚选择：将PB14连接到TIM2的ETR
- ETR时钟配置：TIM_ETRClockMode2Config（极性、分频、滤波）
- ARR设为9 → 每遮挡10次触发一次中断
```

## 八、重要注意事项

1. **TIM2在APB1总线**：开时钟用`RCC_APB1PeriphClockCmd`，不是APB2
2. **预分频器和计数器都有+1偏差**：PSC和ARR的值都要减1
3. **PSC和ARR取值范围**：0~65535（16位）
4. **中断标志位必须清除**：否则会连续触发中断，主程序卡死
5. **滤波器参数`TIM_ClockDivision`**：控制外部输入信号的滤波器时钟分频，与内部定时功能无关
6. **TIM_OCStructInit**：OC结构体变量必须先赋默认值，否则未赋值成员可能导致高级定时器输出异常
7. **PWM引脚必须配置为复用推挽输出**（`GPIO_Mode_AF_PP`）：因为引脚控制权要交给定时器

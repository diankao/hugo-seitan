# Unix时间戳笔记（12-1）

---

## 一、时间戳简介

### 基本定义
Unix时间戳（Unix Time Stamp）是从**UTC或GMT的1970年1月1日零时零分零秒**开始所经过的秒数（不考虑闰秒）。

### 时间戳 vs 年月日时分秒

| 计时系统 | 特点 | 示例 |
|---------|------|------|
| **年月日时分秒** | 进位制（60秒→1分钟，60分钟→1小时...） | 2023-01-01 12:00:00 |
| **Unix时间戳** | 永不进位，始终用秒表示 | 1672588800 |

> 目前时间戳秒数已达到16亿级别。

### 时间戳的优势

| 优势 | 说明 |
|------|------|
| **简化硬件电路** | 只需一个大秒计数器，无需考虑年月日寄存器、进位、大月小月、平年闰年等复杂逻辑 |
| **时间间隔计算方便** | 两个时刻相减即可得秒数，无需跨月跨年复杂计算 |
| **存储占用小** | 一个大变量即可，无需存储年月日时分秒多个变量 |

### 时间戳的劣势

| 劣势 | 说明 |
|------|------|
| **占用软件资源** | 每次转换需要复杂计算（考虑大月小月、平年闰年等） |

## 二、时间戳的存储格式与溢出风险

### 存储格式
时间戳存储在秒计数器中，为32位或64位整型变量。

### 32位时间戳的溢出（2038年危机）

| 类型 | 范围 | 溢出时间 |
|------|------|----------|
| **32位有符号数** | -2^31 ~ (2^31-1) ≈ ±21亿 | **2038年1月19日** |
| 32位无符号数 | 0 ~ (2^32-1) ≈ 42亿 | 2106年 |
| 64位 | 极大 | 数千年后 |

> 早期Unix系统多用32位有符号数存储时间戳，因此存在2038年溢出风险。现代设备（手机、电脑）已采用64位存储。

### STM32的时间戳
STM32的RTC核心计时部分是**32位可编程计数器**，实际使用**无符号32位**，溢出时间为2106年，无需担心。

## 三、时区处理

### 时区划分
- 地球分为24个时区，每个时区相差1小时
- 穿过英国伦敦的经线为本初子午线，是时间标准基准
- **GMT（格林尼治标准时间）**：即伦敦标准时间

### 时间戳处理时区的方式

所有时区共用一个时间戳秒计数器，通过添加时区偏移得到当地时间。

```
秒计数器: 0（伦敦时间 1970-01-01 00:00:00）
         ↓ +8小时偏移
北京时间: 1970-01-01 08:00:00（东八区）
```

> 时间戳起点（1970-01-01 00:00:00）指的是伦敦时间，北京时间对应为1970-01-01 08:00:00。

## 四、UTC和GMT

### GMT（Greenwich Mean Time）
- 全称：格林尼治标准时间
- 基于地球自转和公转确定
- 以英国伦敦格林尼治天文台为准

### UTC（Coordinated Universal Time）
- 全称：协调世界时
- 基于原子钟确定，比GMT更精确

### 闰秒
由于地球自转速度变化，UTC偶尔需要增加或减少1秒来与GMT保持同步，这就是**闰秒**。

> 时间戳计算时不考虑闰秒。

## 五、时间戳与日期时间的转换

### 转换流程

```
Unix时间戳（秒计数器）
         ↓ 复杂计算（考虑大月小月、平年闰年）
年月日时分秒
```

### 转换难点
计算步骤非常复杂：
1. 先算1年有多少秒 → 得到当前年份
2. 再算1天有多少秒 → 得到当前是第几天
3. 再计算几月几号
4. 最后计算几时几分几秒

需要考虑：
- 大月小月（31天、30天、28/29天）
- 平年闰年（365天、366天）

### C语言time.h库函数
C语言官方已提供现成的转换函数，封装在`time.h`中。

| 函数 | 功能 |
|------|------|
| `localtime()` | 秒计数器 → 本地时间（年月日时分秒） |
| `gmtime()` | 秒计数器 → GMT时间 |
| `time()` | 获取当前时间戳 |
| `mktime()` | 年月日时分秒 → 时间戳 |

> 使用这些函数可以轻松实现时间戳与日期时间的互相转换，无需手动编写复杂算法。

## 七、时间戳应用示例

### 计算时间间隔
```
时间1: 2023-01-01 08:00:00 → 时间戳 1672531200
时间2: 2023-03-01 18:00:00 → 时间戳 1677679200

间隔秒数 = 1677679200 - 1672531200 = 5148000秒
间隔小时 = 5148000 ÷ 3600 = 1430小时
```

### 时区转换
```
伦敦时间戳: 1672588795
        → 转换为伦敦时间: 2023-01-01 15:59:55
        → 加8小时: 2023-01-01 23:59:55（北京时间）
```

## 八、STM32 RTC与时间戳

STM32的RTC（实时时钟）外设核心是一个**32位可编程计数器**，用于存储Unix时间戳。

| 特性 | 说明 |
|------|------|
| 计数器位宽 | 32位无符号数 |
| 溢出时间 | 2106年（远超设备寿命） |
| 数据范围 | 0 ~ 4,294,967,295（约136年） |

> STM32的RTC配合BKP（备份寄存器）和VBAT（备用电池），可在主电源断电后继续计时，并保持时间不丢失。

# FreeRTOS任务调度与优先级

## 题目

FreeRTOS的任务调度机制是什么？优先级如何影响任务执行？

## 答案

### 调度策略

**FreeRTOS使用抢占式调度：**

```c
#include "FreeRTOS.h"
#include "task.h"

void demonstrate_scheduling() {
    printf("FreeRTOS Scheduling Strategy:\n");
    printf("- Preemptive scheduling\n");
    printf("- Time slicing for equal priority\n");
    printf("- Priority-based task selection\n");
}
```

### 优先级继承

**互斥量优先级继承：**

```c
SemaphoreHandle_t mutex = NULL;

void high_priority_task(void *pvParameters) {
    while(1) {
        printf("High priority task waiting for mutex...\n");
        
        if (xSemaphoreTake(mutex, portMAX_DELAY) == pdTRUE) {
            printf("High priority task got mutex\n");
            
            vTaskDelay(100 / portTICK_PERIOD_MS);
            
            xSemaphoreGive(mutex);
        }
        
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
}

void medium_priority_task(void *pvParameters) {
    while(1) {
        printf("Medium priority task running\n");
        vTaskDelay(200 / portTICK_PERIOD_MS);
    }
}

void low_priority_task(void *pvParameters) {
    while(1) {
        printf("Low priority task taking mutex...\n");
        
        if (xSemaphoreTake(mutex, portMAX_DELAY) == pdTRUE) {
            printf("Low priority task got mutex\n");
            
            vTaskDelay(1000 / portTICK_PERIOD_MS);
            
            xSemaphoreGive(mutex);
        }
        
        vTaskDelay(2000 / portTICK_PERIOD_MS);
    }
}

void setup_priority_inheritance() {
    mutex = xSemaphoreCreateMutex();
    
    xTaskCreate(low_priority_task, "Low", 
                128, NULL, 1, NULL);
    xTaskCreate(medium_priority_task, "Medium", 
                128, NULL, 2, NULL);
    xTaskCreate(high_priority_task, "High", 
                128, NULL, 3, NULL);
}
```

### 任务优先级动态调整

```c
void dynamic_priority_task(void *pvParameters) {
    TaskHandle_t my_handle = xTaskGetCurrentTaskHandle();
    UBaseType_t current_priority;
    
    while(1) {
        current_priority = uxTaskPriorityGet(my_handle);
        printf("Current priority: %u\n", current_priority);
        
        if (current_priority < 3) {
            printf("Increasing priority...\n");
            vTaskPrioritySet(my_handle, current_priority + 1);
        }
        
        vTaskDelay(2000 / portTICK_PERIOD_MS);
    }
}

void priority_changer_task(void *pvParameters) {
    TaskHandle_t target_task = (TaskHandle_t)pvParameters;
    
    while(1) {
        printf("Changing target task priority...\n");
        
        UBaseType_t new_priority = uxTaskPriorityGet(target_task);
        vTaskPrioritySet(target_task, 
                       (new_priority == 3) ? 1 : 3);
        
        vTaskDelay(3000 / portTICK_PERIOD_MS);
    }
}
```

### 获取任务信息

```c
void task_info_collector(void *pvParameters) {
    UBaseType_t task_count = uxTaskGetNumberOfTasks();
    TaskStatus_t *task_status_array;
    uint32_t total_run_time;
    
    task_status_array = pvPortMalloc(task_count * sizeof(TaskStatus_t));
    
    while(1) {
        task_count = uxTaskGetSystemState(
            task_status_array,
            task_count,
            &total_run_time
        );
        
        printf("\n=== Task Status ===\n");
        printf("Total tasks: %u\n", task_count);
        printf("Total run time: %lu\n", total_run_time);
        
        for (UBaseType_t i = 0; i < task_count; i++) {
            printf("Task: %s, Priority: %u, State: %d\n",
                   task_status_array[i].pcTaskName,
                   task_status_array[i].uxCurrentPriority,
                   task_status_array[i].eCurrentState);
        }
        
        vTaskDelay(5000 / portTICK_PERIOD_MS);
    }
}
```

### 总结

**调度机制特点：**
- 抢占式调度，高优先级任务优先执行
- 相同优先级任务时间片轮转
- 支持任务挂起、恢复、优先级调整
- 提供优先级继承避免优先级反转

**优先级使用要点：**
- 高数字表示高优先级
- 合理设置避免饥饿现象
- 关键任务设置高优先级
- 注意优先级继承问题

**最佳实践：**
- 监控堆栈使用情况
- 避免过长时间占用CPU
- 合理使用临界区
- 动态调整任务优先级
- 定期检查任务状态

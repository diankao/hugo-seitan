# FreeRTOS任务创建与删除

## 题目

如何在FreeRTOS中创建和删除任务？任务创建的参数有哪些含义？

## 答案

### 任务创建

**基本语法：**

```c
#include "FreeRTOS.h"
#include "task.h"

TaskHandle_t task_handle = NULL;

void task_function(void *pvParameters) {
    while(1) {
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
    
    vTaskDelete(NULL);
}

void create_task_example() {
    BaseType_t result = xTaskCreate(
        task_function,           // 任务函数指针
        "Task1",               // 任务名称
        configMINIMAL_STACK_SIZE, // 堆栈大小
        NULL,                   // 任务参数
        1,                      // 优先级
        &task_handle           // 任务句柄
    );
    
    if (result == pdPASS) {
        printf("Task created successfully\n");
    } else {
        printf("Task creation failed\n");
    }
}
```

**参数详解：**

| 参数 | 类型 | 说明 |
|------|------|------|
| pxTaskCode | TaskFunction_t | 任务函数指针 |
| pcName | const char* | 任务名称（调试用） |
| usStackDepth | uint16_t | 堆栈大小（字） |
| pvParameters | void* | 传递给任务的参数 |
| uxPriority | UBaseType_t | 任务优先级 |
| pxCreatedTask | TaskHandle_t* | 返回的任务句柄 |

### 任务删除

**删除自身任务：**

```c
void self_deleting_task(void *pvParameters) {
    for (int i = 0; i < 5; i++) {
        printf("Task running, iteration %d\n", i);
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
    
    printf("Task deleting itself\n");
    vTaskDelete(NULL);
}
```

**删除其他任务：**

```c
TaskHandle_t task_to_delete = NULL;

void create_and_delete_task() {
    xTaskCreate(task_function, "TaskToDelete", 
                128, NULL, 1, &task_to_delete);
    
    vTaskDelay(5000 / portTICK_PERIOD_MS);
    
    if (task_to_delete != NULL) {
        vTaskDelete(task_to_delete);
        task_to_delete = NULL;
        printf("Task deleted\n");
    }
}
```

### 任务优先级

**优先级设置：**

```c
#define HIGH_PRIORITY    3
#define MEDIUM_PRIORITY 2
#define LOW_PRIORITY     1

void high_priority_task(void *pvParameters) {
    while(1) {
        printf("High priority task\n");
        vTaskDelay(100 / portTICK_PERIOD_MS);
    }
}

void medium_priority_task(void *pvParameters) {
    while(1) {
        printf("Medium priority task\n");
        vTaskDelay(200 / portTICK_PERIOD_MS);
    }
}

void low_priority_task(void *pvParameters) {
    while(1) {
        printf("Low priority task\n");
        vTaskDelay(500 / portTICK_PERIOD_MS);
    }
}

void create_priority_tasks() {
    xTaskCreate(low_priority_task, "Low", 128, NULL, 
                LOW_PRIORITY, NULL);
    xTaskCreate(medium_priority_task, "Medium", 128, NULL, 
                MEDIUM_PRIORITY, NULL);
    xTaskCreate(high_priority_task, "High", 128, NULL, 
                HIGH_PRIORITY, NULL);
}
```

### 任务堆栈

**堆栈大小计算：**

```c
void calculate_stack_size() {
    uint32_t local_vars[10];
    uint32_t function_call_depth = 5;
    uint32_t interrupt_stack = 512;
    
    uint32_t required_stack = 
        sizeof(local_vars) + 
        (function_call_depth * 32) +
        interrupt_stack;
    
    printf("Required stack size: %lu bytes\n", required_stack);
    
    xTaskCreate(task_function, "Task", 
                required_stack / sizeof(StackType_t), 
                NULL, 1, NULL);
}
```

### 任务参数传递

**传递整数参数：**

```c
void task_with_int_param(void *pvParameters) {
    int param = (int)pvParameters;
    printf("Received parameter: %d\n", param);
    
    while(1) {
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
}

void create_task_with_param() {
    int task_param = 42;
    xTaskCreate(task_with_int_param, "ParamTask", 
                128, (void*)task_param, 1, NULL);
}
```

**传递结构体参数：**

```c
typedef struct {
    int id;
    char name[20];
    float value;
} TaskConfig;

void task_with_struct_param(void *pvParameters) {
    TaskConfig *config = (TaskConfig*)pvParameters;
    printf("Task ID: %d, Name: %s, Value: %.2f\n",
           config->id, config->name, config->value);

        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
}

void create_task_with_struct() {
    TaskConfig config = {
        .id = 1,
        .name = "MyTask",
        .value = 3.14f
    };
    
    xTaskCreate(task_with_struct_param, "StructTask", 
                256, &config, 1, NULL);
}
```

### 任务状态

**任务状态查询：**

```c
void check_task_state() {
    TaskHandle_t task_handle = NULL;
    xTaskCreate(task_function, "StateTask", 
                128, NULL, 1, &task_handle);
    
    eTaskState state = eTaskGetState(task_handle);
    
    switch(state) {
        case eRunning:
            printf("Task is running\n");
            break;
        case eReady:
            printf("Task is ready\n");
            break;
        case eBlocked:
            printf("Task is blocked\n");
            break;
        case eSuspended:
            printf("Task is suspended\n");
            break;
        case eDeleted:
            printf("Task is deleted\n");
            break;
        default:
            printf("Unknown state\n");
    }
}
```

### 任务挂起与恢复

```c
TaskHandle_t suspendable_task = NULL;

void suspendable_task_function(void *pvParameters) {
    while(1) {
        printf("Task running\n");
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
}

void suspend_resume_example() {
    xTaskCreate(suspendable_task_function, "Suspendable", 
                128, NULL, 1, &suspendable_task);
    
    vTaskDelay(3000 / portTICK_PERIOD_MS);
    
    vTaskSuspend(suspendable_task);
    printf("Task suspended\n");
    
    vTaskDelay(3000 / portTICK_PERIOD_MS);
    
    vTaskResume(suspendable_task);
    printf("Task resumed\n");
}
```

### 总结

**任务创建要点：**
- 合理设置堆栈大小
- 根据重要程度设置优先级
- 正确传递任务参数
- 保存任务句柄以便管理

**任务删除要点：**
- 删除自身使用NULL
- 删除其他任务使用句柄
- 删除后清理句柄
- 避免删除正在使用资源的任务

**最佳实践：**
- 使用有意义的任务名称
- 为关键任务设置合适优先级
- 监控堆栈使用情况
- 合理设计任务通信机制

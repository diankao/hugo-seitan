# HDR视频实现与实时合成难点

## 题目

HDR 视频如何实现？实时合成的难点在哪里？

## 考察点

HDR技术、实时处理能力

## 回答要点

### 1. HDR 概念

**HDR（High Dynamic Range）**：
- 高动态范围成像
- 捕捉更亮和更暗的细节
- 提升画面表现力

**动态范围**：
- 人眼：约 20 档光圈（10⁶:1）
- 普通 Sensor：约 10 档（1000:1）
- HDR Sensor：约 15 档（32000:1）

### 2. HDR 实现方式

#### 多曝光合成（Multi-Exposure）
**原理**：
- 连续拍摄不同曝光的多帧
- 合并成一张 HDR 图像
- 需要 Scene 静止或快速切换

**流程**：
```
帧序列：低曝光 → 正常曝光 → 高曝光 → 低曝光 → ...

合成步骤：
1. 对齐多帧
2. 估计辐射度
3. 色调映射
4. 输出 HDR 图像
```

**优点**：
- 效果好
- 动态范围最大

**缺点**：
- 需要快速切换曝光
- 对齐精度要求高
- 有运动鬼影

#### 单帧 HDR（Sensor 级 HDR）
**原理**：
- Sensor 内部同时采集不同曝光
- 使用像素级 HDR
- 一次拍摄即可

**实现方式**：
- **对数像素 HDR**：不同像素不同曝光
- **行交错 HDR**：不同行不同曝光
- **子像素 HDR**：单个像素多次采样

**优点**：
- 无运动鬼影
- 一次拍摄完成
- 适合视频

**缺点**：
- 动态范围有限
- 传感器成本高

#### 拉伸处理（Tone Mapping）
**原理**：
- 提升低曝光区域亮度
- 压缩高曝光区域
- 增强对比度

**常用算法**：
- **全局 Tone Mapping**：简单的 gamma 曲线
- **局部 Tone Mapping**：自适应增强
- **Reinhard 算法**：感知保持
- **Bilateral Filter**：边缘保持

### 3. HDR 视频实现

#### 帧级 HDR
```cpp
// 多曝光合成
void generate_hdr_frame(frame_t* frames, int frame_count, hdr_frame_t* hdr) {
    // 1. 对齐多帧
    for (int i = 0; i < frame_count; i++) {
        align_frame(&frames[i], &frames[0]);
    }

    // 2. 估计辐射度
    float radiance[height][width];
    for (int y = 0; y < height; y++) {
        for (int x = 0; x < width; x++) {
            radiance[y][x] = estimate_radiance(frames, x, y);
        }
    }

    // 3. 色调映射
    tone_mapping(radiance, hdr);
}
```

#### 曝光切换策略
```c
// 曝光序列
typedef enum {
    EXPOSURE_LOW,
    EXPOSURE_NORMAL,
    EXPOSURE_HIGH
} exposure_level_t;

// 循环切换
void switch_exposure() {
    static exposure_level_t current = EXPOSURE_NORMAL;
    static int frame_count = 0;

    if (++frame_count >= 3) {  // 每 3 帧切换一次
        frame_count = 0;
        current = (current + 1) % 3;
    }

    set_sensor_exposure(current);
}
```

### 4. 实时合成难点

#### 对齐精度
**问题**：
- 曝光切换时图像位移
- 手持拍摄有运动
- 对齐误差导致鬼影

**解决**：
- 高精度运动估计
- 光流法对齐
- 特征点匹配
- 使用 IMU 辅助

```cpp
// 运动估计
void estimate_motion(frame_t* prev, frame_t* curr, motion_t* motion) {
    // 光流法
    optical_flow(prev, curr, &flow);

    // 转换为变换矩阵
    flow_to_transform(&flow, motion);
}

// 对齐帧
void align_frame(frame_t* frame, motion_t* motion) {
    warp_frame(frame, motion);
}
```

#### 曝光切换无缝性
**问题**：
- 曝光参数突变
- 亮度跳变
- 用户感知明显

**解决**：
- 渐进式切换曝光
- 帧间混合过渡
- 预测下一帧曝光

```cpp
// 渐进切换
void gradual_exposure_change(int current_exp, int target_exp, int steps) {
    int step = (target_exp - current_exp) / steps;

    for (int i = 0; i < steps; i++) {
        current_exp += step;
        set_sensor_exposure(current_exp);
        wait_frame();
    }
}
```

#### 噪点控制
**问题**：
- 高曝光帧暗部噪点多
- 低曝光帧亮部噪点多
- 合成后噪点放大

**解决**：
- 多帧降噪
- 自适应降噪强度
- 保留边缘信息

```cpp
// 降噪
void denoise_frame(frame_t* frame) {
    // 1. 分块处理
    for (int block_y = 0; block_y < height; block_y += 8) {
        for (int block_x = 0; block_x < width; block_x += 8) {
            // 2. 计算局部噪声
            float noise_level = estimate_noise_level(frame, block_x, block_y);

            // 3. 自适应降噪
            adaptive_denoise(frame, block_x, block_y, noise_level);
        }
    }
}
```

#### 色彩一致性
**问题**：
- 不同曝光色彩偏差
- 自动白平衡差异
- 合成后色彩不统一

**解决**：
- 色彩校正矩阵
- 统一白平衡
- 全局色彩匹配

```cpp
// 色彩校正
typedef struct {
    float r[3];
    float g[3];
    float b[3];
} ccm_t;  // Color Correction Matrix

// 应用 CCM
void apply_ccm(frame_t* frame, ccm_t* ccm) {
    for (int y = 0; y < height; y++) {
        for (int x = 0; x < width; x++) {
            pixel_t* p = &frame->data[y][x];

            float r = p->r * ccm->r[0] + p->g * ccm->r[1] + p->b * ccm->r[2];
            float g = p->r * ccm->g[0] + p->g * ccm->g[1] + p->b * ccm->g[2];
            float b = p->r * ccm->b[0] + p->g * ccm->b[1] + p->b * ccm->b[2];

            p->r = CLAMP(r, 0, 255);
            p->g = CLAMP(g, 0, 255);
            p->b = CLAMP(b, 0, 255);
        }
    }
}
```

#### 计算量
**问题**：
- 实时处理计算量大
- 帧率要求高
- CPU/GPU 负担重

**解决**：
- 硬件加速
- 降低分辨率计算
- 多线程并行
- 优化算法复杂度

```cpp
// 多线程处理
void* process_thread(void* arg) {
    thread_data_t* data = (thread_data_t*)arg;

    for (int i = data->start; i < data->end; i++) {
        process_line(data->frame, i);
    }

    return NULL;
}

// 创建多个线程
void parallel_process(frame_t* frame) {
    pthread_t threads[4];
    thread_data_t data[4];

    int lines_per_thread = frame->height / 4;

    for (int i = 0; i < 4; i++) {
        data[i].frame = frame;
        data[i].start = i * lines_per_thread;
        data[i].end = (i + 1) * lines_per_thread;

        pthread_create(&threads[i], NULL, process_thread, &data[i]);
    }

    for (int i = 0; i < 4; i++) {
        pthread_join(threads[i], NULL);
    }
}
```

### 5. 性能优化

#### 算法优化
- 使用查找表加速
- SIMD 指令集优化
- 减少分支预测失败

#### 硬件加速
- GPU 并行计算
- DSP 专用算法
- NPU 智能降噪

#### 分辨率处理
- 低分辨率计算对齐
- 高分辨率应用变换
- 金字塔处理

### 6. 质量评估

**客观指标**：
- 动态范围（Dynamic Range）
- 信噪比（SNR）
- 色调映射质量

**主观评价**：
- 过渡是否自然
- 噪点是否明显
- 细节是否保留

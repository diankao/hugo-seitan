# 4K/8K视频实时编码实现与性能优化

## 题目

如何实现 4K / 8K 视频实时编码？瓶颈在哪里？如何优化？

## 考察点

视频编码技术、性能优化方法

## 回答要点

### 1. 数据量计算

**4K 视频（3840x2160 @ 30fps）**：
- 原始数据：3840 × 2160 × 30 × 2（YUV420）≈ 500 MB/s
- YUV 格式：每像素 1.5 字节
- 带宽要求：约 4 Gbps

**8K 视频（7680x4320 @ 30fps）**：
- 原始数据：7680 × 4320 × 30 × 2 ≈ 2 GB/s
- 带宽要求：约 16 Gbps

### 2. 性能瓶颈分析

#### 计算瓶颈
- 编码算法复杂度高：H.264/H.265
- 帧内预测：计算密集
- 帧间预测：运动估计、运动补偿
- 环路滤波：去块效应、去噪

#### 内存带宽瓶颈
- 大量数据拷贝
- 内存访问不连续
- 缓存命中率低

#### 缓存一致性瓶颈
- 多核共享缓存
- 缓存一致性开销
- False Sharing

#### 功耗限制
- 高分辨率编码功耗大
- 移动设备散热受限
- 需要降频保护

### 3. 硬件加速方案

#### 专用编码器芯片
- 使用硬件编码器（VCE、NVENC、Media SDK）
- 支持的格式：H.264/H.265/VP9/AV1
- 优势：功耗低、性能高

#### 多核并行
- 利用多核 CPU
- 帧级并行
- Slice 级并行
- Tile 级并行（H.265）

#### 异构计算
- ARM：控制逻辑、任务调度
- DSP：复杂算法计算
- GPU：并行处理
- NPU：AI 增强

### 4. 软件优化方案

#### Zero-copy 设计
```cpp
// 避免内存拷贝
void encode_frame(uint8_t* src) {
    // 直接使用源地址，不拷贝
    encoder->input_buffer = src;
    encoder->encode();
}
```

#### DMA 传输
- 使用 DMA 代替 CPU 搬运
- 减少 CPU 负担
- 提高传输效率

#### 多线程模型
```cpp
// 生产者-消费者模型
std::queue<frame_t> frame_queue;
std::mutex mutex;
std::condition_variable cond;

// 采集线程
void capture_thread() {
    while (running) {
        auto frame = sensor->capture();
        {
            std::lock_guard<std::mutex> lock(mutex);
            frame_queue.push(frame);
        }
        cond.notify_one();
    }
}

// 编码线程
void encode_thread() {
    while (running) {
        std::unique_lock<std::mutex> lock(mutex);
        cond.wait(lock, []{ return !frame_queue.empty(); });
        auto frame = frame_queue.front();
        frame_queue.pop();
        lock.unlock();
        encoder->encode(frame);
    }
}
```

#### 环形缓冲区
- 预分配内存池
- 避免频繁分配释放
- 提高缓存命中率

### 5. 编码参数优化

#### GOP 结构优化
- 合理设置 I 帧间隔
- 减少 I 帧数量
- 提高编码效率

#### 码率控制
- CBR（恒定码率）：带宽稳定
- VBR（可变码率）：质量更好
- 根据场景动态调整

#### 分辨率/帧率调整
- 4K 30fps vs 4K 60fps
- 根据性能动态降级
- 用户体验优先

### 6. 内存优化

#### 内存对齐
```cpp
// 对齐分配
void* aligned_alloc(size_t alignment, size_t size);
```

#### 缓存优化
- 提高缓存命中率
- 避免缓存失效
- 优化内存访问模式

#### 流水线设计
- 采集 → 处理 → 编码 → 存储
- 各阶段并行
- 减少等待时间

### 7. 实时性保障

#### 帧率统计
- 统计每帧编码时间
- 超时预警
- 自动降级策略

#### 优先级调度
- 编码线程高优先级
- 其他任务低优先级
- 避免被抢占

#### QoS（Quality of Service）
- 设置 CPU 核心亲和性
- 限制其他任务占用
- 保证编码任务资源

### 8. 监控与调优

#### 性能监控
- CPU 使用率
- 内存带宽
- 编码帧率
- 丢帧率

#### 工具
- perf：性能分析
- strace：系统调用追踪
- top/htop：资源监控
- 自定义统计：帧耗时统计

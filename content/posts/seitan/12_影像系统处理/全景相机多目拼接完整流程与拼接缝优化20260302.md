# 全景相机多目拼接完整流程与拼接缝优化

## 题目

全景相机多目拼接的完整流程是什么？拼接缝如何优化？

## 考察点

全景拼接算法、图像处理技术

## 回答要点

### 1. 完整拼接流程

#### 第一步：相机标定

**内参标定**：
- 焦距（focal length）
- 主点（principal point）
- 畸变系数（distortion）

**外参标定**：
- 旋转矩阵（R）
- 平移向量（t）
- 俯仰角、偏航角、翻滚角

**标定方法**：
- 张正友标定法
- 棋盘格标定板
- 使用 OpenCV 的 calibrateCamera()

```cpp
// OpenCV 标定示例
vector<vector<Point3f>> objectPoints;
vector<vector<Point2f>> imagePoints;
Mat cameraMatrix, distCoeffs, rvecs, tvecs;

calibrateCamera(objectPoints, imagePoints, imageSize,
               cameraMatrix, distCoeffs, rvecs, tvecs);
```

#### 第二步：图像配准

**特征点检测**：
- SIFT（Scale-Invariant Feature Transform）
- SURF（Speeded-Up Robust Features）
- ORB（Oriented FAST and Rotated BRIEF）

**特征点匹配**：
- 暴力匹配（Brute Force）
- FLANN（Fast Library for Approximate Nearest Neighbors）
- RANSAC 剔除误匹配

**单应性矩阵计算**：
```cpp
Mat H = findHomography(srcPoints, dstPoints, RANSAC);
```

#### 第三步：投影变换

**投影模型选择**：
- 立方体投影
- 等距柱状投影（Equirectangular）
- 球面投影

**投影变换**：
```cpp
// 将图像投影到球面
```

#### 第四步：融合处理

**多频段融合（Multi-band Blending）**：
- 使用拉普拉斯金字塔
- 在不同频段进行加权融合
- 保留细节，平滑过渡

**拉普拉斯金字塔构建**：
```cpp
// 构建高斯金字塔
vector<Mat> gaussPyramid;
buildGaussianPyramid(img, gaussPyramid, levels);

// 构建拉普拉斯金字塔
vector<Mat> lapPyramid;
for (int i = 0; i < levels - 1; i++) {
    Mat expanded;
    pyrUp(gaussPyramid[i + 1], expanded);
    lapPyramid.push_back(gaussPyramid[i] - expanded);
}
```

#### 第五步：无缝拼接

**加权融合**：
- 基于距离的权重
- 距离图像中心越远权重越小
- 过渡区域平滑权重

```cpp
// 计算权重
Mat weight = Mat::zeros(img.size(), CV_32F);
for (int y = 0; y < img.rows; y++) {
    for (int x = 0; x < img.cols; x++) {
        float d = distanceToCenter(x, y);
        weight.at<float>(y, x) = exp(-d * d / sigma);
    }
}
```

### 2. 拼接缝优化

#### 多频段融合

**原理**：
- 低频段：大范围融合
- 高频段：保留细节
- 逐层融合重建

**优势**：
- 保留图像细节
- 平滑过渡
- 减少鬼影

#### 泊松融合（Poisson Blending）

**原理**：
- 求解偏微分方程
- 保持梯度一致性
- 无缝融合边界

**实现步骤**：
1. 定义融合区域
2. 构建拉普拉斯方程
3. 使用共轭梯度法求解
4. 得到融合结果

```cpp
// OpenCV 泊松融合
Mat result;
seamlessClone(src, dst, mask, p, result, NORMAL_CLONE);
```

#### 颜色校正

**问题**：
- 不同相机曝光不一致
- 白平衡差异
- 色彩不匹配

**解决方法**：
- 全局直方图匹配
- 局部色彩调整
- 增益/偏移校正

#### 曝光补偿

**自动曝光融合**：
- 动态调整曝光
- 多曝光合成
- 保留高光和阴影

### 3. 性能优化

#### 实时性优化
- GPU 加速：使用 CUDA
- 多线程并行处理
- 分辨率缩放：先在低分辨率计算

#### 内存优化
- 图像分块处理
- 流式处理
- 复用缓冲区

#### 算法优化
- 使用 ORB 替代 SIFT（更快）
- 限制特征点数量
- 使用查找表加速投影

### 4. 质量评估

**客观指标**：
- PSNR（峰值信噪比）
- SSIM（结构相似性）
- 重投影误差

**主观评价**：
- 拼接缝可见度
- 几何畸变程度
- 整体观感
